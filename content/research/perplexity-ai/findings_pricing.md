# Perplexity.ai Pricing Research Findings

## Research Overview

This research provides a comprehensive analysis of Perplexity.ai pricing models based on available information from Wikipedia and other sources. Note: Direct access to official pricing pages was limited due to bot detection challenges on the platform.

## Free Tier Limitations

**Current Free Tier Features:**
- Basic search engine functionality available without charge or registration
- Freemium model allows access to core features
- Access to standard AI search capabilities
- Can use Sonar search engine (based on Meta's Llama 3.3)

**Free Tier Limitations:**
- Limited access to advanced language models
- No access to proprietary models like Sonar and R1 1776
- Restricted API access
- No internal document search capabilities
- Limited features compared to paid tiers

## Pro and Pro Plus Pricing

**Perplexity Pro Subscription:**
- **Basic Pro Tier:** Offers enhanced features including:
  - Access to advanced language models (GPT-5.4, Claude 4.6, Gemini 3.1 Pro)
  - Stronger security and data protection
  - Internal document search capabilities (search uploaded documents alongside web content)
  - API access for programmatic integration
  - Ability to select between different backend models
  - Document upload and indexing capabilities

**Pro Plus Features:**
- Enhanced model selection (includes more advanced proprietary models)
- Higher usage limits
- Advanced search capabilities
- Access to newer model features as they're released
- Early access to experimental features

**Subscription Model Transition (2026):**
- In February 2026, Perplexity transitioned to a subscription-first model
- Discontinued AI-integrated advertising strategy
- Focus on preserving user trust in the "answer engine"
- Prioritizing objective results over ad revenue

## Enterprise and Team Pricing

**Enterprise Features:**
- Custom pricing models for organizational needs
- Team management capabilities
- Enhanced security and compliance features
- Advanced API access and integration capabilities
- Internal knowledge search with file indexing
- Volume discounts available for large teams

**Enterprise Pro Features:**
- Upload and index up to 500 files
- Simultaneous search across web content and internal documents
- Support for multiple file formats (Excel, Word, PDF, etc.)
- Advanced administrative controls
- Priority support

**Microsoft Azure Integration:**
- January 2026: Three-year, $750 million commitment with Microsoft Azure
- Secures GPU capacity for advanced "Deep Research" features
- Supports "Model Council" feature for comparing multiple LLM outputs

## Cost Breakdowns and Comparisons

**Competitive Context:**
- As of early 2026, Perplexity reached $21.21 billion valuation
- Annual Recurring Revenue (ARR) grew from $80 million (late 2024) to ~$200 million (February 2026)
- Processing ~780 million queries monthly (May 2025) with 20%+ month-over-month growth
- ~30 million queries daily

**Free Pro Access Programs:**
- Free year of Pro access offered to:
  - Students
  - U.S. Military Veterans  
  - Government employees

## Model Council Feature

**February 2026 Introduction:**
- Allows users to compare outputs from multiple large language models simultaneously
- Includes models like GPT-5.2 and Claude 4.6
- Provides comparative analysis capabilities
- Enhances transparency and model selection options
