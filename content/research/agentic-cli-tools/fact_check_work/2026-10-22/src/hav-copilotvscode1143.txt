 Agents Copilot harness as the default The Copilot harness is now the default for new sessions in VS Code. It's our latest harness, built on the Copilot SDK, a shared foundation that helps align behavior, capabilities, and improvements across Copilot products. When you start a new session, Copilot in the harness picker indicates that the session uses the Copilot harness: In VS Code, you can keep Copilot harness sessions running in the background and access them from both the VS Code editor window and the Agents window. These sessions run through the Agent Host Setting: setting(sessions.chat.compareAgents.enabled) (Agents window only) Compare how different models and harnesses approach the same coding task. Run attempts in parallel, review their results, and combine ideas into one solution. In this release, history is restored in small slices instead of one long blocking task, so the window stays responsive.
