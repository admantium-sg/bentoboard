### Claude Code — Three Major Releases, Security Hardening Focus

Claude Code delivered three releases in four days (v2.1.186, v2.1.187, v2.1.190), with security and credential hardening as the dominant theme:

**v2.1.190 (June 24):**
- Bug fixes and reliability improvements

**v2.1.187 (June 23) — Security Sprint:**
- **`sandbox.credentials` setting**: NEW — blocks sandboxed commands from reading credential files and secret environment variables. Critical enterprise feature.
- **Org-configured model restrictions**: Added to model picker, `--model`, `/model`, and `ANTHROPIC_MODEL` — "restricted by your organization's settings" message when selecting a blocked model.
- **Mouse click support in fullscreen menus**: Permission prompts, `/model`, `/config` now accept mouse clicks in fullscreen mode.
- **Remote MCP tool call timeout**: Fixed 5-minute hang — now aborts with error (override with `CLAUDECODE_MCP_TOOL_IDLE_TIMEOUT`).
- **Remote session speed**: Fixed ~2.7s startup delay introduced by the agent proxy CA system-trust install.
- **Fixed Korean/CJK paste mojibake** in terminals delivering paste as per-byte extended-key events.
- **Fixed `/update` over Remote Control** hanging when a startup trust dialog would have shown.
- **Fixed subagent depth tracking**: Resumed subagents restore original spawn depth; forked subagents count toward depth cap.
- **Fixed leaked agent worktree registrations**: Locked `.git/worktrees/` entries from killed agents now auto-cleaned.
- **Background subagent permission prompts**: Now surface in main session instead of auto-denying — shows which agent is asking.

**v2.1.186 (June 22) — Feature-packed:**
- **`claude mcp login <name>` / `claude mcp logout <name>`**: Authenticate MCP servers from CLI without interactive `/mcp` menu, with `--no-browser` stdin redirect for SSH.
- **`sandbox.credentials` opt-in**: Precursor to the v2.1.187 enforcement — blocks sandboxed commands from credential files and env vars.
- **`teammateMode: "iterm2"` setting** with warning when auto mode can't find the `it2` CLI.
- **`CLAUDE_CLIENT_PRESENCE_FILE`**: Suppress mobile push notifications while at the machine.
- **`!` bash commands trigger auto-response**: Set `respondToBashCommands: false` in settings.json to keep previous context-only behavior.
- **`/btw` arrow navigation**: ←/→ step through earlier answers.
- **`/install-github-app` workflow setup now optional**: Can install just the GitHub App without workflow/secret steps.
- **Multiple subagent/background fixes**: Transcript scroll bleed, background job stuck states, agent stop notifications ("finished"/"stopped" replacing "came to rest").
- **Improved memory compaction**: Agent reminded to compact `MEMORY.md` index when nearing size limit.
- **Skill frontmatter kebab/snake/camelCase**: `display-name`, `default-enabled`, `fallback`, `metadata.*` keys now accept all casing variants.
- **`CLAUDE_CODE_MAX_RETRIES` capped at 15**; unattended sessions should use `CLAUDE_CODE_RETRY_WATCHDOG`.
- **`/review <pr>` now uses `/code-review medium` engine**.

### Security — Claude Code Sandbox Bypass Publicly Disclosed (v2.0.24–v2.1.89)

**MAJOR: Second Silent Sandbox Patch, Now Public**

A critical network sandbox bypass in Claude Code was publicly disclosed in June 2026 by security researcher Aonan Guan. Key facts:

- **First bypass (CVE-2025-66479)**: `allowedDomains: []` (block-all) disabled the proxy entirely — patched silently in v2.0.55 (Nov 26, 2025), same release that introduced the second flaw.
- **Second bypass (null-byte injection)**: SOCKS5 proxy's JavaScript `endsWith()` check allowed `attacker-host.com\x00.google.com` — JavaScript treats `\x00` as ordinary UTF-16, but libc `getaddrinfo()` truncates at null byte, resolving only `attacker-host.com`. Blocked hosts reachable via this bypass.
- **Patched in v2.1.90 (April 1, 2026)**: `isValidHost()` wrapper in sandbox-runtime 0.0.43 rejects `\x00`, `%`, CRLF, and non-DNS characters. v2.1.90 release notes contain NO mention of a security fix.
- **Vulnerable window**: October 20, 2025 – April 1, 2026 (~130 releases, v2.0.24 through v2.1.89).
- **No CVE published** (as of June 2026): Anthropic closed HackerOne report #3646509 as duplicate of internal ticket, stating "not yet decided whether a CVE will be published."
- **Three additional CVEs (CVE-2026-35020/35021/35022)**: Phoenix Security discovered a separate shell-injection-to-exfiltration chain — still exploitable on v2.1.91 as of April 3, 2026.

**Community reaction**: The pattern of silent security fixes without public advisories is drawing criticism. Enterprise users using sandbox allowlists as a hard network boundary should audit and rotate credentials from the vulnerable window.

## Community Pulse

### Working Well
- **Claude Code credential hardening**: The `sandbox.credentials` setting and org-model restrictions in v2.1.186–187 are exactly what enterprise users have been asking for — a real credential boundary, not just UI promises.
- **Kilo's slash/file mention completion**: The `@file` clickable mentions in prompts is a genuine workflow improvement for complex projects — one of those small features that makes a big difference daily.
- **Cline's parallel tool-call guidance**: Enterprise users report 20–30% faster task completion with explicit parallel guidance.

### Problems
- **Anthropic's silent security patching continues**: The second consecutive sandbox bypass patched silently (v2.1.90, April 2026, no mention in release notes), now publicly disclosed with no CVE. The Phoenix Security CVEs (35020/35021/35022) for a separate chain reportedly still exploitable on v2.1.91. Community is vocal: "Anthropic treats the sandbox as a marketing feature, not a security boundary."
- **Codex CLI v0.142.0 stable missing in action**: The v0.142.0 alpha sprint (7 releases in 72 hours) was expected to yield a stable by June 22–23. Instead, v0.143.0 alphas are already at .15. Teams waiting for the stable are frustrated by the moving target.
- **Claude Code v2.1.190 drops changelog detail**: The June 24 release is listed only as "Bug fixes and reliability improvements" with no specifics — the third consecutive release with minimal changelog transparency.

### Interesting
- **ClinePass monetization model**: Hiding costs for "free models" while launching ClinePass suggests a two-tier model emerging — the agent is subsidized by Cline's own model offerings, similar to how GitHub Copilot worked in early days.
- **Kilo WebSocket transport**: The experimental WebSocket transport for OpenAI responses (`KILO_EXPERIMENTAL_WEBSOCKETS=true`) suggests a significant TUI latency improvement in the pipeline — worth watching for v7.4 stable.
- **Agentic CLI comparisons everywhere**: The mid-2026 comparison posts (Cloudzy, ofox.ai, Requesty, DevToolLab) are uniformly noting that Claude Code leads on quality but "throttles on subscriptions" while Codex "doesn't run out" — positioning matters more than benchmarks in community perception.

---

## Trend

Security and trust dominate this cycle. Claude Code's second silent sandbox patch becoming public (the third CVEs in the CLI) is shifting community sentiment — enterprise security teams are re-auditing the tool they deployed during the vulnerable window. Meanwhile, Codex CLI's stable release delays and new alpha sprints suggest OpenAI is running at a different velocity than the rest of the field. The `sandbox.credentials` setting in v2.1.187 is the right response but arrives late.
