## Tool Releases & Features

### Claude Code — v2.1.247 (August 26, 2026)
- **SendFeedback tool:** Claude can draft feedback reports when issues occur, submitted via `/feedback`
- **`/claude-api cost-optimize`:** Profiles existing project API spend and works through cost levers (caching, token hygiene, batch, effort, model choice) one measured change at a time
- **`/claude-api` skill expanded:** Full Admin API coverage — organization members, invites, workspaces, API keys, rate limit reports, workload identity federation, CMEK
- Cross-session peer messages collapse to one-line preview by default (Ctrl+O expands)

### Claude Code — v2.1.248 (August 27, 2026)
- **`--restricted` flag** (`CLAUDE_CODE_RESTRICTED=1`): removes built-in tools that run commands or code and WebFetch (unless named in `--tools`), keeps file tools inside working directory, refuses `bypassPermissions`, ignores user/project/local settings files — sandboxes agent execution to a minimal trusted surface
- **Per-agent prompt cache TTL:** `experimental.cacheTtl` in agent frontmatter ("5m" or "1h") sets TTL when no subagent TTL is configured
- **Cross-session messaging expands:** `SendMessage`/`ListAgents` now works between sessions on the same machine on Bedrock, Vertex, and Foundry, and when telemetry is disabled
- **`/usage-credits`:** New command for Enterprise orgs billed through AWS Marketplace, self-serve Enterprise, and Enterprise trials — request higher limits from admin
- **Self-hosted runner labeling:** `claude self-hosted-runner --client-label <label>` overrides the label the runner registers with
- Server-managed settings diagnostics: startup warning when settings fail to load, `/doctor` and `/status` explain load failures for Bedrock/Vertex/third-party providers
- Improved Workflow tool: description reduced from ~5.7k tokens to ~1k; script-writing reference moved to bundled `workflow-authoring` skill
- `/ultrareview` and locally seeded cloud sessions now skip uploading uncommitted edits to `prod.env`-style files, `*.tfvars`, and credential file backups
- Multiple stability fixes: prompt-cache miss on OAuth refresh, usage-limit resume cache misses, cloud session credential timing, Windows keyboard navigation

### Codex CLI — v0.150.0 Stable (August 26, 2026)
Major release with 50+ PRs. Key features:
- **@ mentions for cross-task referencing:** Reference and coordinate other Codex tasks from the terminal — shifts Codex toward a multi-agent coordination hub
- **`/copy` picker:** Select full responses, individual code blocks, or blockquotes
- **Auto-naming:** Unnamed terminal tasks receive descriptive titles automatically; `/rename` suggests editable titles
- **Markdown link rendering:** Clickable link labels in supported terminals
- **Permission mode cycling keybindings:** Vim mode improvements with `.` to repeat last edit
- **Interrupt hooks:** Run commands or MCP handlers when an active turn is interrupted
- **Security hardening:** Untrusted projects no longer supply AGENTS.md instructions; credential redaction improved in diagnostics; Windows sandbox elevated setup and Unicode path fixes; managed deny-read rules enforced after permission changes; Unix shutdown hangs prevented
- **Bug fixes:** Remote MCP bearer-token lookup fixed; Amazon Bedrock conversation compaction and multi-agent compatibility resolved
