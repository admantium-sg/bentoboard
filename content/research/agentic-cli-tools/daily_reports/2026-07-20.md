# Daily Report — July 20, 2026

## New Findings (since July 19, 2026)

### Claude Code v2.1.215 — /verify and /code-review Now Require Explicit Invocation (July 19, 2026)

v2.1.215 is a single-change release: Claude Code no longer runs `/verify` and `/code-review` skills autonomously — users must now invoke them explicitly with `/verify` or `/code-review`. The change ends previously implicit behavior where Claude would automatically run these skills under certain conditions. The W29 features (MCP connectors in artifacts, screen reader mode, stacked slash commands, /fork→/subtask, auto-mode Broad opt-in, MCP auto-background, claude auto-mode reset, corporate launcher) shipped across v2.1.207–v2.1.212 and are covered in prior reports.

**Source:** https://code.claude.com/docs/en/changelog

### Claude Code W29 Feature Highlights — Shipped July 13–17 (Summary)

W29 features landed across v2.1.207–v2.1.212:

**MCP connectors in artifacts:** Published artifacts can now call MCP connectors each time someone views them — dashboards pull live data and take actions on demand rather than rendering static snapshots. Each call runs through the viewer's own connections, with viewer approval before the first connector call. Also added: public sharing links, editor roles for Team and Enterprise plans, and artifacts from Claude Tag sessions.

**Screen reader mode:** CLI output replaces the visual terminal interface with plain, linear, labeled text readable by screen readers (VoiceOver, NVDA). Enabled via `claude --ax-screen-reader`, the `CLAUDE_AX_SCREEN_READER` env var, or the `axScreenReader` setting. This is a significant accessibility milestone for a terminal-native tool.

**UX improvements:** Stacked slash commands (`/plan /grill-me <prompt>`) now parse and activate in order. `/fork` now copies the conversation into a new background session with its own row in `claude agents` — the old in-session forked subagent is now `/subtask`.

**Corporate/enterprise additions:** Auto mode no longer needs `CLAUDE_CODE_ENABLE_AUTO_MODE` opt-in on Amazon Bedrock, Google Cloud Agent Platform, and Microsoft Foundry (admins can disable with `disableAutoMode`). New `claude auto-mode reset` command restores defaults (`--yes` skips confirmation). New `CLAUDE_CODE_PROCESS_WRAPPER` / `processWrapper` setting lets enterprises wrap Claude Code's subprocesses (daemon, agent view) through a required wrapper executable.

**MCP reliability:** MCP tool calls running longer than 2 minutes now move to the background automatically (threshold tunable with `CLAUDE_CODE_MCP_AUTO_BACKGROUND_MS`).

**Source:** https://code.claude.com/docs/en/whats-new/2026-w29 | https://releasebot.io/updates/anthropic/claude-code

### Antigravity CLI — v1.1.x Series with /codesearch, Async Startup, Copy-on-Select (July 10–16, 2026)

Google's Antigravity CLI (successor to Gemini CLI) shipped a substantive feature batch across the v1.1.x series:

**New /codesearch command:** Added `/codesearch` (aliases `/cs` and `/search`) for interactive workspace code search — regex by default, `-F/--literal` for exact matching, `f:/file:` globs to filter paths. A dedicated code-search command is a notable workflow addition for a terminal-native agent.

**UX polish:** Copy-on-select in no-flickering mode — dragging highlights text and releasing copies ANSI-stripped selection to clipboard; virtual scrollbar now hidden so it doesn't interfere with multi-line output copying.

**Performance:** Skills now load asynchronously — interactive startup no longer blocks on synchronous filesystem-heavy skill discovery. Customization loading (skills, rules, agents, hooks) improved via consolidated directory walks and filesystem lookup caching.

**Bug fixes:** Custom agents with `subagent: false` no longer appear in the available-subagents list; headless (`-p/--print`) runs now honor persisted `settings.json` policies; `/btw` side-questions no longer leak as duplicate conversation entries; custom Enter bindings now work correctly.

**Source:** https://github.com/google-antigravity/antigravity-cli/releases

### Cline v4.0.9 — Dramatic Install Size Reduction, Optional Provider SDKs (July 16–17, 2026)

Cline shipped SDK v0.0.65 / CLI v3.0.46 (v4.0.9):

**Install size cut by 55%:** Claude Code and Codex provider SDKs are now optional peer dependencies loaded on demand. `npm i -g cline` drops from ~640MB to ~285MB — a significant improvement for CLI-first users and CI/CD environments.

**New model:** Kimi K3 added to the bundled ClinePass model fallback lineup.

**OAuth reliability:** Runs now retry once after refreshing expired OAuth credentials.

**Team runs improvements:** The spawn tool is no longer exposed to teammate agents; errored teammate runs now report as failed instead of completed.

**Token handling fixed:** Max output token handling improved across gateway routing, OpenAI vendor, and reasoning models.

**Source:** https://github.com/cline/cline/releases
