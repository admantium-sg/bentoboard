## New Findings (4)

### GitHub Copilot CLI v1.0.98 — Gemini 4 Argon, Keystroke Preservation, Ask Expansion
140th release of 2026. Adds support for Gemini 4 Argon model. Command hooks complete reliably even when child-exit signals are lost under Node. MCP status and /mcp commands stay synced after split-view session switches. Resuming a session now respects abandoned pending-permission work. Keeps ordinary characters typed while the input box is still coming up at startup instead of dropping them. Expand /ask answers with Ctrl+E, copy with Ctrl+Y, and reopen the last usable completed answer with /ask or /btw.
Source: https://www.havoptic.com/r/github-copilot-v1.0.98

### Claude Code v2.1.300 — Virtual Text, Agent Transcript Views, Advisor on AWS
242nd release of 2026. Adds virtualText to mod prompt decorations — text drawn in the prompt box that never enters the draft or submitted prompt. Adds $.ui.view({ agentId }) for mods to show an agent's transcript in the main view. Adds /advisor on Claude Platform on AWS — no advisor runs until picked with /advisor, and CLAUDECODEDISABLEADVISORTOOL=1 turns it off. Adds OpenTelemetry GenAI semantic-convention attributes to trace spans (genai.provider.name, genai.conversation.id, genai.tool.name, error.type).
Source: https://www.havoptic.com/r/claude-code-2.1.300

### Claude Code v2.1.299 — Idle Compaction, File Mention Controls
241st release of 2026. Adds idle compaction: a 200K+ token conversation left idle for ~54 minutes is compacted before its one-hour prompt cache expires. Add CLAUDECODEDISABLEFILEMENTIONS to give Claude file paths for @ mentions without file contents. Add CLAUDECODEIDLECOMPACTMINTOKENS to change the 200K-token minimum. Both require v2.1.290 or later.
Source: https://www.havoptic.com/r/claude-code-2.1.299

### Antigravity CLI v1.3.5 — Auto Mode, /Compact, Syntax Highlighting in Diff
66th release of 2026. Adds Auto mode: approves file edits and safe commands without asking, still prompts before irreversible actions. Commands that would leave the terminal sandbox are first reviewed by a separate agent. Choose with --mode auto or press Shift+Tab to cycle modes. Available on Linux and macOS, Windows support coming later. Adds /compact command to reclaim context space on demand. Adds syntax highlighting to /diff file view and folding with Ctrl+O to expand/collapse.
Source: https://www.havoptic.com/r/antigravity-cli-1.3.5

## Community Pulse

**Working well:** Claude Code continues dominating r/vibecoding with 226 mentions — described as "part workspace, part builder, part teacher." Terminal-only workflow validated as a feature: users report spending less time in IDEs. Auto mode in Antigravity addressing demand for less interruption-driven workflows.

**Problems:** Token burn on workplace agents like Viktor remains the top complaint — one five-person team reported exhausting their allowance in 36 hours of real use. Agent washing (labeling basic automation as agents) remains the community's main pet peeve.

**Interesting:** Antigravity CLI's Auto mode launch drew a direct response from CEO Varun Mohan confirming more features are "imminently" coming — notable for the public, rapid iteration loop with the community.
