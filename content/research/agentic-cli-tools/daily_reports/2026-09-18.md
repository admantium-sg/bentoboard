### Claude Code — v2.1.275: Account Confirmation on Save, Send-Now Key, claude.ai Skill Sync (September 17, 2026)
220th release of 2026. New features: when a gateway names the signed-in account, you confirm before the credential is saved — `/status` also shows the account. Added a send-now key (ctrl+enter / ctrl+x ctrl+s) that interrupts the current turn and dispatches all queued messages at once; sent and queued messages show in gray until the model receives them. Skills and plugins enabled on your claude.ai account now sync to terminal sessions signed in with it — opt out via `syncClaudeAiSkills: false` or `syncClaudeAiPlugins: false`. Added `/plugin install --marketplace` to offer marketplace before installing. Also fixes: restored memory file's age note no longer changes between requests after compaction/resume (fixing prompt cache misses); `--forward-subagent-text` stream-json now properly forwards subagent messages.

**Source:** https://www.havoptic.com/r/claude-code-2.1.275

### Claude Code — v2.1.274: Memory Warnings, Corrupted Transcript Self-Heal (September 16, 2026)
219th release. Added a visible warning when memory usage is critical with steps to free memory or restart safely. Sessions stuck endlessly retrying "unexpected tooluseid" 400 errors are now self-healing — corrupted transcripts auto-recover or end with a clear `/rewind` hint. Added `CLAUDECODEMCPSTARTUPWAITMS` to bound how long the first non-interactive turn waits for connecting MCP servers. Multiple MCP fixes: HTTP+SSE servers failing with 422 now reconnect properly; Streamable HTTP MCP tool calls no longer time out at 5 minutes; MCP prompts/resources refresh on list-changed notifications; 403 insufficientscope now names missing permissions and points to `/mcp` re-authentication. Hook-driven sessions with `/goal` now compact properly instead of hitting "Prompt is too long."

**Source:** https://www.havoptic.com/r/claude-code-2.1.274

### Kilo — v7.7.3: KiloClaw Removed, Logo Animation, Worktree Repair (September 15-17, 2026)
Major architectural change: KiloClaw — the VS Code chat panel, sidebar button, TUI `/kiloclaw` command, Kilo Chat client, and associated gateway endpoints — has been removed entirely. The Kilo logo on the welcome screen now animates on hover. ChatGPT Codex quota displays alongside other provider usage in CLI and VS Code. PR lookup no longer stalls on unresponsive GitHub CLI. Chat search restricted to user/assistant messages — reasoning blocks, tool calls, and output no longer pollute results. **Source:** https://github.com/Kilo-Org/kilocode/releases

### Cline — Security Fixes: rg.exe/git.exe Path Hijack, Silent File Overwrite (September 2026)
Critical Windows security fixes landed in Cline's September release. On Windows, opening a repository containing a file named `rg.exe`, `git.exe`, or `powershell.exe` no longer runs that planted executable instead of the real program — Cline now sets the `NoDefaultCurrentDirectoryInExePath` opt-out at startup, blocking this path hijack vector. Also fixed: `apply_patch` silently overwriting existing files when the model uses "Add File" on a path that already exists. Long tasks now compact properly using the provider's own token count rather than a character-based estimate — disassembly, image dumps, and minified sources were previously causing compaction to never fire. Images attached to models that can't read them now get a warning badge instead of being silently dropped.

**Source:** https://github.com/cline/cline/releases

## Community Pulse

**Working well:** Claude Code's send-now key (ctrl+enter) for instantly dispatching queued messages mid-turn is a highly requested workflow feature — developers running long tasks with queued follow-ups no longer need to wait for completion before submitting next steps.

**Problems:** The Cline security fixes this cycle highlight an ongoing concern: path-hijack vulnerabilities through planted executables remain a real attack surface in AI coding tools that execute in user repositories. This is a category-level security reminder rather than a Cline-specific issue.

**Interesting:** Kilo's removal of KiloClaw is a notable strategic pivot — the team is consolidating around core Agent Manager and worktree functionality rather than maintaining a parallel chat panel. The open-source community discussion around this has been active, with some users viewing it as a simplification and others noting the loss of VS Code-native chat.
