# Daily Report: Agentic CLI Tools — August 14, 2026

## Summary

Claude Code shipped two more patches (v2.1.229, v2.1.231) fixing MCP OAuth edge cases and adding VS Code session groups. Kilo v7.4.22 landed with clickable file references, PR review thread actions, and OpenCode v1.18.x upstream. Codex CLI had no new releases, but the ChatGPT desktop app gained a Linux preview and Computer History memory feature.

---

## Tool Releases & Features

**Claude Code** — v2.1.231 (Aug 13): Fixed MCP OAuth sign-in failing with redirect URI mismatch for servers using pre-registered OAuth clients (e.g., Slack). v2.1.229 (Aug 12): SSE keepalive pings prevent idle-timeout disconnects on Vertex and Bedrock during long thinking pauses; plugin marketplace `command` sources allow an IDE to print the plugin directory re-resolved each session without restart; `ListAgents` now labels cloud sessions and marks disconnected Remote Control sessions as `offline`; VS Code sidebar gains session groups (right-click to create/rename/delete, Cmd/Ctrl-click to move multiple sessions).

**Kilo v7.4.22** — Community contributions: file references in agent responses become clickable links when they match real files; PR comment actions (resolve/unresolve threads, jump to comments, scroll-to-top for diff view); Morph WarpGrep retired; model default reasoning variant selectable in chat and Agent Manager; structured AWS access keys and GCP service-account JSON supported for Bedrock/Vertex connection in VS Code; subagent permission phantom deny-rule bug fixed (read-only agent's bash allowlist no longer incorrectly ceiling a delegated writable subagent's bash commands). OpenCode upstream bumped to v1.18.13 with code mode MCP adapter, Azure GPT-5.6 support, xAI prompt cache routing improvements, and GitHub Copilot model routing fixes.

**OpenAI Codex CLI** — No new CLI releases since v0.147.0 (Aug 7). Codex app updates this week: Linux desktop preview launched for Ubuntu/Debian/Fedora on x64 and ARM64; Computer History feature (Opt-in, available to ChatGPT Pro/Business/Enterprise) tracks activity across apps and websites as a memory/timeline that Codex and ChatGPT can use.

---

## Community Pulse

**Working well:** Kilo's clickable file references in agent output address a long-standing UX gap — clicking a mentioned file path and landing on the exact line is a workflow win. Codex's Linux desktop preview expands the app beyond macOS, which had been the only desktop option since launch.

**Problems:** MCP OAuth on macOS is still generating intermittent failures — v2.1.231 is the third patch addressing OAuth issues in as many releases. The redirect URI mismatch fix addresses Slack specifically, but users on other pre-registered OAuth clients may still hit issues.

**Interesting:** Computer History in ChatGPT is the first cross-app memory system that Codex can read from — if it gains parity across platforms, it could become a significant context signal for agents working across multiple tools. TrustKernel's PlugClaw (thumb-sized private AI computer) suggests hardware-isolated agent execution is becoming a product category, not just an enterprise checkbox.

## Market & Funding

The week of Aug 10–16 brought a wave of vertical-specific agent launches beyond the coding/CLI space: Zeplyn integrating with Schwab Advisor Center (wealth management account-opening workflow), Ahrefs launching Letaido (marketing agent workspace), Upwave's Bayes (campaign analytics agent), and SKALE Agent Pit (prediction-market agent sandbox). This reflects a broader pattern: agents embedding deeply into regulated industries and specialized workflows rather than remaining horizontal tools. The category is分化 — horizontal coding agents (Claude Code, Codex, Kilo) consolidate around stability and interoperability, while vertical agents race into finance, marketing, and operations.

---

## Trend

Horizontal CLI agents are in a polish and hardening phase (OAuth fixes, session management, upstream library bumps), while the broader agentic ecosystem is expanding sideways into industry-specific workflows. The gap between "writes code" and "verifies the user-visible result" noted in the TestMu review — none of the nine CLI tools render the finished UI — remains the category's open problem.
