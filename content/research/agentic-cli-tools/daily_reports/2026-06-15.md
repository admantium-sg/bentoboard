## New Findings (June 14)

### Crush v0.77.0 (June 14, 2026) — User-Level Context, Named Hooks, Socket Fixes

Crush's first stable release since v0.76.0 (June 5) brings several user-experience improvements:

- **User-level context files**: Set `~/.config/AGENTS.md` or `~/.config/crush/CRUSH.md` and Crush will reference it on session start — just like project-level context files, but at the user level. Enables personal defaults without a per-project file.
- **Better commit messages and PR descriptions**: Improved system prompt so LLMs author clearer, more human-readable commit messages and PR descriptions instead of overly technical ones.
- **Named hooks**: Hooks can now have a name field, making them easier to identify in the CLI (contribution by @BrunoKrugel).
- **Client-server socket fixes**: Stale sockets now cleaned up on startup; Unix sockets now live in `$XDG_RUNTIME_DIR` on Linux and `$TMPDIR` on macOS instead of `/tmp`. Client-server mode getting closer to prime time.
- **Dependency fixes**: Bumped Lip Gloss to v2.0.4 and Glamour to v2.0.1 to fix crashes identified by contributor @taciturnaxolotl.

**Source:** https://github.com/charmbracelet/crush/releases

### OpenAI Codex CLI v0.140.0-alpha.19 (June 14, 2026) — 19 Alphas, Stable Still Imminent

One more alpha dropped June 14 at 02:03 UTC, bringing the v0.140.0 series to 19 alphas. The extended alpha cycle continues — community speculation points to multi-agent v2 concurrency controls and agent residency LRU caching as the stabilization blockers. Stable release still appears imminent given the release velocity.

**Source:** https://github.com/openai/codex/releases

### Kilo v7.3.44 (June 12, 2026) — Autonomy Preset, Gateway Deep Links

Latest pre-release:
- **Agent autonomy preset during VS Code onboarding**: Users choose their autonomy level during Kilo setup in VS Code — new users get a clearer entry point.
- **Kilo Gateway catalog models from VS Code deep links**: Direct navigation to specific models in the catalog from VS Code.
- **Escape stops Agent Manager prompts** while sessions are still starting.
- **Review comments render as interactive message cards** instead of raw markdown.
- **Agent Manager terminals use editor font settings**: Respects `terminal.integrated.fontFamily` and `terminal.integrated.fontSize` (including Nerd Font glyphs).

**Source:** https://github.com/Kilo-Org/kilocode/releases

### Kilo v7.3.43 (June 12, 2026) — Embedded LanceDB, MCP Boot, Large Sessions

Continuing the June 12 Kilo sprint:
- **Embedded LanceDB as default vector store**: Semantic search works without a separate Qdrant server — major simplification for self-hosted deployments. Existing Qdrant users and Intel Mac users can opt back in via `indexing.vectorStore`.
- **MCP servers start during worktree session initialization**: Reduces delay before first response.
- **Large session forks faster**: Retains final task outcomes instead of duplicating resumable subagent histories.
- **Fork Session button** added to completed Agent Manager sessions.
- **Virtualized transcript rendering**: Large chat transcripts stay responsive by mounting only viewport-visible conversation rows.

**Source:** https://github.com/Kilo-Org/kilocode/releases

## Community Pulse

### Working Well
- **Crush user-level context files**: The ability to set `~/.config/AGENTS.md` at the user level is a natural extension of the project-level AGENTS.md pattern — enables personal defaults across all projects without creating per-project files.
- **Kilo embedded LanceDB**: Eliminating the Qdrant dependency is a significant simplification for self-hosted deployments. One less infrastructure component to manage.
- **Crush commit message improvements**: The team actively improving LLM output quality for real-world workflows (commit messages) rather than chasing feature flags.

### Problems
- **Codex CLI v0.140.0 stable nowhere in sight**: 19 alphas and counting. The community's frustration from last week continues to build — some wondering if multi-agent v2 features are fundamentally harder to stabilize than expected.
- **Kilo's rapid pre-release cadence**: 43 releases in the v7.3.x series with frequent breaking changes between minor versions makes it hard for users to know which version to pin.

### Interesting
- **Crush client-server mode approaching prime time**: Socket location fixes and stale socket cleanup suggest the team is actively preparing client-server mode for general use. When it ships, it would enable persistent Crush sessions as a background service.
- **Kilo autonomy preset at onboarding**: First CLI tool to offer explicit autonomy-level choice during setup — signals growing attention to the user-onboarding experience as a differentiator.
- **Claude Code silent since June 12**: Three days without a new release is notable for Claude Code's typical cadence — possibly preparing a larger release or in a stabilization phase after the Fable 5 push.

## Trend

Crush ships its first stable in 9 days with meaningful UX improvements (user-level context, named hooks, commit message quality), while Kilo continues its rapid pre-release sprint with infrastructure wins (embedded LanceDB, MCP boot-time improvements). Claude Code is quiet — its longest gap since the Fable 5 launch. Codex CLI continues its 19-alpha run toward what appears to be a significant multi-agent v2 stable release.
