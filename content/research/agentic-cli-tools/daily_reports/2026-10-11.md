## New Findings (October 10–11, 2026)

### Antigravity CLI v1.3.3 — Pinned Prompt, Plugin Auto-Load, macOS Security Tightening (October 10, 2026)
64th release of 2026. Keeps your conversation prompt pinned at the top while scrolling so you can instantly jump back. Plugins can now declare tools with `meta: {"antigravity/alwaysLoad": true}` in their tools/list response so the agent gets those tools directly without on-demand discovery. Also supports root-level `agents.json` in plugins to declare subagents alongside skills and rules. macOS sandbox now blocks sandboxed commands from reading `~/Library/Application Support` by default (where desktop apps keep credentials and session tokens) — previously readable, now opt-in. HTML error pages from corporate proxies show the page title instead of raw HTML. Other improvements: Jujutsu commands no longer hang in interactive pager, stopped subagents clear pending approvals immediately, and `--remote-control` now exits clearly when Application Default Credentials are detected (not yet supported). Ships every 1.5 days — 21 releases in the last month.

**Source:** https://www.havoptic.com/r/antigravity-cli-1.3.3

### Kiro CLI v2.29.0 — Session Memory for Local V3 Sessions (October 9, 2026)
53rd release. Kiro can now learn useful context from your work and recall it in later chat sessions. For example, if Kiro learns while debugging that a repository's integration tests fail until the local database is seeded, a later session seeds it first instead of rediscovering the cause. When Kiro uses a memory, the chat shows a Memory entry with `command=get` and the memory's title while Kiro is still working. In a local V3 session, type `/memories` and select config to choose read & write, read only, or off. With read & write, automatic memory updates let Kiro create and refine memories, including after a session ends. In an untrusted workspace, Kiro can read memories but cannot add, change, or delete them. Select list to search, preview, and open stored memories. Ships every 5.3 days — 7 releases in the last month.

**Source:** https://kiro.dev/changelog/cli/

## Community Pulse

**Working well:** Antigravity's pinned prompt (v1.3.3) is a small but highly practical UX improvement — in long debugging sessions, being able to jump back to your prompt without scrolling solves a real friction point. Combined with plugin auto-load (`alwaysLoad`), plugins can now eagerly expose their best tools rather than waiting for discovery.

**Problems:** The macOS sandbox change in Antigravity v1.3.3 blocking `~/Library/Application Support` could break existing workflows for users who rely on terminal-accessible credentials stored there. Users should verify their setups after upgrading and explicitly allow access if needed.

**Interesting:** Kiro's session memory (v2.29.0) is a notable step toward persistent contextual knowledge in CLI agents — similar to how Claude Code and other tools approach memory, but implemented at the session level for local V3. The trust model (read-only in untrusted workspaces, read & write in trusted) mirrors established permission patterns. The `/memories` command interface for managing stored context is clean and discoverable.

## Trend

The concentrated Oct 8-9 release wave (Claude Code 3x, Codex 2x, Copilot 2x, Antigravity 2x) remains the standout pattern — the ecosystem ships in coordinated bursts rather than evenly distributed.
