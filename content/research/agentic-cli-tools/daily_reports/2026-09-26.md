## Tool Releases

### Claude Code v2.1.283 (September 25)
227th release of 2026. Enterprise-grade model governance: `availableModelsMatch="exact"` locks an `availableModels` entry to a specific model version, blocking new releases until explicitly allowlisted. `deniedModels` managed setting blocks specific models even when availableModels permits them. New `/doctor prompt-audit` (also `/checkup prompt-audit`) audits CLAUDE.md files, skills, agents, and commands for prompting patterns written for older models — helping teams catch model-specific instructions before they cause issues. Added `x-claude-code-prompt-id` to gateway hint headers (opt-in via `CLAUDECODEGATEWAYHINTHEADERS=1`) so LLM gateways can correlate requests serving the same prompt. Added Mantle upstream provider for Amazon Bedrock. MCP tool results now save images to files so Bash, Read, and other tools can open them. First-request latency improved by reusing the preconnected API connection. Compacted spinner now shows tokens streaming in real time. `/tasks` gains paging keys, mouse wheel, and click support. Claude Code ships every 1.1 days — 28 releases in the last month.
Source: https://www.havoptic.com/r/claude-code-2.1.283

## Community Pulse

**Working well:** Reddit community (r/vibecoding, r/ArtificialIntelligence) continues to validate the autonomous CLI agent category. Claude Code leads with 226 mentions — described as "part workspace, part builder, part teacher." The terminal-only workflow is seen as a feature, not a limitation: users report spending less time in IDEs and more time reviewing agent output. The `/clear` workaround between tasks is widely adopted for managing long sessions.

**Problems:** "Agent washing" — tools labeled as agents that are just automation with a new label — remains a community pet peeve. Real agents are distinguished by whether they act on initiative or wait for every instruction. Token/credit burn on workplace agents like Viktor is a recurring complaint (one five-person team burned their allowance in 36 hours). WezTerm and VS Code users have been frustrated by garbled Mermaid/LaTeX rendering — now fixed in Antigravity CLI v1.2.11.

**Interesting:** Claude Code now ships 28 releases per month — averaging 1.1 days between releases. The release velocity signals a mature engineering org with continuous deployment rather than feature milestones.
