## Tool Releases

**Claude Code v2.1.158 (May 30) — Auto Mode on Bedrock, Vertex, Foundry**

Auto mode — Claude Code's agentic automation mode — is now available on AWS Bedrock, Vertex AI, and Microsoft Foundry for Opus 4.7 and Opus 4.8. Opt in with `CLAUDE_CODE_ENABLE_AUTO_MODE=1`. This extends the convenience of auto mode beyond the default Anthropic endpoint to enterprise cloud environments.

**Source:** https://code.claude.com/docs/en/changelog

**Claude Code v2.1.157 (May 29) — Plugin System Overhaul, Auto-Loading Skills**

Major plugin ecosystem update:
- Plugins in `.claude/skills` directories are now automatically loaded — no marketplace required
- New `claude plugin init <name>` scaffolds a new plugin in `.claude/skills`
- Autocomplete for `/plugin` arguments now covers subcommands, installed plugin names, and marketplace plugins
- `claude agents`: `agent` field in `settings.json` now honored for dispatched sessions, with `--agent <name>` override
- `EnterWorktree` can now switch between Claude-managed worktrees mid-session
- `tool_decision` telemetry now includes `tool_parameters` (bash commands, MCP/skill names) when `OTEL_LOG_TOOL_DETAILS=1`
- Worktrees managed by Claude are now left unlocked when the agent finishes — `git worktree remove`/`prune` can clean them up
- Fixed unprocessable images (zero-byte, corrupt) attached via paste, MCP, or dialog crashing instead of becoming text placeholder
- Fixed sandbox network permission prompts appearing in auto/bypass-permissions mode on desktop app, IDE extensions, SDK
- `/terminal-setup` now disables GPU acceleration in VS Code/Cursor/Windsurf integrated terminals to prevent garbled-text rendering

**Source:** https://code.claude.com/docs/en/changelog

**OpenAI Codex CLI — Rust v0.135.0 (May 28) — Doctor, Vim Mode, Memory DB**

Major release for Codex CLI (build 26.519):
- `codex doctor` now reports richer environment diagnostics: Git, terminal, app-server, and thread inventory for support cases
- `/status` shows remote connection details and server version when connected over remote transport
- Vim mode gained text-object editing, improved word/line-end behavior, and configurable interrupt-turn binding
- `/permissions` now understands named permission profiles and displays configured custom profiles
- Packaged Codex builds include a patched zsh helper across macOS and Linux
- Python SDK now exposes friendly Sandbox presets for thread and turn APIs
- Memory runtime state moved into a dedicated SQLite database (infrastructure upgrade)
- Install scripts support `CODEX_NON_INTERACTIVE=1` for non-interactive installation
- Bug fixes: markdown tables render better in TUI, improved stability on macOS and Zellij, older tmux/iTerm sessions no longer lose Ctrl-C handling

**Source:** https://github.com/openai/codex/releases

**Cline CLI v3.0.15 (May 29) — Cline Hub, Global AGENTS Rules, Model Refresh**

- **Cline Hub** — web app for monitoring connected clients, viewing/driving sessions, streaming assistant output, restarting local hub. Local/LAN/tunnel usage gated by room secret
- **Global AGENTS rules** — agent rules can now be applied across all sessions, not just per-project
- **Plugins can contribute static or dynamic rule content** when installed in the sandbox
- **Discord connector improvements** — sessions bound to individual message authors, `/mute`/`/unmute` from mentions or raw user IDs
- **Model catalog refresh** — Claude Opus 4.8, Moonshot Kimi K2.6, Qwen3.7 Max (with cache support)
- **Steer active connector sessions** across turn keys by matching session ID — replies continue existing session instead of starting duplicate

**Source:** https://github.com/cline/cline/releases

## Community Pulse

**Working well:** Claude Code's auto mode expansion to Bedrock, Vertex, and Foundry brings the enterprise-friendly automation to cloud-native teams without requiring Anthropic API routing. Codex's memory runtime migration to SQLite is an infrastructure cleanliness move that suggests improved reliability for long sessions. Droid's new `/context` modal gives users visibility into context consumption — addressing a real pain point as models hit context window limits.

**Problems:** Cline Hub introduces a web-based monitoring layer that may conflict with the "simple CLI" ethos — enterprise monitoring features can introduce complexity for solo developers who just want a local terminal agent. The Global AGENTS rules feature could be misused for over-broad policy enforcement across teams.

**Interesting:** Three Claude Code releases in one day (155, 156, 157) — then 158 on May 30 — shows the release velocity is sustained. The Opus 4.8 thinking block fix in v2.1.156 was a same-day response to a breaking issue, which demonstrates tight operational responsiveness. Meanwhile, Codex has shipped stable releases at a 3-4 day cadence throughout May.

---

## Trend

Claude Code and Codex CLI are in a sustained feature-velocity race — Claude on plugin ecosystem and multi-cloud auto mode, Codex on Vim UX, cross-platform computer use, and memory infrastructure. Cline is differentiating on connector ecosystem (Discord, Telegram, Hub) and SDK openness. The market is clearly rewarding platform properties over raw model benchmarks.
