## 1. Headline

**The day the products started shipping consent.**

Claude Code `v2.1.317` put an explicit prompt in front of any web or shell tool call that would
send the account email address to the network; warned on `/schedule` when a new cloud scheduled
task picks up connectors the user did not ask for; and gave Agent SDK hook callbacks an
`onFailure: "block"` mode so a failing callback blocks the action instead of letting it run.
Copilot CLI shipped *opt-in* session-management tools with `@mentions` for opted-in local sessions
and stopped a malformed BYOK provider key from being printed in the model error or written to the
session log. Qwen Code shipped headless `prompt.submit` hooks so a prompt can be inspected or
rewritten before submission in `-p` runs.

Underneath that, **the harness learned to measure itself honestly**: oh-my-pi `v18.16.0` fixed a
tokenizer estimate that undercounted Gemini/Grok billing by 11–48% on code-heavy sessions and let
compaction fire late after a model switch, and Atomic `0.9.68` made `--model` mean *that model*
and stopped `atomic -p` hanging forever on a silent piped stdin.

## 5. What this window means

Three threads ran in parallel, all about **the agent acting on the user's behalf** rather than
about what the agent can do.

**Consent became a product surface.** Claude Code put a prompt in front of network egress of the
account email, made hook failures block, surfaced managed-settings load state in the desktop app,
and shipped a per-developer cost-report endpoint with IdP-group attribution behind a retention
knob. Copilot CLI made its session-management tools explicitly opt-in and stopped leaking a
malformed BYOK key into errors and session logs. Qwen Code gave headless runs a `prompt.submit`
hook. Factory Droid CLI shipped `1.2.0` with no changelog at all — and a vendor whose release notes
are invisible cannot answer a consent question either.

**The harness started measuring itself honestly.** oh-my-pi's tokenizer fix removed an 11–48%
undercount against what Gemini and Grok actually bill, and Atomic's `--model` semantics ended a
class of silent fallbacks. Both attack the failure recorded the previous cycle: users cannot plan
around a meter they cannot read. That this work landed in a small Rust/TypeScript harness and a
small Python agent rather than in the flagship products is itself the finding — **the remaining
efficiency work sits below the vendor layer.**

**Packaging became a fork family.** The npm "recently published" listing was dominated by Pi
derivatives (`@earendil-works/pi-coding-agent`, `@code-yeongyu/senpi`, `@averyyy/pi-coding-agent`,
`pi-agent-zh`) plus the genuine article of the week, `deepseek-ai/dsh-superagent-prototype`. At the
same time GitHub's new-repo star velocity migrated from new CLIs to **agent skill packs**. The
ecosystem is no longer minting harnesses at the same rate; it is minting extensions of existing
harnesses and skills, which makes npm publication volume an unreliable proxy for ecosystem size.

Quiet but load-bearing: GitHub pushed `pull_request_target` default-blocking from 2026-11-02 to
**2026-12-02**, changing the mechanics of every agent-triggered GitHub Actions workflow next month.
