**Latest Releases:**
- **v0.120.0** (April 11, 2026)
- **v0.119.0** (April 10, 2026)

**New Features in v0.120.0:**

**Realtime V2 Enhancements:**
- Background agent progress streaming during active work execution
- Queue follow-up responses until active response completes
- Enhanced Realtime V2 backend delegation prompt

**TUI Improvements:**
- Hook activity easier to scan with live running hooks shown separately
- Completed hook output kept only when useful
- Custom TUI status lines can include renamed thread titles
- /resume can jump directly to sessions by ID or name

**MCP & Tool Enhancements:**
- Code-mode tool declarations include MCP outputSchema details for more precise structured tool results
- SessionStart hooks can distinguish /clear sessions from fresh startup or resume sessions
- Tool search result ordering preserved (not alphabetically reordered)

**Bug Fixes:**
- Windows elevated sandbox handling for split filesystem policies
- Sandbox permission handling for symlinked writable roots and carveouts
- Fixed `codex --remote wss://...` panics by installing Rustls crypto provider before TLS websocket connections
- Fixed live Stop-hook prompts to appear immediately
- App-server MCP cleanup on disconnect for proper resource teardown

**Performance & Analytics:**
- Rollout recording more reliable with retry logic
- Guardian follow-up efficiency improved (sending transcript deltas instead of full history)
- Stable Guardian review IDs across app-server events

**New Features in v0.119.0:**

**Realtime Voice (WebRTC):**
- Realtime voice sessions default to v2 WebRTC path
- Configurable transport, voice selection, native TUI media support
- App-server coverage for new flow

**Enhanced MCP Support:**
- MCP Apps and custom MCP servers: resource reads, tool-call metadata, custom-server tool search
- Server-driven elicitations, file-parameter uploads, reliable plugin cache refreshes
- Tool search result ordering preserved
- Faster /mcp inventory listing (avoids slow full inventory probes)
- Disabled servers skip auth probing
- Residency headers honored by codex mcp-server

**Remote/App-Server Workflows:**
- Egress websocket transport support
- `--cd` forwarding for remote sessions
- Runtime remote-control enablement
- Sandbox-aware filesystem APIs
- Experimental `codex exec-server` subcommand

**TUI UX Improvements:**
- Copy latest agent response with Ctrl+O (better clipboard behavior over SSH)
- `/resume` can jump by ID or name
- TUI notifications more configurable (Warp OSC 9 support, opt-in for focused-terminal notifications)
- TUI starts faster (async rate limit fetch)
- `/status` refreshes stale limits

**Resume Flow Stability:**
- Picker no longer flashes false empty states
- Fresher thread names used
- Stabilized timestamp labels
- Resume hints preserved on zero-token exits
- Avoids crashing when resuming current thread

**Sandbox & Platform Fixes:**
- Clearer read-only apply_patch errors
- Network proxy policy refreshed after sandbox changes
- Suppressed irrelevant bubblewrap warnings
- macOS HTTP-client sandbox panic fix
- Windows firewall address handling

**Architectural Improvements:**
- codex-core slimmed down through major crate extractions (MCP, tools, config, model management, auth, feedback, protocol)
- Core compile times reduced (63% and 48% improvements via native async abstractions)
- Bazel diagnostics and dependency wiring improved
