# Daily Report — August 19, 2026

## New Findings

### Codex CLI — v0.148.0 Stable Lands After 3-Week Alpha Sprint (August 18–19, 2026)

The alpha sprint is over. **v0.148.0 is now stable**, closing a three-week run that began with alpha.1 on August 1 and produced 21+ alpha tags before the stable release. This is the most feature-dense stable release this cycle:

**New features:**
- **`/export`** — Export complete TUI conversations to Markdown, either to clipboard or a new file
- **`codex exec fork`** — Fork sessions from the CLI, plus session archiving/restoring from the resume picker
- **Draft prompts while TUI initializes** — type ahead while the terminal UI boots up, with fork/resume progress shown during startup
- **Estimated thread credits/cost in `/status`**, status lines, and terminal titles for eligible workspaces
- **Amazon Bedrock Runtime as built-in provider** — use AWS profile credentials and region directly; includes GPT-5.6 routing
- **Async hooks + MCP tool invocation** — hooks can now run commands asynchronously and invoke MCP tools directly
- **Model switching reliability** — fixes a bug where model switches or settings updates left stale instructions behind or changed an active turn mid-stream

**Reliability:**
- Turns reconnect through temporary provider outages
- MCP servers recover after OAuth reauthentication without restarting Codex
- Sandbox restrictions now fail closed for denied or unreadable paths across Linux and Windows
- TUI startup no longer lets buffered terminal input accidentally activate prompts

**Source:** https://github.com/openai/codex/releases

### Claude Code — v2.1.235: Spellcheck, LSP Cache Fix, Memory Optimizations (August 18, 2026)

Quietest release in weeks at 30 changes — this is a polish and reliability sprint following the four-release sprint. Key additions:

**Spellcheck integration:** Optional `spellcheck` setting underlines misspelled words in the prompt input using your installed `aspell`, `hunspell`, or `ispell`. This is the first spellcheck integration in Claude Code's history.

**Performance:** Background cloud sessions (`/ultrareview`, `/autofix-pr`) now consume significantly less memory and CPU — their event streams are no longer re-scanned and re-rendered on every update.

**Bug fixes:** Whole-prompt-cache invalidation fixed when an LSP disconnected or reconnected mid-session; nested markdown list items no longer misalign at depth 3+; prompt input highlights (slash commands, keywords, @ mentions) fixed for multi-line prompts; Shift+Tab in the permission prompt comment field no longer approves edits and grants session-wide edit permission.

**UX improvements:** Permission dialogs now always match what a grant would cover; "don't ask again" withheld when contents can't be fully displayed; Vim mode now preserves NORMAL mode and cursor position when toggling the detailed transcript or closing a panel; embedded `grep` in native macOS/Linux builds now fails fast on pathological patterns instead of exhausting memory.

**Source:** https://code.claude.com/docs/en/changelog

### Cline — v4.1.10: Provider-Executed Web Search, Hub Stability Fixes (August 17–18, 2026)

**v4.1.10** brings provider-executed web search — models that support it can now search the web during a task, with a toggle in Feature Settings. Search calls and results appear in the conversation and persist across session reloads. The feature is off by default.

**Stability:** Two Cline installations on different builds no longer shut each other's Hub daemon down in a loop — build identity is now compared through a total order so at most one side can decide to retire the other. A newer build no longer replaces a Hub that is still serving live sessions — it attaches over the wire protocol and the swap happens once the Hub goes idle. Idle plugin sandbox processes are now reclaimed instead of lingering for the session's lifetime.

**Gateway:** Added a dedicated Cline provider for the Cline gateway, replacing the generic OpenAI-compatible path. Extended thinking budgets and gateway options now properly reach both `cline` and `cline-pass`.

**Source:** https://github.com/cline/cline/releases | https://github.com/cline/cline/compare/v4.1.9...v4.1.10

### Kilo — v7.5.x Pre-Release: JetBrains Agent Manager Beta (August 18, 2026)

A new pre-release branch marks the most significant JetBrains integration update yet:

**JetBrains Agent Manager beta:** Create, open, organize, rename, and delete worktree-based tasks and their sessions directly from the JetBrains IDE. Worktree activity, change tracking, ahead/behind counts, and pull request badges now appear in Agent Manager with clearer row actions, menus, and tooltips.

**Multi-window worktrees:** Open Agent Manager worktrees in new windows and dedicated terminal tabs — a key gap in the previous JetBrains experience.

**Chat UX refresh:** JetBrains chat readability improved with centered readable width, refreshed prompt chrome, stable tail-follow behavior, and clearer failed-turn outcome cards.

**Session recovery:** Preserved recovered non-idle session states including pending permission, pending question, retry, and offline states. Empty persisted sessions now show the intended empty session panel instead of a blank transcript.

**Source:** https://github.com/Kilo-Org/kilocode/releases

## Community Pulse

**Working well:** The `/export` command for TUI conversations is a high-value addition that addresses a long-standing gap — developers using Codex in TUI mode had no clean way to export transcript artifacts. Combined with session forking and archiving, this suggests the team is building toward Codex as a long-term workflow tool rather than a one-off coding assistant.

**Problems:** The persistent alpha sprint pattern — 21+ alphas before v0.148.0 stable — is becoming the norm for Codex. Each sprint delays stable adoption and fragments the ecosystem between early adopters on alphas and conservative users on the previous stable. The new stable shipped without fanfare (no announcement post, just a GitHub release), which may keep enterprise users on v0.147.0 longer than necessary.

**Interesting:** Cloudways launching managed OpenClaw and Hermes agents (August 17) is notable as a DigitalOcean subsidiary entering the managed AI agent space. The OpenClaw mention is interesting given OpenClaw is also the name of the agent platform this cron job tracks — though Cloudways specifies it as a managed deployment option, which is a different value prop than the CLI tools tracked here.

---

## Trend

The CLI agent ecosystem is converging on two distinct release cadences: Claude Code on a tight ~daily patch cycle with incremental security and polish work, and Codex on 3-week sprint cycles that culminate in large stable drops. Meanwhile, Cline and Kilo are both investing heavily in multi-session stability (Hub daemon fixes, worktree management) — the unglamorous but critical infrastructure work that determines whether these tools can run reliably in long-lived developer workflows.
