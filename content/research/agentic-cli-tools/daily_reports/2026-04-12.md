## Major Developments

### 1. Cursor 3.0 - April 2, 2026

**Significance:** Architectural shift from AI-enhanced IDE to agent orchestration platform

**New Components:**

- **Agents Window**: Replaces Composer; run multiple AI agents in parallel across local, worktree, cloud, and remote SSH environments with unified sidebar
- **Design Mode**: Direct UI element annotation for frontend work (Cmd+Shift+D), click-select browser elements instead of textual descriptions
- **Built-in Git**: Native staging, committing, and PR creation within Cursor
- **New Commands**:
  - `/worktree`: Run tasks in isolated Git worktrees
  - `/best-of-n`: Compare outputs across multiple AI models simultaneously

**Cloud & Local Agent Handoff:**

- Start tasks on cloud infrastructure, hand off to local agents for completion
- Cloud agents automatically generate screenshots and demo videos
- Launch from Slack, GitHub, Linear, mobile devices, or web

**Other Recent Features:**

- **Self-Hosted Cloud Agents** (March 25, 2026): Run cloud agents entirely in your own network; data residency/compliance
- **Bugbot Learned Rules & MCP Support** (April 8, 2026): Self-improving code review via PR feedback analysis
- **30+ New Plugins** (March 11, 2026): Atlassian, Datadog, GitLab, Hugging Face, monday.com, PlanetScale, and others
- **Remote Agents** (April 8, 2026): Control Cursor from any device; 598K+ views in 24h

**Pricing Updates:**

Six tiers: Hobby (Free), Pro ($20/month), Pro+ ($60/month), Ultra ($200/month), Teams ($40/user/month), Enterprise (Custom). Credit pool system replaces previous request limit model.

### 2. OpenCode → Crush - April 2026

**Significance:** Complete product relaunch with Charmbracelet organization

**Key Changes:**

- **Name Change**: OpenCode → Crush
- **Repository Move**: Pyasapanchi/opencodecli → charmbracelet/crush
- **Organization**: Independent → Charmbracelet (industrial terminal ecosystem with 25,000+ applications)

**14+ New/Enhanced Features:**

**Platform Support (NEW):**
- Android, FreeBSD, OpenBSD, NetBSD added (7 total platforms)

**Package Management (NEW):**
- FreeBSD, Windows (winget/scoop), Debian/Ubuntu (APT), Fedora/RHEL (YUM), comprehensive Nix support (NUR, flake import, NixOS/Home Manager)

**Provider Integrations (NEW):**
- 15+ providers: Vercel AI Gateway, Synthetic, Z.ai, MiniMax, Hugging Face, Cerebras, io.net, Avian, and OpenAI-compatible custom providers (Deepseek, etc.)

**Model Registry (NEW):**
- **Catwalk**: Community-supported, open source model registry at github.com/charmbracelet/catwalk

**Skills Integration (NEW):**
- Agent Skills standard support
- Cross-compatibility: searches `.claude/skills` and `.cursor/skills` directories
- Built-in `crush-config` skill for self-configuration

**MCP Enhancements (NEW):**
- SSE (Server-Sent Events) transport
- Environment variable expansion via `$(echo $VAR)` syntax
- Granular tool disabling per-server
- HTTP headers for authentication

**Configuration Features (NEW):**
- Custom OpenAI-compatible provider configuration
- Git attribution configuration (trailer_style, generated_with)
- Desktop notifications for permission requests and agent completion
- `.crushignore` support (like .gitignore)
- Custom initialization file names
- YOLO mode (`--yolo` flag to skip permission prompts)
- Granular disabled_tools and disabled_skills lists
- LSP environment variables and custom arguments

**Backed by Charm Ecosystem:**

- Bubble Tea (41.5k stars), Gum (23.3k stars), Glow (24.3k stars), VHS (19.3k stars)
- "Charm technology lives in over 25,000 applications, from leading open source projects, to business-critical infrastructure"

**Migration Notice:**

From original repository: "This is the original OpenCode repository, now continuing at Charm with its original creator, Kujtim Hoxha. Development is continuing under a new name as we prepare for a public relaunch."
