# Daily Report — August 22, 2026

## New Findings

### Claude Code — v2.1.239: Fullscreen Renderer Expansion, /claude-api Upgrade, Cloud Plugin Sync (August 21, 2026)

The 50+ change v2.1.239 landed the day after v2.1.238 in what is becoming a near-daily release cadence. Notable additions:

- **Fullscreen renderer expansion**: the one-time fullscreen offer that was previously restricted now extends to Bedrock, Vertex, Foundry and other setups that were previously excluded; new installs on those platforms now start in fullscreen by default
- **`/claude-api upgrade`**: new command migrates Python projects from `anthropic` 0.x to 1.x, with updated skill context using `anthropic.Timeout` instead of `httpx.Timeout`
- **Cloud plugin sync**: plugins synced from claude.ai now tagged as `name@synced`, work with `claude plugin enable/disable name@synced`, and never override a same-named locally installed plugin
- **Usage limits now show reset time**: the "spend limit already used" banner now tells you when the session or weekly limit resets
- **Bedrock proxy fix**: streaming behind proxies that strip the Content-Type header no longer silently doubles billed API calls by re-running every turn non-streaming
- **Bedrock SSO fix**: startup hanging behind HTTPS proxy when using Bedrock with an SSO profile and `awsAuthRefresh` — credential pre-check now honors `HTTPS_PROXY`
- **Alpine/musl builds**: native image paste, clipboard, and audio-capture add-ons now load on musl-built binaries instead of being refused by the runtime
- **Windows cross-session messaging**: `SendMessage` and `ListAgents` now work across Claude Code sessions on different Windows machines, matching macOS and Linux capability

**Source:** https://code.claude.com/docs/en/changelog

### Codex CLI — v0.149.0-alpha.7.1: Stable Feature Wave Lands in Alpha Chain (August 21, 2026)

The v0.149.0 alpha sprint accumulated features from v0.148.0 stable and pushed them into alpha.7.1. Notable additions in this sprint wave:

- **Interactive `/codex agents` dashboard**: search, start, open, rename, and stop tasks from a dashboard with configurable shortcuts — significant shift from single-session tool toward multi-task agent manager
- **`/cd`, `/pwd`, `/cwd` commands**: manage session working directory directly in TUI without restarting
- **`codex queue`**: send messages to existing local or remote sessions, queuing when the target is busy — a long-requested workflow feature
- **`codex doctor` expanded**: now diagnoses endpoint protection, network/proxy failures, desktop app state, and update connectivity
- **SDK improvements**: TypeScript SDK users can pass exact CLI config overrides and select `max` or `ultra` reasoning effort
- **Security documentation**: DNS exfiltration risks and trust limitations for secure devcontainers now explicitly documented
- **Guardian V2 work**: risk scoring, compaction context bounding, thread-per-turn evaluation, and approval routing — the internal safety layer continues to mature
- **New model catalog sourcing**: Guardian V2 defaults now sourced from the model catalog; experimental app-server project APIs added

**Source:** https://github.com/openai/codex/releases

### Cline — v4.1.12: Image Generation, Enterprise MCP Controls, CRLF Fixes (August 21–22, 2026)

v4.1.12 is a desktop-focused patch addressing integration and quality issues:

- **Image generation inline**: models that support image generation now render results directly in the transcript during tasks — ACP clients receive them as image content
- **Enterprise MCP controls**: MCP entries in the Customize marketplace are now hidden when remote config disables the marketplace, and limited to `allowedMCPServers` when an allowlist is configured
- **CRLF fix**: multi-line diff edit view now renders correctly for files with CRLF line endings on Windows
- **Session resumption**: when resuming a task, the surviving session continues rather than rebuilding from the original task text
- **Task settings isolation**: task-scoped settings overlay clears when the task view is cleared or switched — one task's overrides no longer leak into the next
- **@ file mentions fixed**: file path suggestions no longer break on paths containing spaces
- **PowerShell fail-fast**: PowerShell commands now stop at the first pipeline error instead of flooding output and still reporting success
- **Remote config sync**: coordinated refreshes, session gating, and fail-closed opt-out for remote configuration management

## Community Pulse

**Working well:** The `/cd`, `/pwd`, `/cwd` working directory management commands in Codex and the `codex queue` feature for inter-session messaging represent a notable shift — these tools are evolving from single-shot coding assistants toward persistent, multi-session environments. The interactive agents dashboard in Codex alpha and the Agent Manager inspector tabs in Kilo point in the same direction: managing multiple agent tasks simultaneously is becoming a first-class feature.

**Problems:** The release cadence across all tools is accelerating to the point where changelog tracking is becoming a real burden for power users. Claude Code's near-daily releases, Codex's rapid alpha cycling, and Cline's continuous desktop updates mean that by the time someone writes up a release summary, there are already two more releases. Users are increasingly relying on the changelogs themselves as the only source of truth.

**Interesting:** Cline's rename from "Cline Code" back to just "Cline" (v4.1.11 onward, now complete in v4.1.12) signals a deliberate brand narrowing — the "Code" suffix was causing confusion with "Cline Code Beta." The separate Cline Code Beta side-by-side app (from the August 20 report) combined with this simplification suggests Cline is establishing a clear two-track model: stable Cline for daily driver use, and the separate beta app for tracking experimental builds.

---

## Trend

The agentic CLI category is undergoing a structural shift: tools that began as single-session coding assistants are building toward multi-agent, multi-session management paradigms. Codex's interactive `/codex agents` dashboard, Kilo's inspector tabs, and the cross-session messaging capabilities across Claude Code and Codex all point toward these tools functioning less like intelligent command-line utilities and more like persistent agent orchestration environments. The release cadence is also compressing — what once took weeks now takes days, and Claude Code is shipping near-daily.
