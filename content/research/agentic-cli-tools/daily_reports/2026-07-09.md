## Tool Releases — Claude Code Fires Three Releases in 48 Hours

**Claude Code v2.1.205 (July 8, 2026):** Security-focused release. Key addition: an auto mode rule that blocks tampering with session transcript files — a direct response to concerns about transcript manipulation. Auto-update binary downloads now stream to disk, cutting peak memory usage by ~400MB. Improved agent view shows colored state words and classifier-written headlines instead of raw tool call text. `/doctor` is now a full setup checkup that can diagnose and fix issues; `/checkup` is its alias. Reserved "Claude Browser" MCP server name ahead of Claude Desktop rename; user-configured MCP servers can no longer register under either name. 14 additional fixes including Windows crash fixes and background task notification authenticity improvements.

**Claude Code v2.1.204 (July 8, 2026):** Minor fix — hook events now stream correctly during SessionStart hooks in headless sessions, preventing remote workers from being idle-reaped mid-hook.

**Claude Code v2.1.203 (July 7, 2026):** Login expiration warning added so users can re-authenticate before background sessions are interrupted. Grey ⏸ badge now appears in the footer when in manual permission mode, making the active mode always visible. 36+ fixes including Windows stalling on macOS memory false detection, background session token staleness recovery, daemon auto-upgrade failure silently killing sessions, reduced binary size by ~7MB and startup memory by ~7MB. Default permission mode changed to "Manual" across CLI, VS Code, and JetBrains — pressing left arrow no longer closes background tasks/diff/workflow views.

**Kilo:** Experimental AI image generation tool added, enabled via experimental.image_generation in config. Inline image rendering in chat. Project memory controls in VS Code Context settings tab. Reload action reboots per-directory instance without losing session/history. Timeline scrubbing — click a bar to jump transcript to that message. Agent Manager branch naming deferred until conversation shows durable task.

**Cline CLI:** No new releases since v3.0.38 (July 7/8).

**Codex CLI:** No stable releases documented. Alpha sprint continues.
