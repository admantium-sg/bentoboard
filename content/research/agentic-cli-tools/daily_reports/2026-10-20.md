## New Findings (3)

### Claude Code v2.1.304 — Guided Auto-Mode Setup, Stronger Mod Controls, Worktree Safety Fix (October 19, 2026)
246th release of 2026. Adds `/auto-mode-setup`, a guided setup that reads your project and recent sessions to teach auto mode about your environment. Adds `decider: "person"` to a mod's `tool.check` answer — only the permission dialog or a host's callback can approve the ask, refused with the mod's reason where nobody can be asked. Adds `e.isReadOnly` signal to mod hooks. Fixed `claude --worktree` removing the worktree and its branch without asking at exit when HEAD was detached or on another branch — a critical data safety fix. Fixed sandboxed commands failing to start on Linux when a `denyRead` glob contains brackets that are not a character class. Adds transcript line when a plugin that runs first skips one of your mod's hooks. Ships every 1.1 days — 30 releases in the last month.
Source: https://releases.sh/anthropic/claude-code

### Claude Code v2.1.302 — Fork Subagents Default On, Read Tool Image Memory Fix (October 16, 2026)
244th release of 2026. `Claude -p` and Agent SDK sessions with no permission mode now start in default mode on third-party providers or fresh installs. Fork subagents are on by default across CLI, Agent SDK, desktop app, and VS Code. The Read tool no longer loads image files into memory and refuses image sources over 128 MB. Idle compaction can be toggled off from /config. Ships every 1.1 days — 28 releases in the last month.
Source: https://releases.sh/anthropic/claude-code

### October 2026 Stack Overflow Survey: Claude Code at 65.5% Agent Usage Among Developers (October 2026)
Claude Code is used by 65.5% of developers working with AI coding agents per the October 2026 Stack Overflow Developer Survey, up from 10% in the 2025 survey. GitHub Copilot is at 58.7% and OpenAI Codex at 29.5%. Numbers exceed 50% combined because most developers run multiple agents. The 55-percentage-point jump for Claude Code in one year marks the largest market shift since GitHub Copilot's 2021 launch.

## Community Pulse

**Working well:** The `/auto-mode-setup` guided setup in v2.1.304 is a significant UX investment — it learns from project structure and recent sessions to personalize auto mode behavior, directly addressing the friction new users face when adopting agentic workflows. The fork subagents default-on change across all surfaces (CLI, SDK, desktop, VS Code) suggests Anthropic is treating subagents as a first-class capability rather than an experimental feature.

**Problems:** The v2.1.304 worktree safety fix is notable — `claude --worktree` was silently removing branches without asking when HEAD was detached. This is the kind of silent data-loss bug that erodes trust in agentic tools that touch git operations.

**Interesting:** The combination of `decider: "person"` for mod tool checks and `e.isReadOnly` signal suggests Claude Code's mod/plugin ecosystem is evolving toward more granular permission control. The October 2026 Stack Overflow survey data showing Claude Code at 65.5% versus Copilot at 58.7% in a market where both can exceed 50% (because developers use multiple tools) indicates Claude Code has become the preferred primary agent while Copilot retains IDE-integrated inline completion as a complementary tool.

## Trend

October 20 marks the beginning of a new phase: Claude Code is moving from feature expansion toward ecosystem hardening — the mod hook improvements (`decider: "person"`, `e.isReadOnly`, plugin-skip logging) signal that Anthropic is investing in the extensibility layer rather than adding core capabilities. Fork subagents going default-on across all surfaces confirms the architecture is stable. The rapid rise to 65.5% developer adoption in one year (from 10%) suggests the market is consolidating around Claude Code as the terminal-native agent of choice, while GitHub Copilot maintains its IDE-integrated position.
