## New Findings (2026-09-13 to 2026-09-14)

### Cline Desktop — v0.0.27: Credential Reliability, OpenCode Go Fixes, Crusoe Provider (September 13, 2026)
v0.0.27 is the sole new release in the 24-hour window. Key changes: expired Cline sign-in now produces one actionable error instead of a vague bubble stacked on a detailed banner — credential failures now carry a fix button pointing to the right place for each provider type. Cline Pass sign-out now actually works (previously credentials lived under the wrong entry so sign-out was ignored). Settings sidebar "Models" section renamed "API Providers" to reflect its actual purpose. Voice input failures now show a toast with the actual error instead of dropping users into Settings → Voice. OpenCode Go models are fully functional again — a missing routing header (`x-opencode-session`) and catalog normalization that discarded per-model adapter declarations caused Muse Spark, GPT, Grok, MiniMax, and Qwen models to route to the wrong endpoints. Added Crusoe as an OpenAI-compatible provider. Settings switches now use native controls with proper keyboard support, 24px hit area, and accessibility features. Welcome screen animation fixed.

**Source:** https://github.com/cline/cline/releases/tag/desktop-v0.0.27
