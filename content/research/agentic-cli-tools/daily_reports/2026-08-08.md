# Daily Report — Agentic CLI Tools — August 8, 2026

## Tool Releases (Task 1)

### Codex CLI v0.147.0 — Major Stable Release Lands (August 7, 2026)

The alpha sprint is over: **v0.147.0 is now stable**, capping a ~2-week development sprint. This is the most feature-dense release in recent memory, with six major areas:

**Portable Agent Plugins**: Install plugins from local, personal, workspace, and remote catalogs; search across all four. Plugin manifests are now a first-class artifact type.

**Persistent Conversation Sections**: Organize long transcripts into manually ordered, named sections for incremental browsing — a major quality-of-life improvement for extended projects.

**`--approve-for-me` CLI flag**: Enable automatically reviewed approvals via a new CLI flag, removing the manual confirmation step in trusted environments.

**MCP 2026-07-28 support**: Full opt-in support for the July 2026 MCP revision including paginated discovery, multi-round requests, and non-blocking server startup. SDK upgraded to MCP 3.0.0.

**Cursor/Claude import and sync**: Import Cursor-managed skills and synchronize changes to imported Claude and Cursor conversations without creating duplicates.

**Bedrock expansion**: Cached web search and remote conversation compaction now work with Amazon Bedrock.

**Security hardening**: Secrets and bearer tokens redacted from displayed commands and replayed history; plugin isolation hardened; network access denied when policy updates fail; explicit trust required for unfamiliar local projects.

**Other improvements**: Ratatui 0.30.2, V8 150.4.0; macOS notarization secured via Azure Key Vault; deprecated `codex exec --full-auto` removed (use `--sandbox workspace-write`).

### Claude Code — 4 Days of Silence; CVE-2026-54316 Confirmed Patched at Black Hat (August 5, 2026)

Claude Code remains at **v2.1.222 (August 4)** — 4 days without a release, continuing the silence that began August 4 after the double-drop. Meanwhile, Novee Security presented at **Black Hat USA (August 5)** disclosing CVE-2026-54316: Claude Code's command validator stripped single-quoted text before its 23 checks ran, allowing a payload embedded in `git push --receive-pack` (a flag git executes) to reach the CI runner. The attack chained through Hugging Face's public download counter as an exfiltration channel, leaking an API key one character at a time. **Patched in 2.1.163**; all releases from 0.2.54 through 2.1.162 are affected. Anthropic rates it Moderate (CVSS v4 6.0); NVD scored it 9.1 (CVSS v3.1). Neither CVE is in CISA's Known Exploited Vulnerabilities catalog as of August 7. The Claude Code GitHub advisory is at GHSA-fg94-h982-f3mm.

Also notable from the Black Hat presentation: **OpenAI's Codex had no product-version patch** — OpenAI's position is that its sandbox behaved as documented. The fix was a repository-level workflow change separating Codex passes into different jobs with read-only sandbox, plus a documentation update classifying repository instruction files as untrusted input.

The presentation also covered Gemini CLI: CVE-2026-12537 (CVSS 4 score: 10.0) — OS command injection in the container launcher via a crafted `.gemini/.env` file. Fixed in Gemini CLI 0.39.1 and run-gemini-cli 0.1.22.

**Source:** https://thehackernews.com/2026/08/claude-code-and-gemini-cli-flaws-let.html | https://novee.security/blog/critical-flaws-in-anthropic-google-and-openais-coding-agents/

### ChainDrop npm Worm Plants Claude Code SessionStart Hooks in 400+ Packages (August 4–7, 2026)

Pillar Security reported (August 4) that the ChainDrop npm worm — which backdoored 400+ npm packages and 2,212 versions, stealing developer and CI credentials — inserted a **Claude Code SessionStart hook** and a **VS Code folderOpen task** in compromised repositories. The hooks fired when a developer opened the workspace (VS Code) or started a coding agent session (Claude Code), not just during npm install. Three infection points covered the full developer lifecycle: workspace open, agent session start, package install. Microsoft confirmed the ChainDrop details August 4 on its security blog. This is a live, in-the-wild supply-chain attack that specifically weaponized Claude Code's extension hooks.

**Atlas shutdown in 1 day (August 9)**: OpenAI's Atlas browser stops working tomorrow. No Windows/iOS/Android release was ever shipped. Agentic browsing is being consolidated into ChatGPT and Codex directly.

### Community: Security Surface Expanding as a Primary Concern

The Black Hat 2026 disclosures represent a qualitative shift in how the security community views agentic CLI tools. Three distinct attack surfaces are now documented: (1) the model-output harness layer that validates and executes commands, (2) workspace hooks and extension points that fire on developer actions, and (3) supply-chain compromise of the packages agents consume. The ChainDrop/Pillar finding specifically shows that Claude Code's SessionStart hook was a chosen infection vector — meaning the attack was designed around the agent's extension API. Community reaction: this is different from traditional appsec; the blast radius of a compromised package is now measured in agent session compromise, not just developer workstation.
