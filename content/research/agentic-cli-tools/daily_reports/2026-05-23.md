## Community Pulse

**Working well:** Cline's rapid release cadence (5 releases in 3 days) with focus on developer experience — inline question prompts, loading dialogs, concurrent plugin loading. OpenCode's diff viewer GA and Grok OAuth additions show active development momentum.

**Problems:** PowerShell security vulnerabilities in Claude Code (permission bypasses) and Cline's inflated token usage counting bug show that security and correctness remain ongoing concerns in the CLI space.

**Interesting:** DeepSeek TUI's viral trajectory (10K stars in ~4 months) demonstrates independent developers can still break through with single-developer projects. xAI Grok Build entering the market with ACP support and CLAUDE.md compatibility shows the CLI tool ecosystem is becoming a strategic battleground for model providers.
