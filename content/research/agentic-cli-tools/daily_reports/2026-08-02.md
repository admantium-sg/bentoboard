## Tool Releases

### OpenCode v1.18.11 — MCP Reconnection Fixes, Desktop Polish (August 1, 2026)

New stable release fixing MCP and desktop reliability issues:

**Core:** Stopped MCP SSE connections from getting stuck in reconnect loops after server error responses — a significant reliability fix for MCP server integrations. Also fixed provider model configs that use interleaved reasoning fields like `reasoning_text` or custom field names.

**Desktop:** External links now open in the system browser instead of inside the app. Fixed stale session tab state in the desktop title bar, legacy directory picker opening at home folder when no home path is loaded, file tree tab clipping when resized smaller, and debug gutter label/value misalignment.

**Source:** https://github.com/anomalyco/opencode/releases/tag/v1.18.11
