# Daily Report — July 25, 2026

## New Findings (since July 24, 2026)

### Claude Code v2.1.219 — Opus 5 Default, Nested Subagents Deepen (July 24, 2026)

Fresh release shipping 28 changes including a notable default shift for multi-agent workflows:

**Claude Opus 5 now default Opus model:** Added as `claude-opus-5` — 1M context, fast mode at $10/$50 per Mtok. The `/model` picker now highlights only the newest model's name. Opus 4.7 removed from fast mode; `/fast` applies to Opus 5 and Opus 4.8.

**Nested subagents default raised to depth 3:** Subagents can now spawn nested subagents up to depth 3 by default (was depth 1). Set `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=1` to disable nesting. This is a direct response to increasingly complex multi-agent pipelines.

**New `sandbox.network.strictAllowlist` setting:** Denies non-allowlisted hosts for sandboxed commands without prompting — enterprises get a new network isolation knob beyond the binary on/off.

**New `DirectoryAdded` hook:** Fires after `/add-dir` or SDK `register_repo_root` registers a new working directory mid-session.

**MCP server errors in init event:** `mcp_server_errors` now listed in headless stream-json init event for `--mcp-config` entries skipped by validation; terminal runs print a startup warning.

**Dynamic workflows default to medium size:** Now default to "fewer than 15 agents" guideline. Pick "unrestricted" in `/config` for unlimited.

**Nested subagent forwarding in stream-json:** Subagents spawned at depth-2+ now appear when `--forward-subagent-text` is set.

**Multiple fixes:** Permission approved during self-hosted runner restart no longer dropped on resume. Fable model row no longer shows "Requires usage credits" for eligible plans. SIGTERM during runner startup no longer leaves stale active rows. Vim mode ← on empty prompt returns to agent view correctly. Screen-reader mode no longer rewrites entire input line on every keystroke.

**Source:** https://code.claude.com/docs/en/changelog

### Kilo v7.4.16 — Past Chats @mentions, Diff Previews, Tool Approval Explanations (July 24–25, 2026)

Kilo ships a substantial minor release:

**Reference past chats inline with @:** Type @ in prompt to surface a searchable picker of previous sessions (scoped to current workspace/worktree). Selecting one attaches that session's transcript as context so the model can build on prior conversations. Available in CLI TUI and VS Code extension.

**Searchable open-tabs switcher:** New switcher added to sidebar tab bar for quick tab navigation.

**Show why tools auto-approved:** Expanding a tool call now explains whether it ran automatically or after your approval, and which rule allowed it — from your agent, project config, global config, or auto-approve (YOLO) mode.

**Expandable diff previews:** Edit, write, and apply-patch tool results now render as expandable diff previews with clickable file links, change counts, syntax-highlighted diffs, and clearer multi-file patch sections.

**Session performance for large transcripts:** Improved performance for sessions with large transcripts.

**JetBrains CLI pin update:** Updated to Kilo Core 7.4.15.

**Source:** https://github.com/Kilo-Org/kilocode/releases

### Crush v0.87.0 — MCP OAuth, Claude Channels, LSP/Bang Performance, /etc/crush/crush.json (July 21–24, 2026)

Major Crush release featuring community-driven contributions:

**MCP OAuth:** Long-requested OAuth 2.1 support for HTTP MCP servers — required for some MCPs to function. Community contribution from @joestump and @taciturnaxolotl.

**Claude Channels MCP extension:** Initial implementation supporting the Claude Channels MCP extension (code.claude.com/docs/en/channels-reference) — MCPs can now send notifications to Crush when certain events happen.

**LSP performance boost:** @TheJhyeFactor vastly improved CPU and memory usage when handling LSP servers in large repositories. See PR #3370 for technical details.

**Bang mode performance boost:** Same contributor improved output streaming performance in bang mode. See PR #3381 with benchmarking data.

**System-wide config at /etc/crush/crush.json:** System-wide Crush configuration for NixOS and multi-user compatibility. Contribution from @Muttaqin86.

**Fixed Copilot + GPT-5.6:** All three GPT-5.6 models (Sol, Terra, Luna) now fixed when running via GitHub Copilot.
