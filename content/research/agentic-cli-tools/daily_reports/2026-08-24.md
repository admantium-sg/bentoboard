### Cline — v4.1.15: MCP Auto-Approve Fix; v4.1.14: Model Catalog Explosion (August 23–24, 2026)
Two releases in 24 hours:

**v4.1.15:** MCP toggle fix — the "Use MCP servers" toggle now properly auto-approves all MCP tool calls when enabled. Previously it only worked for tools individually opted in, making the toggle appear broken. Task completion telemetry restored for interactive sessions.

**v4.1.14:** Model catalog refresh adds Claude Fable 5, Grok 4.6 on Vertex, DeepSeek V4 Flash variants (including vision preview), MiMo v2.5, Qwen3.8 27B, Gemma 4 26B, LongCat 2.0, Nemotron 3.5 Lightning, and Thinking Machines' Inkling. Hub session resilience improved: reconnecting clients replay missed events with deduplication. Langfuse traces now carry session identity for hub-backed and delegated-agent runs.

**Source:** https://github.com/cline/cline/releases

### Kilo — v7.4.23: PR Review Overhaul, Agent Manager Inspector Tabs, NVIDIA STT (August 20–24, 2026)
Major release with extensive PR workflow improvements and multi-agent visibility:

**PR Review comments overhaul:** Resolved threads collapse into one-line rows in a Resolved group; structured review comments with Send to agent, Resolve, Copy, Open file, and Open on GitHub actions; single button sends all unresolved comments; comments arrive as structured data rather than pasted text.

**Delegated subagent sessions** now open in Agent Manager inspector tabs alongside terminals — better visibility into multi-agent workflows.

**NVIDIA Parakeet TDT 0.6B v3** as default speech-to-text model with dynamic discovery and offline fallback.

**JWT share tokens** now accepted on Kilo share URL imports.

Performance optimizations for Agent Manager tab switching, context transition, large session loading, and reactive re-renders.
