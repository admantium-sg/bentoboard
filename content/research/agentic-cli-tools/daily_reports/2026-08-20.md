## New Findings (4)

### Claude Code — v2.1.236: Cross-Session Idle Notifications, macOS Sandbox Hardening
30+ changes continuing the recent reliability push. `ANTHROPIC_DEFAULT_MODEL` env var sets the default model for new sessions. Cross-session `SendMessage` now supports `notify_when_idle` — ask another Claude Code session on this machine to send one notice when it next goes idle, opt-in and one-shot with no polling (macOS and Linux). macOS sandbox hardening: wildcard read-deny rules (e.g. `**/.env`) now take precedence inside allowed read regions and cannot be bypassed by renaming the denied file. Fixed: clipboard copy/background housekeeping/cloud sessions breaking after session directory deletion; fullscreen renderer failing permanently after single failed start; `/model` picker rendering taller than the terminal; self-hosted runner sessions resuming on wrong runner. Improved auto mode: `Monitor` allow rules set aside while auto mode active. `/usage` now shows usage-credits spend for Team and Enterprise. VSCode: screen reader support for transcript with live announcements.
**Source:** https://code.claude.com/docs/en/changelog

### Codex CLI — v0.149.0 Alpha Sprint Begins; Two Alpha Tags Land
New development cycle: v0.149.0-alpha.1 and alpha.2 now live following v0.148.0 stable release. Features: `/export` for Markdown conversation export, `codex exec fork` for session forking, session archiving/restoring from TUI resume picker, estimated thread credits in `/status` and terminal titles, Amazon Bedrock Runtime as built-in provider with GPT-5.6 routing, async hooks that can invoke MCP tools. Model switches no longer leave stale instructions. Sandbox fail-closed for denied paths on Linux and Windows.
**Source:** https://github.com/openai/codex/releases

### Cline — Desktop v0.0.14: Voice Input, Cloud Sessions Preview, Cline Code Beta
Voice input: dictate into composer with microphone button transcribed by configured provider model. Cloud sessions (preview): run sessions in Cline's cloud, connect GitHub, hand off between devices with transcripts/approvals/queued prompts in sync. Model-driven image generation renders inline. Redesigned question prompts with explicit option selection, button submission, and keyboard shortcuts. Finished agent runs collapse into single expandable summary. New "Cline Code Beta" app installs side-by-side tracking experimental branch. Early proof-of-concept for SSH remote environments.
