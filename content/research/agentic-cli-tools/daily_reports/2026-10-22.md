### Claude Code v2.1.306 + v2.1.307 — Two Releases in One Day, Safety Telemetry Event, MCP Duplicate-Call Fix
248th and 249th releases of 2026. v2.1.306 fixed `claude -p` inside cloud sessions falsely reporting "Not logged in" when started without the session's environment variables, and fixed an API error being masked as "prompt is too long" plus an unnecessary compaction in sessions with many MCP tools. v2.1.307 added `/claude-api api-version` to move Claude API code to API version 2026-10-21, and added a new `claudecode.safetyevent` OpenTelemetry event emitted for every tool call that a permission rule, auto mode, a safety check, a hook, or the sandbox stopped, prompted, or sent back. v2.1.307 also fixed HTTP MCP tool calls being sent twice when the connection closed mid-call (only read-only or idempotent tools are now retried), MCP servers reported as timed out after macOS/Linux sleep, MCP servers showing "needs authentication" while the macOS login keychain was locked, "Autocompact is thrashing" errors on turns reading many PDFs/images, and Agent SDK model switches being refused when the API took more than 5 seconds to confirm (now 15 seconds). Ships every 1.4 days — 25 releases in the last month.

### Antigravity CLI v1.4.4 — Auto Mode Comes to Windows 11 24H2+, Combined Per-Turn Diffs
72nd release of 2026. Auto mode now runs on Windows 11 version 24H2 and later for personal Google Accounts, selectable via `--mode auto`, Agent Mode in /config, Shift+Tab, or Remote Control Settings (Agent remains the default). /diff gains a whole-file toggle (f) and hunk folding (Ctrl+O) in Commit Tree and Per Turn views, and Per Turn diffs are consolidated so multiple edits to one file in a turn show as a single combined diff. Adds `meta["antigravity.google/rootconversationid"]` to MCP tools/call requests so MCP servers receive the top-level conversation ID even from nested subagents. Auto mode's sandbox-escape review now includes the assistant's preceding question on short replies like "yes", checks every subcommand in pipelines, and prompts before destructive Git or file commands. `agy plugin validate` gained stricter checks. /compact now retains tool declarations on summarization requests so the model API reuses its cached prompt prefix. Fixed subagents losing plugins inherited from the parent session. Ships every 1.4 days — 21 releases in the last month.
Source: https://www.havoptic.com/r/antigravity-cli-1.4.4

## Community Pulse

**Working well:** Permission ergonomics were the theme across three of the four major tools on October 21. GitHub Copilot CLI v1.0.102 made subagents honor custom and MCP tool approvals, killing duplicate permission prompts — a direct fix for the multi-agent friction that also plagued Claude Code. Antigravity CLI v1.4.4 made Auto mode's sandbox-escape review context-aware (it now includes the assistant's preceding question on short replies like "yes" and checks every subcommand in a pipeline), and Claude Code v2.1.307 shipped a `claudecode.safetyevent` OpenTelemetry event so teams can finally measure how often the permission layer fires. Zed v1.25.2 separately closed a real security hole: env vars and secrets passed to external agents and MCP servers in remote projects were visible in the local process list.

**Problems:** The auto-mode classifier remains the ecosystem's weakest link, and it is now load-bearing. A GitHub issue reports auto mode silently refusing to launch subagents with permission changes ignored — a dead end with no escape hatch. This lands in the same week that fork subagents became default-on across Claude Code's CLI, SDK, desktop app, and VS Code, and that Antigravity enabled Auto mode on Windows. Meanwhile Hermes shipped three releases in eight days with a mislabeled build (v0.22.1 was built from the wrong commit) and sessions stranded on a gateway that can no longer delete them — release hygiene is lagging feature velocity.

**Interesting:** Copilot in VS Code v1.143's side-by-side model comparison is the first mainstream move toward harness-agnostic agent evaluation: users pick two or more models *and* harnesses (Copilot, Claude, Codex) to attack the same task in parallel and merge the ideas. Read together with Zed enabling ACP session notices and context compaction for external agents, the IDE layer is shifting from hosting a single vendor's agent to hosting a marketplace of them — and shipping the observability primitives to compare them fairly.

## Trend

October 21 was a coordinated release day across the ecosystem: Claude Code, Antigravity CLI, GitHub Copilot CLI, GitHub Copilot in VS Code, Zed, and Factory Droid all shipped on the same date. The unifying theme is permission and safety telemetry — every major tool shipped work in the same three areas (auto-mode classifier behavior, subagent approval inheritance, and OpenTelemetry exposure of stopped/prompted tool calls). That is not coincidence; it reflects the same underlying pressure, which is that autonomous agents have outgrown the "ask the user" model and vendors are building the audit layer around it. The second thread is the opening of the harness marketplace: Copilot in VS Code making the Copilot SDK harness the default while adding cross-harness model comparison, and Zed bringing ACP session notices to external agents, together suggest the IDE is becoming a multi-agent host rather than a single-vendor surface. Funding data remains unchanged — Gravity Fast's tracker is still at $872.5M across 5 disclosed Q4 rounds, with a data cut-off of October 16.
