# Daily Report: Agentic CLI Tools — August 13, 2026

## Summary

Active development across all major tools. Claude Code shipped 8 releases in 9 days (v2.1.221–228), Codex stabilized v0.147.0 and moved into v0.148.0 alpha, Kilo deepened Agent Manager with keyboard UX overhaul and model search improvements.

---

## Tool Releases & Features

**Claude Code** — 8 releases since Aug 4, now at **v2.1.228 (Aug 11)**. Notable: long-standing skills shadowing bug fixed (claude.ai-synced skills no longer override local commands); sandbox credential masking gains JWT-aware and AWS SigV4 options; self-hosted runner support for Team/Enterprise; 200-subagent per-session cap removed; `/review` now an alias of `/code-review` with `ultra` option for cloud reviews; `archive` plugin source for zip-over-HTTPS install with SHA-256 pinning. v2.1.224 also introduced cross-session SendMessage between machines.

**Codex CLI** — **v0.147.0 stable landed Aug 7**: portable agent plugins (local/personal/workspace/remote catalogs), persistent conversation sections, `--approve-for-me` flag, Cursor/Claude import sync, MCP 2026-07-28 with paginated discovery, Bedrock cached web search. **v0.148.0-alpha.9** is the current pre-release.

**Kilo v7.4.21** — Agent Manager keyboard overhaul (Cmd+/ focuses terminal, Cmd+Shift+[ / ] switches tabs), provider-aware model search with personalized suggestions, multi-project worktree repo picker, nested /review in VS Code with staged/unpushed/quick modes, pre-session model catalog browsing, JetBrains editor context in prompts.

## Community Pulse

**Working well:** Claude Code's removal of the 200-subagent spawn cap and the skills-shadow fix are being well-received — the latter was a long-reported pain point where remote skills would silently override local commands. Cross-session messaging between machines (v2.1.224) enables a new class of multi-machine workflows.

**Problems:** MCP OAuth on macOS still causing intermittent 401 bursts after keychain timeouts (partially fixed in v2.1.225). Windows path corruption for `\u`-prefixed segments (e.g., `C:\Users\unicorn`) was a persistent issue until v2.1.218 — users on affected paths should verify.

**Interesting:** The `/review → /code-review` aliasing in v2.1.223 suggests Claude Code is standardizing its command surface toward explicit naming. Codex's removal of the deprecated `codex exec --full-auto` flag signals the sandbox flags taxonomy is stabilizing.

## Market & Funding

July 2026 closed with 12 disclosed agent rounds worth ~$630M (Gravity tracker). Three patterns:

- **Infrastructure picks-and-shovels** remains the largest category: Prime Intellect $130M Series A (compute + RL frameworks + eval tooling for enterprises building own agents; $100M ARR run rate with Ramp/Zapier)
- **Agent governance** emerged as a fundable category: Neo Security $100M (Bessemer + a16z), Act Security $60M, Hush Security $30M — collectively $190M in 11 days betting the permission-control layer matters as much as the agents themselves
- **Agent payments** as standalone category: Natural $30M Series A (agent orchestration for moving/storing funds autonomously, competing with Stripe)

No August rounds reported yet.

---

## Trend

The CLI agent space is consolidating its feature surface around a stable set of primitives (subagent concurrency, sandbox isolation, cross-session messaging, credential masking) while the ecosystem differentiates on UX (Kilo's keyboard-first Agent Manager) and interoperability (Codex's Cursor/Claude import, MCP 2026-07-28 support). The three-layer funding pattern — infrastructure, governance, payments — reflects a maturing market where the agents themselves are no longer the novel bet.
