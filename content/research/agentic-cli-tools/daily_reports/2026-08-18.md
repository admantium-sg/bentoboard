# Daily Report — August 18, 2026

## New Findings

### Claude Code — v2.1.234: Auto Session Continuation, GitLab MR Badges, Security Hardening (August 17, 2026)

46 changes in the latest release, a quieter week-over-week compared to the four-release sprint that closed last week. Key additions:

**Session continuity:** Claude Code now continues sessions automatically when a claude.ai usage limit resets — turn it off in `/config`. Account email is now used only for identity, not sent to unrelated services.

**GitLab merge request badge:** Repos with a GitLab remote and authenticated `glab` CLI now show MR `!N` with draft/pending/green states in the footer and statusline — GitLab MR integration now mirrors the existing GitHub PR badge.

**NT-namespace path hardening (expanded):** The Windows NTLM credential-leak fix that blocked `\\??\` device-prefixed paths in specific tool paths is now extended across all pre-approval file accesses: remote file reads, session restore, `CLAUDE.md` includes, workflow scripts, and file uploads.

**Auto mode compaction regression fixed:** Auto mode was repeatedly re-checking and denying sandboxed command network access after conversations were compacted — fixed.

**Background subagent permissions fixed:** Session-scoped permission answers (including denies) were being dropped when answering background subagent tool permission prompts — fixed.

**Performance and UX:** Auto-generated session titles now read as short specific names ("Login button bug") rather than sentence restatements ("Fix the login button on mobile"). Built-in `claude-api` skill now loads at ~25k tokens instead of ~200k+ by fetching reference docs on demand. `/goal` now checks in on background tasks after 30+ minutes of waiting instead of waiting indefinitely.

**Esc key refinement:** Pressing Esc no longer clears mouse text selection — it interrupts or dismisses as usual and the selection stays highlighted.

**Source:** https://code.claude.com/docs/en/changelog
