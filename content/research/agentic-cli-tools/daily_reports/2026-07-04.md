## New Findings

### Claude Code v2.1.200 — July 3, 2026

**Permission mode defaults to "Manual".** Changed the "default" permission mode to "Manual" across the CLI, `--help`, VS Code, and JetBrains. `AskUserQuestion` dialogs no longer auto-continue by default — users must opt into an idle timeout via `/config`.

**Background session reliability sprint.** Multiple critical fixes: sessions no longer silently stop mid-turn after sleep/wake; daemon handover prevents older builds from taking over; stale `daemon.lock` PIDs properly cleaned.

**Rate-limit subagent fix.** Subagents cut off by a rate limit before producing any text output now fail cleanly with an error instead of returning an empty result.

**Accessibility improvements.** tmux 3.4+ rendering flicker fixed via synchronized terminal output; screen-reader output improved with decorative glyphs hidden and transcript symbols labeled.

**Source:** https://code.claude.com/docs/en/changelog

---

### Claude Code v2.1.199 — July 2, 2026

**Stacked slash-skill invocations.** `/skill-a /skill-b do XYZ` now loads all leading skills (up to 5), not just the first.

**SSL/TLS proxy errors now actionable.** Certificate errors (TLS-inspecting proxies, expired certs) now fail immediately with fix hints instead of burning retries.

**Streaming resilience.** Responses discarded on mid-stream server errors now keep partial output with an incomplete-response notice.

**Subagent partial-work recovery.** Subagents cut off by rate limits now return partial work to parent instead of silently failing.

**Background agent daemon crash cycle fixed.** Linux daemon no longer kills itself and all agents every ~50 seconds after unclean shutdown.

**Source:** https://code.claude.com/docs/en/changelog

---

### Cline CLI v3.0.35–36 — July 2–3, 2026

**ClinePass enabled for all CLI users.** Provider now available in CLI (not just VS Code extension).

**Tencent TokenHub provider added.** New provider via SDK v0.0.55.

**Plan mode switch_to_act_mode fix (v3.0.36).** Critical — switching to Act mode now immediately ends plan-mode run and continues with the approved plan. Previously the model kept running with plan-mode tools and edited files through shell commands.

**Source:** https://github.com/cline/cline/releases

---

### Kilo v7.4.0–1 — July 2–3, 2026

**Auto branch naming.** Agent Manager branches get task-focused names once conversation establishes a workstream.

**Memory and session fixes.** Free webview memory for deleted sessions; session sync reliability improved; slow message loading fixed.

**AWS Bedrock SSO fix.** VS Code extension Bedrock requests now work with SSO/credential chain.

**Read-only bash security fix.** Closed escape where allowed commands could run arbitrary programs via flags (`sort --compress-program`, `rg --pre`, etc.).

**Source:** https://github.com/Kilo-Org/kilocode/releases
