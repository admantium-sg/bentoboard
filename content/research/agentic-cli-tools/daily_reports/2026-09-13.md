### Claude Code — v2.1.269: Plugin Eval, Output Styles, Workflow Concurrency (September 11, 2026)
v2.1.269 added `claude plugin eval` to run a plugin's eval suite against Claude Code with scored, reproducible JSON and HTML reports. New `/output-style [name]` lists and switches output styles including over Remote Control and headless sessions. Bash edit diffs show a diff when the Bash tool handles file edits (`bashEditDiffEnabled` setting). `CLAUDE_CODE_WORKFLOW_MAX_CONCURRENT_AGENTS` raises the Workflow tool's per-run concurrent agent limit (1-256). Also fixes a deny-rule bug where rules starting with `!` applied beyond the settings source that wrote them. This was the 214th Claude Code release of 2026.

**Source:** https://www.havoptic.com/r/claude-code-2.1.269

### Claude Code — v2.1.268: Critical Security — Deny Rules Bypassed (September 10, 2026)
The most critical release of the week: two cases where deny rules were silently bypassed were fixed. (1) Paths going through symlinks: deny/ask rules on symlinked directories (`/etc`, `/tmp`, `/var` on macOS; `/bin` on Linux) did not apply when the path was given by its real location, and Bash commands ignored deny rules written against symlinked path spellings. (2) Lines containing `env -C` or `eval`: a Read or Edit deny rule could fail to apply when the permission checker couldn't analyze a command on the same line. Also fixed: `/mcp`, `claude mcp list`, and MCP login errors printing secrets resolved from `${VAR}` placeholders in MCP configs; plugin/marketplace errors showing tokens/passwords from git source URLs; HTTP 400 on third-party Anthropic-compatible endpoints (ANTHROPIC_BASE_URL); WebFetch hanging forever on servers that never close the response (now fails after 300 seconds).

**Source:** https://www.havoptic.com/r/claude-code-2.1.268

## Community Pulse

**Working well:** The weekly release cadence across all major tools remains impressively consistent — Grok Build ships every 0.9 days, Claude Code every 1.1 days, Antigravity CLI every 1.8 days. The security fixes across Claude Code (deny-rule bypasses, secret leakage from `${VAR}` placeholders), Gemini CLI (SSRF in MCP OAuth, fail-closed workspace trust), and Codex CLI (trust handling, macOS sandbox input injection) suggest a coordinated industry push to harden agentic tools against permission and credential leakage. The new Cline v0.0.26 GitHub PR integration was highly requested — developers can now see PR status, CI checks, and merge readiness directly in the tool.

**Problems:** The deny-rule bypass vulnerability in Claude Code (affecting v2.1.268 and earlier) was serious — organizations relying on deny rules to protect `.env` files or credentials may have had those protections silently fail. The v2.1.265 through v2.1.267 regression cycle (with the same-day v2.1.265 → v2.1.266 hotfix) shows the cost of rapid release velocity. The `codex mcp-server` removal in v0.154.0 is a breaking change that will catch some users off guard. The Antigravity CLI September 3-5 third-party tool suspensions remain an open concern for users who rely on multi-tool workflows.

**Interesting:** Claude Code v2.1.269's `claude plugin eval` is a significant addition — reproducible, scored plugin evaluation as a built-in command could become a standard part of plugin development workflows. The new `/output-style` command that works over Remote Control and in headless sessions hints at growing enterprise use cases where Claude Code runs in CI/CD and cloud environments. Grok Build's "Dock Watchers and Loops" showing next run times suggests a scheduling/automation feature becoming a competitive differentiator.
