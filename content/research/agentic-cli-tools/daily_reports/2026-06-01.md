### Cline CLI v3.0.15 (May 29, 2026) — Cline Hub, Global Rules, Discord Connectors

Major feature release:
- **Cline Hub**: New web app for monitoring connected clients, viewing and driving sessions, streaming assistant output, and restarting the local hub. LAN and tunnel usage gated by room secret.
- **Global AGENTS rules**: Agent rules can now be applied across all sessions, not just per-project.
- **Discord connector improvements**: Sessions bound to individual message authors (no more shared chat state), participant mute via mentions or user IDs.
- **OAuth URLs now clickable** in the TUI.
- **Model catalog refresh**: Added Claude Opus 4.8, Moonshot Kimi K2.6, and Qwen3.7 Max (with cache support).
- **Symlink-aware skill discovery** including circular symlink handling.
- **New models via SDK**: DeepSeek V4 Flash and Pro, GPT-5.5 on SAP AI Core, Gemini 3.5 Flash on both Gemini and Vertex providers.

**Source:** https://github.com/cline/cline/releases

### Kilo v7.3.x (May 28-29, 2026) — JetBrains Plugin GA, Mercury Next Edit

Significant releases ahead of v7.3 stable:
- **JetBrains plugin initial release**: Native Kilo Code tool window for JetBrains IDEs. Chat sessions with streamed responses, tool output, reasoning, markdown, todos, and plan follow-ups. Local and cloud session history with search. Bundled Kilo CLI runtime for macOS, Linux, and Windows.
- **Mercury Next Edit**: Multi-line edit prediction beyond cursor including off-cursor and pure-insertion edits. Tab-to-jump / Tab-to-apply workflow. Available via Kilo Gateway (no separate Inception API key required).
- **Agent Manager tool available by default** in VS Code.
- **DeepSeek promoted** to Popular Providers list (replacing GitHub Copilot).
- **Inline session rename** via chat header and History panel.

**Source:** https://github.com/Kilo-Org/kilocode/releases

## Community Pulse

### Microsoft/Claude Code: The June 30 Deadline Is Now ~30 Days Away

Microsoft's decision to cancel Claude Code licenses for Experiences + Devices engineers (June 30 cutoff) is now in its final month. The framing — "benchmarking-then-convergence" via EVP Rajesh Jha — positions this as Microsoft preferring a tool it can shape directly with GitHub over an external vendor's product. However, the wider Microsoft-Anthropic relationship (Foundry, Copilot Cowork, Azure quotas) remains intact.

Community sentiment: mixed. Claude Code is reportedly popular internally, and some benchmarks appear to favor it over Copilot CLI on real engineering tasks. The forced migration asks engineers to give up a preferred tool for a Microsoft-controlled roadmap and billing path.
