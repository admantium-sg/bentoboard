## Summary

Five major new developments: four Claude Code releases (Aug 6–10) with enterprise self-hosted runners and cross-session messaging as the headline features, Codex CLI v0.147.0 with portable agent plugins and native conversation organization, the Atlas browser shutdown (Aug 9), OpenAI's new Daybreak cybersecurity tier (Aug 10), and a Kilo pre-release with JetBrains IDE improvements and Claude/Codex session resumption.

## New Findings

### 1. Claude Code — Four Releases, Aug 6–10 (v2.1.221 through v2.1.227)

**v2.1.224 (Aug 7) — MAJOR: Self-Hosted Runners and Cross-Session Messaging**
- **Self-hosted runners**: `claude self-hosted-runner` lets Team and Enterprise plans run Claude Code sessions on their own machines or containers — web, mobile, and desktop sessions can all connect to self-hosted infrastructure. Major enterprise deployment flexibility.
- **Cross-session SendMessage**: Claude Code sessions can now message each other across any of your machines via `ListAgents` for discovery and `SendMessage` for inter-agent communication — sessions no longer siloed.
- **Sandbox credential masking options**: `extract`, `onExtractNoMatch`, `decode: "jwt"` with `maskClaims`, `awsPairs`/`sigv4` for AWS SigV4 re-signing — enterprise-grade credential isolation.
- **Removed 200-subagent-per-session spawn cap**: Long-running sessions can now spawn unlimited agents (concurrency and depth limits still apply).
- **Archive plugin source**: Install plugins from a zip over HTTPS without git or npm, with optional SHA-256 pinning.

**v2.1.225 (Aug 8) — OAuth Fix, Remote Control by Name**
- Fixed OAuth token bug that broke headless sessions when a stored login's short-lived token replaced the long-lived `CLAUDE_CODE_OAUTH_TOKEN`.
- Fixed MCP OAuth servers on macOS intermittently failing with 401 bursts after keychain timeouts.
- `SendMessage` can now start conversations with Remote Control sessions on other machines **by name** — no longer requires the session to message you first.
- Workspace trust prompt added to `claude agents` for untrusted directories.

**v2.1.227 (Aug 10) — GitHub Action Fix, TUI Rewind Fix**
- Fixed every Bash command failing under `claude-code-action` with `allowed_non_write_users` on GitHub-hosted runners.
- Fixed `/tui` reloading a conversation that had been rewound to before its first message.
- Slash command menu improved: blue now marks only the selected row, matched characters bolded, emoji/accented names keep their glyphs.
- Reduced event-loop stalls on file-not-found suggestions and @-mention checks.

**Impact:** Self-hosted runners address the top enterprise ask — bring-your-own-infrastructure compliance. Cross-session messaging is the missing link for multi-agent orchestration without external orchestration layers. The GitHub Action fix unblocks CI/CD pipelines that many teams rely on.

**Source:** https://releases.sh/anthropic/claude-code | https://code.claude.com/docs/en/changelog

### 2. OpenAI Codex CLI v0.147.0 (Aug 7) — Portable Plugins, Native Organization, MCP 2026

Major release with significant architectural additions:

- **Portable Agent Plugins**: Install portable Agent Plugins from zip over HTTPS, search across local, personal, workspace, and remote plugin catalogs. ([#36544](https://github.com/openai/codex/pull/36544))
- **Conversation organization**: Conversations can now be organized into persistent, manually ordered sections and browsed incrementally — major UX improvement for long projects.
- **Auto-review with `--approve-for-me` CLI flag**: Enable automatically reviewed approvals without manual intervention — streamlines CI/CD and automated workflows.
- **Cursor skill import**: Import Cursor-managed skills and sync changes to imported Claude and Codex conversations without creating duplicates.
- **MCP 2026-07-28 protocol**: Full support for paginated discovery, multi-round requests, and non-blocking MCP server startup. MCP SDK upgraded to 3.0.0.
- **Amazon Bedrock improvements**: Cached web search and remote conversation compaction now work on Bedrock.
- **Security hardening**: Secrets and bearer tokens redacted from displayed commands and replayed history; plugin isolation hardened; unfamiliar local projects require explicit trust.
- **Documentation**: Bundled OpenAI docs skill upgraded with official-source lookup, clearer Codex/model guidance.

**Impact:** The portable plugin system is a significant step toward a unified agentic ecosystem — plugins that work across Codex and Cursor. Conversation organization addresses a top user pain point for long-running projects.

**Source:** https://developers.openai.com/codex/changelog | https://releases.sh/openai/codex

### 3. OpenAI Atlas Browser — Shutdown Aug 9, 2026

Atlas, OpenAI's standalone AI browser, stopped working on August 9, 2026 — approximately 9 months after its October 2025 launch. Atlas never shipped outside macOS in its entire lifespan (no Windows, iOS, or Android).

OpenAI's framing: consolidation rather than abandonment. The company says it is bringing what it learned building Atlas into browser-based agentic capabilities inside ChatGPT and Codex directly, including multiple tabs, downloads, improved navigation, and account login support. ChatGPT Work is positioned as the replacement for complex multi-step, multi-session projects.

Atlas users were advised to export bookmarks and saved pages before the August 9 cutoff.

**Impact:** The Atlas shutdown signals OpenAI's conclusion that standalone agentic browsers can't compete with embedding the capability directly into products users already have open. The agentic browsing wars are now being fought inside ChatGPT and Codex — not as separate browser products.

**Source:** https://aitoolsreview.co.uk/insights/openai-codex-august-2026-updates

### 4. OpenAI Daybreak Blue and Red (Aug 10) — Cybersecurity Tiers

OpenAI introduced Daybreak Blue and Daybreak Red on August 10 — two access tiers for approved defenders in cybersecurity work.

- **Daybreak Blue**: General-purpose security work — vulnerability discovery, secure code review, detection engineering, incident response, malware analysis, patch validation. Uses GPT-5.6 Sol.
- **Daybreak Red**: Authorized penetration testing, red teaming, exploit validation, complex system analysis — uses purpose-trained GPT-5.6 Cyber. Requires separate approval and provisioning.

Both tiers require approved access through Trusted Access for Cyber and apply to a specific identity, workspace/API org, model, and product surface. Work happens in isolated environments with least-privilege permission profiles and Auto-review configured before sandbox boundary crossings.

**Impact:** OpenAI is carving out a specialized cybersecurity segment — distinct from general Codex access. The tiered access model (Blue generalist, Red specialist) mirrors how enterprise security teams actually operate. The separate approval path for Red suggests this is a carefully gated capability.

**Source:** https://learn.chatgpt.com/docs/changelog

### 5. Kilo v7.4.20 Pre-Release — JetBrains IDE Deep Integration

New pre-release focused on JetBrains IDE improvements and cross-editor session support:

- **JetBrains context improvements**: Editor context (active file, open/visible files, selected text, shell context) now included in prompts automatically.
- **Selected text and files as prompt attachments**: Clickable links back to source files and selections.
- **Claude and Codex session resumption**: Can now resume Claude and Codex sessions through Kilo Core's bundled runtime — cross-editor session continuity.
- **Remote CLI file delivery**: Support for remote CLI file delivery in attachment flows.
- **Deferred threshold compaction**: Long-running sessions no longer compact at unsafe points during active tool loops.
- **Kilo Core v7.4.20**: Bumped JetBrains CLI pin to Kilo Core v7.4.20 with upstream OpenCode updates through v1.17.13 and reasoning variant metadata from OpenCode v1.18.11.
- **Speech-to-text models**: Discover available STT models from Kilo Gateway while retaining offline fallback.

**Impact:** Kilo is doubling down on the multi-editor story — not just VS Code anymore. The JetBrains deep integration and the ability to resume Claude/Codex sessions through Kilo Core positions Kilo as an aggregator layer across coding agents and IDEs.

**Source:** https://github.com/Kilo-Org/kilocode/releases

## Community Pulse

**Working well:** Claude Code's self-hosted runners are filling the biggest gap for enterprise deployment — organizations with strict data residency or compliance requirements can now run Claude Code on their own infrastructure rather than relying on Anthropic's cloud. The response in enterprise-focused communities has been notably enthusiastic.

**Problems:** The Atlas shutdown is a reminder that AI products still get killed even when they have real users. Nine months of workflow built around Atlas now needs to be re-engineered into ChatGPT/Codex workflows before the deadline. Some users are reporting difficulty exporting all their data before the cutoff.

**Interesting:** The combination of Daybreak (security-specific Codex tier), the new MCP 2026 protocol (with paginated discovery and non-blocking server startup), and the portable plugin system all point to the same trend — agentic tools are being hardened for enterprise and production environments, not just developer experimentation.

---

## Trend

The past 48 hours confirm a clear bifurcation in the agentic CLI space: the consumer/experimentation layer (Atlas shutting down) is being replaced by enterprise-grade infrastructure (self-hosted runners, Daybreak tiers, MCP 2026 protocol, portable plugins). Claude Code and Codex are both racing to be the platform that enterprises trust for regulated or security-sensitive environments. The next frontier is not capability — both tools have ample capability — it's trust, compliance, and enterprise deployment flexibility.
