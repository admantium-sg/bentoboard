## Detailed Findings

### Codex CLI v0.125.0 Stable Release (MAJOR)

**Source:** GitHub Releases
**URL:** https://github.com/openai/codex/releases
**Date:** April 24, 2026 at 18:00 UTC

**Previous Version:** v0.124.0 (April 23, 2026)
**Current Version:** v0.125.0

**Analysis:**
- This is a **stable release**, following v0.124.0 just 1 day prior
- Demonstrates **accelerated release cadence**: 1 day between major releases (faster than previous 3-day cadence)
- Heavy focus on production-grade architecture and observability features
- Significant improvements to remote session management and permission systems
- Enterprise-grade debugging and deployment capabilities

**New Features:**

1. **Unix Socket Transport for App-Server:**
   - App-server integrations now support Unix socket transport
   - Lower-latency communication for local scenarios
   - More secure than TCP for localhost connections
   - Reduces overhead for app-server plugin system
   - Improves reliability of app-server integration workflows

2. **Pagination-Friendly Resume/Fork:**
   - Improved session state management for large conversations
   - Better handling of resumed sessions and forks
   - Pagination support prevents memory issues with long sessions
   - More reliable session resumption after interruptions
   - Addresses scalability issues with long-running sessions

3. **Sticky Environments:**
   - Environments persist across operations
   - Reduces need for repeated configuration
   - Improved workflow for multi-environment setups
   - Environment state preserved across TUI sessions, user turns, and operations
   - Simplifies complex development workflows

4. **Remote Thread Config/Store Plumbing:**
   - Enhanced remote session architecture
   - Improved thread configuration and storage
   - Better remote session management
   - More reliable remote agent operations
   - Foundation for advanced remote features

5. **Permission Profiles Round-Trip (CRITICAL):**
   - Permission profiles now round-trip across all contexts:
     - TUI sessions
     - User turns
     - MCP sandbox state
     - Shell escalation
     - App-server APIs
   - Consistent permission enforcement across all contexts
   - Prevents permission drift
   - Enterprise-grade security and compliance
   - Addresses production deployment requirements

6. **Model Provider-Owned Discovery:**
   - Model providers now own model discovery
   - AWS/Bedrock account state exposed to app clients
   - Improved provider abstraction
   - More flexibility for enterprise providers
   - Better multi-provider support
   - Foundation for custom model provider integrations

7. **Reasoning Token Usage Reporting:**
   - `codex exec --json` now reports reasoning-token usage
   - Better cost tracking for programmatic consumers
   - Improved observability for usage monitoring
   - Enables enterprise cost management
   - Transparency into reasoning costs vs. completion costs

8. **Rollout Tracing:**
   - Comprehensive rollout tracing across multiple dimensions:
     - Tool boundaries
     - Code-mode boundaries
     - Session relationships
     - Multi-agent edges
   - Debug reducer command for inspection
   - Production deployment observability
   - Root cause analysis for deployment issues
   - A/B testing support
   - Gradual rollout management

**Bug Fixes:**

1. **TUI and Review Interface:**
   - Interrupting /review and exiting TUI no longer wedges interface
   - Fixed delegate startup or unsubscribe hang scenarios
   - More reliable TUI cleanup
   - Improved user experience for interrupted operations

2. **Exec-Server:**
   - No longer drops buffered output after process exit
   - Waits correctly for stream closure
   - More reliable output capture
   - Prevents data loss in streaming scenarios

3. **Project Config:**
   - Now respects explicitly untrusted project config
   - No longer auto-persists trust when user specified otherwise
   - Improved security posture
   - Better respect for user security preferences

4. **WebSocket App-Server:**
   - Less likely to disconnect during bursts of notifications
   - Increased outbound buffer capacity
   - More reliable under heavy load
   - Improved scalability for concurrent operations

5. **Windows Sandbox Startup:**
   - Better handling of multiple CLI versions
   - Improved handling of installed app directories
   - Background Start-Process calls avoid visible PowerShell windows
   - Better Windows support and user experience

6. **Config/Schema Handling:**
   - Rejects conflicting MultiAgentV2 thread limits
   - Resolves relative agent role config paths
   - Hides unsupported MCP bearer-token fields
   - Rejects invalid js_repl image MIME types
   - Improved configuration validation and error messages

**Documentation & Chores:**
- App-server docs and generated schemas refreshed for new APIs
- Rollout-trace documentation covers debug trace reduction workflow
- Refreshed models.json for latest model catalog and reasoning defaults
- Windows Bazel CI improvements for cache reuse
- Plugin marketplace internals moved out of codex-core
- Stabilized flaky approval-popup and plugin MCP tool-discovery tests

**Significance:**
- **Production-Grade Architecture:** Permission profiles, rollout tracing, and Unix sockets indicate focus on enterprise deployments
- **Observability:** Reasoning token reporting and rollout tracing provide enterprise-grade observability
- **Remote Session Management:** Sticky environments and remote thread config/store improve remote workflows
- **Security:** Permission profile round-tripping prevents security drift and ensures compliance
- **Accelerated Cadence:** 1-day major releases suggest either rapid iteration or stabilization phase
- **Multi-Provider Support:** Model provider-owned discovery supports enterprise provider ecosystems

   - Replace sticky unavailable cache with retry backoff

4. **Retry Logging:**

   - Improved debugging for retry scenarios
   - Contributed by @iceymoss

5. **Additional Improvements:**
   - Better logs with structured retry fields
   - Fix re-authorization flow not triggering on certain conditions
   - Various UI fixes and improvements

**Community Contributions:**
