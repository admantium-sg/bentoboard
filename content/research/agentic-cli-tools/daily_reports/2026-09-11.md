## New Findings (2026-09-08 to 2026-09-11)

### Claude Code — v2.1.265: Dynamic Plugin Folders, 1 GB Tool Result Cap (September 8, 2026)
v2.1.265 lets you point `--plugin-dir` at a folder of plugins that auto-load child plugins and pick up changes in real-time. Added a 1 GB cap on tool results saved to disk with truncation notices when files exceed the limit. Multiple fixes including resuming foreground-spawned subagents preserving prompt-cache reuse, plugin path symlink bypass on macOS/Linux, and Windows AppContainer sandbox compatibility. This was the 210th Claude Code release of 2026.

**Source:** https://www.havoptic.com/r/claude-code-2.1.265

### Claude Code — v2.1.266: Critical Hotfix — Proxy/Gateway Auth Restored (September 8, 2026)
Same-day hotfix reverted a v2.1.265 regression affecting LLM-gateway and proxy setups. The undocumented `CLAUDECODEUSEGATEWAY` env variable began forcing Cloud-gateway sign-in on its own, breaking configurations that used API keys, `apiKeyHelper`, or custom auth headers. Fixed without requiring configuration changes.

**Source:** https://www.havoptic.com/r/claude-code-2.1.266

### Claude Code — v2.1.267: Effort Level Limits Across All Providers (September 9, 2026)
New `maxEffortLevel` setting (top-level or per-model) caps effort level on every provider including Bedrock, Vertex, and Foundry — giving administrators control over AI compute spend. Added `--system-prompt-snapshot off` to render system prompts fresh on every request for prompt iteration. Cowork scheduled task cloud startup fix. This was the 212th Claude Code release of 2026.

**Source:** https://www.havoptic.com/r/claude-code-2.1.267

### Claude Code — v2.1.268: Unified Gateway Pricing, Network Access Warnings (September 10, 2026)
Claude apps gateway now syncs pricing set in `gateway.yaml` to all Claude Code clients via managed settings — `/cost` and telemetry now match the gateway spend meter exactly. Added startup warning for gateways with empty `accesscontrol.allowcidrs` and one-time warning for first public address request. New `gatewayInternalNetworks` setting for administrators controlling login access. This was the 213th Claude Code release of 2026.

**Source:** https://www.havoptic.com/r/claude-code-2.1.268

## Community Pulse

**Working well:** Claude Code's 1-release-per-day cadence continues with 213 releases year-to-date. The extensibility preview teased in v2.1.261 ("way more extensible — a little crazy, and very exciting") has the community anticipating a major platform play. OpenAI Codex CLI's worktree isolation feature addresses a long-standing pain point for developers managing multiple branches. Cline's loop detection improvements are well-received — silent failures were a major UX complaint.

**Problems:** The same-day v2.1.265/v2.1.266 regression cycle for proxy setups frustrated enterprise users. The v2.1.265 regression broke existing LLM-gateway configurations without warning, requiring an emergency hotfix hours later. Community members note this pattern of rapid releases occasionally introducing regressions that get patched same-day.

**Interesting:** Concurrent releases across all major tools in a 3-day window (Sept 8-10) suggest synchronized development sprints. The GPT-6-Astra model is now appearing across multiple providers (Claude Code via provider support, Codex CLI via Bedrock) indicating a coordinated model rollout.
