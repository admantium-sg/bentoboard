#### New Features

**Core Features**:
1. **`/sessions` Command**: Browse and resume sessions from Agent Manager
2. **`@` Folder Mentions**: Reference folders in prompts, including top-level folder file contents
3. **Everything Mode**: Session-scoped or global permission toggle for users who fully trust their agents, with command-palette off switch
4. **Local Recall**: Agents can search and read past sessions from sibling worktrees and current repo
5. **`@terminal` Mention Support**: Reference terminal output directly in chat and Agent Manager
6. **Run Scripts**: Execute project-specific `.kilo/run-script` from Agent Manager worktrees with Run/Stop controls
7. **Custom Commit Message Prompts**: Override system prompt for AI commit messages
8. **Agent Manager Sections**: Organize worktrees into custom groups with drag-and-drop, color, and collapse
9. **Agent Manager PR Sync**: PR status shown with approved badge checkmarks
10. **Contribute on GitHub CTA**: Easy link to propose new skills, modes, MCP servers

**Upstream OpenCode Integration** (21 versions synced):
- **AI SDK v6 Support**: Improved provider compatibility
- **New AI Providers**: Venice AI and Poe as built-in providers
- **Event-Sourced Session Sync**: More reliable state management
- **Full HTTP Proxy Support**: Complete proxy configuration
- **OTLP Observability Export**: Observability integration
- **Vertex Anthropic Prompt Caching**: Enhanced Anthropic integration on Google Cloud
- **First-Class PowerShell Support on Windows**: Improved Windows experience
- **Windows Stability Fixes**: Terminal keyboard handling, path canonicalization, process management

---

#### Major Bug Fixes

**Critical Issues Resolved**:
1. **Rate Limiting and Quota Handling**:
   - Sessions no longer get stuck on rate limit errors
   - Extension now retries with exponential backoff
   - Shows countdown timer
   - Allows cancel or switch models while waiting
   - Fixed auth state re-evaluation (was leaving users stuck on free model)

2. **Windows Memory Leak**:
   - Fixed native memory leak where `kilo serve` grew to several GB of RAM within minutes
   - Git diff polling now runs directly in extension host instead of CLI subprocess
   - Diff detail view caps per-file reads at 20 MB to prevent memory spikes on large files

3. **Plan Mode Security**:
   - Plan agent can no longer write files outside plan directory
   - Hardened Plan mode permissions and propagated restrictions to sub-agents
   - Strengthened Ask mode with explicit "supersedes" language to stay read-only

4. **Configuration Resilience**:
   - Invalid or incomplete configuration no longer silently breaks extension
   - Skips broken agent/command/skill configs instead of crashing
   - Surfaces schema validation errors with actionable messages
   - Added `kilo config check` command for diagnostics
   - Config warnings surface in TUI and VS Code

5. **Assistant Prefix Errors**:
   - Fixed "assistant prefill" errors when user queues prompt while previous turn is streaming
   - Queued message no longer lands in middle of prior turn's history
   - Next request always ends with user prompt

6. **Sidebar Diff Viewer**:
   - Fixed file tree rendering (previously cramped on single line due to missing styles)
   - Added per-file revert buttons matching Agent Manager
   - Inline diffs now appear in edit/create-file permission prompts

7. **Session Switching Performance**:
   - Made switching between sessions in Agent Manager near-instant
   - Long sessions no longer freeze UI when selected
   - Chat view self-heals if it missed messages while session was in background

8. **Per-Agent Model Selection**:
   - Now respects per-agent model selections when agent has model configured in `kilo.jsonc`
   - Model selection sticks across agent switches and CLI restarts
   - Clear `~/.local/share/kilo/storage/model.json` to pick up newly edited agent default

9. **MCP Tool Call Display**:
   - Show MCP tool call inputs alongside outputs in chat
   - JSON syntax highlighting for both inputs and outputs

10. **Network Resilience**:
    - Sessions pause on network failures and auto-resume
    - `kilo run` reconnects automatically

## Key Insights

### Kilo's Rapid Iteration Strategy

1. **Prerelease Channel Innovation**:
   - Kilo introduced prerelease channel to accelerate feedback loop
   - Users get early access to features; Kilo gets faster validation
   - Stable releases go through prerelease process first
   - This reduces risk while maintaining velocity

2. **OpenCode Foundation Advantage**:
   - 21 upstream OpenCode versions integrated automatically
   - Community work (Venice AI, Poe providers, PowerShell support) benefits Kilo immediately
   - Shared foundation reduces duplicated effort across ecosystem

3. **Community-Led Development**:
   - 188 PRs in single release cycle shows active community
   - Multiple external contributors acknowledged
   - Codebase indexing feature being built by community member

### Bug Fix Focus Indicates Maturity

1. **Critical Infrastructure Fixes**:
   - Windows memory leak (GB growth) is production-blocking issue
   - Rate limiting stuck sessions affects all cloud users
   - Plan mode security issue is trust-critical

2. **Quality-First Approach**:
   - Kilo prioritized fixing issues over shipping new features
   - Addressed feedback from previous week's GA release
   - Configuration resilience prevents silent failures

### Feature Expansion Patterns

1. **Session Management**:
   - `/sessions` command, Local Recall - focus on persistent context
   - Parallel with Cursor worktrees, Codex memory
   - Industry trend: persistent context becoming standard

2. **Trust Controls**:
   - Everything mode for power users
   - Inline diffs in permission prompts
   - Plan mode hardening
   - Addresses user concern about agent autonomy

3. **Developer Experience**:
   - `@` folder mentions, `@terminal` mentions - natural context reference
   - Run Scripts from Agent Manager - workflow automation
   - Custom commit message prompts - integration customization

### Competitive Positioning

- **Kilo vs Cursor**: Kilo emphasizes open-source foundation (OpenCode) and rapid iteration with prerelease channel. Cursor focuses on IDE-native experience and visualizations.
- **Kilo vs Codex**: Kilo's community-driven approach contrasts with Codex's centralized, OpenAI-controlled development. Kilo benefits from OpenCode ecosystem.
- **Kilo vs OpenCode**: Kilo builds on OpenCode as foundation, adding marketplace, skills ecosystem, and VS Code integration. Kilo's 188 PRs show value-add beyond upstream.
