### Claude Code v2.1.218 — Code Review Goes Background, Windows Path Fix, MCP Diagnostics (July 22, 2026)

Full changelog now available:

**`/code-review` runs as background subagent:** Code review work no longer fills your conversation or stacks slash commands — it runs as a background subagent instead. This decouples review latency from the main conversation flow and keeps stacked slash commands accessible while review proceeds.

**Windows path corruption fix:** Paths with `\u`-prefixed segments (like `C:\Users\unicorn`) were being corrupted into CJK characters in tool inputs, making those files inaccessible on Windows. Now fixed.

**MCP connection diagnostics:** `claude mcp list` and `/mcp` now show HTTP status and error text when a server fails to connect, plus a warning for MCP config values with hidden leading or trailing whitespace.

**Skills with `context: fork` run in background by default:** Fork-context skills now background themselves automatically. Opt out per skill with `background: false`.

**Agent hook trust hardening:** Agent frontmatter hooks now require the agent file's own folder to have accepted workspace trust — preventing hooks from untrusted folders from executing.

**Fork-session lineage preserved after compaction:** Fork sessions no longer lose their lineage after compaction in headless and SDK sessions.

**Improved auto mode safety:** Destructive git commands (reset --hard, checkout -- ., clean -fd, stash drop) are now adjudicated by the auto-mode classifier instead of opening permission dialogs.

**Prompt history reliability:** Fixed prompt history entries being dropped or duplicated when history writes raced or failed.

**Remote session heartbeat fix:** Remote sessions no longer continue sending heartbeats after their worker was replaced.

**Source:** https://code.claude.com/docs/en/changelog

## Microsoft Study — First Empirical Evidence: 24% PR Lift, Social Contagion Drives Adoption (July 1, 2026)

A landmark arXiv paper presents the first large-scale enterprise study of CLI AI coding agents, analyzing Microsoft's early 2026 rollout of Claude Code and GitHub Copilot CLI across tens of thousands of engineers:

**Key finding — 24% PR lift persists over 4 months:** Adopters merge ~24% more pull requests than they would have without the tool (95% CI: +14.5% to +33.7%). The gain does not fade out over the study window — in contrast to IDE-based AI tools where productivity surges often attenuate.

**Copilot CLI +24.9% vs Claude Code +11.4%:** Despite external surveys rating Claude Code more favorably for agentic work, Copilot CLI delivered more than 2x the PR lift at Microsoft (p < 0.0001). Researchers speculate on task mix divergence or deeper Copilot/Microsoft engineering integration.

**Social contagion dominant:** Skip-level peer usage (engineers two reporting levels above or laterally) increases first-use odds by up to 216% when over 25% of skip-level peers adopt. Direct manager and reviewer-peer adoption also strongly predictive. Demographic factors (career stage, tenure) negligible relative to social-behavioral predictors.

**Dose-response relationship:** Peak PR lift of +50% in weeks with 5 tool-use days — frequent users disproportionately benefit.

**Implication for rollout strategy:** Organizations should treat visible peer use as central to deployment — not just licensing and infrastructure. Token spend may be justified by throughput gains, though PR quantity ≠ business value.

**Source:** https://arxiv.org/abs/2607.01418 | https://www.emergentmind.com/papers/2607.01418

## Trend Analysis

The Microsoft study provides the first hard enterprise data point: CLI agents deliver persistent ~24% throughput gains with social contagion as the dominant adoption driver. This has direct implications for how these tools spread — visible peer use matters more than marketing or IT rollout.

The social contagion finding is particularly significant for open-source tools (Cline, Kilo) that lack enterprise sales teams. Their growth may depend more on developer communities and visible internal champion adoption than traditional enterprise sales cycles.

Meanwhile, Claude Code's steganography allegations and Alibaba ban represent the most serious trust crisis the tool has faced. The fact that adoption metrics remain strong despite these concerns suggests either limited awareness among individual developers or genuine value that outweighs enterprise risk perception.

The high alpha velocity on Codex CLI v0.146.0 suggests OpenAI is preparing a significant stable release. Combined with the Microsoft study showing Copilot CLI's outperformance, the competitive dynamics remain intense.
