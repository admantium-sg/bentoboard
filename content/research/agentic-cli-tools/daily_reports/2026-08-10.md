## New Findings

### 1. OpenCode — v1.18.11 + v1.19.x With Azure Fix, xAI Login, RTL, Community Contributions (August 7–10, 2026)

Kilo's bundled OpenCode upstream moved to v1.17.13 with reasoning variant metadata from v1.18.11. Standalone OpenCode releases across the same window added: **Azure GPT-5.5+ completion requests fixed for reasoning-enabled setups**; **xAI login simplified to a single device-code flow** that works better in headless and remote environments; right-to-left layout improvements across desktop tabs, drawers, resizing, and titlebar; community-driven translation expansion; reduced markdown parsing off the main thread for desktop responsiveness; and blob attachment loading fixes for the web UI. Three community contributors merged patches.

**Impact:** Azure enterprise users running GPT-5.5+ with reasoning can now use OpenCode reliably; headless xAI setups are significantly less painful.

**Source:** https://github.com/anomalyco/opencode/releases

### 2. Cline v4.1.7 + Desktop v0.0.11 — Queue Durability, OAuth MCP, Clipboard Paste (August 9–10, 2026)

Two releases since the Aug 9 check. **v4.1.7** (CLI/SDK): prompts queued during an interrupted turn now survive aborts — preserved across user-initiated stops and drained after a turn aborts itself; session context stays durable across aborts and hub restarts; queued turns that fail now report as `run.failed` instead of completing silently; hung MCP servers no longer block session creation (unconfigured stdio servers get a 30-second initialize budget); LiteLLM requests route through Chat Completions instead of the Responses API, fixing calls against LiteLLM proxies; network interruptions mid-stream before any model output are now retried instead of failing the turn.

**Desktop v0.0.11**: View Changes button on completion rows now backed by SDK checkpoints; copy button restored on turn-final response rows; clipboard images can be pasted straight into the composer; folder picker reports failures with manual path fallback; existing sessions no longer overwrite your selected model.

**Impact:** Cline's abort/resume story is now solid — queued work survives interruption, and session state persists across hub restarts. The LiteLLM proxy fix resolves a known compatibility blocker for self-hosted model setups.

**Source:** https://github.com/cline/cline/releases

### 3. Claude Code — Screen Reader Mode, MCP Artifacts, Session Caps, Corporate Launcher (August W29/W30)

The late-July/early-August changelog entry (W29/W30) brings major quality-of-life additions: **Screen reader mode** replaces the visual terminal with plain labeled lines readable by VoiceOver/NVDA — toggled per-session with `--ax-screen-reader`, per-shell via `CLAUDE_AX_SCREEN_READER`, or globally via `axScreenReader` setting. **MCP connectors in Artifacts**: published artifacts can now call MCP connectors live on each view using the viewer's own connections, enabling dashboards with real-time data instead of snapshots. **Session caps**: WebSearch calls and subagent spawns each default to 200 per session (`CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION`, `CLAUDE_CODE_MAX_SUBAGENTS_PER_SESSION`) — stops runaway loops. **Corporate launcher**: `CLAUDE_CODE_PROCESS_WRAPPER` or `processWrapper` setting wraps Claude Code's child processes through a required external executable — key for enterprise managed device requirements. `/fork` now copies the conversation into a new background session with its own Agent Manager row.

**Impact:** Accessibility users get a first-class terminal-free experience; enterprises with strict process-wrapping requirements (MDM, security tooling) can now run Claude Code compliantly.

**Source:** https://releasebot.io/updates/anthropic/claude-code | https://code.claude.com/docs/en/whats-new/2026-w29

### 4. July 2026 AI Agent Funding — $630M Across 12 Rounds (Updated Tracker, August 1, 2026)

The Q3 2026 funding tracker is updated. July closed with 12 disclosed rounds totaling ~$630M. Key categories: picks-and-shovels infrastructure (Prime Intellect $130M Series A, selling compute + RL frameworks + eval tooling to enterprises); agent governance (Neo Security $100M, Act Security $60M, Hush Security $30M — $190M in eleven days betting the control layer is defensible); and agent payments emerged as a funded category. Notable: Lyzr's $100M Series B was raised in part by its own agent SivaClaw managing the fundraising process. Concentration remains extreme — OpenAI and Anthropic took 43% of all H1 2026 venture funding.

**Impact:** Finished agents face investor skepticism; infrastructure and governance layers are attracting nine-figure checks. The governance sub-category is now clearly a fundable company category.

**Source:** https://gravity.fast/blog/ai-agent-funding-tracker-q3-2026/

### 5. Agentic AI Enterprise Stats — 78% Fortune 500 Adoption, 88% Pilot Failure Rate (2026)

New enterprise adoption data from Axis Intelligence: 78% of Fortune 500 companies have adopted agentic AI; market size at $89.6B; ROI measured at 540%. However, 88% of pilots never reach production and only 31% are running agents in production. Salesforce's Agentforce index confirms agent deployments more than doubled year-over-year. 80% of enterprise apps embed an AI agent but only 31% run one in production — the gap between embedding and shipping remains the core challenge.

**Impact:** The numbers confirm the gap between agent enthusiasm and agent deployment. Infrastructure and governance funding (from finding 4) directly addresses the productionization problem.

**Source:** https://axis-intelligence.com/agentic-ai-adoption-statistics-2026/ | https://paul-okhrem.com/enterprise-ai-agents-statistics-2026/

## Community Pulse

**Working well:** Claude Code's screen reader mode is being called a long-overdue accessibility win — developers with visual impairments can now run fully agentic sessions without a visual terminal.

**Problems:** The Azure GPT-5.5+ reasoning bug in OpenCode went unfixed for weeks and affected enterprise deployments — the kind of provider-specific regression that erodes trust in multi-provider tools.

**Interesting:** The $190M governance funding in eleven days (Neo, Act, Hush) plus the enterprise adoption data telling us 88% of pilots fail to ship are two sides of the same coin — the problem the governance startups are solving is enormous and well-documented.

---

## Trend

Codex CLI is in a stable accumulation phase post-v0.147.0; Claude Code's August has been feature-rich (screen reader, MCP Artifacts, session caps) but quiet on the release cadence since the four-release post-CVE sprint; Cline and OpenCode are both iterating rapidly on session durability and enterprise compatibility. The funding and adoption data together suggest the tooling ecosystem is maturing faster than the deployment story — which creates a large market for governance and infrastructure tools.
