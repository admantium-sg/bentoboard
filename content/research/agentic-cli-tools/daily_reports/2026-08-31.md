# Daily Report — 2026-08-31

## New Findings

### Claude Code — Five Releases Land: v2.1.248 Through v2.1.251 (August 27–28, 2026)
Anthropic pushed five releases in 48 hours (v2.1.247 through v2.1.251). The marquee release is **v2.1.251 (August 28)** with 60+ changes:

**Major new capabilities:**
- **`PreModelSwitch` and `PostModelSwitch` hook events:** Block, confirm, or annotate a model switch mid-session — enables policy enforcement and audit logging for enterprise
- **Live subagent streaming to Remote Control clients:** Foreground subagent tool calls and results stream in real time to Remote Control; background subagents still show status only
- **Per-session prompt-cache stats in `/cost`:** Hit ratio, misses, tokens re-cached, warm/cold breakdown per session
- **Spend limit bar in `/usage`:** Visual spend tracking for developers behind a Claude apps gateway with spend limits
- **New CLI commands:** `attach`, `logs`, `stop`, `respawn`, `rm` added to `claude --help`

**Security fixes:**
- File tools (Read, Write, Edit) could follow a swapped symlink post-permission-check to read/write outside approved locations — now fixed
- Plugin marketplace entries could declare commands pointing outside the plugin directory (path traversal) — now rejected
- Grep/Glob not applying `Read(...)` deny rules to symlinked search paths — now fixed
- Project settings could enable detailed beta tracing or raw API body logging — now blocked

**Other fixes:** Agent team final answers now arrive properly; background subagents can reply to unnamed siblings/parents; Claude Desktop cross-session messaging fixed; session transcripts no longer silently overwritten; `Ctrl+G` no longer crashes emacs in background sessions; install binary ~5MB smaller.

**Source:** https://code.claude.com/docs/en/changelog

### Claude Code — v2.1.248: `--restricted` Mode and Experimental Prompt Cache TTL (August 27, 2026)
Added `--restricted` mode (`CLAUDE_CODE_RESTRICTED=1`): removes built-in tools that run commands or code and `WebFetch`, keeps file tools inside working directory, refuses `bypassPermissions`, ignores user/project/local settings. Also added experimental `cacheTtl` for per-agent prompt cache TTL.

**Source:** https://code.claude.com/docs/en/changelog

### OpenAI Codex CLI — v0.152.0-alpha.4: Extensions Can Intercept MCP Tool Results (August 30, 2026)
v0.152.0-alpha chain advances to alpha.4. Key additions:

- **Extensions inspect/replace MCP tool results:** Extensions can now intercept and modify MCP tool results before they reach the model — giving developers control over AI response shaping
- **Configurable MCP grace period:** Grace period for discovering tools from optional MCP servers is now configurable
- **Improved sandbox enforcement:** Using executor's actual home directory, OS, and path conventions for tighter sandboxing
- **Model switch fixes:** Tool availability and reasoning effort now stay correct when switching models or falling back

v0.151.0 stable continues unchanged.

**Source:** https://github.com/openai/codex/releases

### JetBrains Survey: Claude Code at 39% Adoption, Codex 5x Growth (May–July 2026)
JetBrains' Developer Ecosystem Survey 2026 (15,000+ developers, May–July) reveals the CLI agent landscape shifting dramatically:

- **90%** of professional developers use AI coding agents weekly (up from ~47% daily usage in Temporal's survey)
- **68%** use them daily
- **Claude Code:** 39% adoption globally (up from 18% in January 2026); 47% in the US — nearly half of all US developers. 31% say it's their primary AI coding tool (80% conversion from regular use to #1)

- **Google Antigravity:** Stable at 6% adoption; awareness jumped from 29% to 47%. India stronghold: 15% adoption, tied with Cursor

## Community Pulse

**Working well:** Claude Code's growth trajectory confirmed by two independent surveys (JetBrains and Temporal) — 39% adoption in JetBrains' May-July data, 80.8% daily usage in Temporal's August data. The tool has crossed from early-adopter to mainstream. Pricing discussions on Reddit suggest Claude Code's quality premium is accepted by most users.

**Problems:** The cost debate is heating up — r/codex threads argue Codex delivers "50-75% of Claude's token spend for the same output quality." Reliability concerns for Claude Code appear in multiple threads ("becoming unreliable with how regularly it goes down"). The 88% pilot-failure rate in enterprise (from yesterday's report) remains the category's dirty secret.

**Interesting:** JetBrains' finding that Claude Code's 80% conversion rate (from regular use to primary tool) suggests the CLI agent market is consolidating around one winner rather than fragmenting. Yet Reddit's "run both" consensus suggests the hybrid workflow is the practical answer — Claude Code for architecture/UI, Codex for debugging/cost-sensitive tasks.

## Trend

The CLI agent market is maturing: two independent surveys confirm mass adoption while JetBrains documents Claude Code displacing Copilot. The next battleground is cost optimization — extensions intercepting MCP results (Codex v0.1520-alpha.4) and the pricing-ROI threads signal the market is moving from quality race to efficiency race.
