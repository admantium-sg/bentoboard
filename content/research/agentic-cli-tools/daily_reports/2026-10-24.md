### Claude Code v2.1.309 — Sandbox and Permission-Check Hardening Batch (October 22, 2026)
Published 2026-10-22T22:18Z. Sandboxed Bash commands on macOS and Linux no longer run shell startup files outside the sandbox before each command. macOS `denyWrite` glob patterns apply at a path's real location through a symlink. Sandboxed commands and auto-accepted edits can no longer modify the MCP config passed with `--mcp-config`; a disabled MCP server is no longer reconnected by a later permission prompt in print and SDK sessions. Bash permission checks no longer trust a variable set by a command whose redirect can fail, and now prompt for compound commands that `cd` before running git even when the `cd` is wrapped or prefixed. An `Edit(path)` deny rule now blocks a Bash redirect to that path in commands holding a subshell. Worktree-isolated sessions refuse locale-prefixed and zsh arithmetic commands; worktrees and branch checkouts ignore git replace refs. Profile store write protection applies through a symlinked config directory. Fixed repeated compaction under a very large nested CLAUDE.md, ctrl+enter queuing, `!` mode running key-bound slash commands, ctrl+o hiding undelivered messages from other agents, and emoji-split tool previews that broke `jq` parsing of transcripts.

## Community Pulse

**Working well:** Sandbox and permission hygiene had its strongest week yet. Claude Code v2.1.309 closed a long list of real sandbox escapes (shell startup files running outside the sandbox, `denyWrite` bypass via symlink, edits to the `--mcp-config` file, `Edit(path)` deny rules bypassed by a Bash redirect), Antigravity CLI v1.4.6 stopped sandboxed commands from touching `~/.docker`, `~/.kube` and `~/_netrc` — previously writable and therefore a live credential-theft path — and Copilot CLI v1.0.103 finally propagated sandbox settings into ACP sessions including on resume, which closes a gap where an ACP host could run unsandboxed. Antigravity also made per-conversation permission grants apply to subagents, and Copilot v1.0.104-0 moved Assisted Permissions out of experimental mode.

**Problems:** The safety layer is now the dominant complaint, and it is lock-out-level rather than annoyance-level. A harmless hex-encoded clipboard string triggered "Sonnet 5's safeguards stopped the response above" and forced a new session; users report models retrying oversized Bash commands indefinitely after each classifier stop instead of learning the native tool path. Money follows the same pattern — an unbounded recursive `send_later` loop burned $285.12 unnoticed over 9.5 days. On Codex, the desktop/Computer Use surfaces are where the friction sits: missing Chrome native host registration, approvals denied without an Allow dialog, and Scheduled Work tasks silently losing workspace write and network permissions.

**Interesting:** Claude Duet marks the migration of the assistant category itself: the tool now initiates (morning briefs, periodic checks, alerts) rather than answering, and Anthropic explicitly sells approval gates — payments, signed documents, deletions — plus a sensitive-data classifier as features. Note the counter-current from the CLI side: every major CLI this week spent its release budget making sure the agent cannot act unsupervised. The consumer agent wants autonomy with confirmation; the professional CLI wants autonomy with walls. Both are shipping on the same week.

---

## Trend

Two release-day clusters in three days (Oct 22–23) across eight tools, and the unifying theme is containment: sandbox escapes closed, credential paths blocked, deny rules enforced against redirect tricks, permission grants made consistent across subagents. The counterweight is that Anthropic's Claude Duet put the proactive, approval-gated agent into consumer hands on October 21 — the same week agentic CLIs were busy proving that unattended execution still fails, one $285 runaway loop at a time. Funding confirms where the money goes: of $41.9B raised in October, only $1.1B (5 rounds) reached AI developer tools, while foundation models absorbed $36.0B — the tooling layer is consolidating around trust, permissions and measurement rather than new model capability.
