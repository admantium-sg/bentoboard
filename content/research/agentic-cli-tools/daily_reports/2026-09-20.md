## New Findings (2026-09-18 to 2026-09-20)

### Claude Code v2.1.278 — Auto Mode Now Runs Free on Server (September 19, 2026)
224th release of 2026. Auto mode for Claude API/Enterprise users (and on Bedrock, Vertex, Foundry, gateways) now defaults to the server-side classifier, which does not charge for classifier overhead. Sessions show an Auto mode server row in /status indicating whether the classifier runs on the server. Opt out with CLAUDECODEAUTOMODESERVER=0 on Bedrock/Vertex/Foundry/gateways.

**Source:** https://www.havoptic.com/r/claude-code-2.1.278

### Claude Code v2.1.277 — AGENTS.md as Project Instructions, Massive Stability Sweep (September 18, 2026)
223rd release. In projects with no CLAUDE.md, Claude Code now reads AGENTS.md instead and exposes it under "Project instructions" in /config (not yet on Bedrock/Vertex/Foundry). Added CLAUDEGATEWAYPROXYISEGRESSBOUNDARY=1 for gateways whose only egress is a forward proxy. The release notes list 40+ fixes including: sessions that could hang with no result after internal errors now report and exit with code 1; conversations failing with "text content blocks must be non-empty" when an earlier turn held an empty text block; unexpected logout when an older Claude Code build runs on the same machine; mal-formed theme/ApiKeyResponses values in ~/.claude.json no longer crash at launch; Grep/Glob report a clear error when the system is out of processes, memory, or file handles; Write tool now reports a clear error when target path is an existing directory (instead of silently declining); Edit tool fixed for escaped backslash followed by unicode; path null-byte handling fixed; background sessions no longer exit when a plugin LSP server closes; $TMPDIR no longer expands empty in sandboxed Bash commands; WebFetch/WebSearch in Cowork cloud sessions now explain refusals (budget/exhausted/admin policy); and many more.

**Source:** https://www.havoptic.com/r/claude-code-2.1.277

### Claude Code v2.1.276 — Proxy/Gateway Critical Fix (September 18, 2026)
222nd release. Fixed every request failing with "400 … Input tag 'advisor20260301'" when ANTHROPICBASEURL points at a proxy or gateway — a regression from v2.1.275. Critical fix for enterprise deployments using gateway setups.

**Source:** https://www.havoptic.com/r/claude-code-2.1.276

### Antigravity CLI v1.2.7 — LaTeX Math and Mermaid Diagrams in Terminal (September 19, 2026)
50th release of 2026. Now renders LaTeX math equations ($...$ and fenced blocks) and Mermaid flowcharts/sequence diagrams inline in the artifact viewer, with ASCII fallback, horizontal panning for wide diagrams, and m to cycle between Image/ASCII/Raw views. Improved askquestion prompt with Left/Right arrow navigation, inline previews of confirmed write-in answers, and check marks on answered options. API retry backoff capped at 30 seconds (down from 4 minutes). Customization token budgeting overhauled: user and workspace rules now get a dedicated 20,000-token budget so large rule sets no longer evict skills, workflows, subagents, or MCP tools. Legacy findbyname, grepsearch, and listdir tools retired from default agent/subagent baseline. Bubble Tea upgraded to v2.0.9 fixing terminal rendering and keyboard protocol handling.

**Source:** https://www.havoptic.com/r/antigravity-cli-1.2.7

### Antigravity CLI v1.2.6 — Remote Control, Unlimited Headless Timeout (September 18, 2026)
49th release. Added Remote Control via --remote-control flag or /remote-control slash command — creates a session-scoped tunnel to follow and control your active terminal from another device; /remote-control off or closing tears down automatically. Headless (-p/--prompt) runs now have unlimited timeout by default (removed the 5-minute cap), and daemon background commands stay running after the turn finishes in GEMINIAPIKEY sessions. Improved word-wise cursor movement (Alt+F/B, Ctrl/Alt+Arrow) and word deletion (Ctrl+W, Alt+Backspace, Alt+D) now stop at punctuation boundaries. Fixed /model switch mid-turn now waits until the queued prompt begins executing. Fixed oversized diffs (>1 MiB) no longer force-clear session history.

**Source:** https://www.havoptic.com/r/antigravity-cli-1.2.6

### Kilo v7.7.5 — @model/@past-chats/@worktrees Mentions, Memory Leak Fix (September 19-20, 2026)
VS Code and CLI. Added @model, @past-chats, and @worktrees mentions to the Agent Manager New Worktree prompt — past chats and worktrees attach as session references. Worktree-independent slash commands (custom commands, skills, MCP prompts, /goal) now appear in the New Worktree prompt and execute when the worktree is created. Memory leak fixed — Agent Manager session switching had been getting slower the longer the window stayed open because tool card fade animations kept unmounted transcript rows alive. Agent switch now adds a reminder naming the previous and current agent and whether the current agent may modify files.

**Source:** https://github.com/Kilo-Org/kilocode/releases

### Kilo v7.7.4 — Mermaid Zoom Viewer, Worktree Cleanup Overhaul, Programmatic Tool Calling (September 18-19, 2026)
VS Code and CLI. Mermaid diagrams now open in a fullscreen zoom viewer with zoom in/out, mouse-wheel zoom, and drag-to-pan. Worktree cleanup fully overhauled: leftover folder banner now shows count and total size with a "Resolve" action listing each folder's path, size, and git checkout status; JetBrains now tears down backend state and removes the snapshot repository for deleted worktrees (previously VS Code only); directories reappearing after deletion are cleaned up automatically. Experimental Programmatic Tool Calling added: when enabled, the agent calls MCP tools from a confined JavaScript program and discovers tools on demand, reducing MCP tool definitions sent to the model. Chat session titles now generated from sufficient context rather than the first message alone — prevents bare URL or truncated line as title.

**Source:** https://github.com/Kilo-Org/kilocode/releases

## Community Pulse

**Working well:** Antigravity CLI v1.2.7's LaTeX and Mermaid rendering in the terminal is a significant quality-of-life upgrade for developers who work with academic or technical documentation — eliminates the need to switch to a browser to view rendered math. The dedicated 20,000-token budget for user/workspace rules in the same release is a welcome stability improvement for power users with large rule sets.

**Problems:** Kilo v7.7.4's memory leak (session switching slowing over time due to unmounted transcript rows being kept alive) is a notable quality issue that had likely been affecting users for some time before being caught.

**Interesting:** Factory Droid v0.223.0's organization-managed Databricks connector and the new organization skill policy (orgs can disable skills for members) signal deeper enterprise governance features. The PyCharm editor option also expands Factory Droid's reach beyond VS Code-only shops.

## Enterprise Adoption Signals

- **Claude Code v2.1.277** is a reliability release with 40+ fixes that will be welcome in enterprise deployments, particularly the fix for sessions hanging on internal errors and the proxy/gateway regression fix in v2.1.276
- **Factory Droid v0.222.0**'s Windows MSIX installer enables enterprise deployment via device policy and in-place updates — a key requirement for Windows-first enterprises
- **Kilo v7.7.4**'s experimental Programmatic Tool Calling (confined JS program for on-demand MCP tool discovery) is an early look at reducing token overhead from large MCP tool lists — if it matures, this could be significant for repositories with many MCP tools
- **GitHub Copilot CLI v1.0.86**'s AGENTS.md support for custom agents aligns with the broader ecosystem trend (Claude Code and others) of standardizing AGENTS.md as a project instruction format
