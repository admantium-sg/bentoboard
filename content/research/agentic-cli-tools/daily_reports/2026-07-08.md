## Tool Releases — v2.1.202 Marks Claude Code Return to Active Development

**Claude Code v2.1.202 (July 6, 2026):** First new release since July 3. Notable additions include a "Dynamic workflow size" setting in `/config` for controlling how many agents dynamic workflows spawn — an advisory guideline rather than an enforced cap. OpenTelemetry attributes (`workflow.run_id`, `workflow.name`) are now emitted by workflow-spawned agents for reconstructable audit trails. Bug fixes address Remote Control session failures, mTLS handshake transients, installer retry on dropped connections, and re-invoking a loaded skill appending duplicate instructions. The `/review` command reverts to a fast single-pass review; multi-agent review moved to `/code-review`. Fourteen distinct fixes in one release — a return to active development after the post-controversy quiet stretch.

**Cline CLI v3.0.38 (July 7/8, 2026):** Visual redesign with a new blue/amber plan-act accent palette replacing cyan/yellow, applied across dialogs, markdown, and syntax highlighting. Chat input restyled with horizontal rules. Mode-tinted markdown distinguishes plan vs. act output. Technical improvements: `read_files` now tolerates malformed input from weaker models (line-range entries emitted as separate array items are coalesced), and models without a reported context window default to 128K input tokens. Thinking-level picker now defaults to Medium.

**Codex CLI:** Alpha sprint continues — alpha.39 now on GitHub releases page, alongside alpha.37 through alpha.38. No stable v0.143.0 documented on the official changelog yet.

**Kilo:** First GA release of the native Kilo extension for JetBrains IDEs. Runtime download at startup (no longer bundling CLI binaries), verified archives, and improved diagnostics for download failures.

**ChatGPT for iOS 1.2026.181 (July 6):** Codex task management from within conversations — create, search, open, fork, and manage tasks directly. Filters for staged/unstaged changes and branch comparisons. SSH host support with private keys. Usage limits and credit details in task menu.
