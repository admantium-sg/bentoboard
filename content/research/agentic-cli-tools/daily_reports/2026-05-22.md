**OpenAI Codex Appshots (May 21) — "Command-Command" macOS Capture**
- Press both Command keys to send frontmost app window to Codex with screenshot and available text — no copying/pasting/describing
- Uses ScreenCaptureKit + Accessibility APIs: captures visible window bitmap + structured text including content beyond viewport
- Default: Appshot starts new thread; if you interacted with a thread in last 60 seconds, Appshot joins that recent thread
- Consecutive Appshots stack into same thread for multi-capture reasoning
- Stored locally in session file; CLI can resume threads with Appshots but not create new ones
- macOS permission prompts for Screen Recording and Accessibility required
- Privacy concern: removes natural pause for cropping/redacting; can include text outside current viewport
- Source: https://kingy.ai/blog/appshots-inside-openai-codexs-new-command-command-trick-for-macos/

## Market & Enterprise Trends

**Multi-Agent Orchestration Landscape Maturing**
- Claude Code Workflow tool joins established multi-agent platforms (Ruflo with 31k+ GitHub stars, Claude Flow)
- Clear trend: deterministic multi-agent orchestration becoming first-class feature in CLI tools, not just external frameworks
- Ruflo positioned as most adopted open-source multi-agent platform of 2026 (84.8 score mentioned)

**Privacy Concerns with Desktop AI Capture Features**
- Codex Appshots raises questions: removes natural cropping/pausing, can capture text outside viewport
- Chronicle (continuous ambient capture) stores unencrypted local Markdown — separate privacy concern
- Enterprise admins lack Appshots-specific disable switch (unlike Computer Use which has feature pins)
- Industry moving toward user-invoked, scoped capture rather than background ambient capture
