### Cline — v4.1.13: Hub Seamless Upgrades, Tool Calling Fix, Model Catalog Refresh (August 22–23, 2026)

v4.1.13 follows v4.1.12 within a day, continuing Cline's rapid release pace. Key additions:

- **Hub drain-and-upgrade without losing work**: Hub refuses new mutating work while finishing current tasks; clients replay missed events via durable event log; queued runs are not dropped
- **Tool calling fix for custom OpenAI-compatible models**: capability lists inferred from `supportsReasoning` and similar convenience flags were being read as an authoritative denial, stripping all tools; explicitly authored capability lists now correctly decide
- **Model catalog refresh**: defaults changed for DeepSeek, Crof, CrossModel, Eden AI, Kilo, and NanoGPT — users on those providers without pinned models get different defaults
- **Server-side feature flags honored**: app now refreshes flags when account changes
- **Langfuse traces carry session identity**: hub-backed and delegated-agent runs group under their parent session

**Source:** https://github.com/cline/cline/releases

### Kilo — Metabase Security Incident: User Data Exposed via Third-Party BI Provider (August 2–14, 2026)

Kilo Code (recently acquired by Anaconda) disclosed a security incident originating at Metabase, its business intelligence provider. An unknown actor accessed Kilo customer records over ~4 hours on August 2; Kilo was notified August 6 and published its first public statement August 9.

**What was exposed:** Some users' names, email addresses, and possibly billing address and location. Payment card data was reportedly not exposed. A small subset of Kilo Slackbot users had their Slack tokens exposed — all were invalidated as precaution. Kilo has enabled a data export feature for affected users.

**Context:** The incident highlights supply-chain risk in agentic tools that aggregate usage data for product analytics. Kilo Code's parent Anaconda acquired Kilo in mid-2026.

**Source:** https://www.anaconda.com/blog/metabase-incident-impacting-kilo-code-data

## Community Pulse

**Working well:** The Hub drain-and-upgrade mechanism in Cline v4.1.13 addresses one of the most disruptive operational failure modes for team deployments — a Hub restart mid-session. The durable event log and replay mechanism means no queued runs are dropped, and the upgrade path is graceful rather than destructive. This is a meaningful reliability improvement for shared, multi-user Cline deployments.

**Problems:** Kilo's Metabase incident underscores a recurring tension in developer tools: vendors use third-party analytics providers (Metabase for BI, Segment for product analytics, etc.) and that supply chain becomes an attack surface. For agentic tools that may handle sensitive code and workflow data, even "just" email addresses and names from a BI provider breach represents a data governance failure. Users who deployed Kilo Code in regulated environments should audit whether their usage patterns created any additional exposure.

**Interesting:** GPT-5.4's retirement from ChatGPT-authenticated Codex on August 31 marks the third model deprecation wave for this cohort. The pattern is clear: ChatGPT-signed Codex users are on a deprecation treadmill, with OpenAI cycling models every few months. API-key users are unaffected, which reinforces the case for self-managed API access over the convenience of ChatGPT SSO.
