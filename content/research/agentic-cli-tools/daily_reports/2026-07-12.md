# Daily Report — July 12, 2026

## New Findings (since July 11, 2026)

### Claude Code v2.1.207 — Auto Mode Expands, Security Fix, Bedrock Default Bump (July 11, 2026)

**Auto mode without opt-in on Bedrock, Vertex AI, Foundry:** Auto mode is now available by default (not requiring `CLAUDE_CODE_ENABLE_AUTO_MODE`) on Bedrock, Vertex AI, and Foundry. Can be disabled via `disableAutoMode` in settings. This is a notable expansion of auto mode's availability across enterprise cloud providers.

**Critical security fix — plugin shell injection blocked:** `${user_config.*}` in shell-form plugin hooks/monitors/MCP headersHelper is now rejected. Hooks must use exec form (`args` array) or `$CLAUDE_PLUGIN_OPTION_<KEY>`. This closes a shell-injection vector in plugin configurations — same class as the CVE-2025-66479 pattern of bypassing string-handling safeguards.

**Auto-updater symlink fix:** The auto-updater no longer overwrites custom launcher scripts or symlinks at `~/.local/bin/claude` on every release. `/doctor` now reports an externally managed launcher. Long-standing annoyance for custom launcher setups fixed.

**Managed settings security fix:** Remote managed settings from non-interactive runs (`claude -p`, SDK) are no longer permanently recorded as consented without showing the security consent dialog.

**Terminal UX fix:** Terminal no longer freezes or lags when streaming very long lists, tables, paragraphs, or code blocks.

**Bedrock/Vertex/Claude Platform on AWS default to Opus 4.8:** Changed from previous default.

**Plugin config isolation:** `pluginConfigs` no longer read from project-level `.claude/settings.json`; only user, `--settings`, and managed settings are honored. Prevents repo-committed plugin configs from overriding user preferences.

**/`/usage-credits` hardened:** Malformed inputs are now rejected with errors, and amounts over $1,000 require typed confirmation.

**Source:** https://code.claude.com/docs/en/changelog

### OpenAI Codex CLI — v0.144.0 Stable Lands; v0.145.0 Alpha Series Begins (July 2026)

**v0.144.0 stable — biggest stable jump since alpha sprint tracking began:**
- **Writes app-approval mode:** Declared read-only actions auto-approved while prompting for writes — significant for CI/scripted use cases
- **MCP auth elicitation enabled by default:** MCP tools can request authentication interactively without experimental opt-in
- **Usage-limit reset credits UI:** Shows type and expiration; user picks which credit to redeem
- **Ultra reasoning concurrency warning:** Warns when high multi-agent concurrency could spike usage
- **Windows sandbox improvements:** Sessions can delete files in writable roots and access managed primary runtime
- **macOS Intel crash fix:** Code Mode crashes on Intel macOS binaries fixed
- **Companion host fallback:** Code mode works even when companion host binary is unavailable, falling back to embedded runtime
- **Amazon Bedrock model names clarified:** GPT-5.6 family and variant now clearly identified

**v0.145.0-alpha.3/4:** Alpha series already started post-v0.144.0 stable, with installer and code-mode reliability fixes in alpha.4. The stable-to-alpha gap is now narrower than previous cycles — OpenAI appears to be shortening the cycle.

**Source:** https://github.com/openai/codex/releases
