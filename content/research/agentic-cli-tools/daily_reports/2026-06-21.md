## New Findings (June 20–21)

### Claude Code v2.1.185 (June 20, 2026) — Stream Stall UX Tweaks

A quiet release focused on connection feedback clarity:

- **Stream-stall hint rewording**: Changed from "No response from API · Retrying in …" to "Waiting for API response · will retry in …" — clearer signal that the system is actively waiting, not silently failing
- **Stall detection delay extended**: Trigger time increased from 10s to 20s of silence before displaying the hint, reducing false positives during normal API latency spikes

This follows the v2.1.183 auto-mode safety sprint (June 19) — the team appears to be doing post-release polish rather than pushing new features.

**Source:** https://code.claude.com/docs/en/changelog

### OpenAI Codex CLI v0.141.0 (June 18, 2026) — Remote Execution Overhaul

A significant architectural release focused on remote execution infrastructure:

- **Encrypted Noise relay channels**: Remote executors now use authenticated, end-to-end encrypted Noise protocol relays — meaningful for teams running Codex in security-sensitive environments
- **Cross-platform remote execution**: Preserves executor-native working directories and shells across app-server and exec-server boundaries, including filesystem permission paths — enables heterogeneous team setups (Linux CI, macOS dev machines, Windows build hosts)
- **Per-thread stdio MCP servers**: Selected executor plugins can activate their stdio MCP servers per thread, enabling more granular tool access in multi-agent workflows
- **Plugin marketplace improvements**: Discovery adds a "created-by-me" marketplace and auth-specific curated catalogs
- **TUI auto-resolve**: Input prompts can auto-resolve after inactivity with a visible countdown that pauses on interaction
- **Performance**: Reduced latency and memory use in large tool-heavy sessions via caching and eliminated redundant copies; bounded prompt-image caching to 64 MiB
- **Hook security fix**: Hook trust bypass now persists correctly through `codex exec` thread start and resume; PostToolUse hooks correctly reject code-mode tool calls

**Source:** https://developers.openai.com/codex/changelog

### Crush v0.79.1 (June 20, 2026) — Bang Mode Polish

Bang Mode, introduced in v0.78.0, receives its first polish pass:

- **Paste activation fix**: Bang mode now activates correctly when pasting text starting with `!`
- **History inclusion**: Bang commands are now included in session history
- **External editor sync**: Bang mode state stays synchronized when using external editors

**Source:** https://github.com/charmbracelet/crush/releases

### Factory AI Droid v0.150.0 (June 16, 2026) — npm Plugins, Desktop UX, Performance

Droid's rapid release cadence continues:

- **npm plugin sources**: Plugin marketplace definitions can now reference plugins published as npm packages — significantly lowers the barrier for plugin distribution and enables the community to publish tools without git hosting
- **Quit confirmation (Desktop)**: App now asks for confirmation before closing if an active Droid session would be interrupted
- **Long session performance**: Improved chat performance in long-running sessions — addresses a common pain point in agentic workflows
- **Rate limit reset display**: Fixed the rate limit reset time shown for sub-hour resets — improves planning visibility

**Source:** https://docs.factory.ai/changelog/release-notes

## Community Pulse

### Working Well
- **Codex CLI remote execution architecture**: The encrypted Noise relay channels for remote executors plus preserved native working directories is a major step toward heterogeneous team workflows. Teams running mixed OS environments or needing secure remote execution now have a cleaner path.
- **Droid npm plugin sources**: Allowing plugin marketplace to reference npm packages directly is a pragmatic move — it leverages existing infrastructure rather than requiring developers to learn a new distribution format.
- **Crush Bang Mode refinement speed**: Three releases in two days (v0.78.0, v0.79.0, v0.79.1) shows Charm is iterating quickly on user feedback — the paste fix and history inclusion are small but meaningful quality-of-life improvements.

### Problems
- **Claude Code quiet period**: One minor release (v2.1.185) since the June 19 safety sprint — after weeks of rapid releases (v2.1.163–178), this feels like the team may be in maintenance mode or preparing something larger. Users used to frequent updates may wonder if something's coming.
- **Codex CLI v0.141.0 breaking change scope**: The hook trust bypass fix (PostToolUse hooks correctly reject code-mode tool calls) could break workflows that relied on the previous behavior. Teams should test carefully after upgrading.

### Interesting
- **Agentic CLI security hardening trending**: June 2026 has seen significant security work across multiple tools — Claude Code's auto-mode safety (June 19), Codex CLI's hook security fixes (June 18), Droid's command blocklist (v0.147.0, June 12). This reflects a broader industry recognition that agentic tools need enterprise-grade safety guardrails as adoption grows.
- **Codex CLI architectural maturity**: The v0.141.0 release touches core infrastructure (remote execution, relay channels, session management) rather than user-facing features — signals the team is building platform stability rather than chasing feature parity. The mention of multi-agent v2 prompts being updated suggests higher-level orchestration remains on the roadmap.

## Trend

This week shows architectural maturation rather than feature drama: Codex CLI's encrypted remote execution infrastructure, Droid's npm plugin ecosystem expansion, and Crush's Bang Mode polish represent tools settling into reliable release cadences. Claude Code's quietest week in recent memory follows a major safety sprint — likely post-release stabilization.
