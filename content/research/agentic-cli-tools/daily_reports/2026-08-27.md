### Codex CLI — v0.150.0 Alpha Accumulates 50+ PRs; Major Security and UX Push (August 26–27, 2026)
The v0.150.0 alpha chain is actively developing with a large feature set. Key additions landing:

- **@ mentions for cross-task referencing:** Reference other Codex tasks with @ mentions; ask agents to read, create, or message tasks from the terminal — shifts Codex toward a multi-agent coordination hub
- **/copy picker:** Offers selection of full responses, individual code blocks, and blockquotes
- **Auto-naming:** Unnamed terminal tasks receive descriptive titles automatically; /rename suggests editable titles based on conversation
- **Markdown links as clickable labels:** Rendered as clickable labels in supported terminals
- **Permission mode cycling keybindings:** Bind shortcuts to cycle permission modes; Vim mode `.` repeats last edit
- **Interrupt hooks:** New hooks can run commands or MCP handlers when an active top-level turn is interrupted

**Security hardening:** Untrusted projects no longer supply project-level AGENTS.md instructions; managed deny-read rules remain enforced after permission changes; credential redaction improved in app-server diagnostics; Windows sandbox elevated setup and Unicode user path fixes.

**Bug fixes:** Remote MCP bearer-token lookup fixed; elevated Windows sandbox setup fixed; Unix shutdown hangs prevented (detached processes retaining terminal/buffers); Amazon Bedrock conversation compaction and multi-agent compatibility fixed.

**Source:** https://github.com/openai/codex/releases

## Community Pulse

### Okta Agent SSO Goes GA — AI Agents as First-Class Identities (August 24, 2026)
Okta's Agent SSO reached general availability on August 24, bringing AI agents into Okta's Universal Directory as proper identities governed by the same access controls used for human staff. The Cross App Access (XAA) standard is now native to Okta's core SSO product used by over 20,000 organizations. Agents get short-lived tokens instead of hard-coded credentials, policy assignment, and centralized access review — the same lifecycle management as employee accounts. Important caveat: coverage is limited to compatible agents that implement the XAA protocol.

**Source:** https://www.okta.com/products/govern-ai-agent-identity/ | https://quasa.io/insights/okta-agent-sso-replaces-static-keys-but-it-does-not-govern-every-agent

### Temporal Report: 80.8% of Engineers Use AI Agents Daily — Up 70.8% YoY (August 26, 2026)
Temporal's 2026 State of Development Report (550+ engineers, US/UK) documents the mainstreaming of agentic development tools. Daily AI agent usage among engineers reached 80.8%, up from 47.3% a year earlier — a 70.8% relative increase. 90% of respondents say agents have "improved" or "revolutionized" their productivity. The data also shows where agents break down in practice, giving teams a reality check on reliability gaps.

## Market Trends & Ecosystem

### Keenable Exits Stealth: $26M Seed for 100B-Document Agentic Web Search (August 25, 2026)
Keenable launched publicly with a $26 million seed round led by Accel (Conviction Partners, angels participating). Founded by former Yandex search and AI head Andrey Styskin, Keenable has indexed 100+ billion documents with a Search API designed for low-latency, high-frequency agent queries. Already has commercial contracts with multiple AI labs and inference providers. Offers an official MCP server for keyless access at up to 1,000 requests/hour. Key positioning: "web search built for AI agents, not humans" — as Google and Microsoft wind down open search APIs, a dedicated agentic search layer is emerging.

**Source:** https://siliconangle.com/2026/08/25/agentic-web-search-infrastructure-startup-keenable-raises-26m/ | https://www.thesaasnews.com/news/keenable-raises-26m-seed/

### Anthropic Report: 80% of Organizations See Measurable ROI from AI Agents (August 2026)
Anthropic's 2026 State of AI Agents Report (500+ technical leaders) confirms economic momentum: 80% of organizations report measurable economic impact from AI agent investments today, with 88% expecting continued or increased returns. Software development (57%) and customer service (55%) lead near-term impact areas; marketing/sales (46%) and supply chain/logistics (44%) follow closely. The data underscores that agents have crossed the proof-of-concept threshold into production value.

**Source:** https://claude.com/blog/how-enterprises-are-building-ai-agents-in-2026

### A2A Protocol Joins Linux Foundation Agentic AI Foundation (August 20, 2026)
Google's A2A protocol formally joined the Linux Foundation-directed Agentic AI Foundation on August 20, joining Anthropic's MCP under the same neutral governance. AAIF now counts 250+ members including AWS, Anthropic, Block, Bloomberg, Cloudflare, Google, Microsoft, and OpenAI. The consolidation of A2A and MCP under AAIF creates a unified protocol stack for agent-to-tool and agent-to-agent communication — significant for cross-vendor enterprise deployments.

**Source:** https://aiagentstore.ai/ai-agent-news/this-week

### Snowflake CoCo Automations Hits Public Preview (August 21, 2026)
Snowflake moved CoCo Automations into public preview, enabling periodic unattended agent runs in a Snowflake-managed sandbox. Each run creates a Cortex thread that can be inspected and continued interactively. Data platforms becoming execution environments for scheduled, data-native agents — a notable expansion of where agent workloads run.

**Source:** https://aiagentstore.ai/ai-agent-news/this-week

### Aderant Launches Early Access to Law Firm AI Agents (August 26, 2026)
Legal software vendor Aderant opened early access to Agent Center, offering purpose-built AI agents for law firm back-office: billing, collections, compliance, forecasting, and rate management. Agents target appeals, collections, talent evaluation, time-entry quality, outside counsel guideline compliance, general ledger forecasting, and billing rates — all embedded within Aderant's Stridyn platform and MADDI AI layer.
