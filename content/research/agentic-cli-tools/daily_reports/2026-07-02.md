## New Findings (June 27 – July 2, 2026)

### Claude Code — v2.1.195–197: Sonnet 5 Lands as New Default

**v2.1.197 (June 30) — Claude Sonnet 5 becomes the default:**
- **Claude Sonnet 5** is now the default model in Claude Code, shipping with a native **1M-token context window** (both default and maximum; no smaller variant) and **128k max output tokens**.
- Introductory pricing of **$2/$10 per Mtok** through August 31, 2026, then standard $3/$15.
- SWE-Bench Verified: **92.4%** (+12pt over Opus 4.6). OSWorld-Verified: **88.3%** (beats the 72.4% human expert baseline). GPQA Diamond: **96.2%**. ARC-AGI-2: **84.7%**.
- Anthropic's most agentic Sonnet yet, with adaptive thinking, same tool set as Sonnet 4.6.
- Three breaking behavior changes noted; chatforest.com has a migration guide.

**v2.1.196 (June 29):**
- **Organization default models**: Admins set it in the org console; appears as "Org default" or "Role default" in `/model` when the user hasn't picked one.
- **Clickable file attachments in chat**: Cmd/Ctrl-click reveals the file in Finder/Explorer.
- **Security fix**: `claude mcp list`/`get` no longer spawns `.mcp.json` servers for repos self-approved via committed `.claude/settings.json`; untrusted workspaces show `⏸ Pending approval`.
- **Streaming idle watchdog on by default**: Aborts and retries when a response stream produces no events for 5 minutes. Set `CLAUDE_ENABLE_STREAM_WATCHDOG=0` to disable.
- Remote session mid-turn crash recovery: sessions interrupted by a server restart now auto-resume.
- Background agents killed by daemon restart auto-resume when agents view next opens.
- `/code-review` token usage cut ~25% by merging five cleanup finders into one.

**v2.1.195 (June 26):**
- `CLAUDE_CODE_DISABLE_MOUSE_CLICKS`: disables mouse click/drag/hover in fullscreen while keeping wheel scroll.
- Hook matcher exact-match fix: hyphenated identifiers like `code-reviewer`, `mcp__brave-search` now exact-match (use `mcp__brave-search__.*` for wildcard).
- Background session reliability improvements on Windows (background shells handed off instead of killed).
- Voice dictation improvements for languages without spaces (Japanese, Chinese, Thai).

### Cline — v4.0.0 Catastrophic Rollback, v4.0.1–5 Recovery

**v4.0.0 (June 26) — Biggest Architecture Migration in Cline History:**
- SDK-backed VS Code extension runtime, ClinePass full integration, Customize marketplace, Cline Plugins, queued prompts — then immediately pulled.

**v4.0.1 (June 28) — Emergency Rollback:**
- Stable VS Code extension **rolled back to pre-SDK-migration codebase** (effectively v3.89.2).
- Triggered by serious regressions reported within ~48 hours of v4.0.0:
  - Broken split diff view — agent modified files directly instead of showing diffs for review.
  - `run_commands` schema errors — commands arriving as string instead of array.
  - Agent bypassing PLAN/ACT control flow — allegedly ran commands and edited files without user approval (Issue #11931 — highest severity).

**v4.0.2 (June 29):** ClinePass provider enabled for all users; feature flag removed.

**v4.0.3 (June 29–30):** Reasoning effort (including xhigh) for DeepSeek thinking models; ClinePass provider experience improved.

**v4.0.4 (June 30):** ClinePass fully available everywhere in UI (onboarding, settings, promo banner, credit-limit action).

**v4.0.5 (June 30):** Claude Sonnet 5 support added across Anthropic, Bedrock, Vertex, Claude Code, SAP AI Core, OpenRouter, and Vercel AI Gateway providers.

### Crush v0.81.0 — Scrollbar, Herdr Integration, CPU Fix

v0.81.0 shipped after June 27 (nightly builds, then promoted):

- **Chat scrollbar**: Navigate long sessions with a visible scrollbar. Three modes: `default` (hides after 2s), `always`, `never` — configurable via `options.tui.scrollbar`.
- **Herdr agent status signaling**: herdr.dev integration now picks up Crush agent status and sends notifications when blocked or finished.
- **Lower CPU usage during thinking traces**: streaming thinking renders now cached to avoid CPU burn during long reasoning traces.
- **Fix startup deadlock**: prevented when a configured model ID no longer exists at provider.
- **Fix session breaking on non-vision model with images**: sessions now skip images instead of breaking.
- **Herdr socket integration**: agent management tool now integrates with Crush.
- Tool call names can now be expanded in UI.
- Provider warnings from fantasy step results now logged.

## Community Pulse

### Working Well
- **Claude Sonnet 5's benchmarks are remarkable**: SWE-Bench Verified 92.4%, OSWorld 88.3% beating the human baseline, and 1M context at $2/$10/Mtok introductory pricing is being received as a major value upgrade for agentic coding workflows.
- **Kilo's macOS sandboxing**: The cross-platform sandbox now covers Linux and macOS with network and shell confinement — meaningful for teams that need real security boundaries around agent execution.
- **Crush's chat scrollbar**: Small quality-of-life addition that users have been requesting for months — the "obvious" UI feature that somehow took this long.

### Problems
- **Cline v4.0.0 broke the trust boundary**: The most serious issue reported was the agent bypassing the PLAN/ACT approval flow and running commands without user consent. For a tool that edits files and executes shell commands, this is an operational safety incident. The rollback was fast, but the damage to user trust in the v4 release train is notable.
- **Cline CLI/VS Code extension version divergence**: After v4.0.0's rollback, the CLI and VS Code extension are now on fundamentally different architectural tracks. The CLI is on v3.0.x while the VS Code extension went through v4.0.0→4.0.5. Users mixing both products need to carefully track which version has which features.
- **Codex CLI v0.142.0 stable still missing after 10 days**: The stable release expected since June 22 still hasn't shipped. Alpha sprint now at 35+ releases with no stable branch. Teams depending on stable APIs are increasingly frustrated.

### Interesting
- **Claude Sonnet 5's migration guide has "breaking changes"**: Multiple sources note three breaking behavior changes in Sonnet 5. The community is carefully reviewing the migration guide before upgrading production Claude Code setups.
- **Kilo's Anaconda Desktop integration**: Connecting to a local Anaconda Desktop text-generation model server directly from Kilo CLI/VS Code is a new vector for local model users — Anaconda being a data science/ML platform rather than a dedicated LLM API provider suggests Kilo is targeting a broader local model audience.
- **ClinePass becoming unavoidable**: Every release since mid-June adds more ClinePass integration. v4.0.4 removed the feature flag entirely, making ClinePass the default experience everywhere. The subscription model's progression is accelerating.

---

## Trend

The field is bifurcating along security and architecture lines. Kilo and Claude Code are both investing heavily in sandboxing (Kilo's cross-platform shell/network confinement, Claude Code's streaming watchdog and credential blocking). Cline's v4.0.0 rollback is a cautionary tale about the risks of architectural migration in tools that have file-system and shell access — the trust boundary is everything. Meanwhile, Claude Sonnet 5's arrival as the default in Claude Code with 92.4% SWE-Bench sets a new capability benchmark that puts pressure on all other tools to match or differentiate.
