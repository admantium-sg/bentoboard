## New Findings (June 3–7)

### Claude Code v2.1.163–168 (June 4–6, 2026) — Reliability Sprint

Five releases in three days — rapid reliability and enterprise hardening:

- **v2.1.166 (June 6):** `fallbackModel` setting — configure up to three fallback models tried in order when primary is overloaded/unavailable; `--fallback-model` now applies to interactive sessions too. Claude Code retries a turn once on fallback when API rejects a non-retryable error. Cross-session messaging hardened: messages relayed via `SendMessage` from other Claude sessions no longer carry user authority — receivers refuse relayed permission requests, and auto mode blocks them. Glob pattern support in deny rules (`"*" denies all tools`).

- **v2.1.165 (June 5):** Bug fixes and reliability improvements

- **v2.1.163 (June 4):** `requiredMinimumVersion` and `requiredMaximumVersion` managed settings — Claude Code refuses to start if its version is outside the allowed range. `/plugin list` command added. Hooks' `Stop` and `SubagentStop` can now return `additionalContext` to give feedback and keep the turn going. Skills: `\$` escape syntax for literal `$` in command bodies. `claude agents` URL filtering — typing a URL into the list filters to the session whose first prompt contained it.

- **v2.1.162 (June 3):** `claude agents --json` now includes `waitingFor` showing what a blocked session is waiting on. `claude update` now announces target version before downloading. Remote Control shows as persistent footer pill instead of startup message. Renamed Windsurf to Devin Desktop in `/ide` menu. 40+ bug fixes including startup hang on read-only config dirs, JetBrains terminal flickering on 2026.1+, hook conditions firing on `$()` in bash commands, and deny rules on `$HOME` paths not blocking Bash commands referencing via `$HOME`.

**Source:** https://code.claude.com/docs/en/changelog
