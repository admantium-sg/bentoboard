# Daily Report — September 25, 2026

## Tool Releases

### Claude Code v2.1.282 (September 24)
226th release. `maxProseWidth` caps prose width in wide terminals while tables/code blocks stay full-width. Telemetry variable visibility added to startup, `/status`, and `claude doctor`. `allowClaudeInChromeWithManagedMcp` managed setting added. `store.readinessgraceseconds` added to Claude apps gateway for `/ready` grace period.
Source: https://www.havoptic.com/r/claude-code-2.1.282

### Antigravity CLI v1.2.10 (September 24)
53rd release. Medium verbosity mode between high and low. Flicker-free Mermaid/LaTeX rendering with pre-rendering and Ctrl+= / Ctrl=- zooming. Agent now knows sandboxed commands can read/write artifact/scratch directories. Headless runs with partial streaming + error now exit code 3 (was code 0). Subagent worktrees no longer treated as artifacts.
Source: https://www.havoptic.com/r/antigravity-cli-1.2.10

### Devin Desktop v3.10.35 (September 24)
55th release. Fixed startup crashes on Mac M6 chips. Fixed memory leak in agent command center. Fixed folder selection on SSH/WSL hosts. MCP servers from ACP client now usable and listed in `/mcp`.
Source: https://www.havoptic.com/r/windsurf-3.10.35

### Gemini CLI v0.61.0 (September 23)
78th release. Hardened prompt injection protection (build file modifications, untrusted flags). Hardened filesystem sandbox boundaries and isolated runtime state. Fixed AgentLoopContext property spreading.
Source: https://github.com/google-gemini/gemini-cli/releases/tag/v0.61.0

### Antigravity IDE v2.16.0 (September 22)
124th release. WSL section in Application Settings on Windows. Office document attachments (Word, Excel, PowerPoint) drag-and-drop with native Gemini reading. Live subagent cards in conversation stream with hover-to-stop. Skills discovery now under 1 second on large/network-mounted projects (was 60+ seconds).
Source: https://www.gradually.ai/en/changelogs/antigravity/
