## Tool Releases — Claude Code v2.1.206, Cline v3.0.39/v4.0.7, Kilo v7.4.4

**Claude Code v2.1.206 (July 9, 2026):** A dense feature and polish release. `/cd` now gets directory path suggestions matching `/add-dir` behavior. `/doctor` now proposes trimming CLAUDE.md files by cutting content Claude could derive from the codebase. `/commit-push-pr` auto-allows git push to the repo's configured push remote in addition to `origin`. Gateway: `/login` now supports Anthropic-operated public gateway endpoints. `EnterWorktree` now asks for confirmation before entering worktrees outside the project's `.claude/worktrees/` directory. Background agents now upgrade in the background right after a Claude Code update, eliminating the slow stale-session upgrade when attaching. Fixes include: expired login errors masked as "model issue" now prompt `/login` correctly; `--resume`/`--continue` not responding on startup; MCP servers configured via `--mcp-config` ignoring per-server `request_timeout_ms` (causing 60s timeouts); OAuth MCP servers requiring manual re-auth after failed token refresh; `--permission-prompt-tool` crashing with "MCP tool not found" before MCP server connects; `/model` picker rows printing wrong prices; server-provided model rows being misplaced; desktop sessions stuck showing "running" after slash command mid-turn. Also improved `/code-review` quality on claude-opus-4-8 across all effort levels, and the agents view status column now uses full terminal width instead of truncating at 64 characters. Ctrl+X permanently removes completed sessions; deleted background jobs stay deleted.

**Cline v3.0.39 / v4.0.7 (July 9/10, 2026):** ClinePass gets a limit-reached error with one-click switch to usage-based billing. Free models now organized into Subscribed and Free tabs in the model picker. The retired GLM 5.1 model removed from ClinePass. Fixed OpenAI Codex model metadata under the GPT Subscription provider. str_replace edits now report accurate diffs. Context compaction now preserves canonical session history. Detached hub daemon now emits telemetry with user_id in identity. Cline provider requests now send versioned client-identity headers.

**Kilo v7.4.4 (July 9, 2026):** Sandbox settings are now configurable as first-class settings with controls in a dedicated Sandboxing settings page for all supported macOS and Linux users — disabled by default. Updated SDK to v7.5.0.
