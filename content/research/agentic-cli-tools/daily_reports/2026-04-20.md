### Factory AI Legacy-Bench (NEW BENCHMARK)

**Source**: Factory AI Blog
**URL**: https://factory.ai/news/legacy-bench
**Date**: April 1, 2026
**Authors**: Leo Tchourakov, Abhay Singhal, Eno Reyes

**Overview**:
New benchmark designed to measure frontier AI agent capabilities on legacy software engineering tasks spanning COBOL, Fortran, Java 7, BASIC, C, Assembly, and more.

**Benchmark Composition**:

| Language | % of Benchmark | Domains |
|----------|---------------|---------|
| COBOL    | 46%           | Financial settlement, payroll processing, insurance claims, telecom billing, VSAM file handling |
| Java 7   | 32%           | Enterprise middleware, CDR processing, warehouse logistics, binary parsing, EJB patterns |
| BASIC    | 6%            | Business applications, accounting, data processing |
| C        | 5%            | Systems programming, low-level debugging, protocol implementation |
| Fortran  | 5%            | Scientific computing, numerical methods, physics simulation |
| Assembly | 5%            | x86 firmware parsing, protocol decoding, hardware simulation |

**Key Findings**:
- **Overall Pass Rates**: 16.9% to 42.5% across 12 model-agent combinations
- **Context**: Same frontier models score >70% on Terminal-Bench 2 and SWE-bench Verified
- **Java 7**: Best performance (bug fixing works due to visible stack traces)
- **COBOL**: Worst performance (silent errors, 31 of 44 unsolved tasks are COBOL)
- **Task Difficulty**: Bug fixing > 2x > Implementation > 2x > Migration

**Model Performance (Top Models)**:
- **GPT-5.3-Codex**: Overall leader (42.5%), leads COBOL (34.8%), weak on C
- **Gemini-3.1-Pro**: Most balanced (38.7%), strongest BASIC (81.0%)
- **Opus 4.6**: Ties GPT on Java 7 (54.2%), leads C (34.3%), worst COBOL (18.1%)
- **GLM-5**: Competitive Java 7 (40.6%), ties best Fortran migration (67%), 0% Assembly bug fixing

**Agent Comparison**:
- **Droid vs Provider Agents**: Droid consistently outperforms model provider's own agent on same model
- **Gap Largest on Hardest Tasks**: Consistent with Terminal-Bench observations
- **Systematic Verification**: Droid's scaffolding enforces compile-run-verify loop

**Failure Patterns** (97% of failures, agent believes it succeeded):
1. **Subtle logic bugs**: Code nearly correct, wrong calculation cascades
2. **Missing feature subsets**: Common path works, edge cases fail
3. **Output format mismatches**: Logic correct, formatting wrong (critical in legacy)
4. **Byte-level precision errors**: Trailing newline missing, field one byte short
5. **Spec misinterpretation**: Internally consistent but doesn't match spec

**Benchmark Construction**:
- **Hundreds of tasks** in full benchmark
- **10 sample tasks** publicly available on GitHub
- **Format**: Uses Harbor task format (compatible with Harbor-compatible agents)
- **Validation**: Containerized environments with hidden verification tests

**Why Legacy Code is Different**:
1. **Format precision is non-negotiable**: Fixed-width records, packed decimals, byte-aligned structures
2. **Validation loop is degraded**: No stack traces, silent failures, restricted terminal access
3. **Business rules are embedded**: Code is only documentation of complex logic
4. **Cross-paradigm migration**: Requires mapping between fundamentally different computational models

**Open Source**:
- GitHub repository: https://github.com/factory-ai/legacy-bench
- Evaluation harness available
- Open to submissions and contributions

**Significance**:
- First comprehensive benchmark for legacy code maintenance
- Addresses gap where real-world critical infrastructure lives
- Shows agents perform significantly worse on legacy vs modern code
- Validates need for specialized tools and approaches for legacy modernization
- COBOL dominance in benchmark reflects real-world critical systems (46% of benchmark tasks)

### Legacy-Bench Exposes Critical Gap

1. **Performance Gap is Large**:
   - 16.9-42.5% pass rates vs >70% on modern benchmarks
   - COBOL is particularly challenging (34.8% best vs >70% modern)
   - 31 of 44 unsolved tasks are COBOL

2. **Real-World Relevance**:
   - Legacy code runs critical infrastructure (financial settlement, telecom)
   - Engineers who understand it are retiring faster than replaced
   - Gap represents real business risk and opportunity

3. **Agent Design Insights**:
   - Validation loops are critical (Java works because of stack traces)
   - Silent errors are deadly (COBOL fails because no feedback)
   - Format precision matters (one wrong byte breaks interface)
   - Verification scaffolding matters (Droid beats provider agents)

4. **Market Opportunity**:
   - Legacy modernization is multi-trillion dollar market
   - First-to-solve legacy automation gains significant advantage
   - Specialized tools and approaches needed for legacy code
