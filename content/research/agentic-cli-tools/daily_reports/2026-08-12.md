## New Findings

### 1. Claude Code — v2.1.228 (August 11, 2026)

New release landing ~24 hours after v2.1.227. Notable fixes include:

- **Session redraw fix**: Interactive sessions that could freeze their entire UI after a rare layout error, while the process kept running silently — a particularly nasty UX failure for unattended runs.
- **Windows git path fix**: Git Bash not found when Claude Code launched from a parent folder of the git installation — affected Windows users working from workspace roots.
- **Cross-session messaging inbox**: Messaging now reliably creates an inbox in the first session after install or upgrade — previously a race condition.
- **Remote Control /resume leak fixed**: Resuming a Remote Control session no longer leaks the resumed conversation's title or history into the connected session.
- **Self-hosted runner improvements**: Repos whose checkout hook fails are now skipped with a warning instead of failing the whole runner; sessions no longer end in the gap between a background task finishing and its follow-up turn.
- **Project memory folder preserved**: Session cleanup no longer deletes contents inside a project's memory folder.
- **Skills shadowing eliminated**: Skills synced from claude.ai no longer shadow local commands or MCP prompts — a long-standing source of confusion in mixed skill environments.
- **Write tool behavior aligned**: Newer models can now overwrite an existing file they haven't read this session, matching the Edit tool's rules. Older models still require the read first.
- **Compaction UX improved**: Retry countdown and stall hint now appear during compaction instead of only a progress bar.

**Impact:** A reliability and polish release — the fixes target edge cases that surface in production, unattended, and enterprise workflows. The skills shadowing fix is especially welcome in teams with large local skill collections.

**Source:** https://code.claude.com/docs/en/changelog#2-1-228 | https://releases.sh/anthropic/claude-code

### 2. Kilo — v7.4.21: Agent Manager Keyboard UX, Model Search, Nested /review (August 2026)

New minor release with significant UX work on the Agent Manager:

- **Agent Manager keyboard navigation overhaul**: Cmd+/ focuses a visible embedded terminal before hiding it; Cmd+Shift+T creates a side terminal only while that terminal area has focus; Cmd+Shift+[ / ] switch terminal tabs; Cmd+Shift+M focuses the Agent Manager prompt instead of opening VS Code Problems; Cmd+W hides the last side terminal instead of stopping its shell.
- **Model search relevance**: Provider-aware results and personalized usage suggestions in the model search.
- **Multi-project worktree repo selection**: Users can now choose the repository when creating or importing a worktree in multi-project mode.
- **Nested /review support**: Staged, unpushed, and quick review modes in VS Code.
- **Pre-session model catalog browsing**: Can now browse an instance's model catalog before a session starts.
- **Slash commands in worktree prompts**: model, agent, variant, and sandbox slash commands available in Agent Manager worktree prompts.
- **"Why was this approved" line moved**: Moved to after the tool output with an icon and a Display setting to hide it.
- **Underlying model display**: Shows underlying models for every Vertex AI model.

**Impact:** The keyboard navigation overhaul makes the Agent Manager significantly faster for power users living in keyboard-first workflows. The worktree repo selection is a meaningful improvement for teams managing multiple projects.

**Source:** https://github.com/Kilo-Org/kilocode/releases

### 3. Cline — v4.1.8: Yolo Mode Removed, Fable 5 on Vertex, Compaction Fixed (August 2026)

Key changes:

- **Yolo Mode removed**: The Yolo Mode toggle was cosmetic — nothing in the approval path read it. It's been replaced by making the auto-approve menu the single source of truth for unattended runs. Setups that had Yolo Mode or auto-approve-all turned on are migrated to auto-approving every action, so unattended behavior is preserved.
- **Compaction on reasoning models fixed**: The summarizer no longer hardcodes a 1024-token output cap. It now honors explicit max-output-tokens settings, defaults to 4096 (lowered when the model reports less), and logs a diagnostic when a summary comes back empty. Previously, compaction was silently skipped on reasoning models.
- **Fable 5 on Vertex**: claude-fable-5 added to the Vertex model catalog. Pricing shows as "unknown" rather than wrong — correct behavior since Vertex bills region-dependently.
- **Custom Vertex model IDs**: Custom Vertex model IDs are passed through unchanged, routing Claude-style IDs to the Anthropic-on-Vertex path correctly.
- **Hub daemon upgrade fix**: Hosts reconnecting to stale managed Hub daemons is fixed — daemons now carry a runtime build fingerprint, so upgrading retires and respawns a daemon still running older code.
- **"View Changes" button restored**: Completion rows now show the View Changes button backed by SDK checkpoints.

**Impact:** The Yolo Mode removal clarifies Cline's unattended story — no more hidden toggles that don't do what they say. The compaction fix resolves a silent reliability issue that would have caused session context to balloon on reasoning model users.

**Source:** https://github.com/cline/cline/releases

Non-CLI items worth noting from the wider agentic ecosystem:

Signals a push toward grounding agents in licensed, live source data — relevant for agentic coding tools that could eventually surface research context.

**Impact:** The emergence of MCP servers for domain-specific licensed data (research, finance) suggests the MCP ecosystem is expanding beyond developer tooling into enterprise verticals. AgentPay is a leading indicator of agentic financial infrastructure maturing.

## Community Pulse

**Working well:** Claude Code v2.1.228's skills shadowing fix is getting positive response — teams with large local skill collections have been working around this bug for months, and the fix eliminates an entire class of unexpected behavior.

**Problems:** Cline's Yolo Mode removal is correct behavior, but some users who relied on it as a mental model may need to reconfigure their unattended setup to use the auto-approve menu explicitly.

**Interesting:** The compaction fix in Cline v4.1.8 — the summarizer silently skipping on reasoning models — was a hidden reliability issue that would have caused context to grow unbounded on long sessions. This is the kind of silent failure that's hard to debug without knowing the tool internals.

---

## Trend

Claude Code is in a high-velocity bugfix and polish phase following its enterprise feature drops (self-hosted runners, cross-session messaging). Kilo and Cline are both converging toward better keyboard-first UX and clearer unattended run semantics. The broader agentic ecosystem is branching into vertical domains — research data, manufacturing, payments — via the MCP server ecosystem.
