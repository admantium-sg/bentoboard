**Claude Code v2.1.149–150 (May 22–23, 2026) — `/usage` Breakdown, Security Fixes**

Two releases with significant quality-of-life and security work:
- **v2.1.150 (May 23):** Internal infrastructure improvements (no user-facing changes)
- **v2.1.149 (May 22):** `/usage` now shows per-category breakdown of limit drivers (skills, subagents, plugins, per-MCP-server cost); `/diff` detail view keyboard-scrollable; GFM task list checkboxes render in markdown output

## Market & Industry Context

**Cline SDK Open-Sourced — Benchmark Claims Exceed Claude Code Performance**

Cline extracted its internal agent harness into a standalone open-source TypeScript SDK (`@cline/sdk`), rebuilding all products (CLI, VS Code, JetBrains) on top of it. The architectural redesign provides:
- Stateless, portable agent loop — sessions survive UI restarts and move across surfaces
- Layered TypeScript stack: `@cline/shared` (types, schemas, tool helpers) → `@cline/llms` (provider gateway) → `@cline/agents` (browser-compatible agent loop) → `@cline/core` (Node runtime)
- Individual packages installable: use just `@cline/llms` for LLM proxy, or `@cline/agents` for stateless loop in serverless/browser

**Benchmark claims (Cline team, pass@1 as of May 8, 2026):**
- Claude Opus 4.7: Cline CLI 74.2% vs Claude Code published 69.4% (+4.8 pts)
- Claude Opus 4.6: Cline CLI 71.9% vs Claude Code published 65.4% (+6.5 pts)
- Kimin K2.6 (open-weight): Cline 55.1% vs OpenCode 37.1% (+18 pts) and Pi-Code 45.5% (+9.6 pts)

Cline also reports faster task completion and lower token cost vs the old CLI in internal runs.

## Community Pulse

**Working well:** The `--profile` migration in Codex CLI v0.134.0 signals a broader industry move toward user-scoped configuration over global defaults. Claude Code's `/code-review` rename from `/simplify` with correctness-focused effort levels is being received positively — the old "clean up and fix" behavior that confused users is gone. OpenCode's diff viewer GA after two weeks of iteration shows the value of shipping experimental features early and iterating based on feedback.

**Problems:** The Cline SDK benchmark claims are self-reported and not independently verified. The coding agent benchmark space remains fragmented — Terminal-Bench 2.0, SWE-Bench Pro, and ad-hoc pass@1 runs make cross-tool comparisons difficult without standardized evaluation protocols. The Cline team notes scoring was done by them using their own methodology.

**Interesting:** Codex CLI v0.134.0's conversation history search (`[#23519](https://github.com/openai/codex/pull/23519), [#23921](https://github.com/openai/codex/pull/23921)`) is the first CLI tool in this class to add semantic search across past sessions. This addresses a pain point where developers lose context from earlier sessions — if it works well, expect similar features from Claude Code and OpenCode.

## Trend

CLI coding agents are converging on multi-session management (search, resume, background) as the next major UX frontier. The feature set from 2024–2025 (model quality, tool count, context window) is now table stakes — the differentiator in 2026 is session durability, cross-session memory, and profile/configuration management.
