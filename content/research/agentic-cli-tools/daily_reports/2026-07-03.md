## New Findings

### Claude Code v2.1.198 — July 1, 2026

**Claude in Chrome is now generally available.** The Chrome extension for Claude Code has moved from beta to GA — users can now interact with Claude Code directly from the Chrome browser.

**Background agent notifications via Notification hook:** Sessions that need input or finish now fire the `Notification` hook (`agent_needs_input` / `agent_completed`) — enabling external integrations to respond to agent lifecycle events.

**`/dataviz` skill added:** New built-in skill for chart and dashboard design guidance with a runnable color-palette validator.

**Claude Platform on AWS (anthropicAws) in Gateway:** Added as an upstream provider; model-not-found responses now advance the failover chain — important for enterprise multi-provider setups.

**Background agents auto-submit PRs:** Background agents launched from `claude agents` now commit, push, and open a draft PR when they finish code work in a worktree, instead of stopping to ask.

**Explore agent model upgrade:** Built-in Explore agent now inherits the main session's model (capped at Opus) instead of running on Haiku — significantly better exploration quality.

**Subagents inherit extended thinking:** Subagents and context compaction now inherit the session's extended thinking configuration, improving output quality on delegated tasks.

**Reliability fixes:** Transient network errors (ECONNRESET) now retry with backoff instead of failing; agent teams now report failures correctly; `/diff` refreshes on branch switch.

**Source:** https://code.claude.com/docs/en/changelog

## Industry Analysis

**Codepick roadmap (June 2026):** Updated guide confirms 2026 as "the year AI coding enters the agent engineering phase" — from completion to delegation, from isolated tools to workflow entry points, from prompt tricks to systems engineering (context management, permissions, MCP, sandboxes, audit logs, cost controls). Key insight: teams now need governance frameworks for which agents can modify which repos, access which secrets, and spend which budget.

**Three-layer stack emerging:** IDE for real-time collaboration, CLI for local execution, cloud agents for asynchronous delegation. CLIs are not being replaced — they remain the preferred surface for experienced developers due to proximity to git, tests, build scripts, and CI pipelines.
