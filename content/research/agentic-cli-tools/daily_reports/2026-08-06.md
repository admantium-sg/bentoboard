### Codex CLI — v0.146.1 Stable Patch; Alpha Sprint Slows (August 5, 2026)

Codex CLI rust-v0.146.1 landed August 5 as a focused security/UX patch on top of the major v0.146.0 (July 29) stable:

- **Safer automatic-review defaults for cyber-capable models** — adjusts how Codex handles permission and review decisions for models with advanced cyber capabilities, making defaults more conservative

### Cline — Two Post-Stable Releases: v4.1.4 and v4.1.5 (August 4–5, 2026)

Beyond the v4.1.3 (Aug 3) checkpoint/messaging release covered last cycle, Cline shipped two further releases:

**v4.1.4 (August 4):**
- **Plan mode hard-blocks file-editing shell commands** — run_commands stays read-only; file manipulation, sed/perl in-place edits, redirection, mutating git subcommands, package installs, and nested command strings (sh -c, eval, sudo, xargs) are rejected with a tool error on both Windows and PowerShell
- **Context-window overflow recovery** — instead of raw provider errors, overflows now trigger a deterministic force-compaction and retry once; genuinely unrecoverable cases surface actionable messages
- **Root-session persistence is lazy** — sessions written to database only after first user turn, eliminating empty history entries from sessions closed prematurely
- **Empty responses retry on all providers** — previously only Ollama retried empty model responses; now OpenRouter, Cline, and OpenAI-compatible endpoints do too
- **Claude 4.6+ and 5.x adaptive-era models fixed** — no longer rejected with "thinking.type.enabled is not supported" when resolving from offline catalog or hand-typed model IDs
- **Bedrock prompt caching restored** — cache reads/writes were reporting zero because Bedrock sends Converse cachePoint markers instead of Anthropic cache_control format; converter now handles both
- **Upgraded to AI SDK 7** — Ollama switched to native AI SDK provider with wire fixes for empty think settings, mid-stream errors, attachment-only turns

**v4.1.5 (August 5):**
- **Reasoning settings unified across AI SDK providers** — effort levels and enable/disable toggles behave consistently on all providers including Ollama, instead of relying on per-provider overrides
- **Chutes recognized as a provider** — added to supported provider list
- **Model-initiated plan-to-act switching removed** — switching out of plan mode is now user-driven only; model no longer decides mid-turn
- **Free model promotion end dates explained** — retired free models now show a dedicated notice with a model-picker button instead of a generic error

Source: https://github.com/cline/cline/releases

## Community Pulse (Task 2)

### Steganography Crisis Fades but Token-Bloat Comparison Remains Live

The steganography allegation (2,445 HN points) peaked in July and has faded from top-of-mind community discussion — not resolved, but no new major developments in the past week. What persists is the token-bloat comparison: "Claude Code sends 33k tokens before reading the prompt; OpenCode sends 7k" (706 HN points, 396 comments) continues to circulate as a efficiency/cost argument against Claude Code.

The July 2026 last30days.ai brief on Claude Code (published Jul 28) captures the community verdict: "Claude Code sits at an inflection point between explosive adoption and serious institutional backlash." The Alibaba ban over backdoor allegations, combined with the ongoing steganography controversy, continues to represent "enterprise-level" risk perception. On the positive side, non-coding use cases (MRI second opinion, 566 HN points) and the Bun/Rust rewrite discussion (608 HN points, 849 comments) show genuine engagement beyond the controversy.

Atlas shutdown in 3 days (August 9) remains the most concrete near-term event — no Windows/iOS/Android release ever shipped, agentic browsing moving into ChatGPT/Codex directly.
