**Claude Code v2.1.126 (May 1, 2026)**
- Project purge command: claude project purge [path] deletes all state (transcripts, tasks, file history, config) with --dry-run, --yes, --interactive, --all modes
- /model picker now lists gateway models when ANTHROPIC_BASE_URL points to Anthropic-compatible gateway
- --dangerously-skip-permissions expanded to bypass .claude/, .git/, .vscode/, shell configs (catastrophic removal still prompts)
- OAuth login accepts pasted code for WSL2/SSH/container environments where browser callback can't reach localhost
- Windows: PowerShell 7 detection improved (Store, MSI, .NET global tool); PowerShell now primary shell when enabled
- Security fix: allowManagedDomainsOnly/allowManagedReadPathsOnly now enforced even when higher-priority settings lack sandbox block
- Image handling: automatic downscaling on paste, oversized images removed from history with retry
- Auto mode spinner turns red when permission check stalls
- 32 total changes including fixes for stream idle timeout after Mac sleep, OAuth timeout on slow connections, Japanese/Korean/Chinese text rendering on Windows
- Source: https://github.com/anthropics/claude-code/releases/tag/v2.1.126
