### Kilo v7.2.12 Pre-release

**Source:** GitHub Releases
**URL:** https://github.com/Kilo-Org/kilocode/releases
**Date:** April 23, 2026 at 18:58 UTC

**Previous Version:** v7.2.11 (April 21, 2026)
**Current Version:** v7.2.12

**Minor Changes:**

1. **xterm.js-Powered Terminal Tabs:**
   - Open terminal tabs in Agent Manager
   - Click chevron next to + tab button and pick "New Terminal"
   - Keyboard shortcut: Cmd+Shift+T / Ctrl+Shift+T
   - Spawns real shell in selected worktree or Local directory
   - Terminals render as proper tabs alongside agent sessions
   - Support mixed drag-reorder with session tabs
   - Persist position across webview reloads
   - VS Code integrated terminal shortcut (Cmd+/) unchanged

2. **JetBrains Session Chat UI:**
   - Add initial JetBrains session chat UI
   - Improve sandbox debug logging for tracing chat events
   - Expands Kilo beyond VS Code to JetBrains IDEs

**Patch Changes:**

1. **Submit Behavior Restoration:**
   - Restore explicit Submit behavior for single-choice question prompts in VS Code extension
   - Option clicks now stay visible for review
   - No longer immediately sends the answer
   - Better UX for reviewing options before submission

2. **Mid-Turn Message Handling:**
   - Fix mid-turn message handling
   - New prompt sent while assistant working no longer aborts in-flight response
   - Current LLM reply streams to completion
   - Pending suggestion or question automatically dismissed
   - New prompt runs immediately after current step
   - No longer waits for entire multi-step turn to finish
   - Better user experience for queued prompts

3. **TUI Freeze Fix for Large Files:**
   - Fix TUI freeze on huge-file diffs
   - Session-summary and file-view patches now use git directly
   - No longer uses JavaScript Myers implementation
   - Files of any size render full diff without blocking session
   - Addresses performance issue with large codebases

4. **LLM Token Streaming Performance:**
   - Significantly speed up LLM token streaming in long sessions
   - Chat view stays responsive while model streams reply
   - Works even in sessions with hundreds of messages
   - Previously: each SSE batch produced ~1.3 seconds of visible freeze (~80 dropped frames)
   - Streaming ticks now inside single animation frame
   - Massive performance improvement for long sessions

5. **Dependency Updates:**
   - @opencode-ai/ui@7.2.21
   - @kilocode/kilo-ui@7.2.21

**Significance:**
- JetBrains integration expands Kilo beyond VS Code ecosystem
- Terminal tabs in Agent Manager provide native terminal access within web UI
- Massive performance improvements for long sessions (streaming, large files)
- Mid-turn message handling improves UX for impatient users
- Kilo continues to address performance edge cases in long sessions
- 2-day release cadence for pre-releases (v7.2.11 April 21, v7.2.12 April 23)
- Kilo focusing on IDE integration and performance
