## Community & Market

### Steganography Crisis: China Escalates

China's MIIT/NVDB formally classified Claude Code versions 2.1.91–2.1.196 as a severe security backdoor risk on **July 8, 2026**. Key new details:

- **Trigger condition**: Hidden logic only activated when ANTHROPIC_BASE_URL pointed to a non-official endpoint (corporate gateway, LiteLLM, API reseller). Official api.anthropic.com users were not fingerprinted.
- **Technique**: Steganography in system prompt — date separator swap (2026-06-30 vs 2026/06/30) plus Unicode apostrophe variants encoding timezone (Asia/Shanghai, Asia/Urumqi) and a 147-domain XOR+Base64 blacklist match.
- **Anthropic response**: Removed in v2.1.197 (July 2), called it an "experiment" for anti-abuse/anti-distillation. Changelog silent on removal.
- **Enterprise fallout**: **Alibaba banned Claude Code company-wide effective July 10**, directing staff to internal tool Qoder.
- **Scope**: ~20 releases between April 2 and June 29, 2026 carried the hidden logic.
