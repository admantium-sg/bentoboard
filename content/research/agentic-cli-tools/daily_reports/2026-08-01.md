## Tool Releases

### Kilo v7.4.18 — Multi-Project Agent Manager, Scope Picker, Persian UI (August 1, 2026)

New stable with several significant additions:

**Diff Review scope selector and base branch picker:** The Agent Manager diff review now lets you switch between Branch, Staged, Unstaged, and Session scopes per worktree, with the Branch scope's base branch configurable via a picker. Branch remains the default.

**Experimental multi-project Agent Manager:** A persistent project registry catalogs additional Git repositories across restarts, with each project running its own git stats and PR pollers. Sessions created anywhere (sidebar, another window, CLI) appear in the owning project's list immediately. This is a significant architectural step toward managing multi-repo agent workflows.

**Additional changes:** Agent Manager diff review follows sidebar selection instead of a single session; Cmd/Ctrl+/ toggles the Agent Manager terminal more reliably; embedded terminal opening fixes; worktree setup scripts run in the selected toolbar terminal with live output; Persian (Farsi) UI language with RTL layout; skill shell commands shown in the permission prompt with per-command Allow/Reject.

**Source:** https://github.com/Kilo-Org/kilocode/releases

### Cline v4.1.0 — Major SDK Extension Rollout Begins; v4.1.2 Patch (July 30–31, 2026)

**v4.1.0** is the most significant architecture change in recent Cline history: the stable extension is now a combined A/B package containing both the legacy extension and the new SDK-based extension, with a staged remote rollout gradually activating the new extension for users (starting at 1%). Key changes:
- Rollout loader activates exactly one extension per window; falls back to current extension automatically on failure
- Session forking and user-run message APIs for editing earlier prompts
- Auto-compaction state bug fixed (was triggering extra summarizer calls on every turn past the trigger)
- `ClineCore.readLiveMessages` API for reading a resident session's in-memory transcript mid-turn
- Per-server MCP timeout (from cline_mcp_settings.json) now honored instead of hardcoded limits
- Reasoning controls driven by models.dev catalog; OpenRouter defaults to anthropic/claude-sonnet-5

**v4.1.2** (latest): Extension variant indicator ("Legacy" or "Next") in settings About page; MCP routing migrated from random uid to native server-name routing, surviving restarts and server list changes.

**Source:** https://github.com/cline/cline/releases

## Community & Market

### Community Pulse — July 2026 Research Brief: "Cautiously Invested but Sobered"

The last30days.ai July research brief captures the current ecosystem mood:

**Bullish signals:** Tooling ecosystem is maturing fast — multiple high-signal launches (OfficeCLI, OneCLI, FableCut, Flint visualization language for agents) within days of each other suggest a "Cambrian explosion" in agent-native tooling. GPT-5.6 migrations showing "2.2x faster, 27% cheaper" signal real production deployments at scale. Jack Dorsey's Buzz (team chat + AI agents + Git hosting, 377 HN points) shows major platforms betting on agents as a foundational layer. Open-model agent infrastructure (LM Studio Bionic) signals broadening access beyond closed APIs.

**Skeptical signals:** Zuckerberg publicly told staff that agent development is "going slower than expected" (342 pts, 616 comments — most-discussed item in the dataset). GitLost attack on GitHub's AI agent leaked private repos (541 pts) — a demonstrated, named exploit, not theoretical. OneCLI's explicit focus on keeping secrets from AI agents implies credential exposure is a known, active problem.

**Verdict:** Developers are building seriously but also building credential gateways, patching leaks, and asking hard questions in long threads. The Claude Code conversation remains concentrated on HN; Dev.to shows no direct Claude Code coverage in its top posts, with engagement skewing toward burnout and broader AI-futures topics.

**Source:** https://last30days.ai/research/ai-agents | https://last30days.ai/research/claude-code
