The China MIIT/NVDB formal classification (July 8) of Claude Code v2.1.91–2.1.196 as a severe security backdoor risk remains the dominant narrative but has passed peak media intensity. The market appears to be pricing the incident as a known risk rather than an escalating threat — notable given the scale of the accusations.

## Trend Analysis

The CLI agent ecosystem is in a mid-July cooling period on the release front — Claude Code's longest silence in weeks, Codex in intensive alpha stabilization, others quiet. But funding and market activity remain red-hot: $1.8B in July alone, with developer tooling specifically at $420M. The market appears to be separating from the steganography narrative into two distinct trajectories: trust-dependent enterprise sales (where Claude Code faces headwinds) and developer-led bottom-up adoption (where both Codex and Claude Code continue growing).

The benchmark divergence on Terminal-Bench (Codex +13pp lead) could be a strategic vulnerability for Claude Code if terminal-native workflows become the primary CLI agent use case.
