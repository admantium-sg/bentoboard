## New Findings (2026-09-21 to 2026-09-22)

### Factory Droid v0.223.0 — Session Forking, PyCharm, Databricks Connector (September 19, 2026)
CLI v0.223.0 and Desktop v0.180.0 bring several significant features: fork sessions directly from the session list sidebar; organization-managed Databricks connector allowing administrators to set up access for members; PyCharm as a new editor option; hook risk level settings; streaming chat tables that reveal complete rows as they stream; sessions now default to medium autonomy instead of off; typing during startup while Droid finishes initializing; custom model list now shows 8 models before expanding; and credential notice improvements.

**Source:** https://www.gradually.ai/en/changelogs/factory-ai/

### OpenAI Codex CLI rust-v0.155.1 — Voice Conversations, Live Transcripts, Reasoning Summaries (September 18, 2026)
Critical fix for new local TUI sessions that were incorrectly enabling reasoning summaries, causing rejections. This follows v0.155.0 which introduced voice conversations with live transcripts and real-time reasoning summaries. The Rust variant continues rapid iteration with voice/features arriving first on this track.

**Source:** https://www.havoptic.com/tools/openai-codex

### Claude Code v2.1.278 — Auto Mode Server-Side Classifier Billing (September 19, 2026)
Changed auto mode for Claude API, Enterprise, Bedrock, Vertex, Foundry and gateways to default to the server-side classifier, which does not charge for classifier overhead. Added AGENTS.md support: in projects with no CLAUDE.md, Claude Code now reads AGENTS.md instead. Also added gateway proxy header configuration for EGRESS_BOUNDARY setups and optional headers map for upstream proxies.

**Source:** https://www.havoptic.com/r/claude-code-2.1.278

### Kilo v7.7.6 — Git Projects from Agent Manager, Session History Paging (September 18, 2026)
VS Code: Create new Git projects and clone repositories directly from Agent Manager, choose storage location, attach without changing workspace. Load older chats on demand with "Load more" control (previously stopped at 100 most recent). CLI: Auto-compaction threshold now applies to provider-reported token usage plus newly added content. Encrypted reasoning support for OpenAI models via Amazon Bedrock.

**Source:** https://github.com/Kilo-Org/kilocode/releases

### Antigravity CLI v1.2.6 — Remote Control, Unlimited Headless Timeouts, Structured Error Reporting (September 18, 2026)
Added Remote Control via --remote-control flag or /remote-control command for session-scoped remote connections. Changed headless (-p/--prompt) default timeout from 5 minutes to unlimited for long-running agent turns. Improved headless error reporting with structured AGY_ERROR: {...} JSON on stderr and exit code 3. Improved word-wise cursor movement in prompt editor to stop at punctuation boundaries.

**Source:** https://www.gradually.ai/en/changelogs/antigravity/

### Antigravity IDE v2.15.0/2.15.1 — Custom Agent Controls, Windows Sandbox (September 18-19, 2026)
Custom agents can now switch off default prompt sections and default tools and add back only the tools they need. Keyboard navigation improvements (Page Up/Down, Home, End, Escape). Custom agent selection remembered after reload. v2.15.1 adds Windows sandbox support for file and network sandboxing.

**Source:** https://www.gradually.ai/en/changelogs/antigravity/

## Community Pulse

**Working well:** Voice conversation features are spreading across tools — OpenAI Codex CLI now has live transcripts and reasoning summaries in Rust builds. Antigravity CLI's Remote Control feature enables following and controlling active terminal sessions from another device, a capability being requested across the industry.

**Problems:** No major issues reported this cycle.

**Interesting:** The Antigravity IDE's new custom agent controls let users build agents from scratch by disabling defaults and adding only needed tools — this marks a shift from configure-via-settings toward configure-via-capability selection, potentially influencing how other tools approach agent customization.

- **Antigravity Windows sandbox** — File and network sandboxing on Windows (Sep 19) signals growing desktop OS coverage for enterprise security policies
