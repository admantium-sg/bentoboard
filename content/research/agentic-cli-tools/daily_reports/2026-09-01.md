# Daily Report — 2026-09-01

## New Findings

### Claude Code — v2.1.252: Bug Fixes for macOS, Remote Control, and Task Notifications (August 31, 2026)
Quiet close to August: v2.1.252 landed as a four-fix patch. Bash commands on some Macs were failing with "task output swap refused (tasks dir moved or linked)" — corrected. The "always allow" permission setting was not persisting when a project had no pre-existing `.claude/settings.local.json` — fixed. Remote Control sessions in Claude Desktop or VS Code were stalling for minutes after a tool finished when the connection to claude.ai was degraded — resolved. Background task notifications carrying very large failure output (e.g., git errors on a full disk) were bloating the conversation past the API request size limit — capped.

**Source:** https://code.claude.com/docs/en/changelog

### OpenAI Codex CLI — v0.152.0-alpha.5/6/7: Extensions Intercept MCP Results, Sandbox Hardening (August 30–31, 2026)
The v0.152.0 alpha chain advanced through alpha.5, alpha.6, and alpha.7. Key additions across the three tags: **Extensions can now inspect or replace MCP tool results before they reach the model** — giving developers explicit control over AI response shaping. The MCP server discovery grace period is now configurable. Remote sandbox enforcement improved using the executor's actual home directory, OS, and path conventions. Tool availability and reasoning effort stay correct when switching models or falling back. Nested subagent token usage now counts toward root goal budgets. Guardian V2: stale classifications no longer authorize actions after permission state changes. v0.151.0 stable continues unchanged.

**Source:** https://github.com/openai/codex/releases

### Cline — Desktop v0.0.21: Two-Pane Marketplace, Session Stop Propagation, Cloud Handoff Beta (August 30, 2026)
Major desktop release:

**Two-pane marketplace explorer:** browsable list on the left, full catalog metadata on the right, with category tag filters behind a "more" toggle.

**Session stop propagation:** stopping a session now stops everything it started — abort propagates to delegated subagents and teammates instead of leaving orphaned work. Cancelled teammate tasks persist as cancelled.

**Cloud sessions beta (preview):** hand off local sessions to Cline Cloud and continue from cloud workspaces, with recovery for interrupted transfers and preservation of prompt, attachments, and session state.

**Environment picker beta:** choose between local, SSH remote, and Cloud environments from the desktop app, with experimental realtime voice and avatar overlay.

**Provider telemetry:** model catalog now refreshes from live catalog so newly released models appear without app updates. Provider 401/403 responses now classified as authentication errors rather than generic failures.

**Source:** https://github.com/cline/cline/releases

### Kilo — v7.5.6: Agent Manager Worktree Cross-Referencing, Compaction Model, Mermaid in JetBrains (August 30, 2026)
Solid minor release with meaningful Agent Manager improvements:

**Cross-worktree @ picker:** reference other Agent Manager worktrees with a searchable @ picker that prioritizes recently opened worktrees. Share paths, branches, and session IDs without attaching diffs or chat history.

**Separate compaction model:** choose a different model specifically for conversation compaction in Context settings — users can now dedicate a cheaper/faster model for compaction while using a premium model for actual coding work.

**/review worktree:** review all committed and uncommitted Agent Manager worktree changes with `/review worktree`.

**Mermaid diagrams in JetBrains:** render all Mermaid diagram types in JetBrains chat, with editor-tab viewing, zoom, pan, fit-to-view, source view, and PNG copy.

**Cross-session search:** search the latest 5,000 chats across the worktree family, displaying the best 50 matches in sidebar and Agent Manager.

**Source:** https://github.com/Kilo-Org/kilocode/releases

## Community Pulse

**Working well:** The compaction model split in Kilo v7.5.6 addresses a recurring user pain point — using an expensive model for compaction is wasteful. Community response to the Cline cloud handoff beta is cautiously positive, with emphasis on recovery guarantees.

**Problems:** No major complaints surfacing today. The quiet is notable — after the August sprint intensity from Claude Code and Codex, the lighter release slate gives the community breathing room.

**Interesting:** Cline's two-pane marketplace redesign signals a shift toward discovery UX in agent tooling — the previous single-column list was widely criticized as unusable with large catalogs. The community is watching whether it drives more plugin adoption.
