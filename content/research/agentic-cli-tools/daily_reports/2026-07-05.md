### Cline CLI v3.0.37 — July 4, 2026

**Weaker model tool call resilience.** Models like DeepSeek that emit malformed tool calls (wrong argument types, truncated JSON) are now handled gracefully and run instead of erroring out — reduces failure cascades with lower-quality models.

**Plan/act mode visibility.** Plan/act mode switches are now visible to the model, so it knows when you change modes mid-session — smoother transitions and fewer confused responses.

**Source:** https://github.com/cline/cline/releases

### Microsoft Enterprise Study: CLI Coding Agent Adoption & Impact — July 2026

A newly published arxiv paper documents Microsoft's early 2026 rollout of Claude Code and GitHub Copilot CLI to tens of thousands of engineers. Key findings:

**Adoption patterns:**
- First use spread primarily through social networks — peer influence is the dominant driver
- Retention was associated more with engineers' coding activity than demographics — active coders keep using it, regardless of age, role, or experience level

**Impact metrics:**
- Adopters merged roughly **24% more pull requests** than they would have without the tool
- The lift persisted across the four-month study window — not a novelty effect

**Context:**
- Claude Code was the most popular AI-based developer tool among Pragmatic Engineer survey respondents in early 2026
- 41% of all code written in 2025 was AI-generated; crossing 50% expected in high-adoption orgs by late 2026
- Average agentic AI funding round size Q4 2025/early 2026: $155M (vs. $82M in H1 2025)
- Coding /dev-tool startups collectively raised >$3B — highest-funded agentic AI sub-sector

**Note:** The study window ended April 29, 2026, before Microsoft's decision to discontinue Claude Code licenses for most engineers in favor of Copilot CLI.

**Source:** https://arxiv.org/html/2607.01418v1

## Community Pulse

**Working well:** The Microsoft study confirms the 24% PR lift validates what many individual developers have reported — CLI agents are producing measurable output gains in enterprise settings, not just anecdotal improvements.

**Problems:** Microsoft moving away from Claude Code toward Copilot CLI raises questions about enterprise lock-in. The study noted Claude Code was the most popular tool among developers, yet procurement decisions went otherwise.

**Interesting:** The social-network adoption pattern (peer influence > demographics) suggests companies should focus on visible internal champions rather than broad email announcements for rollout success.
