## New Findings (June 11)

### Claude Code v2.1.173 (June 11, 2026) — Fable 5 Name Fix, Windows Sandbox Fix

Minor patch release, but two meaningful fixes:
- **Fable 5 `[1m]` suffix normalization**: Fable 5 includes 1M context by default, but model names were appearing with a duplicate `[1m]` suffix. The suffix is now stripped automatically — fixes model picker confusion and potential billing edge cases.
- **Windows sandbox warning fix**: Fixed spurious "sandbox dependencies missing" startup warning on Windows when sandbox was enabled in settings.

**Source:** https://code.claude.com/docs/en/changelog

### OpenAI Codex CLI v0.140.0-alpha Series (June 10–11, 2026) — Six Alphas in 36 Hours

Six alpha releases in roughly 36 hours (alpha.4 and alpha.7 on June 10; alpha.8 through alpha.11 on June 11, culminating at 19:12 UTC). No detailed changelog extracted for individual alphas, but the cadence (multiple per day) and the PR activity visible in v0.139.0's changelog suggest the v0.140.0 stable is close. Active PR themes in the alpha cycle include: multi-agent v2 concurrency controls, v2 agent residency LRU caching, and remote-control websocket enrollment fixes.

**Source:** https://github.com/openai/codex/releases

### Cline CLI v3.0.24 (June 11, 2026) — Plugin Architecture, Windows Stability

Major patch on the same day as the VS Code 1.123 compatibility fix:
- **Plugin commands can submit prompts**: Plugin commands can now submit prompts directly to the agent — enables richer plugin-tool integrations.
- **API base URL override**: Added support for overriding the API base URL, improving self-hosted and proxy deployments.
- **Device auth auto-open**: Opens the verification URL automatically when starting device authentication.
- **Single shared Cline Hub**: Enforced a single shared Cline Hub — stale hubs are now respawned after an upgrade, fixing session fragmentation.
- **Windows console flicker fix**: Suppressed flickering console windows on Windows.
- **Tool result truncation fix**: Fixed truncation of structured tool operation result strings — oversized tool output stays within limits.
- **Command echo removal**: Stopped echoing the full command text in `run_commands` tool results.

**Source:** https://github.com/cline/cline/releases

### Cline CLI v3.89.1–v3.89.2 (June 11, 2026) — VS Code 1.123+ / Node 24 Compatibility

Same-day two-release patch addressing the VS Code 1.123 update:
- **v3.89.1**: Restored the Anthropic provider on VS Code 1.123+, where the updated Node 24 runtime broke the bundled Anthropic SDK. Also handles DeepSeek V4 reasoning format.
- **v3.89.2**: Complete fix — upgraded bundled Anthropic SDK to a release compatible with Node 24, and updated Vertex AI provider to a compatible Anthropic Vertex SDK release.

This is a significant same-day response to a breaking VS Code update. Teams using Cline in VS Code with Anthropic models were broken for hours.

**Source:** https://github.com/cline/cline/releases

### GitHub Copilot CLI — Agent Becomes Default (Phased Rollout from June 2026)

GitHub announced a phased transition to make Copilot CLI agent (currently in public preview) the default experience. The announcement came June 2 but the rollout is now active:
- **Agent picker**: Users can choose between Agent mode (default, full autonomy), Ask mode, Custom agents, and Plan mode (collaborative planning before implementation).
- **New slash commands**: `/remote` for remote control from github.com or GitHub Mobile, `/compact` for manual context compression, `/chronicle` for session history analysis and personalized tips.
- **Agent debug panel** (public preview): Chronological event log of agent interactions, useful for debugging custom agents and sub-agent workflows.
- **Remote control**: Available via Settings > Tools > GitHub Copilot > Chat > Enable Copilot CLI Remote.
- Copilot Business/Enterprise admins must enable the Editor preview features policy first.

**Source:** https://github.blog/changelog/2026-06-02-introducing-copilot-cli-and-agentic-capabilities-enhancements-in-jetbrains-ides/

## Community Pulse

### Working Well
- **Cline's rapid VS Code 1.123 fix**: The Node 24 / VS Code 1.123 compatibility break was fixed within hours by the Cline team — impressive turnaround for a same-day regression. Community noting Cline's responsiveness to ecosystem changes.
- **GitHub Copilot CLI agent default**: The `/chronicle` command (session analysis, personalized tips, improvement suggestions) is being called "surprisingly useful" — the idea of an AI that learns from your own usage patterns and suggests optimizations is resonating.
- **Claude Code's Fable 5 normalization fix**: Quiet but important — the `[1m]` suffix duplication was causing confusion in billing and model picker UIs. Quick fix after the June 10 launch.

### Problems
- **Cline's frequent version numbers**: Cline is now shipping concurrent streams (v3.0.x stable, v3.89.x as the latest) with overlapping dates — community noting difficulty tracking which version to install. The dual-track versioning (cli vs VS Code extension) creates confusion.
- **Codex CLI v0.140.0 stable not yet out**: Six alphas in 36 hours with no stable in sight — the community is watching closely. Some expressing concern about stability of the alpha cycle.

### Interesting
- **GitHub Copilot CLI's `/chronicle` feature** marks an interesting divergence: while other tools focus on raw capability (more agents, more context, more tools), Copilot CLI is adding meta-learning features — analyzing how you use the tool and suggesting improvements. First tool to explicitly offer AI-assisted productivity coaching within the CLI session.
- **Cline's plugin commands submitting prompts** suggests a move toward agent-to-agent plugin communication — plugins that don't just extend tool sets but can actively drive the agent's behavior.
- **Phased rollout of Copilot CLI agent default** is a notable shift for GitHub — previously Copilot CLI used a non-agentic default (Ask mode). Making agentic the default signals that GitHub believes the technology is mature enough for general use.
