# Daily Report — September 27, 2026

## Tool Releases

### Factory Droid v0.228.0 (September 26)
CLI v0.228.0, Desktop v0.185.0. Major command palette rebuild — now reaches every page and setting with category tabs and ranked results. New `/migrate` workflow command takes large work from an agreed plan to a verified outcome, with a migration files view showing plan and validation documents in the app. Skills can now be activated and highlighted anywhere in a message, not only at the start. New delegation audit events in audit logs. Image generation now lets you choose which model Droid uses. Other improvements: Slack posts outside your conversation now name the person who asked; mid-session plugin discovery loads project plugins when you enter a repository during a session; `/compress` summarizes your current session and `/handoff` starts a summary-only successor. Fixes: custom model fallback to an available one when your configured model is no longer accessible; macOS sign-in reliability when system keychain is unavailable.
Source: https://www.gradually.ai/en/changelogs/factory-ai/

### Antigravity IDE v2.17.0 — Plan Before You Build (September 22)
125th release. Rules no longer crowd out skills and subagents — rules now get their own 20,000-token budget, stopping large rules files from pushing tools out of context. Custom agents can declare their own hooks in their front matter with paths relative to the agent, project, or absolute. "Save Video" right-click option from any video in chat, file viewer, browser recording, or full-screen preview. Per-project configuration moved from `.agents/settings.json` to `/.gemini/config.json`. Skills discovery on large projects and network-mounted folders now under 1 second vs 60+ seconds before. Large files and diffs no longer freeze the app — syntax highlighting and line diffing run off the main thread, with files over 100 KB falling back to plain text. Rewinding a conversation now correctly restores post-rewind state instead of potentially restoring an earlier state.
Source: https://www.gradually.ai/en/changelogs/antigravity/

### Antigravity CLI v1.2.9 (September 23)
55th release. Direct `@` prompt syntax to message subagents with autocomplete for running and completed subagents. Vim numeric count multipliers added: 3dw, 2d3w, 3dd, 3x, 3rX, 3p, 3u, [count]G/gg/$, and counted text objects. Critical fixes: headless runs no longer leave daemon processes running after exit; database corruption risk from file lock contention resolved; context compaction fixed for scenarios where tool configuration was rejected. Improved artifact viewer with Left/Right pan hints for wide diagrams.
Source: https://www.gradually.ai/en/changelogs/antigravity/

## Community Pulse

**Working well:** Factory Droid's new `/migrate` command is drawing attention — it formalizes the workflow of taking a plan through to verified outcome, addressing a common pain point in agent-assisted development. The mid-message skill activation is another quality-of-life improvement for developers who want to sprinkle in specific capabilities without restructuring their prompts.

**Problems:** The community continues to grapple with context management — rules having their own 20K token budget in Antigravity IDE is a direct response to tools getting crowded out. This pattern (large instruction files pushing tools out of context) appears across multiple CLI agents and remains a recurring theme.

**Interesting:** Reinventing.AI released eight open-source AI Employee packages on GitHub under MIT license, covering 59 scheduled business routines across 11 agent harnesses. This represents a different model from the integrated CLI tools — portable, role-based agents that work with existing tooling rather than locking users into a single platform.
