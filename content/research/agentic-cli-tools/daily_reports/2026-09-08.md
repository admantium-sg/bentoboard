## Community Pulse

**Working well:** The rapid release cadence continues across all major CLI tools — Claude Code averaging 1 release per day, Codex CLI averaging 2-3 releases per week. Users appreciate the steady improvements and the new extensibility preview teased by Anthropic.

**Problems:** The Google Antigravity account suspensions for third-party tool users (including paying $250/month subscribers) has caused significant concern in the community. Developers using OpenClaw or OpenCode with Gemini CLI are losing access with little warning. This highlights the risk of building workflows dependent on provider OAuth integrations.

**Interesting:** The funding data shows a concentrated summer funding window — 8 of 12 rounds announced between July 29 and August 4. Instinct's $250M personal agent round signals investors see trusted personal agents acting across apps as highly valuable. Meanwhile, enterprise-focused companies like HappyRobot and Freehand are also securing large rounds, showing parallel investment in both consumer and B2B agentic AI.
