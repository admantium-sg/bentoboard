## Tool Releases

### Cline v4.1.3 — Checkpoint Workspace Rewind, Message Editing, Ollama Timeout Fix (August 3, 2026)

New release patches the SDK extension with significant quality-of-life improvements:

**Checkpoint restore becomes true workspace rewind:** Files Cline created during a task are now captured in the snapshot and restored to their checkpoint-time content; files created after the checkpoint are removed. Pre-restore recovery snapshot lets you roll back the entire operation. `.gitignored` paths are left untouched. Old checkpoints keep conservative behavior.

**Message editing:** Edit any earlier message in a conversation — the app forks the session at that point, rewinds the workspace to that run's checkpoint, and re-runs from the edited prompt. Restores are transactional and workspace-atomic.

**Ollama improvements:** Response-start timeout raised to 5 minutes (was 30 seconds) so large models that cold-load no longer fail before finishing loading. Empty Ollama responses (no text, reasoning, or tool call) are now retried at the model boundary instead of failing the task.

**Fixes:** Legacy/new extension bundle invalidating each other's Cline account sessions; provider settings edits discarded before config finished loading; checkpoint creation broken in VS Code and CLI.

**Source:** https://github.com/cline/cline/releases
