## New Findings (June 13)

### Claude Code v2.1.176 (June 12, 2026) — Session Localization, Remote Control Fixes, Hook Polish

Claude Code's third release in 24 hours brings session localization, credential caching improvements, and extensive Remote Control hardening:

- **Session titles in conversation language**: Titles are now generated in the language of your conversation. Set the `language` setting to pin a specific language.
- **`footerLinksRegexes` setting**: New setting for regex-matched link badges in the footer row, configurable via user or managed settings.
- **Bedrock credential caching improvement**: Credentials from `awsCredentialExport` are now cached until their `Expiration` timestamp instead of a fixed 1 hour — reduces re-authentication frequency for enterprise users.
- **`availableModels` enforcement hardening**: Alias model picks can no longer be redirected to a blocked model via `ANTHROPIC_DEFAULT_*_MODEL` environment variables, and `/fast` now refuses to toggle when it would switch to a model outside the allowlist.
- **Auto mode Fable 5 fallback**: Fixed auto mode failing on Fable 5 for organizations without Opus 4.8 enabled — classifier now falls back to the best available Opus model.
- **Hook path pattern matching fixed**: Documented patterns like `Edit(src/**)`, `Read(~/.ssh/**)`, and `Read(.env)` now match correctly.
- **Linux sandbox symlink fix**: Fixed sandbox failing to start when `.claude/settings.json` is a symlink with an absolute target.
- **tmux clipboard fix**: Fixed `/copy` and mouse-selection copy not reaching the system clipboard inside tmux over SSH; tmux paste buffer now works on versions older than 3.2.
- **Remote Control hardening**: Multiple fixes — session no longer silently switches model when connecting from web/mobile; disconnect notifications show human-readable reasons; sessions properly disconnect when signing in to a different account.
- **Background session fixes**: `/cd` and worktree moves now correctly report the new directory's git branch; `claude agents` search finds PRs opened during scheduled wakeups; background sessions show clearer guidance when auto-update blocks submission.

**Source:** https://code.claude.com/docs/en/changelog

## Community Pulse

### Working Well
- **Claude Code's Bedrock credential caching**: Caching credentials until expiration instead of a fixed 1 hour is a meaningful quality-of-life improvement for enterprise users — reduces unnecessary re-authentication cycles.
- **Cline's Fable 5 same-day support**: Continuing the pattern of adding support for major model releases within hours. The dual-track versioning (v3.0.x stable vs v3.89.x latest) remains confusing but the rapid response to new models is appreciated.
- **Crush's sigstore verification rollout**: The step-by-step verification guide (download checksums, verify with cosign, then verify artifacts) is well-documented and accessible even for users unfamiliar with sigstore.

### Problems
- **Codex CLI v0.140.0 stable nowhere in sight**: 18 alphas and counting. The community's mild frustration from last week has grown — some wondering if multi-agent v2 features are fundamentally harder to stabilize than expected.
- **Cline's dual versioning still confusing**: v3.89.2 vs cli-v3.0.24 releasing on the same day with different features highlights the ongoing confusion about which track to follow.

### Interesting
- **Claude Code `footerLinksRegexes`**: A new setting for footer link badges with regex matching — suggests customization and branding use cases are being addressed. Organizations can now add custom link badges that match specific patterns.
- **Cline plugin commands submitting prompts**: This is a significant capability unlock — plugins can now drive agent behavior, not just provide tools. Opens up more complex plugin-driven workflows.
- **Claude Code hook path pattern matching fixed**: Patterns like `Edit(src/**)` and `Read(.env)` now work as documented. This was a long-standing issue that affected users with specific project structures.

---

## Trend

The ecosystem is in a hardening and polish phase. Claude Code is working through Remote Control reliability (multiple releases addressing session management, clipboard, and authentication edge cases), Cline is stabilizing its SDK architecture while adding Fable 5 support, and Codex CLI continues its extended alpha cycle toward v0.140.0 stable. The pattern from last week continues: feature velocity is down, reliability and governance polish is up across all tools. The 18-alpha Codex cycle suggests the next major capability unlock (multi-agent v2) is close but not quite ready for stable release.
