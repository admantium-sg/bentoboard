## Tool Releases & Features

**Claude Code v2.1.149 (May 19) — Session Management, OTEL, Security Fix**
- `claude agents --json` lists live Claude sessions as JSON for scripting (tmux-resurrect, status bars, session pickers)
- Added `agent_id` and `parent_agent_id` to `claude_code.tool` OTEL spans; background subagent spans now nest under dispatching Agent tool span
- Status line JSON input now includes GitHub repo and PR information when detected
- Plugin Discover/Browse now shows plugin's commands, agents, skills, hooks, and MCP/LSP servers before installation
- Agent tab title shows awaiting-input count so you know when agent needs attention
- Slash command and @-mention suggestion list now supports mouse hover and click in fullscreen mode
- Security fix: fixed permission-prompt bypass where bare variable assignments to non-allowlisted environment variables in Bash commands were auto-approved
- Multiple bug fixes: terminal display freeze, progressive corruption in long sessions, macOS background session crashes under Full Disk Access, /branch failing after worktree, resume sessions picking up wrong model
- Source: https://github.com/anthropics/claude-code/releases
