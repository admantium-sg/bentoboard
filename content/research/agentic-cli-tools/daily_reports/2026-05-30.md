## Tool Releases

**Claude Code v2.1.157 (May 29) — Plugin System Overhaul, Auto-Loading Skills**

Major plugin ecosystem update:
- Plugins in `.claude/skills` directories are now automatically loaded — no marketplace required
- New `claude plugin init <name>` scaffolds a new plugin in `.claude/skills`
- Autocomplete for `/plugin` arguments now covers subcommands, installed plugin names, and marketplace plugins
- `claude agents`: `agent` field in `settings.json` now honored for dispatched sessions, with `--agent <name>` override
- `EnterWorktree` can now switch between Claude-managed worktrees mid-session
- `tool_decision` telemetry now includes `tool_parameters` (bash commands, MCP/skill names) when `OTEL_LOG_TOOL_DETAILS=1`
- Worktrees managed by Claude are now left unlocked when the agent finishes — `git worktree remove`/`prune` can clean them up
- Fixed unprocessable images (zero-byte, corrupt) attached via paste, MCP, or dialog crashing instead of becoming text placeholder
- Fixed sandbox network permission prompts appearing in auto/bypass-permissions mode on desktop app, IDE extensions, SDK
- `/terminal-setup` now disables GPU acceleration in VS Code/Cursor/Windsurf integrated terminals to prevent garbled-text rendering

**Source:** https://code.claude.com/docs/en/changelog

**Claude Code v2.1.156 (May 29) — Opus 4.8 Thinking Block Fix**

- Fixed an issue when using Opus 4.8 where thinking blocks were modified, leading to API errors

**Source:** https://code.claude.com/docs/en/changelog

**OpenAI Codex CLI — Computer Use on Windows, Remote Control GA (May 29)**

Version 26.519 shipped May 29 with significant platform expansion:
- **Computer use now works on Windows** — Codex can operate Windows desktop apps by seeing, clicking, and typing in the foreground
- **Remote control now supports Windows devices** — start Codex work from ChatGPT on iOS/Android or from a Mac running Codex, check progress remotely
- **Profile section** now shows profile details, usage stats, and token activity

**Source:** https://developers.openai.com/codex/changelog

**Cline CLI v3.0.15 (May 29) — Cline Hub, Global AGENTS Rules, Model Refresh**

- **Cline Hub** — web app for monitoring connected clients, viewing/driving sessions, streaming assistant output, restarting local hub. Local/LAN/tunnel usage gated by room secret
- **Global AGENTS rules** — agent rules can now be applied across all sessions, not just per-project
- **Plugins can contribute static or dynamic rule content** when installed in the sandbox
- **Discord connector improvements** — sessions bound to individual message authors, `/mute`/`/unmute` from mentions or raw user IDs
- **Model catalog refresh** — Claude Opus 4.8, Moonshot Kimi K2.6, Qwen3.7 Max (with cache support)
- **Steer active connector sessions** across turn keys by matching session ID — replies continue existing session instead of starting duplicate
- **OAuth URLs now clickable** in the TUI

**Source:** https://github.com/cline/cline/releases

## Community Pulse

**Working well:** Claude Code's plugin auto-loading (`.claude/skills` directory) removes the friction of marketplace discovery — developers can now ship personal plugins or internal team plugins without distribution overhead. Codex CLI's Windows computer use expansion brings the cross-platform story full circle after macOS/Linux computer use matured.

**Problems:** Cline Hub introduces a web-based monitoring layer that some users may view as increased complexity — the "simple CLI" appeal vs. the enterprise monitoring dashboard is a design tension worth watching. Global AGENTS rules across all sessions could also be misused for over-broad policy enforcement.

**Interesting:** The same day three Claude Code releases dropped (155, 156, 157) shows the velocity of the release train. The Opus 4.8 thinking block fix in 156 was rapid response to a breaking issue. Cline's model catalog now includes three Opus 4.8 variants (standard, 1M context) alongside Kimi K2.6 and Qwen3.7 Max — the multi-model strategy is fully operational.

---

## Trend

The CLI agent tool space is converging on platform differentiation: Claude Code on plugin ecosystem and multi-agent orchestration, Codex on cross-platform computer use and enterprise remote control, Cline on SDK openness and connector flexibility. The battleground has shifted from "which model" to "which platform properties."
