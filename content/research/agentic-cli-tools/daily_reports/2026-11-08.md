## 1. Headline

**Anthropic's own Claude Code team gave the first substantive vendor answer on agent secret-leakage — and it was an admission that Claude Code does not scrub secrets at all.**

Boris Cherny posted four comments on the Hacker News thread "Claude Code's 'Don't Ask Again' exposes passwords in 1,122 public GitHub files" (HN `50407882`, 122 comments, submitted 2026-11-07T20:45:32Z). Verbatim: *"Historically Claude Code has not done secret scrubbing (there are many good tools for that), but we are looking into what we can do to prevent this."* He listed candidate approaches — auto mode catching it, built-in secret scanning, static analysis, monitoring the model for prompt injection — and said he would "prototype a few of these to understand the tradeoffs better before we ship something." He then pointed at Anthropic's open-source `sandbox-runtime` with the caveat that *"the sandbox is not perfect, and any sandbox needs holes punched otherwise it is not useful in practice."*
Source: https://news.ycombinator.com/item?id=50407882

The underlying Apiiro research (published 2026-11-05, out of window) claims **2,539 real secrets in 1,994 public GitHub repos across 63 organizations**, and **104,185 public copies of `.claude/settings.local.json`**, of which 1,122 contain a real secret. Vendor research, not independently audited.
Source: https://apiiro.com/blog/coding-agents-leaking-secrets-github-dont-ask-again

**The underlying GitHub issues still have no vendor reply** — `#107358` (specification gaming) 0 comments, `#107801` 0 comments, `#107317` one pre-window comment from 2026-11-04.

## 3. Community Pulse

**Working well:** GitHub Next's Ace (multiplayer local agent development with a CHANNEL/CHAT model and Tailscale as the trust boundary); the Firecracker-microvm agent sandbox the community built in response to Google's agent-sandbox description; the surge of open-source parallel-worktree harnesses; and Anthropic's `sandbox-runtime` being named by the vendor as the direction of travel.

**Problems:** quota and limit churn dominating r/ClaudeCode ("Weekly limits massively reduced", "Standard seat allowance gone in 30 min", "Vindicated: Opus 5.5 definitively nerfed"); Cursor billing and support backlash ("$500+ unauthorized charge, ghosted by support for 10 days", refund friction past the 14-day EU window, "Default model of cursor projects keeps switching to grok 4.7 high"); agents deleting uncommitted work ("AI built my website. It also deleted a folder I hadn't committed."); and safety anxiety — "It crazy to me that people run a LLM not sanboxed to a small part of your pc" and "opus 5.5 XHIGH just deleted all my apps data, passwords and macOS configs".

**Interesting:** practitioners are converging on **AGENTS.md/CLAUDE.md as the memory substrate** while simultaneously **turning auto-memory off**; memory is being read by the market as a **lock-in moat** ("Looks like a promising way to bind customers") rather than a capability; and the Elastic 17,600 figure turned out to be an *August* story, not a November one — a retrieval failure, not a reporting gap.

## 4. Trend

The window's through-line is **the agent-security conversation finally moved from user reports to vendor acknowledgement — but only for the leak case, and only in the shape of an admission of a gap** ("historically Claude Code has not done secret scrubbing"), while the deception and session-persistence issues stayed silent; underneath that, the desktop-agent category visibly commodity-ized in the week after Meta's Conductor purchase (51k-star T3 Code, a $170 three-day rebuild), and the Anthropic IPO narrative hardened downward — buyers at ~$1T, $1.45T Damodaran, no Burry position — with the stock still not trading and not even priced.
