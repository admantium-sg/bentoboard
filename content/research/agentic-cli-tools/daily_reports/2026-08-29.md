### Claude Code — v2.1.251 (August 28, 2026)
**Major release.** The 202th Claude Code release of 2026 adds hooks-driven model switch control and live subagent observability. Key additions:

- **PreModelSwitch and PostModelSwitch hook events** — block, confirm, or annotate any model switch; `SessionStart` resume hooks now receive session staleness and estimated re-cache cost
- **Live subagent tool streaming to Remote Control clients** — foreground subagent tool calls and results stream in real time to Remote Control clients (background subagents remain status-only)
- **Spend limit bar in `/usage`** and `rate_limits.spend_limit` status line field for Claude apps gateway users
- **Per-session prompt cache analytics** in `/cost` — hit ratio, misses, tokens re-cached, warm/cold breakdown; matching `prompt_cache` object for status line scripts
- **CLI attach/logs/stop/respawn/rm** added to `claude --help`; `--resume` message now names exact `claude attach <id>` command
- **Security fixes** — symlink swap bug in file tools could read/write outside approved location; plugin path-traversal rejection; project settings could bypass beta tracing restrictions; Workflow tool scriptPath read before permission check; Grep/Glob not applying deny rules through symlinked paths
- **TUI lag fix** — per-second progress ticks replace predecessor instead of piling up with many parallel subagents
- **Agent teams fix** — teammate final answer now arrives in idle notification instead of content-free "available" notice
- **Install size reduced ~5 MB** — native binary trimmed

### GitHub Copilot CLI — v1.0.81 (August 27, 2026)
First Copilot CLI release in 2 weeks. Notable additions:

- **Plugins dashboard** — `/plugin`, `/mcp`, `/skills` give access; `PLUGINSDASHBOARD=false` to opt out
- **Session crash recovery** — startup offers to restore sessions still open when CLI went away; crashes or restarts no longer lose open terminals
- **MCP 2026-07-28 support** shipped to CLI, SDK, IDE, and in-memory clients
- **OpenTelemetry hooks** — hooks can now receive current trace context and emit correlated spans; command hooks get `traceparent` env var
- **Windows WAM auth** — remote MCP servers protected by Microsoft Entra ID can sign in via OS authentication broker (usually no prompt)
- **Gemini 3.7 Flash** support added
- **`/defaultMode` and `/defaultPermissionMode`** settings for startup mode and approval behavior defaults
- **`/copilot app`** command to open GitHub Copilot app in current directory

### Claude Code Ships 202th Release of 2026 — ~0.8 Day Average Cadence
With v2.1.251 landing as the 202nd release, Claude Code is sustaining a sub-daily release cadence (~0.8 days between releases on average over the past month). The release contains substantial new functionality (hook events, live subagent streaming, prompt cache analytics, spend controls) rather than just bug-fix accumulation — a sign the team is still adding features at pace while managing a large changelog.

### GitHub Copilot CLI Crash Recovery Addresses Long-Standing Pain Point
The addition of automatic session restoration after crashes or machine restarts addresses one of the most consistent developer complaints with terminal-based coding agents. Copilot CLI previously shipped every 3.2 days on average — v1.0.81 was the first release in 14 days, suggesting the team focused on a significant feature rather than a rapid bug-fix cycle.
