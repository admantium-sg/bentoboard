### ClauDex — Community Plugin for Claude↔Codex Pair Programming (July 2026)

A community plugin emerged on the OpenAI forum enabling Claude and Codex to pair program together: `/claudex` runs a write > review loop where Claude implements, Codex reviews the diff via `codex exec --sandbox read-only`, they iterate to consensus (max 3 rounds), then Codex can execute. The plugin formalizes what many developers were doing manually — using both tools for different aspects of the same task.

The session handoff guide at codex.danielvaughan.com was updated July 12, 2026 to reflect the current state of Claude Code↔Codex interoperability, including MCP bridge compatibility and known gotchas.
