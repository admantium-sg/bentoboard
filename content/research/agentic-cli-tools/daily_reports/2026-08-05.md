# Daily Report — Agentic CLI Tools — August 5, 2026

## Tool Releases (Task 1)

### Claude Code — Two Releases in One Day: v2.1.221 and v2.1.222 (August 4, 2026)

After 11 days of silence (v2.1.220, July 25), Claude Code shipped **two releases on August 4** — a double-drop that breaks the silence pattern.

**v2.1.221 (August 4):**
- **Focus view** — New VS Code chat-menu toggle (`Ctrl+Alt+F`) that hides tool activity behind expandable per-turn summaries with a live running-tool indicator. Targets users who find the transcript stream noisy during complex multi-step tasks.
- **Sandbox credential file masking (`mode: "mask"`)** — Linux and WSL only. Sandbox commands read a sentinel copy of credential files, with spans captured by an `extract` regex. The sandbox proxy substitutes real values on egress. On macOS falls back to `deny` mode.
- Added `prompt-audit` subcommand to `claude-api` skill for auditing prompts/tool descriptions.
- 20+ fixes: MCP server re-auth improvement, Bedrock auth regression fix, WebSearch 400 error at `xhigh`/`max` effort fixed, Vim mode yank register now survives dialogs.

**v2.1.222 (August 4, same day):**
- **Worktree isolation hardening** — Sessions isolated in git worktrees can no longer run destructive git commands against the main checkout; isolation now applies to file edits and Bash in every session type. Major security fix for multi-repo workflows.
- **PreToolUse auto-allow hook bypass fixed** — Hooks were bypassing tool restrictions in background agent tasks (summaries, compaction, renames). Now correctly enforced.
- **Removed `ultraplan` feature** — A feature appears to have been retired.
- 15+ additional fixes: `/usage-credits` fix for Team/Enterprise, connectivity check now proxy-aware, stream idle timeout fix for custom gateways.

**Source:** https://code.claude.com/docs/en/changelog

### Kilo — v7.4.19 and v7.4.20 (August 2–4, 2026)

### Cline v4.1.3 — Workspace Rewind Goes True; Message Editing Ships (August 3, 2026)

The v4.1.3 release delivers two headline features alongside a batch of fixes:

- **Checkpoint restore = true workspace rewind** — Files created during a task are captured in the snapshot and restored to their checkpoint-time content; files created after the checkpoint are removed. `.gitignored` paths left untouched. Pre-restore recovery snapshot enables full rollback. Old checkpoints retain conservative behavior.
- **Message editing** — Edit any earlier message; session forks at that point, workspace rewinds to the checkpoint, re-runs from the edited prompt. Transactional and workspace-atomic.
- Ollama response-start timeout raised to 5 minutes (was 30 seconds); empty Ollama responses now retried at model boundary; VS Code/CLI checkpoint creation fixed (was broken since v4.1.0).

**Source:** https://github.com/cline/cline/releases
