# Daily Report: Agentic CLI Tools — August 15, 2026

## Summary

Claude Code ships v2.1.233 with GitLab MR support, subagent forking now default, and memory cgroup hardening. Cline v4.1.10 adds native web search to models that support it and fixes daemon replacement loops. Kilo v7.4.23 consolidates JetBrains UX and CLI download reliability. August agent funding hits $633M in 12 days, matching July's full month.

## Tool Releases & Features

**Claude Code — v2.1.233 (August 14, 2026)**
Subagent forking is now on by default — `subagent_type: "fork"` inherits full conversation and prompt cache, and non-teammate agent spawns in interactive sessions run in the background by default. Added `@` mention for directly messaging other Claude sessions by name. GitLab MR URL support added to `--worktree` flag and `claude agents` view (MRs display as `!N`). New opt-in `forward_user_identity` apps gateway setting sends signed-in user identity as headers for per-user spend attribution. New opt-in `CLAUDE_CODE_TOOL_MEMORY_LIMIT` for Linux memory cgroups on Bash — runaway builds can no longer stall the session. `CLAUDE_CODE_WEBFETCH_CACHE_TTL_MS` allows configuring WebFetch cache TTL. Todo/task tools (TaskCreate/Get/Update/List, TodoWrite) are no longer available on Opus 4.8, Sonnet 5, Fable 5, Mythos 5, and newer — set `CLAUDE_CODE_ENABLE_TODO_TOOLS=1` to re-enable. **NTLM credential-leak vector patched**: Windows paths spelled with the NT `\\??\` device prefix were bypassing UNC path validation. Windows auto mode regression from v2.1.232 (Bash permission churn on `cd <dir> && <command> > file`) reverted; Bash input redirections (`< file`) now permission-checked properly.

**Cline v4.1.10 (August 13, 2026)** — SDK v0.0.75 bundle
Models that support it can now search the web during a task — enable via Web Search toggle in Settings; search calls and results persist across session reloads. Dedicated Cline provider for Cline Pass replaces the generic OpenAI-compatible path, restoring extended thinking budgets that silently stopped applying. Two critical fixes: build identity compared through a total order so different Cline installs no longer shut each other's Hub daemon down in a loop (was killing live sessions); newer builds no longer replace a Hub still serving sessions — they attach over the wire protocol and swap happens when the Hub goes idle. Idle plugin sandbox processes now reclaimed instead of lingering for the session. Model catalog refreshed with Crusoe as a new provider and updated model lists across providers. Desktop v0.0.13 also shipped: auto-updates no longer install while a CLI is attached to the Hub, and protection added against older updaters restarting the Hub mid-session and bricking running sessions. Streaming markdown no longer flashes back to raw text on each chunk.

**Kilo v7.4.23 (August 14, 2026)**
JetBrains chat readability overhaul: refreshed session surfaces, softer spacing, clearer prompt bubbles, more consistent hover states. CLI downloads more reliable via retry logic for transient failures and rate limits, plus bypassing authentication on public CLI asset fetches. JetBrains plugin CLI pin updated to Kilo Core 7.4.22. Kilo Core refreshed with upstream provider, model variant, and session runtime updates.

**OpenCode — Desktop/Core Updates (August 12–13, 2026)**
Core: session compaction improvements (keeps complete recent turns, clearer summaries for smaller models); MERGE Gateway reasoning variants; PDF attachments for GitHub Copilot models advertising PDF vision support; Kimi system prompt selection fixed for Moonshot providers; xhigh reasoning effort fixed for xAI models; DeepSeek V4 Flash now uses correct sampling defaults on supported providers. Desktop: Chinese terminology updated; server default model used instead of stale local config.

**Codex CLI — Alpha Sprint at alpha.18, Stable v0.147.0 (August 7–14, 2026)**
Alpha chain progressed from alpha.9 through alpha.18 — nine additional alpha tags in the sprint. Stable remains v0.147.0 (portable plugins, persistent conversation sections, MCP 2026-07-28 support, `--approve-for-me`, Cursor/Claude import, Bedrock expansion). No new stable releases since last report.

## Community Pulse

**Working well:** Subagent forking going default in Claude Code v2.1.233 is a natural maturation — fork-context skills and background subagents have been stabilizing all month, and making fork the default signals the team is confident in the implementation. Cline's web search persistence (search calls replay on reload) directly addresses a long-standing UX complaint about ephemeral tool results.

**Problems:** Todo tools being stripped from Opus 4.8, Sonnet 5, and Fable 5 is a notable capability reduction — these are the most capable models, and the reasoning is presumably that agents should use external task-tracking rather than building it into the tool layer, but the practical impact on workflows that depended on it could be significant.

**Interesting:** The Windows NTLM credential-leak fix in v2.1.233 (paths with `\\??\` prefix bypassing UNC validation) is the third Windows-specific credential-handling fix in as many releases — the credential surface on Windows has been receiving sustained attention. The August funding data shows agent governance consolidating as a category: Zenity ($125M) and Obsidian ($85M, $1.1B valuation) in 48 hours joins July's Neo Security/Act Security/Hush cluster. The average cheque nearly doubled from $53M to $127M in a month.

## Market & Funding

**August 2026: $633M in 12 days** — Five disclosed rounds already match July's full-month total. Two agent-governance rounds in 48 hours underscore the category:

**Zenity $125M Series C (August 3, 2026)** — Led by Norwest, bringing total raised to over $200M. Zenity secures AI agents and autonomous agents accessing sensitive data, invoking tools, and executing workflows. Gartner named it the AI agent governance frontrunner in April 2026. Contributes to OWASP Top 10 and MITRE ATLAS open-source initiatives. The framing is striking: "1 Billion AI Agents" era requiring governance.

**Obsidian Security $85M Series D (August 4, 2026)** — Led by Crescent Cove Advisors at $1.1B valuation, doubling from its prior round. Governs non-human identities and AI agents (including Copilot Studio and Claude) across SaaS environments. Greylock and Menlo Ventures participated. The 48-hour window from Zenity to Obsidian ($210M combined) beat July's entire governance cluster ($190M in eleven days).

Pattern: fewer, larger rounds. Average cheque jumped from ~$53M (July) to ~$127M (August, 12 days). Infrastructure picks-and-shovels and vertical agents with named enterprise customers continue to dominate; thin wrappers don't get funded.

## Trend

The horizontal CLI agent layer (Claude Code, Codex, Kilo, Cline, OpenCode) is in a hardening and polish phase — security fixes, UX refinements, and stability work dominate this week's releases. Meanwhile the broader agentic ecosystem is consolidating around two specific funding narratives: governance (who controls what agents may touch) and vertical automation with real revenue. The average funding round size nearly doubling month-over-month signals the market is picking winners rather than spreading bets.
