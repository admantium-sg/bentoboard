# Daily Report: Agentic CLI Tools — August 16, 2026

## Summary

Claude Code ships v2.1.233 with GitLab MR support, per-user spend attribution, and memory cgroup hardening for Linux. Cline CLI jumps to v3.0.55 with session-safe auto-updates and font refresh. Kilo v7.4.24 brings clickable file references and upstream OpenCode v1.18.0. Codex CLI alpha.19 starts a new sprint. The ecosystem's big story this week: GLM-5.3 claims to have found a serious Cursor vulnerability, and GitKraken's developer survey puts AI coding tool adoption at 96.4% of engineering teams.

---

## Tool Releases & Features

**Claude Code — v2.1.233 (August 14, 2026)**
GitLab merge request URLs now work with `--worktree` and display in `claude agents` view as `!N`. New opt-in `forward_user_identity` apps gateway setting sends signed-in user identity as headers for per-user spend attribution — enterprise teams can finally track spend per developer. New `CLAUDE_CODE_TOOL_MEMORY_LIMIT` env var enables Linux memory cgroups for Bash tool commands, so runaway builds can no longer stall the session. `CLAUDE_CODE_WEBFETCH_CACHE_TTL_MS` allows tuning WebFetch cache TTL (default unchanged at 15 minutes). Fixes: cloud sessions no longer marked lost during env shutdown while waiting on permission prompts; MCP v2 connections no longer endlessly reopening against servers with fixed stream timeouts; idle Linux sessions with sandboxing no longer pin a CPU core at 100%; bundled skill aliases like `/checkup` and `/review` no longer report "Unknown command" when shadowed in `-p` mode. Skill/command argument substitution now prevents values from being re-expanded as template markers. PowerShell permission bypass on `$PSDefaultParameterValues` also patched. Todo/task tools remain stripped from Opus 4.8, Sonnet 5, Fable 5, Mythos 5 and newer.

**Cline — v3.0.55 (August 15, 2026)** — SDK v0.0.75
Auto-updates now deferred when a CLI is attached to the Hub — the update is recorded at startup and applied on exit once the Hub confirms nothing else is attached, preventing the "connection closed (code=1006)" session death that plagued v3.0.54 and earlier. Added explicit defusal for the update path in older CLIs whose updater restarts Hub mid-session and then rejects all replacements, bricking the running session. Streaming markdown no longer flashes back to raw text on each chunk — headings, links, and code now stay rendered as new chunks arrive. Interface switched to Inter and Geist Mono fonts. Web search calls and results from natively-searching models now render in the transcript. `cline doctor fix` now reports honestly about respawning parents and held locks. Model catalog refreshed with Crusoe as a provider.

**Kilo — v7.4.24 (August 15, 2026)**
Clickable file references: code spans in agent responses that match real workspace files become links that open the file at the referenced line; dead links show a "File not found" warning. Agent Manager PR comment actions: resolve/unresolve review threads, jump to comments, scroll-to-top for PR diff view. Subagent permission fix: read-only or delegating agent's `readOnlyBash` allowlist no longer projected onto writable subagents as a bash ceiling, so delegated subagents can run their own allowed commands like `git status`. Structured AWS access keys and Google Cloud service-account JSON now supported for Bedrock and Vertex AI connections in VS Code. Changes from OpenCode upstream v1.18.0: code mode MCP adapter for confined orchestration scripts; hidden execute tool unless code mode enabled; improved model-specific system prompt for Meta Muse Spark; Azure AI GPT-5.6 support; disabled response storage by default for xAI Responses.

**Codex CLI — v0.148.0-alpha.19 (August 15–16, 2026)**
New alpha sprint tag — ninth alpha release in the current cycle (alpha.11 through alpha.19). Stable remains v0.147.0. Alpha sprint continues rapid pre-release development.

## Community Pulse

**Working well:** Cline's auto-update fix is the most meaningful quality-of-life improvement in this cycle — the Hub connection being killed mid-session by a background update was a notorious footgun. Making auto-updates defer to session exit is a clean solution that doesn't compromise security. The font switch to Inter and Geist Mono should also address readability complaints.

**Problems:** The GLM-5.3/Cursor vulnerability claim landed Saturday (August 15) with little public detail yet. The pattern from similar disclosures — Claude Code CVE, Gemini CLI equivalent — suggests this could be real and significant, but no patch timeline or severity rating is publicly confirmed as of this report. Teams using Cursor in automated pipelines should monitor for updates.

**Interesting:** GitKraken's 2026 State of AI in Engineering survey (554 developers and leaders) finds 96.4% of engineering teams using AI coding tools — essentially near-universal adoption. The remaining 3.6% is the interesting question: are those holdouts by choice, skill gap, or organizational constraint? The more telling data point is that code review still lags behind coding in AI integration, which aligns with what the CLI tools have been building — tools like Claude Code's `/review` and Kilo's staged/unpushed/quick review modes are explicitly targeting that gap.

## Market & Ecosystem

**TencentDB Agent Memory: 20K Stars in 90 Days, Adds Team Memory**
TencentDB Agent Memory passed 20,000 GitHub stars in 90 days — one of the fastest-growing AI developer tools this cycle. Team Memory feature launched: lets agents share conversations, documents, code, and institutional knowledge across a team. The 90-day trajectory suggests memory is becoming a must-have layer rather than a nice-to-have. The risk TencentDB is apparently grappling with: shared memory makes agents far more useful *and* far harder to control — the same tension that governance tooling addresses at the infrastructure level.

**Starling MX: Open Standard for AI Memory Architecture**
Starling Memory Works published the Universal Cognitive Architecture — a permanently free (Creative Commons) open standard for connecting organizational knowledge systems to AI models. Unlike many "standards" in the AI space, this one explicitly avoids requiring companies to surrender data ownership. If adopted by major vendors, it could provide the memory interoperability that multi-agent workflows need without vendor lock-in. Worth watching as a potential counterweight to proprietary memory systems.

**DeepJudge Agent Handoff Protocol**
DeepJudge released an open protocol for moving users and their context between AI products — the Agent Handoff Protocol. Harvey and Thomson Reuters have both committed to supporting it. In the legaltech world where context preservation across tools matters enormously, this could become significant. It also echoes a broader theme in the CLI agent space: portability and interoperability, which MCP has been addressing at the tool level.

**Chainlink for Agents**
Chainlink unveiled infrastructure for autonomous AI agents in crypto: data feeds, cross-chain transactions, and protected computation via CCIP and the Chainlink Runtime Environment. For CLI tool users, this is relevant as a leading indicator of where agent infrastructure is heading — tamper-proof tool use with real financial stakes.

## Trend

The horizontal CLI agent layer is in a maintenance and polish cycle — auto-update safety, font/UX improvements, upstream model support updates dominate. Meanwhile the broader agentic ecosystem is proving out two orthogonal thesis: memory (TencentDB, Starling MX) and portability/interoperability (DeepJudge, MCP). The 96.4% adoption rate from GitKraken's survey signals the market is past the "whether" question — the remaining open questions are all about workflow integration, security, and cost.
