### Cline — v4.1.16: Hub Event Log Capped at 64 MiB; Model Catalog Expands (August 24–25, 2026)
Major durability release addressing a long-standing storage issue:

**Hub event log capping:** Previously, event envelopes carrying full session snapshots could accumulate to tens of gigabytes — row and time retention didn't bound file size, and deletes never shrunk the SQLite file. Now capped at 64 MiB on disk. Oldest events are dropped first, space is vacuumed, and pruning runs after every 16 MiB appended instead of waiting for the hourly sweep. Critical for teams running long-lived hub instances.

**Model catalog refresh:** Adds **AgentRouter** and **Opper** as providers; updated model lists and pricing across providers. Note: resolved default model changes for **Aki.io** and **NanoGPT** — users of those without pinned models will get a different default.

**Task completion telemetry restored:** Interactive sessions now properly emit `task.completed` from every teardown path, exactly once.

**Source:** https://github.com/cline/cline/releases

## Community Pulse

### Google ATLAS Study: Fewer Than 10% of AI Conversations Attempt Full End-to-End Automation (August 2026)
Google's ATLAS v1.0 study analyzed nearly 15 million de-identified AI interactions across 150+ countries. Key finding: for non-routine cognitive work where AI is used most heavily, fewer than 10% of conversations attempted to automate a task end-to-end. This paints a very different picture from claims that agents are replacing human work. The real-world picture is still humans working with AI, not AI simply replacing them. Dataset limitation: enterprise use cases are notably absent from the sample.

**Source:** https://siliconcanals.com/t/google-atlas-15-million-ai-interactions-human-collaboration-automation

### Microsoft ThinkingBox: Testing Agent Reliability Beyond One-Off Success (August 2026)
Microsoft released **ThinkingBox**, an open-source sandbox for testing whether AI agents can do real work reliably. The framework catches agents that look smart in single tests but fail repeatedly — a critical distinction for enterprise buyers evaluating agents for production workloads. The tool tests consistency, not just completion rate. This signals that reliability is becoming a buying criterion, not just capability benchmarks.

**Source:** https://agentic.ai/news
