# Daily Report: Agentic CLI Tools — May 17, 2026

## New Findings

### Claude Code v2.1.128 (May 15-16) — Plugin System, Fast Mode, Windows

**New features:**
- **Plugin dependency enforcement** — `claude plugin disable` now refuses when another enabled plugin depends on target (shows disable-chain hint). `claude plugin enable` force-enables transitive dependencies
- **Projected context cost** — Per-turn and per-invocation token estimates added to `/plugin marketplace` browse pane
- **worktree.bgIsolation: "none"** — New setting lets background sessions edit working copy directly without EnterWorktree (for repos where worktrees are impractical)
- **PowerShell improvements** — PowerShell tool now passes `-ExecutionPolicy Bypass` by default; opt out via `CLAUDE_CODE_POWERSHELL_RESPECT_EXECUTION_POLICY=1`
- **Background session persistence** — Model and effort level preserved after waking from idle
- **Shift+Tab in attached agents** — Cycle now includes auto mode
- **Fast mode upgrade** — Now uses Opus 4.7 by default (previously Opus 4.6). Set `CLAUDE_CODE_OPUS_4_6_FAST_MODE_OVERRIDE=1` to pin to 4.6
- **SKILL.md as plugin root** — Plugins with root-level SKILL.md (no skills/ subdirectory) are now surfaced as a skill
- **Plugin details LSP info** — `/plugin details` pane and `claude plugin details` now show LSP servers a plugin provides

**Windows fixes:**
- Fixed right-click paste in claude agents on Windows Terminal and WSL
- Fixed agent view spawning repeated PowerShell processes when listing sessions
- Fixed background sessions on macOS getting "Operation not permitted" errors under ~/Documents, ~/Desktop, ~/Downloads
- PowerShell tool now enabled by default on Windows for Bedrock, Vertex, and Foundry users

**Bug fixes:**
- Fixed corrupt .credentials.json with non-array scopes value hanging CLI on startup
- Fixed stop hooks blocking forever — turn now ends with warning after 8 consecutive blocks
- Fixed Esc/Ctrl+C not cancelling pending `/loop` wakeup while Claude idle
- Fixed `/goal` evaluator firing while background shells or delegated subagents running
- Fixed `NO_COLOR`/`FORCE_COLOR` in settings.json stripping Claude Code's own UI colors
- Fixed daemon not exiting cleanly after binary upgrade (brew upgrade crash-looping fix)
- Fixed background agents crash-looping when Claude-in-Chrome extension connected without shared tab
