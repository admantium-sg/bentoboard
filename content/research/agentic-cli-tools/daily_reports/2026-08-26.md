## Tool Releases & Features

### Claude Code — v2.1.246 Lands: Major Stability and UX Overhaul (August 25, 2026)
v2.1.246 is a substantial release, five versions ahead of last report's v2.1.241. Key additions:

- **Bash wildcard warning:** Startup warning for allow rules with wildcards before the subcommand (e.g. `Bash(git * main)`), since they also match options inserted before the subcommand
- **Auto mode permissions tab:** New tab in `/permissions` for viewing and editing auto mode classifier rules — clearer UX for the safety system
- **Turn completion time:** Completion time now shown at the end-of-turn line (e.g. `✻ Sautéed for 23s · done 6:05 PM`)

**Bug fixes include:** fullscreen transcript blanking after resize; severe slowdown on diffs with very long single lines (base64 strings now truncated with a marker); erratic fullscreen scrolling when at earlier messages; background sessions failing to open after machine sleep; headless/remote MCP interruptions incorrectly reported as "completed with no output"; `Notification` hook not firing during sandbox network permission prompts; API auth token refresh on idle; session telemetry credentials sent to wrong host when using third-party gateway; and ~25 more fixes spanning plugin system, slash commands, keybindings, theme handling, and platform-specific cleanup. The breadth of fixes signals a push toward production-grade stability.

**Source:** https://code.claude.com/docs/en/changelog

### Codex CLI — Browser Expansion and Site Tools (August 25, 2026)
No new version bump since v0.149.1, but the releasebot picked up a feature update:

- **Broader browser support:** ChatGPT browser extension now works in Microsoft Edge, Brave, Opera, and Vivaldi — not just Chrome. Set up in Settings > Computer Use in the ChatGPT desktop app
- **Site tools (WebMCP):** In the desktop app's built-in browser, ChatGPT Work and Codex can use tools provided by websites to interact with the page. Requires GPT-5.6 Sol or Terra and the latest desktop app. Unavailable for GPT-5.6 Luna or Enterprise/Edu workspaces
- **Cloud browser sign-in:** On eligible plans, ChatGPT Work on web, iOS, and Android can authenticate to supported websites through the cloud browser, keeping sessions separate from local browser data

The v0.150.0 alpha chain continues (currently at alpha.8 per last report) — stable remains v0.149.1.

**Source:** https://releasebot.io/updates/openai/codex | https://developers.openai.com/codex/changelog/?type=codex-app

## Market Trends & Ecosystem

### Global Venture Funding Hits $510B in H1 2026; AI Absorbs 70%+ (August 2026)
Crunchbase data confirms record first half: $510 billion in global venture funding, surpassing all of 2025 ($440B). Q1 was $305B; Q2 was $205B. More than 70% of Q2 capital went to AI companies, up from just under 50% a year earlier. OpenAI and Anthropic together took $217B — 43% of all startup funding in H1.

The concentration picture: 16 companies raised billion-dollar rounds in Q2, totaling $108.6B (53% of all Q2 funding). Seven of those are frontier AI labs. The implication for agentic CLI tools: compute and model layer dominance continues to compress margins for pure-play agent startups, but the infrastructure and vertical agent layers remain active.

**Source:** https://news.crunchbase.com/venture/global-startup-exits-ipo-ma-soar-ai-q2-h1-2026/
