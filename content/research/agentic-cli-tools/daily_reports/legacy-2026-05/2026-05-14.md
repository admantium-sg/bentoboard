# Agentic CLI Tools - Daily Report 2026-05-14

## Summary

Today's research surfaces continued rapid iteration across all major CLI tools, significant Q1 2026 funding data showing agentic AI investment tripling year-over-year to $12B, and a new $65M seed for enterprise agentic OS infrastructure.

## New Findings

### Claude Code v2.1.140 (May 12): Subagent Matching and Bug Fixes
- Improved Agent tool subagenttype matching — now accepts case- and separator-insensitive values (e.g., "Code Reviewer" resolves to code-reviewer)
- Updated agent color palette
- Fixed /goal silently hanging when disableAllHooks or allowManagedHooksOnly is set — now shows clear error message instead of indicator that never resolves
- Fixed regression where symlinked settings files caused misattributed change events and spurious ConfigChange hooks
- Fixed claude --bg failing with "connection dropped mid-request" when background service was about to idle-exit
- Fixed background service startup failing on machines with enterprise endpoint security
- Fixed remote managed settings not retrying on 401 — now retries once with force-refreshed token
- Fixed Read tool calls failing validation when offset passed as whitespace-padded or +-prefixed string
- Plugins now warn when a default component folder is silently ignored

**Source:** https://www.havoptic.com/r/claude-code-2.1.140

### GitHub Copilot CLI v1.0.47 (May 13): Fork Named Sessions
- /fork now accepts an optional name
- Forked sessions display their origin in the sessions dialog
- Copilot Max subscribers now see correct models available to their subscription tier
- Support for j/k keys in up/down navigation in /diff view
- --resume now supports Copilot cloud agent sessions where agent hasn't pushed changes to branch

**Source:** https://www.havoptic.com/r/github-copilot-v1.0.47

### Gemini CLI vv0.42.0 (May 12): Auto-Update and Stability
- Auto-update no longer switches to less stable channels unexpectedly
- Passes node arguments via NODEOPTIONS during relaunch to support SEA (Self-Contained Application)
- Adds --delete flag to /exit command for session deletion
- MCP subagent parsing now handles missing oauth fields correctly
- Extension-backed MCP clients disconnect properly on stopExtension
- A2A pushMessage now has explicit empty log guard
- New ability to @ mention the Gemini robot in conversations
- Documentation workflow now includes workspace trust

### Agentic AI Funding Hits $12B in Q1 2026 — Tripling Year-Over-Year
Venture capital investment in agentic AI startups reached $12B in Q1 2026, representing ~40% of all AI venture capital during the quarter (up from 15% a year ago):

- **Cognition Labs — $2B Series C at $14B valuation:** Largest funding round in agentic AI history. Devin now handles code generation, debugging, deployment, and maintenance for 500+ enterprise customers. Expanded to data engineering, DevOps, and QA testing agents.

- **Adept AI — $1.5B Series C at $11B valuation:** Builds agents that interact with enterprise software through natural language commands. ACT-2 platform automates workflows across any software including legacy systems without APIs. 200+ enterprise customers. Strategic investments from ServiceNow ($200M) and Workday.

- **Induced AI — $800M Series B at $5.2B valuation:** London-based browser automation agents for insurance claims processing, healthcare prior authorizations, regulatory filing.

- **Other notable:** Sierra AI ($600M), Relevance AI ($350M), Lindy AI ($250M), Hebbia ($200M), 11x ($175M)

- Q1 average deal size grew from $28M to $67M; $100M+ deals increased from 3 to 14 YoY

**Source:** https://callsphere.ai/blog/agentic-ai-startup-funding-12-billion-q1-2026-tripling-year-over-year

- Palo Alto-based startup building "trusted agent operating system for the enterprise"
- Enables organizations to deploy, secure, and orchestrate autonomous AI agents with full operational control, memory systems, and multi-agent coordination
