# DIAC - Agentic CLI Tools - 2026-05-11

## New Findings (4 entries)

**Cursor SDK Public Beta Launch (May 2026):**
Cursor released its SDK for programmatic agent deployment. Developers can now build agents with the same runtime, harness, and models that power Cursor — accessible via `npm install @cursor/sdk`. Cloud sessions run on dedicated VMs with strong sandboxing; agents can work autonomously even when laptop sleeps or network drops. Use cases include CI/CD-triggered agents for summarizing changes and fixing CI failures, custom internal agent platforms, and embedding agents directly into customer-facing products. Enterprises like Faire already using it — Senior Engineering Manager George Jacob: "Cursor offers a great cloud experience for running many agents in parallel from the editor and CLI. We're excited about the SDK as a path to running our own programmatic agents on that same cloud runtime, without managing VMs or working around memory limits."

**Gemini CLI v0.42.0 Nightly (May 7): Real-Time Voice Mode Ships:**
Google's Gemini CLI shipped real-time voice mode with both cloud and local backends — the first major voice integration in this tool. Additional May 7 changes include shell command safety evals, JSON output for AgentExecutionStopped in non-interactive mode, randomized sandbox container names, improved MCP list UX in untrusted folders, and better OAuth handling for headless Linux.
