## New Findings

### Claude Code v2.1.139 (May 11): Agent View and /goal Command
Major new features for multi-agent coordination:

- **Agent View (Research Preview):** Single list of every Claude Code session — running, blocked on you, or done. Run `claude agents` to get started.
- **/goal Command:** Set a completion condition and Claude keeps working across turns until it's met. Works in interactive, -p, and Remote Control. Shows live elapsed/turns/tokens as an overlay panel.
- **/scroll-speed Command:** Tune mouse wheel scroll speed with live preview.
- **claude plugin details <name>:** Shows plugin's component inventory and projected per-session token cost.
- **Transcript navigation improvements:** ? for keyboard shortcuts, {/} to jump between user prompts, v to toggle shortcut panel.
- **Hook continueOnBlock:** New PostToolUse config option — set to true to feed the hook's rejection reason back to Claude and continue the turn.
- **MCP stdio servers:** Now receive CLAUDEPROJECTDIR in environment.
- **/mcp Reconnect:** Now picks up .mcp.json edits without a restart.
- **/context all:** Per-skill token estimates now account for model's tokenization.
