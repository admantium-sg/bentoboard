# Daily Report — Agentic CLI Tools — August 7, 2026

## Tool Releases (Task 1)

### Claude Code — Silence Holds; Security Fixes in Latest Releases (August 5–7, 2026)

No new releases since v2.1.222 (August 4). The double-drop (v2.1.221 + v2.1.222) on August 4 remains the most recent activity. The security-focused changelog for those releases is now fully visible: worktree isolation hardening prevents destructive git commands from file-editing or Bash in worktree-isolated sessions; PreToolUse auto-allow hooks now correctly enforced in background agent tasks (summaries, compaction, renames); `/code-review` is now an alias of `/code-review` with `ultra` for deep cloud reviews; and `1M_CONTEXT` enforcement now applies to every model with a native 1M window rather than a fixed list, with a startup warning when auto-compaction isn't holding sessions to 200K.

**Source:** https://code.claude.com/docs/en/changelog

### Codex CLI — v0.147.0 Alpha.13 Ships Cyber-Model Safety Patch (August 5–6, 2026)

The alpha sprint continues but appears to be in late stabilization — the chain now spans alpha.6.5 through alpha.13 with no stable v0.147.0 yet. The v0.146.1 stable remains the current recommended version.

**Source:** https://github.com/openai/codex/releases

### Cline v4.1.6 — Meta Muse Spark Added, Error Telemetry Fixed (August 6–7, 2026)

Cline pushed v4.1.6 since the v4.1.5 (Aug 5) reported yesterday:

- **Meta Muse Spark 1.2 Contributor on Cline provider** — new model available directly through Cline's built-in provider alongside a refreshed model catalog.
- **Error telemetry fix** — failures are now attributed to the model actually in use for a run, instead of being misreported against the wrong model.
- **Reasoning settings now portable across AI SDK providers** — effort levels and enable/disable toggles map to AI SDK's native reasoning setting (including Ollama), replacing per-provider overrides.

**Source:** https://github.com/cline/cline/releases

### Kilo — Pre-Release Surge: JetBrains Bundled CLI, Session Resumption, OpenCode Sync (August 5–7, 2026)

Two pre-releases since v7.4.20 (Aug 4) show Kilo is in active pre-release:

- **JetBrains bundled Kilo Core CLI** — Kilo Core ships as a bundled CLI with the JetBrains plugin, with developer tooling for pinning, unpinning, and updating. No separate install required.
- **Claude and Codex session resumption** — sessions created with Claude or Codex can now be resumed through Kilo Core's bundled runtime.
- **Remote CLI file delivery** — new support for delivering attachment files remotely via the bundled CLI runtime.
- **Improved JetBrains session diffs** — full-file editor diffs, multi-hunk diffs, fallback handling, gutter line numbers, session-scoped diff paths.
- **Defer threshold compaction during active tool loops** — long-running sessions no longer compact at unsafe points mid-task.
- **Upstream OpenCode through v1.17.13, reasoning metadata from v1.18.11** — stays current with OpenCode's latest model metadata.

**Source:** https://github.com/Kilo-Org/kilocode/releases
