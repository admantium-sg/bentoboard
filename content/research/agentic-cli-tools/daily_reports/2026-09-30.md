### Claude Code — v2.1.284: Sonnet 5.5 Default, Permission Granularity, Spend Tracking (September 28, 2026)

### Claude Code — v2.1.285: Desktop Launch from Terminal, Plugin Config at Install (September 29, 2026)

Adds `allowedProviders` managed setting to limit which API providers a machine may use. Adds `CLAUDE_CODE_DISABLE_WEB_FETCH` to turn off the WebFetch tool entirely. Ships every 1.3 days — 26 releases in the last month.
