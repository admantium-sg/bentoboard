**Claude Code v2.1.314 — a large, security-leaning release; new "block writes outside working directories" permission and gateway IdP-group routing (GitHub published 2026-10-30T01:06:26Z; npm `@anthropic-ai/claude-code` published 2026-10-30T00:12:56Z, `latest` = `next` = 2.1.314, `stable` still lags at 2.1.308)**. The release adds `permissions.blockWritesOutsideWorkingDirectories`, which makes Write/Edit/NotebookEdit refuse paths outside the working directories in *every* permission mode, and adds an optional `groups` list to Claude apps gateway upstreams so only developers in listed IdP groups are routed there (on failover too). Also added: `guardrail_trace` logging for Bedrock gateway upstreams (records which guardrail filter fired, without the matched text), and idle compaction for VS Code and Claude Desktop's Code tab (a 200K+ token conversation left idle gets summarized and that summary is used on the next message once the prompt cache expired). Notable fixes: `claude -p` exiting 0 with no output on startup failure (now prints the error, exits 1); Bedrock sessions with many images failing every turn; sessions failing turn after turn with "Invalid effort level" when an admin caps a model's effort (now lowers effort, retries and says which level it uses); MCP servers that work without sign-in showing "needs authentication" (now used signed out); `claude mcp logout` reporting success when the sign-in was not removed; PreCompact hook output cut at 10,000 characters; `~/.claude/skills/.trash` and `~/.claude/plugins/.trash` now capped at ~1024 entries each; and model IDs spelled with a dot behind an LLM gateway (e.g. `claude-opus-4.8`) no longer treated as an older model with wrong context window/output limit/effort/cost. Note: no `2.1.313` exists — the version jumps from 2.1.312 to 2.1.314.

Fixes include retrying provider throttling correctly instead of reporting it as context overflow (#59649), preserving more context headroom when fitting tool output into the window (#59934), and keeping Git snapshots working in split-index repositories (#59417). **Breaking change in the `@opencode/ai` package**: the fal, Black Forest Labs, Replicate and Stability providers are removed along with their entry points (#59977), and five legacy provider paths are renamed to nested paths (#59506).

**Crush v0.99.0 — "Catwalk v3, hooks!" — the largest Crush release to date (GitHub published 2026-10-29T16:25:08Z; stable moves from v0.98.2 to v0.99.0)**. Crush now speaks **Catwalk v3**, where provider `type` describes the API format rather than the vendor (`completions` = OpenAI-compatible, `responses` = OpenAI or routed through it, `messages` = Anthropic-compatible); existing configs are migrated automatically so `openai`, `openai-compat` and `anthropic` keep working. CLI flags follow: `crush provider add deepseek --type completions --base-url ... --api-key ...`, `--can-reason` is replaced by `--thinking always|never|toggleable`, and a new `--max-attachments N` flag. **Hooks are no longer tool-only** — session, turn, permission and compaction lifecycle hooks are added, plus PostToolUse and PostToolUseFailure, and hooks are now validated against the list of known events so typos are caught early (docs map each event to its Claude Code equivalent). Client/server mode gains host themes over the server API, host context (open files appear in completions), client-appended text for the next prompt, shared viewing (clients see which session another client is looking at) and piped permissions via `CRUSH_PERMISSIONS_PIPED=1`. Server behavior: `SIGHUP` now reloads config instead of stopping the server, and quitting through a service manager shuts down gracefully so in-progress work is saved. Fixed: tool failures no longer end the agent turn (#4143), forked child processes no longer write over the TUI, and the first prompt in a new session no longer duplicates itself.
- https://github.com/charmbracelet/crush/releases/tag/v0.99.0

**Antigravity CLI 1.4.10 — streaming rewritten for terminal scrollback; subagent context-loss bug fixed (GitHub published 2026-10-29T03:50:43Z)**. Agent reply streaming now scrolls off-screen lines into the terminal's own scrollback instead of repainting the whole screen, and text wrapping writes whole runs of text at a time — **"streaming writes about 70% fewer bytes to the terminal"**, which matters mainly over slow SSH. Memory: the CLI returns about **100 MB** of startup-leftover memory to the OS 15 seconds after the interactive UI opens (print and headless modes unaffected). The post-compaction size shown in the compaction marker and `/context` now also counts what the summary carries into the next prompt (earlier requests, artifact, subagent and running-task snapshots), with `(N summary)` still showing the summary alone. **Fixed: subagents losing the task their parent gave them and the parent's ID after context compaction** (including `/compact`) — a subagent's summary now keeps the parent's 10 most recent messages. Also fixed: conversations with many/large images being rejected for exceeding the model's request size limit (images now capped at 2000 pixels per side, large PNGs sent as JPEG when much smaller, and a JPEG-saved-as-PNG mismatch no longer rejected), and the `/browser` subagent not receiving the current page snapshot when the page belongs to an isolated browser context (e.g. `isolatedContext` or an attached Incognito window).
- https://github.com/google-antigravity/antigravity-cli/releases/tag/1.4.10

**Factory announcement — "Droid 1.0: Building a Frontier Harness" (published 2026-10-29, Factory Research)**. Factory's largest Droid update to date, built around **programmatic tool calling (PTC) made the default**, implemented as a **Script tool**: the model writes JavaScript that runs in a sandbox with no file, network or system access of its own, so a single model request can make hundreds of tool calls and the instructions/history are sent once instead of every few calls. Factory's own numbers in the post: on Terminal-Bench 4 with GPT-6.1 Sol, **Droid $0.79 per passed task at 57.6%** vs Codex 54.0% (~$0.90), OpenCode 51.0% and Devin 45.0% — "3.5 points higher than Codex at 12% lower cost"; with Claude Opus 5.5, **Droid $4.73 at 65.2%** vs Cursor 62.1%, OpenCode 62.1%, Devin 59.6% and Claude Code 57.6%, "up to 24% lower cost". A replayed failing-unit-test session took 5 model calls / 41.6 s with the Script tool versus 10 model calls / 56.8 s with direct tool calls, with model-call time falling from 42.3 s to 28.0 s. The design rationale is the internal **Agent Factory**, where agents study benchmark failures plus real-session friction, propose changes and test them across every affected model family. Factory states Droid remains model-independent and claims up to 20% greater efficiency than the native harnesses built for the models it supports.
- https://factory.ai/news/frontier-harness
