### 1. Mach-Mind-4-Flash: Post-Training MoE Efficiency Breakthrough
**arXiv:2607.09375** (July 10, 2026) — cs.LG — cs.CL
- 35B MoE / 3B activated parameters, matching 100B-class performance via post-training alone
- **HMPO (Hybrid Median-length Policy Optimization)**: single-stage token-efficiency compresses reasoning chains 19-46% with ≤0.7pp accuracy loss
- Multi-Teacher On-Policy Distillation (MOPD): routed reverse-KL eliminates see-saw degradation of mixed-reward RL
- Benchmarks: 92.70 AIME'26, 82.82 IFBench, 80.74 Behavioral-SafetyBench, 75.80 BFCL-v4, 72.31 BrowseComp-zh, 84.20 ClawBench
- Key insight: reasoning chain compression (HMPO) is the efficiency breakthrough — 19-46% shorter CoT with negligible accuracy loss
- Paper: https://arxiv.org/abs/2607.09375

### 2. Test-Time Scaling for Small VLMs (2607.09438)
**arXiv:2607.09438** (July 10, 2026) — cs.CL — cs.AI — cs.LG
- Test-time scaling transfers to small open VLMs (Qwen2.5-VL-7B, Qwen3.5-4B) on EXAMS-V multilingual benchmark
- Largest factor: **parseability** (answer commitment) — many chains reason correctly but never commit to answer letter; guided repair step fixes this
- Larger decoding budget (1k→2k tokens): +3.7pp; more chains (8→16): only +0.15pp
- PRM-guided beam search trails plain self-consistency by 0.39pp at 8x cost; neither multimodal PRM nor generative critic beats majority vote
- Largest gain: policy model itself (+11.4pp)
- Best: 84.1% on ImageCLEF 2026 Visual MCQ leaderboard
- Key insight: for TTS, **parseability and token budget > search method sophistication**
- Paper: https://arxiv.org/abs/2607.09438

### 3. Agora: Auction-Based Task Allocation for LLM Agents (2607.09600)
**arXiv:2607.09600** (July 10, 2026) — cs.AI — cs.CL
- Incentive-compatible auction mechanism for dynamic task allocation among expert models and tools
- Treats reasoning steps as tradeable items; agents bid based on **rectified competence** (capability minus overconfidence)
- Critical logic routed to most capable solver, not most overconfident
- Single auction parameter controls cost-quality trade-off
- Key insight: **competence-rectified bidding** prevents overconfident models from monopolizing tasks
- Paper: https://arxiv.org/abs/2607.09600

### 4. QANTA 2026: Task-Specific Multimodal QA (2607.09623)
**arXiv:2607.09623** (July 10, 2026) — cs.CL — cs.AI
- ICML 2026 EMM-QA Workshop — Rank #1 overall system
- Two-agent architecture: Tossup agent (when to answer under uncertainty, GPT-4.1-mini) + Bonus agent (answer selection, GPT-4.1)
- Tossup: confidence-calibrated answering + numeric reasoning policy reduces overconfident predictions
- Bonus: leadin-aware reasoning, structured relational reasoning, multimodal evidence integration
- No retrieval pipeline or model ensembles; efficient reasoning policies + confidence calibration
- Key insight: **task-specific reasoning policies** outperform general-purpose systems on constrained benchmarks
- Paper: https://arxiv.org/abs/2607.09623

### 5. RashomonLLM: Explanation-Prediction-Reflection Agentic Workflow (2607.09502)
**arXiv:2607.09502** (July 10, 2026) — cs.LG — cs.AI — cs.IR
- Rashomon Explanation paradigm: builds set of faithful, prediction-guiding explanations rather than single explanation
- Explanation-Prediction-Reflection agentic workflow: explanations generated by iteratively aligning with predictions
- Proves: explanation fidelity bounds performance; coupled explanation-prediction improves accuracy (not trade-off)
- Outperforms SOTA on accuracy and explanation quality across churn, clinical survival, click-through prediction
- Key insight: **explaining and predicting are complementary, not competing objectives** when properly coupled
- Paper: https://arxiv.org/abs/2607.09502

### 6. Deceptive Grounding: Entity Attribution Failure in Clinical RAG (2607.09349)
**arXiv:2607.09349** (July 10, 2026) — cs.CL — cs.AI — cs.LG
- "Deceptive grounding" (DG): RAG passes faithfulness/hallucination/citation checks but presents drug Y's evidence as evidence about drug X
- Invisible to standard RAG evaluation — every claim sourced from real documents about wrong entity
- 8-87% DG rates at peak adversarial conditions; medical/biomedical fine-tuned models reach 86.7%
- **Domain specialization amplifies the failure**, not mitigates it
- 7.8% overall DG in deployed clinical RAG; 13.6% for recently approved drugs
- Entity-attribution verification detects DG at 97.0% precision / 98.7% recall
- Key insight: **no existing RAG framework implements entity-attribution verification** — critical gap for clinical deployment
- Paper: https://arxiv.org/abs/2607.09349

### 7. Information Floors in LLMs (2607.09487)
**arXiv:2607.09487** (July 10, 2026) — cs.LG — cs.CL — stat.ML
- "Neural collapse is forbidden" in language models — within-class variance is allocated information storage
- Within-token context (79-91%) dominates variance; macro-category structure (4-12%) is minimal — stable across 100x parameter range
- Token-level weight decay penalizes category proportional to type count (not occurrence mass), creating imbalanced K-class problem
- A "converse floor" forces within-category dispersion proportional to conditional mutual information
- Key insight: **identity dispersion, not total variance, tracks information across models and over training**
- Paper: https://arxiv.org/abs/2607.09487
