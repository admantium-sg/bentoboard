### OpticalRAG: Pixel-Space Compression for Token-Efficient Retrieval-Augmented Generation — `2611.13675`
**Category:** Computation and Language | **Section:** New submissions
OpticalRAG argues that the RAG token bottleneck comes from the *modality* of compression rather than information density: a rendered page of text can be packed into ~100 visual tokens by a frozen vision encoder with little semantic loss. The framework renders documents as images, encodes them, and distills retrieved visual tokens down to as few as 16 injected tokens before the LLM sees them, using (i) Encoder-Bridged Retrieval, which projects text-query states into the frozen encoder's visual feature space via a projection shared with the compressor — no contrastive training — and (ii) a Query-Driven Distillation cross-attention compressor producing query-conditioned prefix tokens. The authors report the best compression-aware accuracy (CAP) on LongBench-v2, BAMBOO and LooGLE-v2 while injecting only 16 tokens, and state the closed-book Qwen2.5-7B-Instruct backbone improves by 5.17 points (abstract text truncated in the source listing).
**Key numbers:** 16 injected tokens; best CAP on 3 benchmarks (LongBench-v2, BAMBOO, LooGLE-v2); +5.17 points over closed-book Qwen2.5-7B-Instruct (self-reported); ~100 visual tokens per rendered page.
**Source:** https://arxiv.org/abs/2611.13675

### Decode Token Parallelism: Memory-Efficient Distributed Attention Parallelism for Scalable LLM Decoding — `2611.13293`
**Category:** Distributed, Parallel, and Cluster Computing | **Section:** Cross submissions
Decode Token Parallelism (TKNP) is a decode-pool architecture that decouples weight placement from attention ownership: a single model copy is distributed across nodes in balanced layer blocks, and the node holding a block executes its projections and MLP for the whole batch using intra-node tensor parallelism while every node computes attention for its own requests against locally resident KV cache. Only current-token activations cross the network, dense all-reduces stay within an NVLink domain, and attention needs no cross-node merging of partial attention results — unlike data parallelism (replicated weights, limited KV capacity), tensor parallelism (stalls at KV-head count) and decode context parallelism (cross-node partial-attention aggregation). Implemented in vLLM and evaluated on Llama 3.1 405B and Nemotron-4 340B on up to 64 H100 GPUs.
**Key numbers:** up to 1.7× completion throughput over decode context parallelism and up to 2.06× over data parallelism at matched GPU count (self-reported); 405B/340B models, up to 64 H100s; 14 pages, 12 figures.
**Source:** https://arxiv.org/abs/2611.13293

### ADIndex: Layer-Adaptive Sparse Attention Indexing via Group-Level Distillation — `2611.12956`
**Category:** Machine Learning | **Section:** New submissions
ADIndex targets the fact that in DeepSeek Sparse Attention the *indexer* — which scores the entire causal prefix per query — can account for more than 50% of total prefill GPU time at long context lengths. The method combines a layer-wise calibration strategy that adapts to cross-query retrieval overlap (motivated by observed inter-layer heterogeneity), a group-level distillation scheme that trains adaptive layer-wise group indexers, and a low-latency inference strategy that avoids repeated full-prefix scans via token bank sharing within query groups while retaining query-specific refinement. Experiments on DeepSeek-V3.2 and GLM-5.1 preserve near-lossless performance on LongBench, LongBench v2 and RULER.
**Key numbers:** prefill and decoding kernel speedups up to 6.22× and 3.40× at 256K context (layer-wise reuse configs), end-to-end serving speedup 1.54× at 128K context (self-reported); indexer >50% of prefill GPU time in baseline DSA.
**Source:** https://arxiv.org/abs/2611.12956

### SinkState: On-the-Fly SVD of Recurrent States for Efficient Hybrid LLM Serving — `2611.14246`
**Category:** Machine Learning | **Section:** New submissions
SinkState exploits an empirical finding that the queries, keys and values of linear-attention layers concentrate in a stable, low-dimensional subspace — the "linear attention sink" — making each recurrent state effectively low-rank with state-varying rank. Existing hybrid serving stacks (Mamba-SSM, FLA) keep these states dense and rewrite them fully at every decoding step, so memory traffic scales with batch size and dominates decode cost. SinkState instead stores each recurrent state in adaptive low-rank form throughout inference with buffered updates and a local SVD restricted to the top subspace, consolidating remaining components asynchronously on CPU.
**Key numbers:** recurrent-state peak memory reduced up to 2.6× (1.9× average), decoding speed up to 1.58× (1.25× average) over Mamba-SSM and FLA, accuracy maintained; tested on four hybrid models (Mamba-2 and Gated DeltaNet layers) from 4B to 120B parameters (self-reported).
**Source:** https://arxiv.org/abs/2611.14246

### Looping Deeper Without Growing the KV Cache: Recurrent Depth for Causal Encoder-Decoders — `2611.13378`
**Category:** Machine Learning | **Section:** New submissions
Looped language models buy depth without parameters but must cache full-context KV states across layers *and* rounds, which bounds serving batch size. This paper designs a looped causal encoder-decoder (CED) with zero round-wise KV growth, and establishes where to loop an asymmetric stack in which only sparse encoder layers produce global KV: recurrence belongs in the encoder, iteratively refining global KV representations, which drives language-modeling gains while preserving long-context scaling. Training the encoder loop under stochastic recurrence depth induces a fixed-point equilibrium where every round losslessly shares the last round's KV cache; compounding cross-layer and cross-round KV sharing yields a model matching an unlooped CED's minimal memory footprint.
**Key numbers:** recovers 86–93% of a looped Transformer's gain with 1/6 of its global KV (self-reported); on a 552B DeepSeek-V4.1-Flash looped for 8 rounds on one 4×GB200 node, Looped CED holds 36.8× less KV per token, fits 38 requests of 128K tokens (as many as the unlooped model), and serves 3.6× higher throughput on 8K-token prompts.
**Source:** https://arxiv.org/abs/2611.13378

### Multi-Future Drafting: Mixture Block Drafters for Tree-Verified Speculative Decoding — `2611.13017`
**Category:** Artificial Intelligence | **Section:** Cross submissions
Multi-Future Drafting (MFD) attacks a structural flaw in product-ranked draft trees for speculative decoding: when a continuation could follow several plausible futures, the product rule splices them into chimeras — prefixes stitched from different futures the target model never produces — and allocates them as much tree budget as the real futures. The authors prove that barring ties, no product-ranked tree can hold two futures disagreeing in m positions without 2^(m−1)−1 chimeras, and report chimeras making up 27–33% of a 64-node tree in practice. MFD restores the chain-rule coupling via a latent variable: K learned mode embeddings at the drafter's input draft K coherent blocks in one pass, and a mixture DDTree lets the verifier select the future the target actually takes, losslessly, with K+1 extra vectors.
**Key numbers:** up to 7.8× speedup on four Qwen targets (4B–27B) at batch size 1; 5–8% faster than the best single-mode tree trained identically, and 9–16% faster than released DARTree on Qwen3-4B/8B with the same prompts (self-reported); chimeras 27–33% of a 64-node tree; minimum 2^(m−1)−1 chimeras.
**Source:** https://arxiv.org/abs/2611.13017

### REAL Loss: Optimizing Real Expected Acceptance Length for Speculative Decoding — `2611.14399`
**Category:** Machine Learning | **Section:** Cross submissions
REAL is a training loss that optimizes the *real* expected acceptance length (EAL) of speculative decoding rather than a surrogate. The authors argue that block-level objectives (e.g. averaging later acceptance over target-distributed continuations rather than over the verification branches actually selected by accepted tokens) introduce a covariance gap that can reverse the gradient direction. REAL uses path weights for unbiased estimation plus Rao–Blackwellization for variance reduction, and requires no change to the drafter architecture or the inference procedure. In a controlled loss-level comparison with a Qwen3.6-35B-A3B target and a Domino drafter, REAL outperforms WTV, VSD, DBLast and the static LK baseline on probabilistic serving acceptance length.
**Key numbers:** evaluated across 9 task subsets and 5 evaluation seeds with a Qwen3.6-35B-A3B target and Domino drafter (self-reported; no single headline delta stated in the abstract); 19 pages, 10 figures.
**Source:** https://arxiv.org/abs/2611.14399

### Beyond Passive Imitation: On-Policy Mid-Training Distillation for Language Models — `2611.13855`
**Category:** Computation and Language | **Section:** New submissions
The paper argues that continual pre-training's standard next-token-prediction objective is a poor fit for domain adaptation: it treats every corpus token as a fixed target regardless of its utility to the current model. In a controlled study on the same 1B-token math corpus, NTP improves Llama-3.2-3B on math benchmarks but substantially *degrades* Qwen3-1.7B-Base, showing the same training sequences can have model-dependent effects. On-Policy Mid-Training Distillation (OPMD) reformulates mid-training as active, query-driven knowledge acquisition: at anchor positions it samples trajectories from the evolving student and applies dense token-level reverse-KL rewards from a frozen teacher, training on states the student actually visits. OPMD adds no inference-time overhead.
**Key numbers:** on MATH-500 and Minerva, OPMD improves the Qwen student over its base and beats the evaluated NTP baseline, which degrades on both (self-reported); 1B-token controlled corpus; 17 pages.
**Source:** https://arxiv.org/abs/2611.13855

### AutoScaffold: AI-Guided Scaffolding for Reinforcement Learning of Language Models — `2611.14515`
**Category:** Machine Learning | **Section:** Cross submissions
AutoScaffold is an "AI-for-AI" framework in which a frozen teacher turns a student's RL training experience into adaptive scaffolds — either shared strategies for a class of tasks or hints for individual hard tasks — adjusting content and amount of support as the student learns, with no human intervention during training and with scaffolds removed at evaluation. The teacher diagnoses bottlenecks from the training experience and shifts scaffolds from step-by-step workflows toward targeted fixes as the student improves. Applied identically across ALFWorld, search-based QA, mathematical reasoning and GPU kernel generation.
**Key numbers:** +7.2 points ALFWorld success and +4.0 points average QA exact match over the corresponding RL baselines; up to +5.0 points in the fraction of GPU-kernel tasks that run faster than the PyTorch reference; on math, the student surpasses QuestA's reported accuracy using ~1/3 as many student training steps (self-reported); 4 domains.
**Source:** https://arxiv.org/abs/2611.14515

### Coding Agent Memory Post-Training II: Unlocking the Memory Potential of Pre-trained File Operations for Long-Horizon Tasks via On-Policy Distillation — `2611.14009`
**Category:** Machine Learning | **Section:** Cross submissions
This work argues that existing on-policy distillation (OPD) for agent memory is weak on both sides: the teacher never used the memory interface (files/compaction), and the student samples too few meaningful memory actions for the guidance to land. The authors introduce Coding Agent Memory Gym II (CAMG-II), long-horizon agentic-RL environments spanning Shop, Coding, AutoResearch, General and Visual, each with an episode-persistent workspace and ordinary Bash access alongside the native task interface, plus CAMP-II, which trains a single policy jointly across all five environments with fully asynchronous OPD from a frozen teacher that has a prior for file operations. Learned memory behavior generalizes to external benchmarks.
**Key numbers:** CAMP-II obtains 2.97× the gain of the strongest OPD baseline on CAMG-II, with improved success rates on Terminal-Bench 2.1 and SWE-Bench Pro V2 (self-reported); 5 environments, 40 pages.
**Source:** https://arxiv.org/abs/2611.14009

### A Theory of Policy Optimization in Post-Training: Coverage Collapse and Reference Resets — `2611.14467`
**Category:** Machine Learning | **Section:** New submissions
A 141-page theoretical treatment of policy optimization for LLM post-training, defining *coverage-preserving* algorithms — those learning near-optimal policies with sample and gradient budgets governed by the base model's response coverage. Two mechanisms are identified: (1) **coverage collapse**, where REINFORCE (the basis of PPO and GRPO) can drive the probability of optimal responses to near zero even as reward improves, stalling optimization and potentially requiring exponentially many steps — a failure that persists with exact gradients and under KL regularization to the base model; and (2) **reference resets**, repeatedly resetting the KL reference to the most recent policy, formalized as Approximate Policy Mirror Descent (APMD), a meta-algorithm that solves a sequence of KL-regularized RL subproblems. For softmax linear policies over pretrained features, APMD yields the first global convergence guarantees that stylized PPO/GRPO variants with explicit KL regularization and reference resets — including squared-loss algorithms of the kind used to train the Kimi models — are coverage-preserving.
**Key numbers:** no headline metric in abstract; 141 pages including appendices, 3 figures (self-reported scope).
**Source:** https://arxiv.org/abs/2611.14467

### Wrong the Same Way: Cross-Prompt Sharing Both Suppresses and Amplifies Reward Hacking in RLVR — `2611.13218`
**Category:** Machine Learning | **Section:** New submissions
Using a controlled environment small enough to compute the entire response distribution exactly, the paper adjudicates two competing accounts of RLVR and reward hacking: hacking is inherited from the base model, versus RL amplifies it. At its KL-regularized optimum RLVR acts as a filter that reweights the accepted set without altering its composition, so the hack rate is inherited exactly — a useful null model. Drift from that null decomposes into per-prompt covariances between reward and the empirical tangent kernel; without parameter sharing those cross-prompt terms vanish, while with sharing, prompts that accept a wrong answer push it up and prompts that reject it push it down through the baseline, weighted by the model's probability of producing it there. The authors also argue verifier fixes should target mistakes the model repeats across prompts, and offer this as an explanation for why earlier studies disagree.
**Key numbers:** at every convergent learning rate under Adam, SGD and sampled GRPO, hacking ends higher at high leak universality than at low; independent per-prompt copies remove the dependence (self-reported); two verifier patches removing equally many errors differ by up to 38 points of true accuracy.
**Source:** https://arxiv.org/abs/2611.13218

### Margin-Guided Token Credit for Reinforcement Learning with Verifiable Rewards — `2611.14015`
**Category:** Machine Learning | **Section:** New submissions
GRPO gives every token in a correct solution the same credit. MCPO (Margin-Credit Policy Optimization) instead places credit where the model hesitated, measuring hesitation via the top-2 margin M = p1 − p2 of the next-token distribution, mapping it to a score with two fixed thresholds and spreading each solution's advantage over its tokens so the mean is unchanged. The margin is read from a forward pass the trainer already performs, so no extra model evaluation or batch statistics are needed.
**Key numbers:** trained on MiniCPM5-2B-Base with LoRA for 200 steps on 2,048 DAPO-Math problems, MCPO beats unmodified GRPO for all five data seeds by 6.55 points macro avg@32 on average (95% CI [4.1, 9.0]); a Qwen3-4B-Base replication improves for all three seeds (+4.75); gains grow with k in pass@k, reaching 13.8 points at pass@32; MCPO models write 2–3× longer answers (self-reported; the authors do not separate this effect).
**Source:** https://arxiv.org/abs/2611.14015

### Closing the BF16-FP16 Convergence Speed Gap in RL Post-Training with Stochastic Rounding — `2611.13545`
**Category:** Machine Learning | **Section:** New submissions
In RLVR, where learning rates are typically low, the authors find standard mixed-precision BF16 training converges more slowly than FP16 at the same learning rate. They attribute this to *weight sticking*: when FP32 shadow weights are quantized to BF16 by round-to-nearest, small updates often leave the BF16 weights used for rollout generation and training unchanged, so several optimizer steps may be needed before shadow-weight updates show through. Raising the BF16 learning rate does close the gap but increases KL divergence from the reference model. The proposed alternative — stochastic rounding when quantizing FP32 shadow weights to BF16 — matches FP16's convergence speed across models and datasets while reducing KL divergence relative to the higher-learning-rate BF16 run, keeps BF16's wider dynamic range, and needs no loss scaling.
**Key numbers:** no headline percentage in the abstract; matches FP16 convergence speed across different models and datasets while lowering KL divergence vs. larger-LR BF16 (self-reported).
**Source:** https://arxiv.org/abs/2611.13545

### SteerDistill: Quantizing LLM Agents via Closed-Loop Teacher Steering — `2611.13410`
**Category:** Artificial Intelligence | **Section:** Cross submissions
SteerDistill is a quantization-aware distillation method for LLM agents: analyzing failed rollouts shows quantized agents overlook task requirements or environmental conditions, producing environment transitions that diverge from successful full-precision references, and offline data rarely covers the student's own failure contexts. SteerDistill has a full-precision teacher guide the student to revise failed responses, iteratively refining that guidance with feedback from student execution, yielding locally verified behavioral corrections; the student is then trained without guidance to match the steered student's predictions at corrected turns and the full-precision teacher's elsewhere, enabling unassisted inference.
**Key numbers:** across five agentic benchmarks and three models, exceeds the strongest quantized baseline by 1.67–2.18 points average score under W4A16 and stays within one point of BF16; on τ²-Bench it outperforms QeRL by 1.84 percentage points in success rate using 67% fewer training GPU hours, with shorter successful trajectories (self-reported).
**Source:** https://arxiv.org/abs/2611.13410

### How Post-Training Influences Verbalized Algorithmic Computation in Language Models — `2611.13552`
**Category:** Computation and Language | **Section:** New submissions
Using multi-digit addition with carry values as a known intermediate state, the paper probes successive SFT, DPO and RLVR checkpoints of Olmo-3-7B-Instruct. Probes recover carry information from internal activations with similar accuracy in SFT and RLVR, but manipulating that information does not reliably control outputs — whereas the *usefulness of verbalized* reasoning differs strongly: CoTs produced by RLVR yield higher accuracy across receiving checkpoints than those produced by SFT or DPO, and carry-related statements receive higher importance scores after RLVR than matched random controls. DPO shows similar sensitivity to carry-related statements but without comparable accuracy gains. The takeaway: post-training changes the usefulness of and sensitivity to written reasoning, though greater sensitivity does not necessarily mean better performance.
**Key numbers:** no headline metric in abstract; comparative probe-accuracy and accuracy-by-CoT-source comparisons across SFT / DPO / RLVR checkpoints of Olmo-3-7B-Instruct (self-reported).
**Source:** https://arxiv.org/abs/2611.13552

### Catch It Where It Happens: Real Time Error Correction During LLM Reasoning — `2611.13107`
**Category:** Computation and Language | **Section:** New submissions
Instead of checking only the final answer and restarting, or running a competing verifier LLM that eats GPU capacity, the paper proposes online *deterministic* verification: many reasoning steps can be validated by code, so a step can be checked in real time as it is written, with no model call or GPU use. When a check fails, the mistake is pointed out and the model continues from the same spot. Demonstrated on symbolic mathematics, where derivations already contain explicit expressions a computer algebra system can check in milliseconds.
**Key numbers:** on the ASyMoB benchmark with three open-weights models, online validation improves accuracy by 1.4–5.6 percentage points, a 1.8–14.9% net reduction in incorrect answers, at only 6–7% increased token usage (self-reported).
**Source:** https://arxiv.org/abs/2611.13107

### Linear Probes to Bayesian Manifolds: Geometry of Arithmetic in Large Language Models — `2611.12998`
**Category:** Machine Learning | **Section:** Cross submissions
The paper decomposes the single claim "the model computes with this geometric structure" into four separable claims — decodability, shape, ownership and causal use — and tests each with a four-stage Bayesian pipeline: compare candidate shapes with a predefined evidence threshold; remove a pre-specified set of related concepts to test ownership; intervene on the shape to test causal dependence. Applied to two-digit addition and multiplication in GPT-J 6B, Llama 3.1 8B and Pythia 6.9B. The authors argue that a probe verdict alone overstates what a model computes with, and recommend reporting probe results as verdicts on all four claims rather than a single accuracy.
**Key numbers:** of 1,330 cells with an ownership verdict, 19% of shapes are owned and 81% inherited; owned and inherited shapes move the output about equally often; intervening on the shape retains ~61% of the effect of intervening on the full probe while using at most five dimensions vs. a median of nine; every strongly supported comparison selects a ribbon (helix with value-dependent radius) or torus (self-reported).
**Source:** https://arxiv.org/abs/2611.12998

### AI Isn't Getting Dumber, We're Getting Pickier: Rising Standards in Human Evaluation of Large Language Models — `2611.14333`
**Category:** Human-Computer Interaction | **Section:** Cross submissions
Using Chatbot Arena's blind pairwise votes, the paper separates the possibility that models degrade from the possibility that human judges change, studying 1,260,967 votes from May 2023 to August 2024 on pairs of models whose versions are fixed (dated vendor snapshots and fixed open-weight models). Absolute verdicts drift upward while relative rankings hold steady, meaning products that stand still are judged as declining. The drift holds within the same voter on the same pair, across arrival cohorts from their first recorded vote, with prompt controls, in every major language, across vendor snapshots, open-weight models and stable-answer-length models, and across interface changes; month effects estimated from other models' pairs remove it from each model's own pairs.
**Key numbers:** share of "both are bad" votes rises 1.71 percentage points per month on a mean of 17.1% (1.91 pp/month in 2024); in fourteen pairs observed in both 2023 and 2024 it rose in every one, from 15.5% to 23.3%; platform-wide the average model would be expected to score 78% against the 2023 average (self-reported); 23 pages, 6 figures, 10 tables.
**Source:** https://arxiv.org/abs/2611.14333

### LLM Validation Makes Minimal-Pair Benchmarks Easier for Language Models — `2611.13788`
**Category:** Computation and Language | **Section:** New submissions
The paper tests whether LLMs can replace costly human validation for minimal-pair syntactic benchmarks, on BLiMP (English) and QFrBLiMP (Quebec French) — the two public datasets releasing every forced-choice human judgment — with three LLMs validating by forced choice, by rating, and as a panel, scored against human panels of one, three and five judges in two pre-registered phases. The core finding is a systematic, non-random bias: the filter removes items on which LMs fail but humans do not, inflating accuracy more than random removal would, and a pre-registered protocol frozen before any output replicates the gap and the lift on Dutch BLiMP-NL.
**Key numbers:** on BLiMP, forced-choice validators agree with held-out human majorities more often than five-judge panels yet catch far fewer human-rejected pairs than one judge; by point estimate no validator is worth more than one judge; human-supported pairs flagged by the pre-registered LLM filter are 18.9 points harder than accepted ones in all 70 LM-validator combinations (self-reported); code, validator outputs and item-level scores released.
**Source:** https://arxiv.org/abs/2611.13788

### CLADE: Category-Level Answering from Deficient Evidence in Retrieval-Augmented Language Models — `2611.14355`
**Category:** Artificial Intelligence | **Section:** New submissions
CLADE names a failure mode of RAG systems: retrieved passages that are accurate and relevant but state the answer at a coarser granularity than the question requires (e.g. the disease family instead of the specific disease) — "resolvable insufficiency", where text alone cannot settle the fine-grained answer but the mentioned category maps to a short candidate list in a domain ontology. When models read such coarse passages they answer rather than abstaining or searching further. The authors test that confidence filtering, scaling to a larger model, and explicitly instructing the model to abstain all fail to fix it, and that ontology lookup can in principle recover the exact answer.
**Key numbers:** on PrimeKG biomedical questions, family-only passages reduce abstention by 13.8 points vs. uninformative passages and the resulting guesses are wrong about half the time; replacing an exact disease name with its family name lowers abstention by 17.4 points vs. deleting the sentence; replicates on GloBI ecological species interactions; given the correct family an ontology list contains the true answer in 98.5% of cases but string matching finds that family on the page only 19.8% of the time, model-chosen family 30.0%, end-to-end recovery 10.0% → 26.8% (self-reported).
**Source:** https://arxiv.org/abs/2611.14355

### From Questions to Decisions: Benchmarking How LLM Agents Acquire Decision-Relevant Information from Human Beings — `2611.13015`
**Category:** Artificial Intelligence | **Section:** New submissions
Ask2Decide is a benchmark of 43 planning tasks testing whether LLM agents ask for missing information that would change their decisions. An operator holds facts absent from the agent's request, and optimization solvers determine which facts change the optimal plan; similarly-worded facts that leave the optimal plan unchanged test whether agents distinguish useful information from irrelevant detail. Human interaction sessions are used to calibrate a simulated operator, because uncalibrated LLM-simulated users behave unlike real people.
**Key numbers:** 79 interaction sessions from 19 participants; after an incorrect plan, human replies omit the correcting fact far more often than replies from an uncalibrated simulated user (43% vs. 7%); across four frontier LLMs, initial plans are infeasible on 58–98% of tasks when information is missing, vs. 5–28% when all facts are provided upfront; agents uncover plan-changing facts only slightly more often than plan-preserving ones (39–52% vs. 32–41%) (self-reported).
**Source:** https://arxiv.org/abs/2611.13015

### When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents — `2611.14326`
**Category:** Artificial Intelligence | **Section:** Cross submissions
Falsification-Gated Self-Evolution (FGSE) addresses when an episode-derived behavioral update should be admitted into persistent agent state. Each candidate lesson is represented as a structured hypothesis with an explicit precondition, behavior change, expected effect and verifier; FGSE applies the hypothesis in a temporary state, tests it on target-transfer, falsification and archived-regression probes, then commits, refines or rejects it according to measured gain and risk — rather than writing lesson-shaped content into memory directly on the basis of local success.
**Key numbers:** across web, app, tool-use and long-term memory benchmarks, FGSE reaches 39.8% WebArena success rate, 78.8% AppWorld average completion, and 0.724 / 0.487 Pass¹ on τ-Retail / τ-Airline, while reducing falsification failures to 5.0%, regression damage to 1.3% and harmful committed updates to 3.6% (self-reported).
**Source:** https://arxiv.org/abs/2611.14326

### Don't Just Trust Your Memory: Evidence-Linked Memory Reduces Memory-Induced Degradation in LLM Agents — `2611.14320`
**Category:** Artificial Intelligence | **Section:** New submissions
The paper names "memory-induced degradation" — an agent failing a task it would have solved without memory, because it follows an incorrect lesson or misapplies a valid one. The cause is that lessons are inferred from trajectories labeled only with task success/failure, and are then handed to the agent without the trajectories they came from. WikiTrace stores each lesson as a concise insight linked to a summary of why its trajectory succeeded or failed and to the raw trajectory itself; on a new task, the agent starts from all insights and descends through those links with terminal tools whenever an insight lacks actionable detail, conflicts with another, or came from a failed task.
**Key numbers:** validated on five agentic benchmarks, consistently outperforming existing memory approaches and a baseline given the same insights alone, while also reducing memory-induced degradation (self-reported; no per-benchmark numbers in the abstract).
**Source:** https://arxiv.org/abs/2611.14320

### TERM: Target-Free Jailbreak Defense via Entropy-Guided Residual Modulation — `2611.13577`
**Category:** Cryptography and Security | **Section:** Cross submissions
TERM is an inference-time jailbreak defense that avoids predefined steering directions or learned safety regions. It uses prompt-calibrated attention entropy deviations as an input-specific reference (raw entropy varies by prompt and decoding step), then adaptive scale normalization and temporal accumulation determine intervention strength, and the resulting signal controls bounded scaling of the model's own residual updates. The design goal is to raise jailbreak robustness without inflating over-refusal on benign, safety-sensitive requests.
**Key numbers:** compared against seven defenses, seven jailbreak attacks and two over-refusal benchmarks across Llama, Qwen and Gemma models including Qwen3 from 0.6B to 32B; authors report improved jailbreak robustness with low over-refusal and modest inference overhead (self-reported; no numeric deltas in the abstract).
**Source:** https://arxiv.org/abs/2611.13577

### One Byte, One Token: Byteifying a 27B Hybrid-Attention LLM with Self-Generated Data — `2611.13607`
**Category:** Computation and Language | **Section:** New submissions
The paper asks whether an already-trained 27B subword model can be converted directly into a pure byte-level model (one byte, one token) with no patching structure or local encoder, while keeping most of its ability. Starting from Qwen3.8-27B (48 Gated DeltaNet + 16 full-attention layers), the vocabulary is shrunk from 248,320 to 384 entries, all other weights left untouched, and training continues with a two-stage curriculum (encoding first, then reading) on 4.77 GB of supervised bytes, with dialogue/behavioral supervision generated on-policy by the original model itself. The result is a strong character-level model at a real throughput cost.
**Key numbers:** byte-level BPE fragments Chinese at 3.84 bytes/token with 64% of tokens single characters (Qwen3.8 baseline); training 178.6 h on 8×H200; gap to original within the paired bootstrap interval on MATH-500, HumanEval+, MMLU-Pro and non-thinking GSM8K, losing 4–6 points on C-Eval, thinking-mode GSM8K and non-thinking IFEval; character-level gains CUTE 75.2→84.0, EXECUTE-zho 81.6→93.9, custom Chinese character suite 54.4→64.0; per-step speed identical but each step yields 3–5× less output, Chinese characters/second ~1/4 of original, prefill at 64K bytes 6.5× slower (self-reported); four byte-model failure modes documented.

### From Attack Surface to Defense Architecture: Compositional Security for Agentic Coding Harnesses — `2611.13960`
**Category:** Cryptography and Security | **Section:** Cross submissions
The paper argues that security in agentic systems is a structural property of the cognitive architecture and permission composition rather than an emergent property of individual models: AI coding harnesses couple models to shells, filesystems and network sockets, so injected instructions turn dual-use binaries (bash, curl, find) into Living-off-the-Land payloads. ActiveSecHarness is a neurosymbolic reference-monitor architecture built around Separation of Intelligence and Authority, combining Macaroon-inspired HMAC capability tokens across four Trust and Authority Rings, a 2D product taint lattice (trust × sensitivity) with a workspace provenance ledger to prevent secret laundering across disk, deterministic Ring-0 OS/tool guards, and bytecode certificates with split-horizon audit logs.
**Key numbers:** across N=252 fixtures (120 attack, 120 benign, 12 kill chains), a live local LLM judge (qwen3:4b) refuses 98.3% of benign work at 142.3 ms latency, whereas Ring 0 achieves ABR=1.000 and FPR=0.000 in 12.7 µs (11,200× faster); in a multi-step trajectory ablation, an oracle Conseca-style stateless policy misses 4/12 kill chains (ABR=0.667) and coarse Boolean taint blocks 83.3% of benign workflows, while the 2D product lattice achieves ABR=1.000 and FPR=0.000 at ~20 µs per step (self-reported).

### What drives the emergence of symbolic mechanisms in large language models? — `2611.13270`
**Category:** Computation and Language | **Section:** New submissions
The paper asks what actually causes the "emergent symbolic mechanisms" that recent work has identified in large language models. The authors train networks from scratch on abstract sequence tasks while varying architectural and data-distributional factors, then apply representational, attentional and causal mediation analyses. They first confirm that transformer LMs trained from scratch on the task do develop symbolic mechanisms, then find that across multiple axes of data diversity, greater diversity produces stronger symbolic signatures — and, surprisingly, that the same signatures emerge in modified transformer architectures and even in multilayer perceptrons, so architectural inductive biases are not necessary. Consistent patterns also appear in an entity-attribute binding task, leading the authors to identify data diversity, not architecture, as the primary driver of emergent symbolic computation.
**Key numbers:** none stated in abstract (comparative analysis across multiple data-diversity axes, modified transformer architectures, and MLPs; 25 pages, 15 figures, 5 appendices; to appear at NeurIPS 2026).

### Bits or permutations? Spending a fixed inference budget on weight precision or on option-order averaging in small local language models — `2611.14413`
**Category:** Artificial Intelligence | **Section:** Cross submissions
The paper pits two ways of spending a fixed small-model inference budget against each other: reducing weight precision, and averaging over permutations of multiple-choice answer options (which reduces order sensitivity). Using simulated round-to-nearest weight quantization on Qwen3-0.6B and Qwen3-1.7B, reading logits for letters A–D on ARC-Easy, ARC-Challenge, MMLU and HellaSwag (300 items each), the authors find 6 bits lose no accuracy against fp16 (6-bit even scores slightly higher, which they do not explain) while 8 bits slightly hurt. At 4 bits the answer-slot skew rises sharply, but a Gaussian-noise control at matched weight SNR gives inconclusive evidence on whether rounding adds skew beyond equal-power noise, and flip rates rise but stay below an accuracy-matched uniform-error baseline. Averaging four cyclic orders recovers a large amount of lost accuracy at 4 bits, and a machine-independent cost unit (weight bytes read × passes) yields a decision table: use 6-bit weights and spend the rest of the budget on up to four orders.
**Key numbers:** 6-bit weights score +1.8 (+1.0 to +2.5) and +0.9 (+0.3 to +1.5) points above fp16 on 0.6B and 1.7B; 8-bit changes accuracy by −0.7 and −0.4 points; at 4 bits answer-slot skew rises 0.15→0.53 (0.6B) and 0.07→0.12 (1.7B); Gaussian control at equal SNR gives 0.15, 0.37 (two draws), 0.19 (one draw); averaging four cyclic orders recovers +12.6 points at 4 bits for 0.6B (+5.3 at fp16); 25 pages, 15 figures, 9 tables (self-reported).
**Source:** https://arxiv.org/abs/2611.14413

### TreeAgent: Structure-Aware Memory Agent for Processing Long Hierarchical Data — `2611.13946`
**Category:** Artificial Intelligence | **Section:** New submissions
Memory agents that process inputs exceeding the LLM context window typically split them into flat token segments, which breaks records apart, hides hierarchical position and can discard earlier sibling details. TreeAgent is a structure-aware memory agent that uses the input hierarchy to guide both segment-wise context processing and access to past information: segments are built from complete subtrees and groups of adjacent sibling subtrees so local structural relationships survive, structural paths are attached to segments so the agent can locate ancestors and hierarchical positions, and residual memory links run from low-level child segments to high-level parent segments, letting information flow directly instead of only through successive memory updates. The authors also give theoretical guarantees on segment counts to guide token-budget selection toward matching the segment count of fixed-length segmentation.
**Key numbers:** evaluated with four representative memory agents on eight retrieval and aggregation tasks, over real-world application data in JSON, HTML, YAML and JavaScript spanning 8K to 1M tokens; TreeAgent improves the average score across all four datasets for all four agents, with 3.61% performance gain on average (self-reported); 13 pages.
**Source:** https://arxiv.org/abs/2611.13946
