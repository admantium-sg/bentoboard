## New Findings Summary

### 1. Latent Reasoning Paradigm Debate

**LLM Reasoning Is Latent, Not the Chain of Thought** (arXiv:2604.15726, April 17, 2026)
- Position paper arguing reasoning is latent-state trajectory formation, not surface CoT
- Three hypotheses formalized: H1 (latent-state), H2 (surface CoT), H0 (serial compute)
- Evidence supports H1 as working hypothesis
- Key recommendations: Treat latent-state dynamics as default object of study; disentangle surface traces, latent states, and serial compute in evaluations

### 2. Efficiency Breakthroughs

**Abstract Chain-of-Thought** (arXiv:2604.22709, April 24, 2026)
- 11.6x fewer reasoning tokens vs standard CoT
- Reserved vocabulary tokens instead of natural language reasoning
- Policy iteration warm-up with self-distillation
- Emergent power law distribution over abstract vocabulary

**QeRL** (NVlabs, ICLR 2026)
- NVFP4 quantization + LoRA for RL acceleration
- Quantization noise increases policy entropy → better exploration
- Enables 32B LLMs to train on single GPUs via RL

**TurboQuant** (Google, ICLR 2026)
- 6x memory reduction for LLM inference
- 8x H100 attention speedup vs FP32
- KV cache compression to 3 bits with zero accuracy loss

### 3. Prompt Engineering Automation

**DSPy-Based Declarative Learning** (arXiv:2604.04869)
- Automated modular prompt optimization
- Combines symbolic planning + gradient-free optimization + automated module rewriting
- Reduces hallucinations, improves factual grounding

**TDD Governance for Multi-Agent Code Generation** (April 29, 2026)
- AI-native Test-Driven Development framework
- Classical TDD principles as prompt-level governance mechanisms

### 4. Test-Time Compute Evolution

**Scaling Test-time Compute for LLM Agents** (arXiv:2506.12928)
- First systematic exploration for language agents
- List-wise verification method performs best
- Extends TTS from pure reasoning to agent workflows

## Key Takeaways

1. **Latent vs Surface Reasoning:** Paradigm shift emerging - reasoning appears to happen in latent space, not in explicit CoT tokens
2. **Efficiency Gains:** Major compression advances (11.6x, 6x memory) making longer reasoning chains practical
3. **Agent Integration:** Test-time compute scaling now extending to multi-agent systems
4. **Automation:** Prompt engineering moving from art to automated optimization
