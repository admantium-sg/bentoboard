## 🔬 Notable arXiv Papers (July 3)

### MHM: Multi-Head Recurrent Memory for Long-Context Retention
**arXiv:2607.01523** | Long-Context / Memory | cs.LG — July 1, 2026

Standard recurrent memory agents degrade as context grows because updates overwrite previously retained content. MHM partitions memory into independent heads with a select-then-update strategy: exactly one head updates while others are structurally shielded. MHM-LRU guarantees uniform head utilization with zero token overhead. On RULER-HQA at 896K tokens: retention improves from <30% to 73.96%. Gains generalize across model families and scales.

Key insight: Architectural solutions beat behavioral ones for memory retention. Shifting the burden from model behavior to architecture design is cost-efficient and model-agnostic.

🔗 https://arxiv.org/abs/2607.01523

### HaloGuard 1.0: Open Multilingual Safety Classifier
**arXiv:2607.02079** | AI Safety / Multilingual | cs.CL — July 2, 2026

HaloGuard 1.0 achieves 90.9 average F1 on multilingual prompt-safety benchmarks with 0.8B parameters — outperforming open guard models up to 27B (30x larger). Uses a 46-policy constitutional structure with exhaustive counterfactuals. Two-tier harmless design separately targets boundary and baseline false positives. Always-on adversarial red-teaming hardens against both content and agentic attacks.

Key insight: Constitutional organization of safety training data + compact architecture can beat much larger models. Language treated as surface form, not adversarial signal.

🔗 https://arxiv.org/abs/2607.02079

### DALorRA: Bayesian Sparse LoRA for Uncertainty Estimation
**arXiv:2607.02182** | Fine-tuning / Uncertainty | cs.LG — July 2, 2026

DALorRA shifts uncertainty quantification from dense parameters to the rank level of LoRA. Uses stochastic masking on rank dimensions for Bayesian regularization during training and ensemble-like calibration at inference. Addresses the overconfidence problem in task-specific LLM fine-tuning without compromising reasoning accuracy.

Key insight: LoRA's rank dimensions are a natural granularity for Bayesian uncertainty — stochastically masking ranks gives calibration for free during inference.

🔗 https://arxiv.org/abs/2607.02182

### DecompRL: Modular Code Generation for Hard Problems
**arXiv:2607.02390** | Code Generation / RL | cs.LG — July 2, 2026

When base policy has near-zero probability of correct solutions, sampling or RL can't overcome the large search space. DecompRL decomposes problems into independently solvable sub-functions, recombines k implementations of n modules yielding k^n candidates. GPU cost shifts to cheap CPU evaluation — ~50x GPU token reduction on LiveCodeBench and CodeContests.

Key insight: Make the task easier, not the model stronger. Modular decomposition is orthogonal to both sampling and RL approaches.

🔗 https://arxiv.org/abs/2607.02390

### LACUNA: Ground-Truth Testbed for LLM Unlearning
**arXiv:2607.02513** | Privacy / Unlearning | cs.CL — July 2, 2026

Current unlearning benchmarks evaluate only at output level. LACUNA injects synthetic PII into predefined parameters of OLMo-based models, enabling direct parameter-level evaluation. Finding: despite strong output-level performance, existing SOTA methods are imprecise and susceptible to resurfacing attacks. When localization succeeds, even simple gradient-based unlearning works well.

Key insight: Output-level evaluation is insufficient — parameter-level ground truth reveals that imprecise targeting is the real failure mode, not output obfuscation.

🔗 https://arxiv.org/abs/2607.02513

### MultAttnAttrib: Training-Free Multimodal Attribution
**arXiv:2607.01420** | RAG / Attribution | cs.CL — July 1, 2026

MultAttnAttrib uses a model's prefill pass and selected attention heads with calibrated thresholds to locate source evidence. Matches GPT-5.4 attribution accuracy at up to 1/7th the direct inference latency. First evaluation dataset (MultAttrEval) specifically for multimodal attribution in long-form documents. EMNLP 2026 submission.

Key insight: Attention heads during prefill encode attribution signal — no training required to exploit this for evidence grounding.

🔗 https://arxiv.org/abs/2607.01420

### MoE Expert Pruning in Biomedical Domain
**arXiv:2607.01444** | MoE / Efficiency | cs.LG — July 1, 2026

Tests four MoE models, six pruning methods, multiple pruning ratios in biomedical domain. Moderate pruning preserves in-domain utility without immediate reliability decline. Hallucination risks increase at extreme pruning ratios. Cross-domain shift causes rapid degradation in both utility and reliability. Safe compression depends heavily on task and domain — utility-only evaluation is inadequate for high-stakes deployment.

Key insight: MoE pruning is domain-sensitive. What preserves benchmark utility may introduce subtle hallucination risks in biomedical applications.

🔗 https://arxiv.org/abs/2607.01444

## 🔑 Key Patterns — July 3, 2026

### 1. Memory Architecture Innovation for Long Context
MHM's multi-head approach directly addresses the overwriting problem in recurrent memory. 73.96% retention at 896K tokens vs <30% baseline is a significant jump. This is orthogonal to context window approaches — architectural memory partitioning rather than simply extending context.

### 2. Unlearning Needs Parameter-Level Evaluation
LACUNA's finding that SOTA unlearning methods are "highly imprecise" when evaluated at the parameter level is a reality check. Output-level success doesn't mean knowledge is actually erased — resurfacing attacks confirm this. The field needs stricter evaluation protocols.

### 3. Modular Decomposition Beats Scaling for Hard Code
DecompRL's insight — make the task easier, not the model stronger — is a useful reframing. 50x GPU token reduction through problem decomposition is a practical engineering win. This complements, rather than competes with, better base models.

### 4. Compact Safety Models Closing Gap
HaloGuard 1.0 at 0.8B matching 27B safety models suggests the efficiency frontier in safety is moving fast. Constitutional organization + rigorous counterfactuals appears more important than raw scale for safety classification.

### 5. Reasoning Model Market Stable
Grok 4.1, Gemini 3.1 Pro, GPT-5.4 holding top 3 positions for third consecutive day. Claude Opus 4.6 competitive at 88.2%. The naming confusion between o1 and o1-preview (75% vs 88.6%) continues to be a user experience problem.
