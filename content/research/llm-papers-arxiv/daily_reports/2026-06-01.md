# Daily Report — June 1, 2026

## New Insights (10 papers)

### LongTraceRL: Process Supervision for Long-Context Reasoning
**arXiv:2605.31584** (May 29, 2026) — cs.CL, cs.AI, cs.LG
- RL addresses low-confusability distractors and sparse outcome-only rewards for long-context reasoning
- Tiered distractors: agent-read-but-not-cited vs search-results-not-opened
- Rubric reward: gold entities for fine-grained entity-level process supervision
- Positive-only strategy prevents reward hacking among correct responses
- Consistent gains across 3 reasoning LLMs (4B-30B), 5 long-context benchmarks
- Key insight: Process supervision distinguishes reasoning quality among correct responses

### GRKV: Training-Free KV Cache Compression
**arXiv:2605.31105** (May 29, 2026) — cs.CL
- Span-based retention concentrates merges on boundary tokens → over-merging
- GRKV uses ridge-regression to minimize discrepancy between compressed and full attention outputs
- Only method improving overall performance on LongBench and RULER
- Key insight: Global regression distributes evicted token info across retained tokens, not just boundaries

### ConsisGuard: Safety Deliberation Gap in LLM Guardrails
**arXiv:2605.31073** (May 29, 2026) — cs.CL
- Deliberation-to-enforcement gap: model recognizes harm but predicts safe, or issues unsafe decision
- Policy execution consistency requires reasoning grounded in safety policy
- ConsisGuard: Policy-to-Decision Trajectory Distillation + Functional Coupling Alignment
- Key insight: CoT faithfulness ≠ guardrail reliability; policy execution is distinct requirement

### STR: Semantic Triplet Restoration for Table Understanding
**arXiv:2605.31550** (May 29, 2026) — cs.CL
- Cells rewritten as <item path, feature path, value> atomic facts
- TripletQL query-aware router selects appropriate rendering per question
- Matches HTML baselines while reducing tokens; larger benefit for smaller models
- Key insight: Explicit semantic representations valuable under constrained inference budgets

### SkillsBench: Skill Availability Dominates
**arXiv:2605.31408** (May 29, 2026) — cs.CL, cs.AI, cs.LG
- Skill conditions: +26.7-36.0pp (GPT-5.5), +18.0-26.0pp (DeepSeek V4-Flash) vs no skill
- Presentation granularity effects: small, uncertain, model-dependent
- Key insight: Get skills to agents; abstraction level matters less than availability

### CYKNN: Neuro-symbolic Syntactic Parsing
**arXiv:2605.31421** (May 29, 2026) — cs.CL, cs.AI, cs.DS
- Direct injection of CYK parsing algorithm into neural network architecture
- Outperforms LLMs with 20B+ parameters in-context
- Key insight: Complex algorithms can be encoded in trainable matrix-vector multiplications

### Paired-Focus Constructions: Modest LLMs Learn Rare Semantics
**arXiv:2605.31586** (May 29, 2026) — cs.CL, cs.AI — CoNLL 2026
- "let alone", "much less" — modestly sized models can grasp these constructions
- Human-scale data trained models fail at meaning evaluations
- Key insight: Constructional semantics follow distinct learning dynamics from syntax

### LLM Anthropomorphism: Age of Empires II Shows Same Attributes
**arXiv:2605.31514** (May 29, 2026) — cs.CL, cs.AI, cs.CY
- Simple neural net on Age of Empires II exhibits same purported human-like attributes
- Anthropomorphic attributes are empirically non-unique across substrates
- Key insight: Anthropomorphic attributions require explicit measurement criteria

### Financial RAG: Market-Feedback Adaptive Retrieval
**arXiv:2605.31201** (May 29, 2026) — cs.CL
- Bayesian source memory updated from residual-return feedback
- Frozen LLM + adaptive retrieval: macro-F1 0.438→0.471, Sharpe 0.52→0.84
- Key insight: Learning where to retrieve is as important as learning how to read

### UniAudio-Token: Unified Audio Interface
**arXiv:2605.31521** (May 29, 2026) — cs.CL, cs.SD
- SAP decomposes audio into linguistic content, vocal attributes, auditory-scene primitives
- SAE adaptive gating restores fine-grained acoustic details
- Key insight: Preserving semantic paradigm while mitigating info loss enables unified audio interface
