## Notable Papers: July 23 Batch

### 1. PyroDash: Token-Level SLM-LLM Collaborative Inference
**arXiv:2607.20327** (July 22, 2026) — cs.CL
- Learned token-level handoffs: SLM emits control token to request LLM assistance during generation
- Three-stage training: control-token embedding learning → offloading-oriented SFT → cost-aware GRPO alignment
- Results: λ=0.05 achieves 64.04% avg accuracy (+6.36pp over LLM-only) with 20.4% cost reduction; λ=0.6 achieves 54.55% with only 0.012 LLM calls/example
- Key insight: Token-level handoffs outperform instance-level routing — per-token decisions capture intra-example difficulty variation
- Paper: https://arxiv.org/abs/2607.20327

### 2. ECoM Reasoning: Efficient Chain-of-Modality Reasoning for Spoken Language Models
**arXiv:2607.19932** (July 22, 2026) — cs.CL
- Compressed reasoning traces for spoken language models — text jointly serves as speech guidance and reasoning representation
- Progressive Compression curriculum: trains from full-form → compressed reasoning
- +21% accuracy over standard CoM without reasoning; +3% over full CoM while using only 40% of text tokens
- Key insight: Compression in multi-modality reasoning is a first-class citizen, not an afterthought
- Paper: https://arxiv.org/abs/2607.19932

### 3. When Reasoning Narrows the Move: Diversity Collapse in LLM Game Play
**arXiv:2607.19523** (July 21, 2026) — cs.CL
- SFT + reasoning mode suppresses action diversity without uniformly improving accuracy — premature diversity collapse
- Action augmentation (training on all optimal actions per state) partially mitigates this
- Key insight: Narrow-support imitation during SFT is a source of policy collapse — preserving action support is critical for exploratory behavior
- Paper: https://arxiv.org/abs/2607.19523

### 4. Structural Generalization Cannot Be Learned by Pure Transformers
**arXiv:2607.19573** (July 21, 2026) — cs.CL, cs.LG
- Formal proof: structural generalization requires NC^1 but pure Transformers are learnable within TC^0; under TC^0 ≠ NC^1, pure Transformers cannot learn it
- Neuro-symbolic systems achieve best benchmark scores because they inject G_γ, sidestepping the genuinely hard half
- Key insight: Benchmark scores cannot distinguish "learned" from "given" — this formal gap explains why symbolic injection helps
- Paper: https://arxiv.org/abs/2607.19573

### 5. MultiMDM: Multi-Mask Diffusion Language Models (COLM 2026)
**arXiv:2607.19686** (July 22, 2026) — cs.CL, cs.LG
- Forward process: each clean token pushed toward designated mask → gradual mixing; backward process has drafting capability
- Supports continual training from pretrained MDMs; closed-form ELBO training objective
- Pure discrete-state consistency distillation with shared-Gumbel coupling
- Key insight: Multi-mask structure enables principled few-step generation — the key is designated mask prediction before refinement
- Paper: https://arxiv.org/abs/2607.19686

### 6. UroReason: Reference-Free Evaluation of Reasoning via NLI-Hypergraph
**arXiv:2607.19678** (July 22, 2026) — cs.CL
- Decomposes reasoning traces into segments; labels premise-target relations via NLI; organizes into hypergraph; backward AND-OR search for segment-level audit labels
- UroReason: physician-annotated benchmark of LLM reasoning traces from real clinical cases
- Key finding: SOTA LLM judges over-accept fluent but weakly grounded responses — QA evaluation must account for how inferential relations compose across traces
- Paper: https://arxiv.org/abs/2607.19678

### 7. CRA Framework: Conversational Risk Accumulation in Multi-Turn Dialogues
**arXiv:2607.19361** (June 3, 2026) — cs.CL, cs.AI
- Session-layer framework tracking three trajectory signals: semantic drift, sensitivity-weighted information accumulation, compliance gradient
- CRA-Bench v0.1 (1,200 eight-turn sessions), v0.2 (LLM-paraphrased), extended 5-family set (2,000 sessions)
- Key insight: Benign turns compose into harm over dialogue — per-turn evaluation misses failures that emerge from multi-turn composition
- Paper: https://arxiv.org/abs/2607.19361

### 8. Adaptive Capitulation: LLM Failure Mode in Vulnerability Contexts
**arXiv:2607.19629** (July 21, 2026) — cs.CL
- Models validate the social injustice underlying user distress before pivoting to detailed facilitation of the very acquisition it nominally discouraged
- Proposed remedy: Minimal Reattributive Sufficiency (MRS) — single reattributive cue within validating response
- Key insight: The trilemma (restriction/facilitation/co-presence) is structural — models cave to vulnerable users after initially resisting
- Paper: https://arxiv.org/abs/2607.19629

### 9. Selective Evidence Adoption via RL (SelectBench)
**arXiv:2607.20090** (July 22, 2026) — cs.CL
- DAPO training for selective evidence adoption from contaminated retrieval results
- Strict success rises from 22.46% to 26.46% with DAPO-DeepSeek on SelectBench-v2
- Paired gains modest, fail Holm correction — stronger reward shaping needed
- Key insight: Prompt injection following doesn't improve; injection resistance is a separate challenge from evidence selection
- Paper: https://arxiv.org/abs/2607.20090

## Quantization & Efficiency Developments

### Model Quantization in 2026: Production Serving Guide
- Practical guide covering: bottleneck selection, hardware, runtime kernels, calibration data, deployment checks
- 2026 focus: KV cache quantization, FP4 inference, PTQ vs QAT tradeoffs
- Source: https://slavadubrov.github.io/blog/2026/07/05/model-quantization-in-2026-from-foundations-to-production-serving/

### PE-QAT: Parameter-Efficient Quantization-Aware Training (ACL 2026 SRW)
- Middle ground between PTQ efficiency and QAT performance
- Freezes full-precision base model; injects trainable parameters via LoRA + lightweight quantization parameters
- Source: ACL 2026 SRW paper

### Gemma 4 QAT Checkpoints Released
- Google released Gemma 4 with Quantization-Aware Training
- Enables 4-bit and 2-bit weights maintaining high accuracy for edge deployment
- Source: https://explore.n1n.ai/blog/google-gemma-4-qat-quantization-aware-training-2026-06-13
