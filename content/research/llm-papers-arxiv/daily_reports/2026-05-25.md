## New Findings (May 25)

### LINK: Lexical Interventions for Multilingual Knowledge Transfer
**arXiv:2605.23885** (May 22, 2026) — cs.CL
- Data-level intervention using bilingual vocabularies for lexical substitutions during pretraining
- Up to 2x speedup in training to reach equivalent performance for low-resource languages
- Key insight: Lexical substitution at data level outperforms model-level interventions

### OnePred: Next-Query Prediction via Recursive Intent Memory
**arXiv:2605.23668** (May 22, 2026) — cs.CL, cs.AI
- 22x reduction in per-turn token consumption while exceeding all baselines
- Intent trajectory tracking (not raw history) sufficient for next-query prediction
- Key insight: Bounded per-turn cost independent of conversation length

### SkillOpt: Self-Evolving Agent Skills
**arXiv:2605.23904** (May 25, 2026) — cs.AI
- First systematic controllable text-space optimizer for agent skills
- Zero inference-time model calls at deployment
- Key insight: Frozen agent + trained skill optimizer enables reproducible improvement

### SpaceNum: VLM Spatial Numerical Understanding
**arXiv:2605.23898** (May 22, 2026) — cs.AI
- VLMs largely fail to ground numbers in spatial meaning; perform close to random
- Explicit reasoning provides only marginal gains
- Key insight: VLMs lack genuine spatial-numerical grounding

### EDGE-OPD: Evidence Guided On-Policy Distillation
**arXiv:2605.23493** (May 22, 2026) — cs.AI
- Guided rollouts + evidence mask solves OPSD's failure to learn target identity
- Key insight: Localized evidence masking preserves general capabilities while enabling targeted transfer

### EPC-AW: Epistemic Planning Calibration
**arXiv:2605.23414** (May 22, 2026) — cs.AI
- Multi-agent systems fail due to epistemic miscalibration, not just execution errors
- Improves system-level success by 9.75% average
- Key insight: Epistemic calibration is distinct from execution correctness

### ASAM: Adversarial Multimodal Knowledge Editing
**arXiv:2605.23780** (May 22, 2026) — cs.AI
- Addresses generalization failure across semantic variations in multimodal editing
- Key insight: Adversarial semantic supervision bridges the generalization gap
