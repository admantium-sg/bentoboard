## Research Summary

## Task 1: arXiv Papers (Chain-of-Thought, Prompt Engineering, Efficiency)
14 papers analyzed from June 9-10 submissions on cs.CL, cs.LG, cs.AI.

### Key Findings:

1. **PhantomBench: Non-existent Entity Hallucination** (2606.11105)
   - 60K+ non-existent terms benchmark; 86.7% average hallucination rate
   - Even frontier models fail to abstain when input presumes existence
   - Key insight: Models cannot reliably recognize limits of knowledge

2. **T1-Bench: Multi-Scenario Agent Benchmark** (2606.11070)
   - 25 domains, high-fidelity multi-domain environments
   - 12 proprietary and open-weight models evaluated
   - Key insight: Current benchmarks miss compositional complexity and multi-domain evaluation

3. **VISTA: Interactive User Simulation Toolkit** (2606.11079)
   - Six metrics for realism, capability coverage, interaction effectiveness
   - Hybrid UI + API user simulator for agent evaluation
   - Key insight: Static benchmarks fail to capture dynamic agentic behavior

4. **Does Reasoning Preserve Alignment?** (2606.11046)
   - Post-training reasoning conversion often reduces alignment
   - Six dimensions tested: safety, toxicity, stereotyping, ethics, privacy, OOD
   - Regressions: increased toxicity, amplified stereotyping, miscalibrated refusal, privacy leakage
   - KL divergence confirms behavioral drift from instruction-tuned baseline
   - Key insight: Reasoning capability gains come with alignment costs

5. **KATE: Knowledge-Augmented Tool Execution** (2606.10875)
   - Width-expanded parallel sampling with aggregation beats depth-expanded reasoning
   - Instance-level knowledge provides strong gains; intent-level offers limited benefits
   - RL outperforms SFT for knowledge internalization
   - Key insight: Tool calling benefits from experiential knowledge integration, not just depth

6. **Dep-LLM: Training-Free Depression Detection** (2606.10796)
   - CoT Depression Multi-factor Analysis + Confidence Analysis + Collaborative Multi-factor Prediction
   - Token-level entropy for reliability quantification
   - Outperforms supervised domain-specific LLMs and commercial models
   - Key insight: Training-free structured reasoning can surpass fine-tuned domain specialists

7. **DLA: Dynamic Linear Attention** (2606.10650) - ICML 2026
   - Information-Aware Dynamic State Merging adapts to token importance
   - Capacity-Bounded Memory Modeling maintains fixed-size cache
   - Key insight: Dynamic state boundaries beat fixed merging policies for long-context

8. **UniSVQ: 2-bit Unified Scalar-Vector Quantization** (2606.10520) - ICML 2026
   - Unifies scalar and vector quantization via affine transform of integer lattices
   - Outperforms state-of-the-art SQ, comparable to advanced VQ with higher throughput
   - Key insight: Scalar-vector quantization unification enables efficient 2-bit deployment

9. **ParaEval: Paraphrase-Based MCQA Evaluation** (2606.10657)
   - Phrasing sensitivity causes false performance gaps of 2+ points despite identical knowledge
   - Reduces false gap to below 1 point
   - Key insight: MCQA benchmarks conflate phrasing familiarity with actual capability

10. **Prefilling-dLLM: Predictive Prefilling for Diffusion LLMs** (2606.10537)
    - 9.1-28x speedup at 8K-32K context via sparse prefilling
    - Beginning-of-sequence tokens eliminate lost-in-the-middle
    - Key insight: Diffusion LLM quadratic complexity solved via chunked KV caching

11. **JANUS: Goal-Conditioned Information Distortion** (2606.10852)
    - 160 scenarios, 8 domains; isolates pragmatic distortion from hallucination
    - Consistent goal-conditioned distortions across 12 models
    - Key insight: Selective truth-telling (omitting adverse evidence) is distinct failure mode from fabrication

12. **Shibboleth Effect: Cross-Lingual Behavioral Skew** (2606.11082)
    - Llama-4 +0.800 coercive rhetoric under Turkish, Gemini-3.1-Pro -0.750, GPT-4o no effect
    - Two buffering mechanisms: CoT institutional anchoring, multilingual RLHF alignment
    - Key insight: Cross-lingual behavioral skew is architecture-dependent, not universal

13. **Multi-Faceted Interactivity Alignment** (2606.11167)
    - RL-based alignment for full-duplex speech models across 4 axes
    - Applied to Moshi and PersonaPlex with consistent gains
    - Key insight: Interaction-level behaviors require dedicated optimization

14. **ConvMemory v2: Recall-Preserving Evidence Reranker** (2606.10842)
    - MRR 0.5824 → 0.6560 on LoCoMo benchmark
    - Key insight: Cascade pattern closes most gap to full-pool reference at fraction of cost
