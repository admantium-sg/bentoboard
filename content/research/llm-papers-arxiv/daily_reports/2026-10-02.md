## New Insights

### KaliBench: Cybersecurity CLI Tool Use — Open-Weight Models Below 42%
**arXiv:2610.02206** (Oct 1, 2026) — cs.CL, cs.AI, cs.CR | NeurIPS 2026

- KaliBench: 8,504 query-command pairs spanning 1,642 Kali Linux tools across 23 capability dimensions and 5 security phases
- Multi-stage verification: LLM validation + sandboxed terminal execution + human-in-the-loop refinement
- Key finding: **no open-weight model exceeds 42% exact-command accuracy** in unrestricted setting — CLI cybersecurity tool use is far harder than benchmarks suggest
- SFT + RL with verifiable rewards derived from KaliBench improves an 8B model to performance comparable with a 685B MoE model
- Key insight: cybersecurity CLI commands have razor-thin error margins — benchmark leniency masks a massive practical gap
- Paper: https://arxiv.org/abs/2610.02206

### HC-DLM: Hierarchical Continuous Diffusion Language Models
**arXiv:2610.02193** (Oct 1, 2026) — cs.CL, cs.AI, cs.LG

- Discrete diffusion models: each token decoded independently from its marginal — severs statistical dependencies among tokens decoded together
- Continuous diffusion models: denoiser sees only the continuous state — nothing ties output to valid token config until final decode
- HC-DLM: tokens read out at every step and feed back as scaffold for next latent update — latent is the only persistent generative state
- On Sudoku, Countdown, and LM1B: improves over both discrete and continuous diffusion baselines at matched model size
- Key insight: coupling continuous latent trajectories with discrete token generation bridges the best of both paradigms
- Paper: https://arxiv.org/abs/2610.02193

### AutoCompact: Learning When to Compact Context in Long-Horizon Coding Agents
**arXiv:2610.02163** (Oct 1, 2026) — cs.CL

- AutoCompact trains coding agents to decide when to compact, what to preserve, and how to continue — as part of its policy
- Judge reviews compaction decisions, summaries, and actions after compaction; flawed outputs replaced with corrected ones before execution
- SFT + RL jointly optimizes coding and compaction with task-success rewards
- Results: +9.2% absolute pass rate on SWE-bench Verified, +5.0% on SWE-PolyBench Verified
- Works across all evaluated inference budgets; 256K context window that never overflows vs 16K with fallback compaction
- Key insight: context management is an learnable decision, not a fixed heuristic — agents can learn to compact proactively
- Paper: https://arxiv.org/abs/2610.02163

### SourceLearn: From Knowledge Access to Source-Specific Competence
**arXiv:2610.02150** (Oct 1, 2026) — cs.CL, cs.AI, cs.LG

- LLM agents repeatedly access the same sources but treat each access as isolated — source learning studies developing reusable source-specific competence
- Persistent source model captures reusable understanding: how knowledge is structured, interpreted, and applied
- Self-Directed Source Learning: adaptively revisits source for what remains incompletely understood
- Task-Guided Source Learning: downstream experience reveals local representational gaps and recurring needs
- Results: best performance in 13/15 settings; gains up to 22.6 points over Hybrid RAG
- Key insight: source understanding should compound over repeated access — not just retrieval, but learning
- Paper: https://arxiv.org/abs/2610.02150

### Keyword Harnesses Fail Open: Tool-Use Diagnostics for Small Language Models
**arXiv:2610.02142** (Oct 1, 2026) — cs.CL

- Keyword-matching benchmarks credit small models for tool use they never perform — false positives from lenient harness design
- Matched-architecture pair (661M vs 1,109M): score almost identically on lenient metrics (B4: 0.660 vs 0.650) but 600M emits valid calls on 6/6 examples vs 1B at 0/6
- Root cause in 1B: missing prior on <|tool_call|> token (prob 10^-4 to 10^-5) — erased by web-heavy training phase
- Targeted SFT recipe (diverse corpus, 5x higher LR, ~3.3 GPU-hours) repairs the 1B: valid emission 0.100→0.959
- 97.7% of bf16 embedding table remains bit-identical after repair — changes live in surrounding network, not the trigger token
- Key insight: tool-use capability in small models is fragile and easily suppressed — cheap diagnostic ladders should gate capability claims
- Paper: https://arxiv.org/abs/2610.02142

### Argo-Bench: Enterprise Data Agents on 7.5B-Row ERP Warehouse
**arXiv:2610.02122** (Oct 1, 2026) — cs.CL, cs.AI, cs.DB

- Real enterprise data science: reasoning across dozens of tables, performing statistical analyses, acting on results — not just text-to-SQL generation
- Simulates food delivery platform in NYC with 81M orders in 2024, grounded economics, fraud patterns — exported to ERP warehouse of 235 tables and 7.5B rows
- Simulator ground-truth withheld from agent — tasks require reconstructing facts by navigating the warehouse before acting
- Agents take consequential actions: banning fraudulent accounts, allocating courier budgets, issuing back pay — graded by consequences in simulator
- Strongest of 14 frontier and open-weight models: scores 95+ on only 34.8% of tasks; averages 59.5 points
- Key insight: enterprise data agent benchmarks require full consequential action evaluation, not just query generation — the gap to useful agents remains enormous
- Paper: https://arxiv.org/abs/2610.02122

### VISTA: Visual Harness Achieves 100% on ARC-AGI-3
**arXiv:2610.02200** (Oct 1, 2026) — cs.AI, cs.CV

- VISTA: visual harness giving multimodal models long-horizon vision through direct environment perception + lossless visual memory
- Model actively retrieves and reorganizes visual observations as it reasons
- On ARC-AGI-3: Claude Opus 5.0 improves from 40.68 to 100.00 relative human action efficiency — completes all 25 public games using 57.4% fewer actions than first-time human participants
- Key insight: appropriate harness design unlocks reasoning potential already present in multimodal models — not a capability limit, a harness limit
- Paper: https://arxiv.org/abs/2610.02200

### TESS: Transferable Meta-Network for Data Selection
**arXiv:2610.02092** (Oct 1, 2026) — cs.CL, cs.AI, cs.LG

- Meta-learning for Training-data Selection (MTS): learns data weights from target validation objective
- Existing methods trade off fine-grained valuation vs transferability to unseen data
- Replacing per-sample weights with selection network causes unstable optimization: weight suppression + reliance on easy-to-learn features
- TESS: Pointwise Value Matching (PVM) objective resolves optimization issues
- Strong transfer across datasets, from subsets to full corpora, from smaller to larger models
- Key insight: the obvious approach to meta-learning for data selection fails structurally — loss function design is the unlock
- Paper: https://arxiv.org/abs/2610.02092

### LLM2Jev: LLMs as Jev-Style Decision Models
**arXiv:2610.02076** (Oct 1, 2026) — cs.CL

- Jev-style decision models: return categorical distributions over predefined options without free-form text — software can act on outputs directly
- LLM2Jev: extracts calibrated decisions from next-token probabilities over bracketed numeric identifiers
- Without training: Qwen3.5-4B matches community Jev-style models on same backbone, outperforms letter-logit readouts, supports arbitrary option counts, handles multimodal decisions
- Fine-tuning provides targeted benefits — substantially improves weaker models, diminishing returns for strong backbones
- KL anchors prevent behavioral degradation in conversational text generation; LoRA delivers strongest performance on capable models
- Key insight: modern LLMs already are decision models out of the box — architecture-preserving extraction is the recipe
- Paper: https://arxiv.org/abs/2610.02076
