## Task 1: arXiv Papers (Chain-of-Thought, Prompt Engineering, Efficiency)
10 papers analyzed from June 8 submissions on cs.CL, cs.AI, cs.LG.

### Key Findings:

1. **IS-CoT for Long-Form Generation**: Interleaved Structural Chain-of-Thought (IS-CoT) embeds dynamic Plan-Write-Reflect cycles into generation, addressing length collapse beyond 2,000 words. IS-Writer-8B achieves +3.08 vs DeepSeek-V3.2 on LongBench-Write. (2606.09709)

2. **PsychoSafe Refusal Framework**: Psychologically-informed refusals (crisis, coercion contexts) improve quality28.1% over generic baseline. Resource referral +46.8%, psychological grounding +34.8%. Refusal quality is a learnable skill distinct from safety alignment. (2606.09697)

3. **GGRO Inference Alignment**: Gradient-Guided Reward Optimization monitors token-level entropy to detect drift/misalignment, then injects nudging tokens via reward model gradients. More efficient than sampling-intensive Best-of-N search. Accepted to UAI 2026. (2606.09635)

4. **RLHF Shallow Alignment**: RLHF compresses partisan signal variance to generate balanced output but does NOT remove underlying partisan geometry. Neutrality is functional, not structural — bypass mechanisms reactivate partisan generation. (2606.09735)

5. **Built-in Thinking: Constraint Asymmetry**: Qwen3 thinking mode improves Planning constraints (global counting, structure) but consistently worsens Precision constraints (exact local form). 10-20% of prompts switch pass/fail across modes. Execution gap explains why trace relevance doesn't always translate to compliance. (2606.09662)

6. **AgentServeSim**: Hardware-aware simulator for multi-turn LLM agent serving. Reproduces real-system behavior within 6% error, runs on commodity CPUs. First simulator to model tool-induced gaps and KV cache residency during tool calls. (2606.09613)

7. **SIGA Scientific Simulation**: Self-evolving coding agent adapter for GEOS simulator. 36x wall-clock speedup vs 3-hour human expert. Self-evolution rewrites adapter from prior trajectories. Lightweight grounding layers unlock general coding agents for specialized software. (2606.09774)

8. **SearchSwarm-30B-A3B**: Delegation intelligence model for long-horizon deep research. 68.1 on BrowseComp, 73.3 on BrowseComp-ZH — best among comparable scale. Delegation intelligence is learnable and distinct from general agentic behavior. (2606.09730)

9. **CHAP Protocol**: Collaborative Human-Agent Protocol adds structured human-agent collaboration layer to MCP + A2A. Override becomes structured event with diff/rationale/hash. Human approval becomes non-repudiable signed decision. (2606.09751)

10. **Causal Learnability Evaluation**: Using formal languages as controlled testbed reveals correlational evaluation is fundamentally flawed for determining data requirements. Causal analysis via binning semiring exposes confounders invisible to standard benchmarks. (2606.09822)
