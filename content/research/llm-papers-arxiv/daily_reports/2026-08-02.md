## Key Findings (9 new papers + community)

### 1. ReToken: VLM Visual Retrieval with One Learnable Token
**arXiv:2607.28627** (July 30, 2026) — cs.CV, cs.AI, cs.LG
- Single learnable embedding selects query-relevant visual tokens from pre-filled KV cache
- On Visual Haystacks: +13.4 pts Qwen3VL-8B, +12.4 pts InternVL3.5 (>20% relative)
- On LVBench zero-shot to long video: +8.0 pts with Qwen3VL-8B
- Lightweight design fits on single H100 for training and long-video inference
- Key insight: Retrieval target can be a single learned token — sparse selection from KV cache beats dense processing
- Paper: https://arxiv.org/abs/2607.28627

### 2. Lossy Verification in Speculative Decoding: Failure Modes
**arXiv:2607.26627** (July 28, 2026) — cs.LG
- Systematic analysis of lossy verification schemes in speculative decoding
- Two categories: truncation-based verification and collaborative verification
- Truncation-based methods can degrade severely vs. truncation sampling baseline due to distributional distortion
- Collaborative verification requires controlling draft-probability overshoot vs. target probabilities
- Key insight: Many lossy verification approaches silently rewrite the decoding distribution — "acceleration at the cost of generation quality"
- Paper: https://arxiv.org/abs/2607.26627

### 3. Harness-G: Graph-Structured Retrieval for Search Agents
**arXiv:2607.27652** (July 30, 2026) — cs.CL
- Solves retrieval-equivalence collapse: queries differ but evidence sets overlap in Search-R1 training
- Reformulates free-form query generation as finite action selection (evidence sentence/entity/answer)
- Structured Non-myopic Credit (SNC) assigns downstream gains to earlier enabling actions
- Across 6 QA benchmarks: +10.74 pts at 1.5B, +3.98 pts at 3B vs. Graph-R1
- Key insight: Graph-structured interface eliminates linguistic aliasing — same-state alternatives become directly comparable
- Paper: https://arxiv.org/abs/2607.27652

### 4. OmniScope: Modality-Decoupled Token Compression for Omnimodal LLMs
**arXiv:2607.23193** (July 27 v2, 2026) — cs.CV
- Audio and video relevance peak at different moments — unidirectional guidance loses answer-critical cues
- Uses query as shared semantic anchor; estimates relevance separately per modality
- At 25% token retention: 3.53x prefill speedup, >15% GPU memory reduction, 0.35-pt accuracy drop
- Key insight: Share the query across modalities, but NOT the salience estimates
- Paper: https://arxiv.org/abs/2607.23193

### 5. Is Deep Research Reliable? Misleading Knowledge Induces False Conclusions
**arXiv:2607.20891** (July 30 v2, 2026) — cs.AI
- MisKnow-Agent: 5,933 misleading documents with controllable authority and style
- One misleading doc increases false-conclusion adoption rate (FCAR) from 0% to 54.7%
- Cross-model verification identifies retained instances as misleading — but agents adopt them anyway during research
- Pre/post-research defenses mitigate but don't eliminate false conclusion adoption
- Key insight: Disconnect between focused verification and workflow-level evidence use — continuous verification needed at intermediate states
- Paper: https://arxiv.org/abs/2607.20891

### 6. CoT-Enabled Cybersecurity Triage: +43% Benign Recall
**arXiv:2607.28460** (July 30, 2026) — cs.LG, cs.CR
- Chain-of-thought reasoning for Windows endpoint detection triage
- CoT reasoning degrades label-token probabilities — trains separate calibrator reading full reasoning trace
- At high-confidence operating point: +43.0% benign recall, +18.3% malicious recall vs. direct-label LLM
- Fine-tuned 30B significantly outperforms frontier general-purpose models — targeted training > scale
- Key insight: CoT reasoning and probability calibration require separate training pipelines
- Paper: https://arxiv.org/abs/2607.28460

### 7. GUI Agents Correct But Late: Decision-Time Critical Path
**arXiv:2607.28399** (July 30, 2026) — cs.LG
- Computer-use agents fail when correct action comes after relevant window closes
- Root cause: expensive autoregressive decoding on the decision-time critical path
- AAPT (Adaptive Anticipatory Policy Trees): pre-compiles bounded conditional policy tree during idle screen periods
- Within contested decision window: success rate 0.50 → 0.79 (p=1.8e-3); both baselines achieve zero
- Key insight: Agents need to "think while the world moves" — pre-compilation of action trees during idle periods
- Paper: https://arxiv.org/abs/2607.28399

### 8. β-OPSD: Controllable On-Policy Self-Distillation for Reasoning
**arXiv:2607.28582** (July 30, 2026) — cs.LG
- Vanilla OPSD is β=1 member of policy-optimization family — β weights KL penalty anchoring to reference policy
- β controls trade-off between proximity to reference policy vs. privileged teacher guidance
- Return-to-go credit assignment aligns token updates with sequence-level objective
- Consistent improvement over vanilla OPSD on mathematical reasoning benchmarks
- Key insight: β transforms OPSD from implicit to controllable regularization — geometry of reference-to-teacher path
- Paper: https://arxiv.org/abs/2607.28582

### 9. KAISEN: Subgroup Fairness Auditing for Clinical Risk Models
**arXiv:2607.28608** (July 30, 2026) — cs.LG, q-bio.QM
- 5-phase audit pipeline: subgroup stratification, disparity measurement, mechanism diagnostics, post-hoc mitigation, drift monitoring
- Per-group threshold optimization reduces EOD in 48/48 held-out runs (delta=-0.285)
- Group-wise Platt scaling behaves as a coin flip on EOD (19/48 improved) — audit should report variance, not average
- Mechanism diagnostic classifies 144/144 controlled cases but 0/48 model-driven cases under proxy misspecification
- Key insight: Clinical fairness audits transfer poorly across cohorts — threshold tuned on one cohort fails on another
- Paper: https://arxiv.org/abs/2607.28608
