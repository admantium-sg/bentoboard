## Papers Found (Sep 29-30 submissions)

**10 new papers identified across quantization, long-context efficiency, memory optimization, evidence-gated reasoning, and evaluation methodology:**

1. **STEPQuant: 5x Recurrent-State Compression via Spatial-Temporal PTQ** (2609.38169, cs.CL) — Delta-rule recurrent state quantization accounting for temporal error persistence and spatial error variation. Allocates precision based on error magnitude and memory lifetime, jointly fits key-row and value-column scales. Achieves 68.7% total serving memory reduction at 6-bit quantization matching FP32 accuracy for Qwen3.8-27B and Kimi-Linear-48B. Key insight: uniform quantization wastes precision on transient states — spatial-temporal awareness is critical for recurrent compression.
Source: https://arxiv.org/abs/2609.38169

2. **LongHarness Bench: Efficiency as Critical Axis for Long-Context Evaluation** (2609.38137, cs.CL) — Existing long-context evaluations insufficient for distinguishing modern harnesses. Same model shows markedly different efficiency under different harnesses. Best model-harness reaches only 68% macro-average accuracy. Strategic processing (deciding what to attend to) vs exhaustive processing produces different accuracy-cost tradeoffs. Key insight: efficiency evaluation is as important as accuracy — same model can be fast-but-wrong or slow-but-right.
Source: https://arxiv.org/abs/2609.38137

3. **SYNTH: Fully Synthetic Single-Stage Recipe — 10-140x Fewer Tokens** (2609.37891, cs.CL, NeurIPS 2026) — First open-source synthetic corpus from 58,698 Wikipedia articles that collapses pre-, mid-, and post-training into single training stage. 10-140x fewer training tokens than filtered web data while achieving high factual precision. Back-translated from grounded passages; memorization targeted by seed corpus. Key insight: synthetic data from grounded seeds can replace massive web data — major training efficiency breakthrough.
Source: https://arxiv.org/abs/2609.37891

4. **SCSP: Semantic Compression for Training-Free Long-Context Embeddings** (2609.37782, cs.CL) — Mean pooling dilutes salient semantic information with redundant content. SCSP uses semantic compression prompts + prompt-isolated attention masks to estimate token importance without training. Plug-and-play improvement across zero-shot and fine-tuned models. Key insight: not all tokens matter equally — semantic compression enables training-free long-context improvements.
Source: https://arxiv.org/abs/2609.37782

5. **MGPO: Memory Gain Policy Optimization — 80% Memory Reduction** (2609.37930, cs.CL, cs.LG) — Isolates incremental value of each memory rewrite by crediting marginal contribution to future downstream utility. Improves extraction while reducing average memory length by nearly 80%. Learned memory policy supports reuse and transfer across domains without further training. Key insight: memory optimization requires looking forward — credit assignment to future utility is key.
Source: https://arxiv.org/abs/2609.37930

6. **MERA: Missing-Evidence Retrieval Augmentation** (2609.37443, cs.CL, cs.AI) — Evidence for answers may be scattered across distant turns while question omits locating clues. MERA separates globally searchable memory from question-specific evidence state. Trained 0.6B planner exceeds 30B planner by 4.10% on LoCoMo. Later retrieval rounds increase cumulative evidence recall from 55.5% to 80.5%. Key insight: evidence-guided retrieval without restricting global memory access enables better long-term memory QA.
Source: https://arxiv.org/abs/2609.37443

7. **RBA: Regime Boundary Alignment for Evidence-Gated Abstention** (2609.37491, cs.CL, cs.AI) — RAG models answer 100% even when evidence is missing. RBA trains on both sides of the support boundary. Reduces unsupported-answer rate by more than 60 percentage points while matching supported accuracy. On held-out retrieval-miss slice: reduces unsupported answering from 100% to below 1%. Key insight: abstaining requires positive training signal, not just absence of evidence.
Source: https://arxiv.org/abs/2609.37491

8. **RINSE: Relevance Is Not Sufficient Evidence** (2609.37469, cs.CL, cs.IR, cs.LG) — Retrieved passages often name right entities without providing facts needed to answer. RINSE combines three sufficiency signals. Achieves 0.837 ranking score (chance 0.5) vs best prior method at 0.746. Runs locally before generation in 36.5 ms per question. Key insight: sufficiency can be judged before generation — relevance ≠ sufficiency is core RAG failure mode.
Source: https://arxiv.org/abs/2609.37469

9. **SemOPT: Fixing Semantic Errors in LLM-based Optimization Modeling** (2609.37361, cs.CL, EMNLP 2026 Findings) — Semantic errors: solver code returns objective value but violates original problem intent. SemOPT combines semantic reward model + hierarchical reward-guided search. 7.6% average accuracy improvement over strongest baseline on complex datasets. Key insight: semantic correctness requires reward-guided search, not just syntax validation.
Source: https://arxiv.org/abs/2609.37361

10. **Evaluating Jev: Choice-Based Model Beats Large Generative Models** (2609.37647, cs.CL) — Jev System One model returns choices/rubric positions/probabilities instead of generating text. Beats Qwen3.8-27B on 27 of 37 datasets; Gemma-4-E4B on all 37. 95-99% accuracy on IMDB, SST-2, HellaSwag, ARC; 86.7% on Belebele across 122 languages. Key insight: choice-based models can outperform large generative models on classification — efficiency via specialization.
Source: https://arxiv.org/abs/2609.37647

## Community Pulse

**Working well:** Quantization advances are accelerating. STEPQuant achieves 5x compression on linear attention recurrent states by understanding that uniform quantization fails — temporal persistence and spatial variation require different precision allocation. This could significantly reduce serving costs for long-context models.

**Problems:** The evidence-sufficiency problem in RAG remains unsolved at scale. Even frontier models answer 40-99% of insufficient-evidence questions when instructed to abstain. RBA and RINSE propose complementary solutions, but neither is deployed by major RAG frameworks yet.

**Interesting:** Choice-based models like Jev beating large generative models on 27/37 benchmarks suggests a hidden efficiency frontier. If classification and routing tasks don't need generation, specialized choice models could replace general models at a fraction of the cost.
