## Papers Found (Sep 18 submissions, first checked today)

**4 new papers identified across chain-of-thought, prompt engineering, and efficiency:**

1. **LogicTrack** (2609.21492) — Neuro-symbolic CoT auditing framework. Auto-formalizes reasoning steps into symbolic representations and verifies with automated theorem provers. Solver-Based Backtracking Reward guides inference-time tree search. 56% hallucination reduction under conflicting memories via zero-parameter MDL memory decision layer.

2. **RecreationWorld** (2609.22000) — Hybrid computer-use agents across Ubuntu, macOS, Windows, Android, Web. Given a running reference, agent must discover behavior and build faithful implementation with no prescribed workflow. GPT-6 Astra leads at 58.1% overall but only 2.8% pass all programmatic tests.

3. **MDL Memory Decision Layer** (2609.22043) — Zero-parameter controller between retrieval and generation for RAG. Three-signal complementary encoder (relevance, reliability, task risk). 56% hallucination reduction under conflicting memories; approaches zero in high-risk scenarios. 0.14ms per decision, 50x faster than embedding retrieval.

4. **QuranicMMLU** (2609.22038) — Quranic Arabic linguistic knowledge benchmark. 980 questions across Phonology, Morphology, Syntax, Semantics, Pragmatics. All systems score higher on multiple-choice (84%) than open-ended (60%) — hidden failures.
