## Task 1: arXiv Papers (cs.CL, cs.LG, cs.AI)

### New Papers from May 18, 2026 (80 submissions)

#### Argus: Evidence Assembly for Scalable Deep Research Agents
**arXiv:2605.16217** (May 15, 2026)
- Searcher + Navigator cooperative agent system treating deep research as jigsaw puzzle, not parallel brute-force
- Navigator maintains shared evidence graph, dispatches Searchers to fill gaps, synthesizes source-traced answers
- RL-trained Navigator supports rollouts with 1-64 parallel Searchers without retraining
- 35B-A3B MoE backbone; +5.5pp with 1 Searcher, +12.7pp with 8 parallel Searchers (avg over 8 benchmarks)
- 64 Searchers reach 86.2 on BrowseComp, surpassing all proprietary agents tested
- Navigator reasoning context stays under 21.5K tokens despite parallel search
- Key insight: Cooperative evidence assembly outperforms parallel rollouts that duplicate rather than complete

#### Block Attention Generalization via SemanticSeg + Block Distillation
**arXiv:2605.15913** (May 15, 2026)
- Addresses two block attention challenges: semantic segmentation and block fine-tuning efficiency
- SemanticSeg dataset: 30K+ instances across 16 categories, text lengths 2K-32K
- Lightweight segmenter automatically partitions text into human-instinct-aligned blocks with controllable granularity
- Block distillation: frozen full-attention teacher guides block-attention student via block sink tokens, block dropout, token-level loss weighting
- Achieves near-full-attention performance under block attention — practical pathway for KV cache reuse in RAG

#### Artificial Aphasias in Lesioned Language Models
**arXiv:2605.16222** (May 15, 2026)
- Applies clinical aphasia lesion method to 112,426 outputs from five 1B-scale LMs
- Full range of aphasia symptoms surface, but in distributions distinct from humans
- Attention components (Q,K,V,O) vs feed-forward components (up, gate, down) show different symptom profiles
- Depth effect: early-layer lesions → syntactic/semantic symptoms; late-middle layers → phonological/fluency deficits
- Key insight: Aphasia syndromes heavily influenced by learning/processing details, not domain-invariant consequence of disrupted language

#### Tuning-Free Fair Generation via DebiasRAG
**arXiv:2605.16113** (May 15, 2026)
- Retrieval-augmented debiasing without fine-tuning or prompt engineering
- Three-stage: query-specific debiasing candidate generation → context pool construction → gradient-updated reranking
- Self-diagnosis of bias contexts via regular retrieval; reversed debiasing contexts as fairness constraints
- Preserves intrinsic LLM capabilities while improving fairness across race, gender, age dimensions

#### LLM-Driven Data Augmentation for Cognitive Score Prediction
**arXiv:2605.16077** (May 15, 2026)
- GPT-5 augmentation for Japanese cognitive screening (Hasegawa Dementia Scale)
- Similarity-guided class-balanced selection outperforms random selection
- Substantially reduces prediction error for minority low-score participants
- Demonstrates semantic-guided LLM augmentation for clinical speech analysis class imbalance
