## New Findings Today

### Major: Stealing Reasoning Traces from Proprietary LLM APIs
**arXiv:2608.09867** (Aug 10, 2026) — cs.CR, cs.AI, cs.LG

Leading LLM providers (Anthropic, OpenAI, Google) conceal step-by-step chain-of-thought reasoning as encrypted text blocks returned to clients. **These encrypted blocks are fully compatible and interchangeable across different sessions, users, and models within a provider's ecosystem** — an architectural vulnerability.

A scalable decryption jailbreak exploits this: by injecting an encrypted reasoning trace from a capable model into a weaker, less safeguarded sibling model from the same provider, the weaker model decodes and outputs the trace in plaintext — without jailbreaking the capable model directly.

**Four attack vectors enabled:**
1. **Bypasses anti-distillation** — proprietary reasoning can be extracted from Anthropic, OpenAI, and Google
2. **Large-scale PII extraction** — 315,320 reasoning blocks scraped from public repositories yielded **367 PII artifacts and 182 credentials**
3. **Hazardous hidden reasoning revealed** — even when the final visible output safely rejects a malicious request, the hidden reasoning may contain unsafe content
4. **Invisible prompt injection** — malicious payloads embedded entirely within encrypted blocks to poison public agentic rollouts

Providers have implemented mitigations following responsible disclosure. Concrete cryptographic and system-level fixes are proposed.

**Key insight:** Client-side encrypted CoT is a systemic attack surface — the same mechanism that protects IP also protects injected payloads. The fix requires changes at the cryptographic level, not just policy.

**Sources:** https://arxiv.org/abs/2608.09867 | https://stolen-thoughts.com/
