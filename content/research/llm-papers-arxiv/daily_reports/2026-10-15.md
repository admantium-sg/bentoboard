## New Findings

### Cortex: Consolidating Context into Parametric Memory
**arXiv:2610.20399** (Oct 14, 2026) — cs.CL, cs.AI, cs.CV, cs.LG, cs.MA
- Memory Consolidation (MC): internalizing context-induced gains while preserving non-target capabilities — connects context-specified editing, skill learning, and behavioral steering
- Generates prospective queries to anticipate uses of context; distills context-conditioned outputs into mergeable low-rank or structural FFN updates
- Across 4B–120B dense and MoE backbones: lies on the empirical consolidation–retention Pareto frontier in most settings
- After 50 sequential factual edits on 14B model: recovers 88.9% of context-induced gain while retaining 99.8% of original non-target performance
- Key insight: treating memory consolidation as a first-class objective with prospective query generation enables persistent parametric gains from temporary context
- Paper: https://arxiv.org/abs/2610.20399

### VASPO: Value-Augmented Self-Distillation Policy Optimization for Math Reasoning
**arXiv:2610.20516** (Oct 14, 2026) — cs.CL, cs.AI, cs.LG
- On-policy self-distillation provides dense supervision but reflects local token preferences, not expected return
- VASPO: self-teacher + critic evaluate identical privileged information at student-generated prefixes; critic computes PPO advantages, self-teacher modulates selected positive advantages via bounded probability ratios
- Across 6 mathematical reasoning benchmarks: +2.59pp on Qwen3-4B and +1.81pp on OLMo3-7B over PPO; highest mean accuracy on Knights and Knaves
- Key insight: positional dynamics complementarity — privileged info enhances critic accuracy toward response end, self-teacher strong initially then drops mid-generation then rebounds
- Code: https://github.com/cii030/VASPO
- Paper: https://arxiv.org/abs/2610.20516

### COUNT: N-gram Count Embeddings on Host Memory — 57% Compute Equivalent Improvement
**arXiv:2610.20456** (Oct 14, 2026) — cs.CL, cs.LG
- Existing n-gram methods train embeddings from scratch — expensive GPU memory needed
- COUNT: builds n-gram embeddings WITHOUT adding learned parameters; stores precomputed n-gram counts on host memory, uses corpus frequencies to weight LM's own next-token predictions
- At fixed compute budget: adding COUNT gives 1B-parameter LMs improvement equivalent to 57% more compute
- At limited GPU memory: COUNT lets backbone fill GPU memory — better performance than splitting with learned embeddings
- Key additional benefit: swaps in domain-specific n-gram count table at inference for training-free adaptation
- Key insight: host memory is cheap and underutilized — precomputed n-gram counts without gradient updates enable efficient compute-memory tradeoffs
- Paper: https://arxiv.org/abs/2610.20456

### MMLA-RSI: Recursive Self-Improvement via Reasoning-Time Training and Memory Adaptation
**arXiv:2610.20294** (Oct 14, 2026) — cs.CL, cs.LG
- MMLA-RSI: Memory-Mediated Learning Architecture with two recursive routes — RTT changes policy state, RTMA changes authoritative memory
- RTT: trains the policy proposing its successor; RTMA: memory manager chooses records available to the process proposing its successor
- Four-candidate program selection: retaining LARC feedback updates reduces expected error by 24.65pp and 36.65pp for two initializations
- In chronological CI replay: feedback binding is positive while retention increases loss
- Key insight: both routes make their own adaptation method an object of improvement — successors take over the same role in the next generation
- Paper: https://arxiv.org/abs/2610.20294

### GURI: Gray-Box Hallucination Detection with Token Identities
**arXiv:2610.19996** (Oct 14, 2026) — cs.CL
- Problem: gray-box detectors use only probability-derived representations — observe HOW uncertain but not WHAT the model is uncertain about
- GURI: combines candidate-token probabilities with per-token vector identifiers — exposes which alternatives the model considered
- Across 3 open-weight models and 3 QA benchmarks: mean ROC-AUC from 72.09% to 79.09% over probability-only baseline
- On GPT-4.1 (closed-source): mean ROC-AUC from 67.39% to 71.84%
- 17 of 18 directed cross-model transfers without fine-tuning: GURI outperforms transferred probability-only baseline
- Cross-dataset transfer (HotpotQA ↔ TriviaQA): mean ROC-AUC improvement of 3.76pp over transferred LOS-Net
- Key insight: token identity matters for uncertainty representation — "what the model is uncertain about" is as important as "how uncertain"
- Paper: https://arxiv.org/abs/2610.19996

## Trend Analysis

October 15 sees a notable split: FMRT is undergoing a significant recalibration with most models now "provisional" status — a methodological shift that dramatically reshapes the leaderboard picture. BenchLM remains frozen, with the top 10 completely unchanged from yesterday, suggesting structural stability on the benchmark side. On the research side, memory consolidation is emerging as a distinct thread — Cortex's approach of internalizing context into mergeable parametric updates (88.9% retention after 50 edits) addresses a fundamental problem: making temporary context gains permanent. COUNT similarly exploits cheap host memory via precomputed n-gram counts for training-free domain adaptation. Both point toward a broader theme: efficient use of memory hierarchies rather than always scaling compute.
