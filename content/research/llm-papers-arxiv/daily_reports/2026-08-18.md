## New Findings (Aug 17–18)

### 1. Computational Provenance: Detecting Internal Causal State from Generated Text
**arXiv:2608.16868** (Aug 17, 2026) — cs.CL, cs.AI
- Studies whether generated text carries detectable evidence of which causally relevant internal state occurred during inference
- Trains both FFNN and transformer on arithmetic tasks with mandatory pathway through two discrete intermediate states — same answer, different internal path
- Passed all 128 matched-pair tests in both public and sealed protected evaluations; reproduced across 5 independently trained FFNNs and 3 transformers
- Linear probes on naturally learned intermediate states in answer-only setting did NOT recover the signal — detection requires controlled setup
- **Key insight:** Verified internal computation can leave detectable statistical traces in output text even when the answer is unchanged — opens doors for interpretability via output analysis
- **Paper:** https://arxiv.org/abs/2608.16868

### 2. Semantic Bandits: Exploration-Exploitation Biased by Semantic Priors
**arXiv:2608.16707** (Aug 17, 2026) — cs.CL, cs.AI
- Extends multi-armed bandit to explicitly model textual action labels; studies how semantic priors (from pretraining word co-occurrence) shape LLM exploration behavior
- Semantically informative action labels reduce exploration in favor of exploitation — improves when aligned with reward, severely degrades when misaligned
- Negative rewards trigger substantially more exploration than equivalent positive rewards (expected-scale bias from RLHF/pretraining reward conventions)
- **Key insight:** Language-based task descriptions introduce unavoidable biases from pretraining co-occurrence statistics — critical for deploying LLM agents in real decision-making settings
- **Paper:** https://arxiv.org/abs/2608.16707

### 3. ClawGym II: Black-Box RL on Agent Harnesses
**arXiv:2608.16798** (Aug 17, 2026) — cs.CL, cs.AI, cs.LG
- Unified black-box RL framework for stable, scalable optimization of agents through complex harnesses (SWE-bench, Claude Code, JobBench, OfficeQA)
- Sandbox-based execution infrastructure isolates task environments; decouples policy optimization from opaque harness execution
- Prefix-tree organization of captured model calls enables GRPO/PPO over recovered tree structure; supports mix-harness training
- With Qwen3-30A3B: +9.98 Pass@1 via OpenClaw harness, +14.81 via Claude Code harness; stable over 200–400 optimization steps
- **Key insight:** Black-box RL through agent harnesses is viable and stable — models can be optimized via harness feedback without accessing internal rewards
- **Paper:** https://arxiv.org/abs/2608.16798

### 4. PAS: Monotonic Bidirectional Control of LLM Sycophancy
**arXiv:2608.16650** (Aug 17, 2026) — cs.CL
- PCA-guided Activation Scaling decomposes residual stream into sycophancy-honesty subspace (via PCA) and orthogonal residual; applies distinct scaling exponents for monotonic bidirectional control
- Strong monotonicity: Spearman ρ = +0.92; average 15.4% shift per direction vs 8.7% for baselines
- Ablations confirm decomposition, asymmetric exponents, and layer selection each essential
- **Key insight:** Sycophancy control is achievable with monotonic, gradual effect in both directions — requires asymmetric treatment of steering vectors, not just magnitude scaling
- **Paper:** https://arxiv.org/abs/2608.16650

### 5. OPD Transfers Reasoning Behavior, Not Answers
**arXiv:2608.16647** (Aug 17, 2026) — cs.CL
- Controlled study of on-policy distillation: OPD transfers the teacher's reasoning behavior rather than its answers to particular problems
- Training difficulty barely matters — even problems the teacher never solves are useful for transfer
- Same-origin teacher-student pairs: student reaches teacher performance across languages, reasoning horizons, domains
- Cross-origin pairs: mostly fit trained distribution — combining multiple cross-origin teachers creates mixture-dependent capability seesaw
- **Key insight:** OPD generalization depends on origin relationship; reasoning behavior (not answer content) is what's transferred — has implications for multi-teacher OPD design
- **Paper:** https://arxiv.org/abs/2608.16647

### 6. STAIR: Semantic-Temporal Automaton for Interpretable Temporal Reasoning
**arXiv:2608.16224** (Aug 16, 2026) — cs.CL, cs.AI
- Separates semantic interpretation from precise temporal inference: LLM adapter maps questions to normalized temporal intents; deterministic finite automaton executes policies over canonicalized evidence
- Rule-first design resolves standard questions without invoking LLM; semantic adaptation only when rule path fails
- Guarded execution for point-time containment and before/after selection; semantic adaptation for non-exact intervals and time-anchored queries
- Average F1 improvements: +16.57% (Qwen2.5-7B), +3.10% (GPT-4o-mini) across TimeQA, TempReason-L2/L3
- **Key insight:** Discrete temporal automata can replace probabilistic LLM inference for interpretable, verifiable temporal reasoning — reduces free-form reasoning where rules suffice
- **Paper:** https://arxiv.org/abs/2608.16224

### 7. Bengali Headline Generation: Prompting Strategy > Input Length
**arXiv:2608.15879** (Aug 16, 2026) — cs.CL
- Full article does not improve headline quality; selected lead paragraphs match or exceed full context
- Cross-Lingual Prompting (XLP) yields stronger performance than Bengali Native Prompting (BNaP), especially with contextual enrichment — but model-dependent
- Few-shot substantially improves Gemini; most gain from single demonstration; Llama shows limited benefit from additional examples
- **Key insight:** For document summarization, context relevance and prompt design matter more than input length — has practical implications for low-resource multilingual LLM applications
- **Paper:** https://arxiv.org/abs/2608.15879

### 8. BabelSteering: Multilingual Safety via English Steering Vectors
**arXiv:2608.16577** (Aug 17, 2026) — cs.CL
- Activation steering using refusal directions derived from English safety supervision to generalize across languages
- Gemma 7B: average +11pp refusal of harmful prompts across 8 languages, +17pp for Bengali; no loss on Global MMLU; pseudo-harmful refusals +13pp average
- Inference-time intervention, no retraining, lightweight
- **Key insight:** English-derived safety signals can transfer to other languages via activation steering — practical low-cost mechanism for extending safety guardrails cross-lingually
- **Paper:** https://arxiv.org/abs/2608.16577

### 9. Wiola 13M: Gated Spiral Attention for Parameter-Efficient Small LLMs
**arXiv:2608.14604** (Aug 13, 2026) — cs.CL, cs.AI
- Three drop-in components for the small-scale regime: Spiral Rotary Positional Encoding (improves long-range discrimination, no parameters), Gated Spiral Attention (content-adaptive per-head scalar gate), Butterfly FFN block (multiplicative interaction + bypass path)
- Proves exact equivalence between full-sequence training and cached autoregressive decoding for gated attention — no approximation at inference
- **Key insight:** Small models (10–100M params) should not reuse standard transformer blocks without adaptation — architectural innovations at small scale can match parameter counts while improving capability
- **Paper:** https://arxiv.org/abs/2608.14604

### 10. Decoding Methods Survey: Taxonomy of Inference-Time Approaches
**arXiv:2608.14797** (Aug 14, 2026) — cs.CL | ACM SIGKDD Explorations Newsletter
- Systematic survey of inference-time decoding methods: token-level selection guidance, sequence-level generation control, parallel decoding for acceleration
- Three emerging paradigms identified; comprehensive review with challenge analysis and future directions
- Resource list: https://github.com/wang2226/Awesome-LLM-Decoding
- **Key insight:** Inference-time decoding offers efficiency and controllability without training — increasingly important for LVLMs and resource-constrained deployment
- **Paper:** https://arxiv.org/abs/2608.14797

### 11. LM Head Not a Harmful Bottlenleck After All
**arXiv:2608.16671** (Aug 17, 2026) — cs.CL
- Separates geometric claim (severe projection from D→V) from causal claim (harmful optimization bottleneck)
- Backward-only intervention (reducing gradient rank into transformer while keeping LM head unchanged) increases validation loss — geometric compression confirmed but not harmful
- Factorized forward head increases loss more than backward-only rank reduction — vocabulary-space residual is load-bearing
- **Key insight:** Strong geometric compression exists but the "harmful bottleneck" claim is not supported — LM head projection is not the optimization bottleneck prior work suggested
- **Paper:** https://arxiv.org/abs/2608.16671

### 12. QUMem: Query-Conditioned User-State Inference for LLM Agents
**arXiv:2608.16168** (Aug 17, 2026) — cs.CL, cs.AI
- Structured memory framework: segments interaction histories into episodes, decomposes into factual/preference/insight memories (independently retrievable), plans multi-query retrieval, infers temporally/contextually valid user state
- State-of-the-art on PersonaMem and KnowU-Bench
- **Key insight:** User preference information should be decomposed and independently retrievable — mixing related items from same interaction into one memory unit hurts downstream personalization
- **Paper:** https://arxiv.org/abs/2608.16168

### 13. PLSQLBench: Executable Procedural Database Programming Benchmark
**arXiv:2608.15931** (Aug 16, 2026) — cs.CL
- 2,865 instances (2,594 single-turn, 271 multi-turn conversations, 978 turns); PL/SQL execution-based correctness
- Recurring difficulties: schema grounding, dialect fidelity, procedural control flow, exception handling, cross-turn consistency
- Tool-augmented agents improve schema-grounded evaluations but substantial gaps remain
- **Key insight:** Existing benchmarks miss procedural database programming — LlMs can write general code but struggle with PL/SQL-specific patterns and enterprise database constraints
- **Paper:** https://arxiv.org/abs/2608.15931
