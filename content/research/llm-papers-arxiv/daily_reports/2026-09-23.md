# Daily Report — 2026-09-23
**Topic:** llm-papers-arxiv | LLM research papers and developments

## Papers Found (Sep 22 submissions, first checked today)

**6 new papers identified across chain-of-thought, efficiency, and multi-agent reasoning:**

1. **Flash-dLLM** (2609.26796, cs.CL) — I/O-aware KV caching and parallel decoding for Diffusion LLMs. Training-free inference acceleration framework using fused KV-cache kernel addressing I/O bottlenecks. Achieves 5.1x speedup on GSM8K and 11x on HumanEval vs prior best Elastic-Cache. Unified draft-and-verify decoding without auxiliary model. Submitted Sep 22.
Source: https://arxiv.org/abs/2609.26796

2. **Agensh** (2609.26781, cs.CL) — Scaling organizational intelligence to 1,024 agents. Self-organized multi-agent harness without central orchestrator. Concurrent workers execute cooperation loop: gather context, claim sub-tasks, action, verify, merge. On pandoc: scaling 1→1,024 agents raises test-pass from 33.9%→55.1%. On ProgramBench (hardest 5): 1→128 agents raises pass rate 19.3%→28.8%. Reveals agent count as new scaling dimension. Submitted Sep 22.
Source: https://arxiv.org/abs/2609.26781

3. **SpeakerMem-R1** (2609.26780, cs.CL, cs.AI, cs.IR, cs.LG) — Speaker-centered dual-track memory for multi-party dialogue. Dual-track stores speaker-labeled verbatim messages AND derived states at person/group level. Writer-R1 trained with SpeakerLevenshtein and speaker-conditioned GRPO. Achieves 62.33% on EverMemBench leaderboard (best reported). On LoCoMo: 70.85% across 1,986 questions. RL raises mean accuracy 57.4%→68.2%. Submitted Sep 22.
Source: https://arxiv.org/abs/2609.26780

4. **GravityOCR** (2609.26638, cs.CL, cs.CV) — Diffusion drafts + AR verification for document OCR. AR-block-diffusion model jointly trained for parallel drafting and causal verification. GRPO with sequence/structure-level rewards. On OmniDocBench: AR-path GRPO improves score 94.92→95.16. SGLang serving: 9.7 tokens/forward pass, 3.94x decode speedup on region crops, 1.32x end-to-end page processing. Submitted Sep 22.
Source: https://arxiv.org/abs/2609.26638

5. **Capable yet Parsimonious: Hidden CoT in Frontier Models** (2609.26637, cs.CL, cs.AI, cs.CR) — Extracts hidden chain-of-thought from closed-source frontier models via custom tool API. Extracted reasoning matches native CoT and outperforms no-reasoning baselines across competition math, science, code. Key finding: GPT-6 Astra exhibits token-efficient directed reasoning — selects correct trajectory earlier, resolves elementary steps internally, externalizes only crucial reasoning. Provides behavioral lens on frontier reasoning beyond benchmarks. Submitted Sep 22.
Source: https://arxiv.org/abs/2609.26637

6. **Receptiveness vs Sycophancy** (2609.26579, cs.CL, cs.AI, cs.HC) — Social sycophancy markers (validation, positivity) overlap with conversational receptiveness from social psychology. Responses classified as more sycophantic are also more receptive. Preregistered experiment: participants prefer more receptive responses even among substantively equivalent answers. Demonstrates that conversational receptiveness and substantive independence can be achieved together. Submitted Sep 22.
Source: https://arxiv.org/abs/2609.26579

## Community Pulse

**Working well:** Agensh shows that agent count is a viable scaling dimension — reaching 1,024 agents on a single task with proportional quality gains. Significant for complex coding/problem-solving under time constraints.

**Interesting:** GravityOCR + Flash-dLLM represent two parallel efficiency threads — document OCR acceleration and diffusion LLM inference. Both use draft-and-verify or KV-cache structures but applied to different generation paradigms.

**Notable:** SpeakerMem-R1's dual-track memory (verbatim + structured state) directly addresses the multi-party attribution problem that generic memory systems fail on. The RL training boost (+11pp) for writer specialization is substantial.

**GPT-6 Astra CoT insight:** The hidden CoT extraction paper reveals Astra resolves elementary steps internally — the "parsimonious reasoning" pattern means token efficiency in CoT correlates with reasoning quality. Less externalized reasoning ≠ less reasoning.
