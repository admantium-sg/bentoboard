## New Findings

### Papers from July 9 Submissions

1. **DominoTree (2607.08642)** — Training-free speculative decoding combining block-diffusion with best-first tree expansion. Domino's path-dependent correction enables up to 6.6x speedup over autoregressive decoding on Qwen3-4B. Key insight: path-dependent correction bridges the gap between block-diffusion and tree verification methods.

2. **MAESTRO (2607.08601)** — MoE pruning via Markov-chain modeling of expert activation trajectories. 10.61% performance retention improvement at 50% compression. Key insight: local importance heuristics miss interdependent routing; global routing-aware modeling is essential.

3. **LLM-as-Judge Reliability (2607.08535)** — Judge upgrades are not interchangeable; stronger judges reduce but don't remove bias. Scalar F1 obscures directional bias that RL would reinforce. Key insight: judge reports need bias probes, dataset slices, and audit trails.

4. **UniClawBench (2607.08768)** — First capability-driven benchmark for proactive agents. 400 tasks across 5 capabilities, live Docker evaluation, closed-loop multi-agent feedback. Key insight: capability-driven taxonomy disentangles model capabilities from framework design.

5. **WebSwarm (2607.08662)** — Recursive multi-agent orchestration for web search. Nodes can delegate to child nodes; evidence flows upward for expansion/revision. Outperforms single and parallel multi-agent baselines. Key insight: recursive depth + evidence-grounding + collaboration = the three missing pieces.

6. **UltraX (2607.08646)** — Pre-training data refinement with insertion + deletion + modification operations. Dataset-adaptive prompts + program supervision. Key insight: three-operation editing space more expressive than two; insertion enables synthesis.

7-9. **Cross-seed SAE, AMALIA validity, Citation verifier** — Interpretability (SAE cross-seed alignment), sovereign LLM annotation validity auditing, and RL reward calibration for citation verification.
