## 🔬 arXiv Papers (June 23)

### BabelJudge: LLM-as-Judge Reliability Across Languages
**arXiv:2606.22329** | Benchmark | cs.CL

LLM-as-a-judge has become dominant for scalable evaluation, yet judges carry systematic biases that raw accuracy hides: position bias, verbosity bias, order inconsistency, and cross-lingual degradation.

BabelJudge is an open-source benchmark measuring all four failure modes without requiring human preference labels. Gold-labelling by degradation: controlled perturbations applied to high-quality reference responses create pairwise items with known gold labels by construction.

Evaluated Qwen2.5-7B-Instruct-4bit across English, Hindi, Arabic, and Swahili. Composite bias-penalized reliability drops from 0.714 (Hindi) to 0.550 (Swahili). Raw accuracy masks this gap: 0.835 vs 0.660. Swahili order consistency collapses to 0.480 — near-random.

**Key insight:** Raw LLM-as-judge accuracy numbers are misleading without bias-penalized scoring. Cross-lingual reliability degrades dramatically in lower-resource languages, and the gap is hidden by aggregate accuracy metrics.

🔗 https://arxiv.org/abs/2606.22329

### Knowledge Distillation in Post-Training: When It Helps and When It Fails
**arXiv:2606.22942** | Efficiency | cs.CL

First systematic study of KD in post-training using large-scale Tulu 3 dataset. Key findings: KD outperforms SFT in low-data regimes, but the advantage diminishes with more training data. Distilling from a stronger instruction-tuned teacher restores substantial gains even with abundant data. KD remains effective when the teacher provides knowledge the student cannot easily acquire from training data alone.

Proposed two-stage KD strategy: synthetic teacher-labeled data followed by refinement on human annotations. Consistently effective across domain-specific, low-resource scenarios.

**Key insight:** Post-training KD is not universally beneficial. The teacher's value is in providing genuinely novel instruction-tuning signal — the distillation must transfer knowledge the student couldn't learn from data alone. Simple model size reduction via KD fails when data is abundant.

🔗 https://arxiv.org/abs/2606.22942

### VeriBound: PAC-Bayesian Bounds for Process Reward Models with Formal Verification
**arXiv:2606.20740** | Theory | cs.LG

Process Reward Models (PRMs) trained with formal verification tools (FOVER approach) show cross-task generalization from symbolic tasks to diverse reasoning benchmarks, but no theoretical explanation existed.

VeriBound provides PAC-Bayesian generalization bounds for such PRMs with four results: (i) PAC-Bayesian generalization bound relating empirical verification error to expected error on unseen tasks, (ii) sample complexity bound, (iii) convergence rate, (iv) downstream Best-of-K performance bound.

**Key insight:** Formal verification tools (Z3, Isabelle) can provide theoretically grounded training signals for PRMs, with PAC-Bayesian guarantees of cross-task generalization. This bridges the gap between symbolic reasoning (where formal verification works) and natural language reasoning (where we need PRMs).

🔗 https://arxiv.org/abs/2606.20740

### TriggerBench: Prospective Memory Benchmark for LLMs
**arXiv:2606.23459** | Evaluation | cs.AI

LLMs are increasingly deployed in long interactions, yet existing evaluations focus exclusively on retrospective memory (RM) via explicit queries. Prospective memory (PM) — the ability to spontaneously recall and act on latent constraints without direct prompts — remains unevaluated.

TriggerBench spans 5 dimensions across daily assistant and professional workflow settings. Pairs scenarios with matched RM controls, contrastive positive/negative variants, and overloaded triggers. Measures proactive recall, false-alarm rate, and attentional robustness.

**Key insight:** PM is fundamentally different from RM and is a critical unevaluated gap for LLM agents in long-horizon tasks. An agent that can answer "what should I remember to do?" when asked is different from one that proactively acts on unprompted constraints.

🔗 https://arxiv.org/abs/2606.23459

### GDP-RAG: Grounded Delta Planning for Multi-hop RAG
**arXiv:2606.22681** | RAG | cs.CL

Multi-hop QA remains challenging for RAG: iterative retrieval propagates errors, and over-generated reasoning steps increase cost without improving accuracy.

GDP-RAG targets only the information delta via three design choices: (1) preliminary retrieval to ground planning before execution, (2) gap-conditioned planning prompting only for missing information, (3) skeletal trajectory pairing each subquery with evidence from preliminary retrieval.

**Key insight:** Not all missing information requires full retrieval rounds. Identifying the specific "delta" of what's unknown enables more efficient multi-hop retrieval with fewer wasted steps.

🔗 https://arxiv.org/abs/2606.22681

### Text2DSL: Context-Aware Distillation for DSL Code Generation
**arXiv:2606.22578** | Code Generation | cs.CL

Text2DSL automatic generation of DSL code from natural language. Prior work used prompt-only synthetic generation. New approach: context-aware distillation where teacher LLM operates under structured context (BNF grammar, API specification, closed identifier vocabulary). Two-tier verification: AST validation + runtime acceptance through production polkitd daemon. PolkitBench corpus scaled from 4,204 to 10,000+ verified examples.

**Key insight:** Structured context (formal specifications) as distillation signal is far more effective than free-form prompt-only generation for DSL code synthesis.

🔗 https://arxiv.org/abs/2606.22578

## 🔍 Key Pattern: Benchmark Saturation vs. New Frontiers

Two distinct regimes are emerging in LLM benchmarks: (1) saturation — AIME, FrontierMath Tier 1-3, PhD science all at 90%+, meaning these tasks are effectively "solved" for deployment purposes, and (2) new frontiers being carved out — HLE (46%), METR time horizons (measuring economic value not capability), agentic terminal tasks, and meta-learning (WeirdML) where frontier models still have significant headroom. The field is running out of "easy" benchmark problems faster than expected but discovering new dimensions of difficulty.
