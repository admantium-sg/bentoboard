## New arXiv Papers (May 15 Submissions)

### 1. Grep vs Vector Retrieval for Agentic Search
**arXiv:2605.15184** (May 14, 2026)
- Empirical study comparing grep and vector retrieval on agentic search systems
- Across Chronos, Claude Code, Codex, and Gemini CLI: grep generally yields higher accuracy than vector retrieval
- Tool output presentation (inline vs file-based) impacts performance
- Key finding: Simple grep can outperform semantic vector retrieval for agent harnesses; overall scores depend strongly on harness choice

### 2. Clinical Timeline Reconstruction via Multimodal Alignment
**arXiv:2605.15168** (May 14, 2026)
- Graph-based multimodal framework bridges clinical narratives and structured EHR data
- Timeline reconstruction: anchor events from text → place non-central events → calibrate with EHR temporal evidence
- 34.8% of text-derived events are entirely absent from tabular records
- Key insight: Aligning modalities produces more temporally faithful clinical reconstruction than either source alone

### 3. Audio-Based Tool Calling Evaluation Framework
**arXiv:2605.15104** (May 14, 2026)
- Dataset-agnostic framework converts text benchmarks to audio via TTS with speaker variation and noise
- 7 omni-modal models evaluated on audio-converted Confetti and When2Call
- Gemini-3.1-Flash-Live highest Confetti score (70.4); GPT-Realtime-1.5 best on When2Call (71.9)
- Text-to-voice gap: 1.8 points (Qwen3-Omni) to 4.8 points (GPT-Realtime-1.5)
- Open-source Qwen3 judges (8B+) exceed 80% agreement with proprietary judges

### 4. LLM Strategic Behavior Under Observation
**arXiv:2605.15034** (May 14, 2026)
- LLMs exhibit systematic linguistic adaptation when "watched" (Hawthorne Effect)
- Monitored conditions: +24.9% TTR change; automated AI monitoring: +22.2%; audience-framing: +17.7%
- Human evaluation elicits stronger register formalization than automated AI surveillance
- 100 multi-agent debate sessions across 5 conditions (n=20 each)
- Key insight: LLMs are contextually sensitive communicative actors; observer identity matters

### 5. GranuRAG: Element-Level Multimodal RAG
**arXiv:2605.15019** (May 14, 2026)
- GranuVistaVQA benchmark: real-world landmarks with element-level annotations
- GranuRAG: element-level detection → multi-granularity cross-modal alignment → attribution-constrained generation
- Up to 29.2% improvement over six strong baselines
- Key innovation: Grounding retrieval at element level enables transparent error diagnosis

### 6. Tensor Similarity for Mechanistic Interpretability
**arXiv:2605.15183** (May 14, 2026)
- Weight-based metric invariant to weight-space symmetries (rotation, scaling)
- Captures global functional equivalence; accounts for cross-layer mechanisms
- Tracks functional training dynamics (grokking, backdoor insertion) with higher fidelity than existing metrics
- Reduces similarity verification to algebraic problem vs empirical approximation
- Code: github.com/tdooms/tensor-similarity

### 7. SDAR: Self-Distilled Agentic Reinforcement Learning
**arXiv:2605.15155** (May 14, 2026)
- Treats On-Policy Self-Distillation (OPSD) as gated auxiliary objective with RL as primary backbone
- Sigmoid gate strengthens distillation on teacher-endorsed positive-gap tokens; attenuates negative rejections
- Results on Qwen2.5/Qwen3 families across ALFWorld, WebShop, Search-QA:
  - +9.4% on ALFWorld, +7.0% on Search-QA, +10.2% on WebShop-Acc
- Avoids naive GRPO+OPSD instability; consistently outperforms hybrid baselines

### 8. VPD: Variational Policy Distillation
**arXiv:2605.15113** (May 14, 2026)
- Formalizes learning from language feedback as Variational EM problem
- E-step: teacher refined on trajectory outcomes via adaptive trust-region update
- M-step: student internalizes distributional guidance on own on-policy rollouts
- Co-evolving teacher overcomes passive distillation limitations
- Outperforms standard RLVR and existing self-distillation baselines on scientific reasoning and code generation

## Community & Benchmark Updates (May 1-13, 2026)

### SubQ 1M-Preview: First Commercial Subquadratic LLM
- First commercially available LLM with non-transformer architecture
- Sparse, subquadratic attention: O(n²) → O(n log n) or better
- Native 12 million token context window
- ~1/5 cost of frontier models on long-context workloads
- $29M seed funding; API + SubQ Code product
- Vendor claims 52x faster attention at scale (awaiting independent verification)
- Key question: Does it hold on MRCR, RULER against GPT-5.5 or Opus 4.7?

### GPT-5.5 Instant: New ChatGPT Default
- OpenAI made GPT-5.5 Instant the default across free and paid tiers (May 5)
- Replaces GPT-5.3 Instant; shows up as chat-latest in API
- Headline: faster responses, fewer hallucinations in high-stakes domains (law, medicine, finance)
- No claims about higher reasoning scores
- Key insight: Default model swap affects hundreds of millions of users; "fewer wrong answers in regulated domains" as competition differentiator

### ZAYA1-8B: AMD-Trained Open-Weight MoE
- Released May 6 under Apache 2.0
- 8B total params; ~760M active per token via MoE routing
- First reasoning-oriented open release trained end-to-end on AMD Instinct hardware
- Reports competing with much larger open-weight models on reasoning, math, coding
- If verified: strongest cost-per-token open option in small-MoE band
- Available on Hugging Face and Zyphra Cloud (free serverless endpoint)

### Quantization Benchmark Update (Presenc.ai, 2026)
- **Q4 (4-bit):** Practical production sweet spot; 1-3% perplexity degradation vs FP16
- **AWQ > GPTQ:** Activation-aware scaling gives AWQ 0.5-1.0% lower perplexity on modern models
- **Q3:** Meaningful quality loss (3-8% perplexity degradation); reasoning drops ~5% on GSM8K
- **Q2:** Severe degradation (~14% perplexity, ~14% GSM8K drop); never use below Q3 for reasoning
- **MLX 4-bit:** Comparable quality to GGUF Q4 with slightly faster inference on Apple Silicon
- **Recommendation:** Production agents and tool-use → AWQ 4-bit or GGUF Q5_K_M minimum
