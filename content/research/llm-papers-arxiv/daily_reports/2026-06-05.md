# Daily Report — June 5, 2026

## New Insights (13 papers)

### CLSA: Cross-Layer Sparse Attention with Shared Routing
**arXiv:2606.06467** (June 4, 2026) — cs.CL, cs.AI, cs.LG
- YOCO-based KV-sharing + single routing index reused across layers
- 7.6x decoding speedup, 17.1x throughput at 128K context
- Jointly improves pre-filling, KV-cache storage, and long-context decoding
- Key insight: KV sharing + shared routing index solves efficiency-quality tradeoff in sparse attention

### NF-CoT: Latent Reasoning with Normalizing Flows
**arXiv:2606.06447** (June 4, 2026) — cs.CL, cs.LG
- Normalizing flows model continuous thoughts distilled from explicit CoT
- Preserves KV-cache compatibility, left-to-right generation, tractable likelihood
- Improves pass rates on code benchmarks with less intermediate reasoning cost
- Key insight: Normalizing flows bridge latent reasoning efficiency with autoregressive LM strengths

### ACTS: Agentic Chain-of-Thought Steering
**arXiv:2606.03965** (June 2, 2026) — cs.CL, cs.AI
- Controller agent steers frozen reasoner via MDP; budget-aware strategy control
- Matches full-thinking performance with substantial token savings
- Key insight: Separating controller from reasoner enables budget-aware trade-offs

### SARDI: Self-Augmenting Retrieval for Diffusion LLMs
**arXiv:2606.06474** (June 4, 2026) — cs.CL, cs.AI, cs.LG — ICML 2026
- Discarded low-confidence tokens serve as lookahead for RAG
- Training-free, up to 8x throughput on multi-hop QA
- Key insight: Diffusion model inefficiency becomes retrieval signal

### RedKnot: Head-Aware KV Cache Management
**arXiv:2606.06256** (June 4, 2026) — cs.AI
- Head-level KV cache decomposition; no retraining required
- Position-independent reuse, prefix compression, hot/cold separation
- Key insight: Monolithic KV cache abstraction wastes resources; head-aware is new foundation

### EDIT: Evidence-Diagnosed Intervention Training
**arXiv:2606.06350** (June 4, 2026) — cs.CL
- Internal state diagnostics locate problematic grading steps
- Two-phase: local revision + belief-guided reward shaping
- Outperforms SFT and RL baselines on multi-subject grading
- Key insight: Grading requires local credit assignment via internal diagnostics

### IR3DE: Linear Router for Domain Experts
**arXiv:2606.06098** (June 4, 2026) — cs.CL, cs.LG — ICML 2026 Workshop
- Ridge regression-based routing; 98.4% normalized performance on reasoning
- Dynamic expert addition/removal without router retraining
- Key insight: Simple linear routing outperforms complex models for domain-expert selection

### SkillComposer: Self-Evolving Agent Skills
**arXiv:2606.06079** (June 4, 2026) — cs.CL
- Create, improve, merge operations; self-evolves skills at inference time
- +4.5 on agent tasks, +3.4 on code tasks over 27B executor
- Key insight: Skill abstraction vs task-specificity tension resolved by explicit mechanisms

### PropMe: Propensity-Aware Memorization Evaluation
**arXiv:2606.06286** (June 4, 2026) — cs.CL, cs.AI
- SimpleTrace pipeline: infini-gram-based training corpus attribution
- Consistent gap between capability attacks and ordinary propensity
- Key insight: Memorization audits need both worst-case and propensity metrics

### Value Diversity in Multicultural Agent Systems
**arXiv:2606.05985** (June 4, 2026) — cs.CL, cs.CY
- System-level diversity metric across 19 cultures, 18 backbone models
- Diversity uncorrelated with alignment — complementary properties
- LLM-based societies fall below human diversity; social interaction drives homogenization
- Key insight: Alignment and diversity are distinct axes; agents homogenize rather than preserve plurality

### OpAI-Bench: Multi-Granularity AI-Text Detection
**arXiv:2606.06481** (June 5, 2026) — cs.CL
- Nine sequential revisions, five AI edit operations, four domains
- Edit operation type matters as much as coverage for detectability
- Key insight: Detection must account for how content was edited, not just how much

### Graph-Based RAG for Hallucination Reduction
**arXiv:2606.05901** (June 4, 2026) — cs.CL
- Lightweight graph schema halves hallucinated answers on MoNaCo
- Highest fine-grained truthfulness with modest token increase
- Key insight: Simple graph structures reduce hallucinations without fine-tuning

### CollabSim: Multi-Agent Collaborative Competence
**arXiv:2606.06399** (June 4, 2026) — cs.CL
- MAS fail from collaborative incompetence, not task-solving incompetence
- Tests: common ground, shared understanding, incentive balance, misalignment repair
- Key insight: Collaborative competence is distinct failure mode from reasoning failure

## Key Trends from June 5, 2026

1. **KV-Cache as Infrastructure Primitive**: RedKnot and CLSA signal shift from treating KV cache as passive artifact to active resource; head-aware and cross-layer approaches unlock major efficiency gains
2. **Latent Reasoning Goes Mainstream**: NF-CoT demonstrates normalizing flows can preserve autoregressive strengths while enabling efficient latent reasoning; code generation is primary testbed
3. **Agentic Reasoning Control**: ACTS shows controller-reasoner separation enables budget-aware trade-offs; RL-based strategy selection gaining traction
4. **Diffusion LLMs Catch Up on Efficiency**: SARDI turns discarded tokens into retrieval signal; 8x throughput gains without training
5. **Linear Routing Surprises**: IR3DE shows simple ridge regression beats complex routing for domain expert selection; dynamic composition without retraining
6. **Value Diversity Emerges as Key Metric**: Agent societies fall below human diversity; mixed-backbone systems narrow but don't close gap
7. **Multi-Agent Collaboration Failure Mode Identified**: CollabSim shows collaborative incompetence is distinct from reasoning failure; common ground and alignment matter
8. **Memorization Needs Dual Metrics**: PropMe demonstrates worst-case and propensity are distinct; audits need both dimensions
9. **AI-Text Detection Operation-Sensitive**: OpAI-Bench shows edit operation type matters as much as coverage; sequential revisions reveal gradual signal emergence
10. **Graph RAG Reduces Hallucinations**: Simple graph structures halve hallucinations without fine-tuning; highest truthfulness scores
