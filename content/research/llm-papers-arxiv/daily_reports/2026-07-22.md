# Daily Report — 2026-07-22

## arXiv Papers: 6 Notable Submissions (78 cs.CL total)

### GEAR: Repetitive Copying in Long-Context Reasoning
**arXiv:2607.19345** | cs.CL, cs.AI

New failure mode identified: Frontier LLMs extensively copy text from input into reasoning traces rather than solving problems — intensifies with context length. Root cause is insufficient grounding in key evidence.

Solution: GEAR (Grounding Evidence-Aware Reward) — adds grounding reward for evidence overlap and distractor penalty. Achieves +4.6 points over standard RL with reduced copying and shorter thinking.

### MaLoRA + MaRA: State-Space Adaptation for Reasoning
**arXiv:2607.19326** | cs.CL

Standard LoRA misses token-level variation. MaLoRA adds dynamic recurrent scaling across tokens; MaRA tracks cross-segment state and selects relevant segments.

Results: +10.5% relative F1 improvement over LoRA baseline, up to +18.2% on hardest problems, gains persist under length stress.

### VeyraBench: Format vs Instruction Count vs Context Length
**arXiv:2607.19257** | cs.CL, cs.AI

First controlled study on three under-researched prompt decisions:
- Perfect instruction-following collapses to zero by N=80 rules (all models)
- Near context ceiling: refusal rises to 79-90% — distinct from sycophancy/fabrication
- No reliable markdown advantage; one model favors plain text
- Fabrication never occurred (0/5,760 probes)

### DAIS: Dependency-Aware Intermediate QA Supervision
**arXiv:2607.19088** | cs.CL, cs.AI

CoT flat supervision misses how local conclusions support later decisions. DAIS models dependency structure explicitly in intermediate supervision — converts rationales into stage-level QA records conditioned on previous states.

Average gain 4.2% over strongest baseline on GDPR, AIACT, MedQA, FOLIO.

### CircuitKIT: Mechanistic Interpretability Toolkit
**arXiv:2607.19317** | cs.LG, cs.CL

Unified source-available library connecting circuit discovery, evaluation, and intervention (pruning, editing, steering, selective fine-tuning) through typed serializable representation.

Practical bridging of academic agent research and production deployment. Design patterns, failure mode mitigations (verification pipelines, fallback mechanisms, human-in-the-loop).
