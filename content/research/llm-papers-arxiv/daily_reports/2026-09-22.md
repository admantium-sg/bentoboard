## Papers Found (Sep 21 submissions, first checked today)

**5 new papers identified across chain-of-thought, prompt engineering, efficiency, and agent memory:**

1. **onPanda** (2609.24983, cs.CL, cs.AI) — Token-level correction for on-policy LLM alignment annotation. Locate first inappropriate token, substitute from model candidates or type free-form, truncate and continue. 52% reduction in median annotation time vs manual post-editing. Preserves model's sampling distribution for on-policy SFT and preference data. Natural fine-grained supervision with precise positions and paired positive-negative samples. Submitted Sep 21.
Source: https://arxiv.org/abs/2609.24983

2. **DolphinBench** (2609.24971, cs.CL, cs.AI) — Maps Pareto frontier of agent memory via task completion. Three personas, ~500k tokens per persona, 200 verified tasks per persona (verified by with/without history contrast). First benchmark to require cost+latency+accuracy reporting simultaneously. No prior memory benchmark combines all three. Submitted Sep 21.
Source: https://arxiv.org/abs/2609.24971

3. **OSWorld-Pro** (2609.24890, cs.CL, cs.AI) — Process-based evaluation for computer use agents. 300+ tasks, 2800+ subgoals, 67,000 human annotations. Evaluates subgoal fulfillment via LLM-Judge throughout sequential subgoals rather than only end-state. Claude Opus 5 achieves 75.7% vs 83.4% on OSWorld — process evaluation reveals distinct failure modes end-state misses. Submitted Sep 21.
Source: https://arxiv.org/abs/2609.24890

4. **Human-LLM Deliberation as Interactive Proof** (2609.24895, cs.CL) — Models human-LLM deliberation as prover (unrestricted search) + resource-bounded verifier (requests and checks supporting details). Proves anytime-valid soundness: probability of accepting false claim bounded by chosen error level. Conditions identified for certification of local vs global checks under verifier effort/cognitive budgets. Submitted Sep 21.
Source: https://arxiv.org/abs/2609.24895

5. **SLITE** (2609.24932, cs.CL, cs.SC) — Explainable hybrid model for textual entailment combining structural-relational and distributional-informational layers. 17 interpretable features + logistic regression achieves 83% on 3-class SICK, 96% on SICK-CE (within 2pp of RoBERTa). Structural-relational features drive classification; distributional-informational features essential for neutrality and contradiction detection. Submitted Sep 21.
Source: https://arxiv.org/abs/2609.24932
