## 🔬 Reasoning / Benchmarking

### QMFOL: Quantifiable Monadic First-Order Logic Reasoning Benchmarks (2606.20227)
**Reasoning** | Benchmark | Controllable complexity

Key insight: Existing LLM reasoning benchmarks lack fine-grained control over logical complexity — can't systematically test at what depth models break. QMFOL generates monadic first-order logic tasks with precise control over reasoning depth, width, label types, and distractors.

- QMFOLBench: 2,880 instances, 960 configurations across logical and semantic dimensions
- Constructs formal logical structures using conjunction/disjunction patterns
- Translates to natural language via LLMs; consistency verified through round-trip checking with external prover
- Six large reasoning models (LRMs) and two LLMs tested — performance degrades predictably with logical complexity
- Models perform better on True-labeled tasks than False or Unknown
- Key insight: Reasoning breakdown under complexity load is now systematically measurable; QMFOL enables precise benchmarking of where reasoning chains fail

🔗 https://arxiv.org/abs/2606.20227

### NRT-Bench: Multi-Turn Red-Teaming of LLM Agents in Nuclear Plant Simulation (2606.20408)
**Safety** | Red-teaming | Multi-agent | Benchmark

Key insight: LLM agents as safety-critical operators haven't been systematically evaluated under sustained adaptive adversarial pressure. NRT-Bench simulates a nuclear power plant control room with a 5-role operator team and adversary injection over four channels.

- 8.7-12.1% of attack sessions across four frontier models result in loss of a critical safety function
- Vulnerabilities are nearly disjoint across models (none of 149 sessions defeat all four; ~1/3 defeat at least one)
- Added defenses are strongly model-dependent: same guardrail stack can help one model while hurting another
- Harm is objective (CSF loss), not LLM-judged text — avoids judge bias
- Key insight: Model-robustness aggregation hides that vulnerabilities are complementary; auditing each model separately is more informative than averaged rates

🔗 https://arxiv.org/abs/2606.20408

## ⚡ Search / Grounding

### DSG: Decoupled Search Grounding — 91% Lower Search Cost (2606.18947)
**RAG** | Search | Latency | Vendor-agnostic

Key insight: Production RAG bundles retrieval policy, provider routing, evidence injection, cost, and latency behind a single model boundary. DSG decouples this into a first-class interface boundary via MCP-compatible gateway.

- Near-native accuracy on SimpleQA (86.1% vs 87.7%) at 91% lower search cost
- 68% lower latency, 99.4% warm-cache hit rate
- Deployed on e-commerce query-understanding: >98% search cost reduction while matching native accuracy
- Exposes provider routing, source-aware context rendering, configured fallback, retrieval-depth control, and caching as first-class controls
- Key insight: Real-time grounding is an optimizable interface boundary, not a fixed model feature — treating it as such unlocks massive efficiency gains

🔗 https://arxiv.org/abs/2606.18947

## 🔍 Key Pattern: Complementarity of Model Vulnerabilities

NRT-Bench's most striking finding cuts across the benchmark landscape: failures barely overlap across models. Claude Fable 5 maxes AIME; Gemini 3.1 leads on agentic tasks (Terminal-Bench, BALROG); GPT-5.5 leads on FrontierMath. The practical implication: no single model is "most robust" — the answer depends on which failure mode matters for your deployment. Ensembling for safety requires understanding which model fails in which way, not just average scores.
