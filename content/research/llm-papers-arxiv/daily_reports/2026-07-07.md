# DIAC - LLM Papers / arXiv — July 7, 2026

## New Insights

### CAT: Confidence-Adaptive Thinking for Efficient Reasoning of Large Reasoning Models
**arXiv:2607.00862** (July 1, 2026) — cs.CL — ACL 2026 Industry Track
- LRMs exhibit overthinking on simple queries — generating long CoT trajectories even when unnecessary
- CAT uses the model's intrinsic self-certainty signals as confidence, integrated into preference optimization
- Autonomously modulates reasoning lengths based on problem difficulty — compresses confident responses, deliberates on uncertain ones
- Consistently outperforms SOTA baselines on reasoning accuracy across multiple benchmarks on different base models
- Key insight: Not all queries need the same reasoning depth. Using the model's own certainty as a signal enables adaptive compute allocation without a separate verifier.
- Paper: https://arxiv.org/abs/2607.00862

### Message Passing Enables Efficient Reasoning (MPLMs)
**arXiv:2607.01077** (July 1, 2026) — cs.CL — cs.LG
- Standard CoT is sequentially slow; fork-join (FJ) parallelization helps but threads don't communicate pointwise
- MPLMs introduce lightweight send/receive primitives so threads communicate directly during reasoning
- Two efficiency mechanisms: (1) reduced communication costs by avoiding redundant context sharing, (2) preemption allowing early termination of unpromising branches
- Demonstrated on Sudoku (asymptotically smaller context than CoT/FJ), 3-SAT (branch termination), and long-context QA
- Fine-tuned single model solves 25×25 Sudoku puzzles that remain challenging for standard CoT, FJ, and frontier models without tools
- Key insight: Parallel reasoning is bottlenecked by transient threads that never communicate. Explicit message passing turns multi-thread reasoning into true distributed computation.
- Paper: https://arxiv.org/abs/2607.01077

### How Much is Left? LLMs Linearly Encode Their Remaining Output Length
**arXiv:2607.05316** (July 6, 2026) — cs.CL — cs.LG
- Response lengths are remarkably consistent: step-by-step solutions converge in predictable token counts, retrievals stop after a few sentences, retractions extend responses
- Linear probes trained on frozen hidden states of 7-8B models reveal: total response length is linearly decodable from the prompt's last hidden state BEFORE any output is emitted
- Probe directions transfer broadly across datasets, including controlled synthetic completions never seen in training
- On curated high-loss completions, the probe's estimate shifts upward at the moment the model retracts and restarts — directional behavior no position-only predictor can reproduce
- Key insight: LLMs maintain a plan-like internal representation of output length (decodable, not necessarily used causally). This has implications for early-answer stopping, output compression, and planning-based inference.
- Paper: https://arxiv.org/abs/2607.05316

### Faithfulness to Refusal: A Causal Audit of Neuron Selectors
**arXiv:2607.05355** (July 6, 2026) — cs.CL — cs.ET — cs.LG
- Attribution methods identify important neuron rows for pruning/interpretability/editing, but whether they identify causally important rows is rarely tested directly
- One-shot neuron-row zeroing audit: attribution methods substantially outperform activation/magnitude-based baselines at identifying dispensable rows
- Harmful-vs-benign contrast test: attributed rows are sufficient to install refusal on hate/crime while keeping benign over-refusal low and preserving fluency
- Key finding: Highly rank-stable selectors can be among the least causally valid — rank stability is a misleading proxy
- Refusal lives in a redundant subspace: different attribution methods install it through largely disjoint row sets
- Key insight: Reading attribution scores as causal truth leads to wrong interventions. Causal audits via one-shot zeroing reveal that "important" neurons identified by different methods are largely non-overlapping — there is no unique mechanism for refusal.
- Paper: https://arxiv.org/abs/2607.05355

### Lynx: Progressive Speculative Quantization for KV Transfer
**arXiv:2607.01831** (July 2, 2026) — cs.DC — SIGCOMM '26
- In disaggregated inference, large KV caches must transfer across the network before decoding can begin
- Existing KV quantization achieves low latency OR high accuracy, not both
- Key observation: different bits in KV cache contribute unequally — most significant bits capture coarse attention structure, least significant bits refine precision
- Lynx partitions KV into Anchor stream (MSBs, high priority) and Residual stream (LSBs, low priority)
- Decoding begins upon receipt of Anchor while Residual transfers concurrently; verification ensures equivalence to BF16
- Results: TTFT comparable to aggressive 4-bit quantization while matching BF16 accuracy; 1.43× TTFT improvement over standard 8-bit KV; 5.1% accuracy improvement over SOTA
- Key insight: The KV cache is not an indivisible unit — progressive, split-stream transfer enables speculative decoding from partially-received KV in disaggregated serving
- Paper: https://arxiv.org/abs/2607.01831

## Trend

Adaptive reasoning is the emerging theme: instead of fixed compute per query, models are learning to allocate reasoning depth based on problem difficulty (CAT), communicate across parallel reasoning threads (MPLMs), and even predict how much output remains before generating (remaining length encoding). On the serving side, progressive KV cache transfer (Lynx) enables speculative decoding from partially-received caches in disaggregated setups.
