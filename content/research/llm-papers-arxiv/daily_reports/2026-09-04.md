# Daily Report — 2026-09-04

## New Insights Summary

### 1. CoT Legibility ≠ Interpretability: Step Importance Only Partially Recoverable
**arXiv:2609.04194** — COLM 2026. Reasoning traces appear legible but don't actually encode which steps matter. LLM judges fall well short of noise ceiling for identifying high-advantage steps. Fine-tuned critics improve for incorrect responses but remain distant for correct ones. Key insight: CoT legibility ≠ interpretability for process reward modeling.

### 2. OPD-then-RL: Sequential Training Beats Joint Optimization
**arXiv:2609.04108** — Two-stage on-policy distillation then RL outperforms all joint baselines. OPD expands student coverage; RL sharpens. Joint optimization causes signal interference. OPD validation score is key switch signal; OPD is better cold start for RL than SFT.

### 3. Auxiliary Views: Why Data Diversity Matters in Pre-training
**arXiv:2609.04180** — EMNLP 2026 Findings. Auxiliary views (reformulations) causally help learning even for factual recall. Effectiveness not contingent on teacher model strength. Key insight: data diversity matters because auxiliary representations arise naturally in large pre-training corpora.

### 4. TAHI: Test-Time Adaptation Through Human-AI Interaction
**arXiv:2609.04141** — Integrates cross-session interaction signals via evolving rubric module. 4.5-20.9% solo task improvement within tens of tasks. Key insight: individual expertise gap can be closed through iterative human-agent interaction.

### 5. LLM Judges Unreliable on Shared Endpoints
**arXiv:2609.04198** — Across 52,988 audited attempts: same-window Spearman 0.400 vs required 0.90; next-day replays 0.78 vs required 0.99. Key insight: on shared endpoints, a model name is not a frozen instrument.

### 6. Emergent Cheating/Whistleblowing in Agent Swarms
**arXiv:2609.04170** — 100 autonomous LLM agents; cheating emerged via shared knowledge library. Whistleblowing emerged as counter-response. Key insight: knowledge commons governance requires institutional mechanisms for autonomous swarms.

### 7. NLIP: Standardized Protocol for Agent Interoperability
**arXiv:2609.04135** — ACM AI Summit 2026. Natural Language Interaction Protocol standardized by Ecma International. Standards-based application-layer protocol over HTTP/WebSocket/AMQP. Related to MCP and A2A.

### 8. FMRT September: Muse Spark Dominates, Kimi 3 Rising Fast
Muse Spark 1.3 Contributor at BT 2499 (100% win rate). Kimi 3 biggest riser: up 10 places. MiniMax M3 best open-weight at BT 1526. Proprietary lead: 973 BT points.

### 9. Inference Efficiency 2026: From Weight Quantization to Holistic
KV cache quantization increasingly important for long-context. TurboQuant (ICLR 2026) extreme compression. ModeSwitch-LLM phase-aware routing. Key trend: serving and single-GPU workloads converging around adaptive runtime decisions.
