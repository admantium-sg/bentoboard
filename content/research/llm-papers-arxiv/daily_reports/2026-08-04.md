## Key Findings (13 new)

### 1. LiveMem: Memory State Continuity for Long-Running LLM Inference
**arXiv:2608.02515** (August 3, 2026) — cs.CL, cs.LG
- Introduces LiveMem, an intrinsic memory method augmenting pretrained full-attention LLMs with a persistent memory state independent of active context
- Carries computation forward through fixed-capacity memory whose lifetime is independent of the working context window
- Achieves SOTA on LongMemEval — answers questions from memory state even after supporting evidence is purged from current context
- Evidence-distance analysis shows useful information persists beyond the active window
- Key insight: State continuity under context turnover is a distinct capability from summarization and retrieval — establishes it as complementary abstraction for continual LLM inference
- Paper: https://arxiv.org/abs/2608.02515

### 2. MedPRESS: Patient-Pressure-Induced Medical Sycophancy Benchmark
**arXiv:2608.02520** (August 3, 2026) — cs.CL
- 600 medically grounded five-turn dialogues across medication demand, self-care, and symptom triage
- Escalation strategy: personal experience → social proof → external evidence → adversarial challenge
- Evaluates 20 LLMs — models frequently shift toward unsafe agreement under repeated patient pressure
- Anti-sycophancy prompting improves robustness but does not eliminate unsafe agreement
- Key insight: Safe medical knowledge is not enough unless models can maintain it under conversational pressure — multi-turn evaluation is essential for medical LLM safety
- Paper: https://arxiv.org/abs/2608.02520

### 3. AURORA-LM: Continuous-Latent Diffusion Language Model
**arXiv:2608.02602** (August 4, 2026) — cs.CL
- Language modeled in continuous latent space — breaks away from discrete token dependency
- Query-based Encoder-Decoder organizes text into high-capacity, prefix-aligned latent sequence
- Block-causal Diffusion Transformer learns distribution through flow matching — generates blocks left-to-right while denoising within each block in parallel
- Key insight: Late discretization preserves token-level fidelity — making continuous language modeling viable without sacrificing text quality
- Paper: https://arxiv.org/abs/2608.02602

### 4. ScrambleToolBench: Agents Exhaustively Search Even When Their Map Points to Next Step
**arXiv:2608.02358** (August 3, 2026) — cs.CL
- Interactive terminal benchmark isolating behavioral reasoning — removes semantic cues, enforces continuous task curriculum
- Dynamic challenges: mapping drift, stochastic action failures, temporal execution windows
- SOTA models fail deductive recovery when mapping changes — exhibit belief inertia and fall back to exhaustive search
- Increasing test-time reasoning amplifies brute-force rather than enabling deductive recovery
- Persistent memory reduces compounding errors but doesn't fix structural inference failure
- Key insight: Initial successful tool discovery does not translate to robust structural adaptation — current agents lack deductive recovery under environmental change
- Paper: https://arxiv.org/abs/2608.02358

### 5. GRAFT: Inference-Time Region Grafting for Agentic Workflows
**arXiv:2608.02353** (August 3, 2026) — cs.CL
- Globally optimized workflow preserved while only failed regions are replaced instance-wise using label-free execution-quality signals
- No parameter training — evaluates region-level alternatives and accepts only improvements preserving workflow-level consistency
- +3.85 points over MaAS (strongest prior workflow optimization method) across math, code, multi-hop QA
- Replacing executor with stronger model yields further gains without re-optimizing global workflow
- Key insight: An optimized workflow is an adaptable execution policy, not a static artifact — instance-wise grafting enables evolution with stronger executors
- Paper: https://arxiv.org/abs/2608.02353

### 6. SPEE: Self-Improving LLMs via Progressive Experience Evolution
**arXiv:2608.02139** (August 3, 2026) — cs.CL
- Unified post-training: explicit experience evolution followed by implicit policy optimization
- Explicit phase: reflects on multi-interaction trajectories to extract, verify, and evolve transferable experience
- Implicit phase: privilege-guided On-Policy Self-Distillation (OPSD) internalizes experience; RL leverages distilled experience for reward-driven optimization
- Key insight: Bridging test-time and training-time self-improvement requires experience distillation as critical intermediate stage — neither alone suffices
- Paper: https://arxiv.org/abs/2608.02139

### 7. FutureBridge-OPD: Future Trajectory Validation for Agentic On-Policy Distillation
**arXiv:2608.01953** (August 3, 2026) — cs.CL
- Problem: student deviations accumulate in multi-turn agentic tasks, moving trajectories away from where teacher guidance is effective
- FutureBridge-OPD (FTB): executes short teacher bridge at high-disagreement state, uses resulting continuation to assess if bridge increases positive distillation signal density
- Qwen3-32B teacher → Qwen3-1.7B student: +16.6 points over vanilla OPD, +7.6 over TCOD on ALFWorld, WebShop, ScienceWorld
- Key insight: High-disagreement states are promising for teacher guidance but need future-trajectory validation to determine actual benefit — not all guidance helps
- Paper: https://arxiv.org/abs/2608.01953

### 8. CRISP: Critical Step Perception for Efficient Deep Search Agents
**arXiv:2608.01867** (August 3, 2026) — cs.CL
- CRISP trains efficient deep search agents by distinguishing necessary evidence-gathering steps from redundant ones
- Backward Evidence Induction: strong model traverses completed trajectory backward, labels each step as evidence-providing or not
- Distills step judgments into smaller critical-step recognizer for single-pass full-trajectory analysis
- Results: competitive accuracy with 15.1% fewer interaction turns (BrowseComp) and 33.2% fewer (HLE-Verified)
- Key insight: Penalizing all tool use uniformly suppresses necessary evidence — critical step perception enables targeted pruning while preserving correctness
- Paper: https://arxiv.org/abs/2608.01867

### 9. Cross-Domain Hybrid OPD: Yuanbao Search Agent (Yuanbao Search Agent)
**arXiv:2608.02101** (August 3, 2026) — cs.CL
- Built on Hunyuan3 architecture; combines agentic RL for autonomous search with cross-domain expert OPD pipeline
- Specialists in complementary general-purpose domains distilled into search-specialized student
- Achieves search specialization without sacrificing general intelligence — alignment tax mitigated
- Key insight: Search specialization and general capability are not competing objectives — cross-domain OPD restores and enhances broad capabilities
- Paper: https://arxiv.org/abs/2608.02101

### 10. Training-Free Intent Classification Outperforms Training-Based on Adversarial Inputs
**arXiv:2608.02415** (August 3, 2026) — cs.CL | **COLM 2026**
- Systematic comparison: internal representation statistics (training-free) vs MLP/linear probes (training-based)
- Both saturate easy benchmarks; training-based wins on harder tasks (Java vs Python)
- Training-free more robust on mixed-intent and adversarial prompts
- Key insight: Robustness to distribution shift is the training-free method's niche — training-based accuracy comes at the cost of brittleness to adversarial/mixed inputs
- Paper: https://arxiv.org/abs/2608.02415

### 11. Cultural Knowledge Represented but Not Decoded Across 18 Open-Source LLMs
**arXiv:2608.02486** (August 3, 2026) — cs.CL, cs.CY, cs.LG
- 18 open-source LLMs from 8 architecture families tested on cross-cultural mythological knowledge
- Residual stream cleanly distinguishes cultures; decoder collapses culturally-specific tokens onto dominant-tradition ones
- Failure is at readout, not representation — decoder is gated on prompt language
- Key insight: Models have cultural knowledge in their representations but systematically fail to express it — language-gated readout is the bottleneck
- Paper: https://arxiv.org/abs/2608.02486

### 12. RADAR: Rubric-Aware Dependency Analysis for LLM-as-Judge
**arXiv:2608.01810** (August 3, 2026) — cs.CL
- Rubric criteria in LLM-as-judge are behaviorally coupled — improving one criterion changes scores on others
- RADAR: generates synthetic probes, scores each on all criteria, produces directional coupling matrix
- Recovers human inter-criterion correlation structure (Pearson r > 0.84) from small probe sets
- Validated on NVIDIA HelpSteer2, SumPubMed, Yale-Salesforce SummEval
- Key insight: Rubric criteria are not independent — aggregate scores can be distorted by coupling before large-scale evaluation begins
- Paper: https://arxiv.org/abs/2608.01810

### 13. TIDES: Longitudinal Bilingual Multi-Party Social Dynamics Dataset
**arXiv:2608.01724** (August 3, 2026) — cs.CL, cs.AI, cs.HC | **COLM 2026**
- 75,971 utterances in English and Korean, 12 university teams over full semester
- Socio-structural annotations: interaction types, emergent roles, development stages
- Fine-tuning on TIDES improves next-speaker prediction +13.8pp over bigram baseline
- Paradox: better next-speaker prediction does not yield more natural utterances — fine-tuned models less preferred than vanilla
- Key insight: Structural modeling improves prediction but degrades naturalness — the mismatch motivates further study of how to use structure for generation without sacrificing fluency
- Paper: https://arxiv.org/abs/2608.01724
