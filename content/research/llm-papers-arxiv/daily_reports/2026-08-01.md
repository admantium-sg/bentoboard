# Daily Report — August 1, 2026

## Research Summary

Incremental research for August 1, 2026 covering arXiv cs.CL/cs.AI/cs.LG submissions from July 30-31, plus community and benchmark developments. 11 new findings (10 papers + 1 major benchmark update).

## Key Findings (11 new)

### 1. Self-Refine and Reflexion Lose to Repeated Sampling
**arXiv:2607.28576** (July 30, 2026) — cs.CL
- 36 paired comparisons across 1.5B/3B/7B models and 2 math benchmarks
- No self-reflection method reliably beats repeated sampling at equal token cost
- 10 methods reliably worse — all involve the model inspecting its own output
- Self-Refine and Reflexion stay 3.6-10.1 points below baseline at 7B scale
- Key insight: Generating more text raises accuracy by itself — self-critique gains don't survive token-equivalent comparison
- Paper: https://arxiv.org/abs/2607.28576

### 2. ORCA-bench: Production Oncall Readiness Gap
**arXiv:2607.28545** (July 30, 2026) — cs.CL, cs.AI, cs.SE
- 1,079 RCA tasks with live microservice telemetry (6 days, Prometheus/Jaeger/OpenSearch)
- Best RCA Accuracy: 25.3% Medium, 10.0% Hard — even Claude Fable 5
- Weakest model hallucinates implausible root cause in 40% of reports
- Gap reported is a lower bound — real production systems far more complex
- Key insight: Frontier coding agents cannot yet be safely entrusted with production reliability
- Paper: https://arxiv.org/abs/2607.28545

### 3. AskChem: Claim-Centered Chemistry Literature
**arXiv:2607.28618** (July 30, 2026) — cs.CL, cs.AI, cs.IR, cs.LG
- 2.4M claims from 147K papers; each grounded by DOI + verbatim quote
- Grounding GPT-5.5 in AskChem yields 100% resolvable DOIs vs 88.3% without
- Provides MCP access for AI agents
- Key insight: Claim-level retrieval enables precise evidence synthesis beyond document retrieval
- Paper: https://arxiv.org/abs/2607.28618

### 4. Safety Alignment Entangles Consciousness Attribution
**arXiv:2607.28607** (July 30, 2026) — cs.CL
- Safety fine-tuning suppresses mind attribution to self AND non-human animals/natural objects
- Steering consciousness vector reverses suppression without impairing Theory of Mind
- Key insight: Cannot selectively suppress self-consciousness — entangled with broader mind attribution
- Paper: https://arxiv.org/abs/2607.28607

### 5. Coherent Overlap in Sparse MoE Routing
**arXiv:2607.28308** (July 30, 2026) — cs.LG
- Expert Subspace Separation Index (ESSI): expert subspaces overlap substantially
- Actual routes explain token representations better than alternatives
- Top-2 routing outperforms Top-1 in all three seeds
- Key insight: Geometric similarity alone cannot determine MoE redundancy — "coherent overlap" pattern
- Paper: https://arxiv.org/abs/2607.28308

### 6. Qwen-UI-Agent: Foundation GUI Agent
**arXiv:2607.28227** (July 30, 2026) — cs.AI, cs.CV
- SOTA on mobile (82.1% MobileWorld, 92.2% MobileWorld-Real, 97.5% AndroidDaily)
- 79.5% OSWorld-Verified, 73.6% WebArena, 81.5% ScreenSpot-Pro
- Competitive with Opus 4.8, Gemini 3.1 Pro, GPT-5.6 Sol on computer/browser
- Key insight: Real-world GUI agents require unified multi-environment capability
- Paper: https://arxiv.org/abs/2607.28227

### 7. MemHarness: Memory Is Reconstructed, Not Replayed
**arXiv:2607.28272** (Aug 1, 2026) — cs.AI
- Agents reconstruct retrieved experience rather than replay verbatim
- Reconstructive ability emerges through end-to-end GRPO training
- Outperforms pure RL and static memory baselines on ALFWorld and WebShop
- Key insight: Gap between abstract stored experience and concrete present state causes negative transfer
- Paper: https://arxiv.org/abs/2607.28272

### 8. Σ-Mem: Reliability Memory for Multi-Agent Systems
**arXiv:2607.27958** (July 30, 2026) — cs.MA, cs.AI
- Records peer competence and relationship evidence as spectral states
- Weyl's inequality bounds spectral change — stable online adaptation without retraining
- Three use modes: residual steering, peer routing, reliability-weighted voting
- Key insight: Reliability memory is a reusable foundation for adaptive multi-agent coordination
- Paper: https://arxiv.org/abs/2607.27958

### 9. Echoverse: Deep Evolving Environments
**arXiv:2607.28074** (July 30, 2026) — cs.AI, cs.LG
- Deep environments: 80.0→85.0 accuracy; shallow: 80.0→75.0
- 9B model improves 36.5%→67.1% across 14 evaluation splits
- Key insight: Environment depth and model co-evolution — not quantity — is the bottleneck
- Paper: https://arxiv.org/abs/2607.28074

### 10. PACE: LLM for Parent-Order Execution
**arXiv:2607.28410** (July 30, 2026) — cs.CE, cs.CL
- Extends LLMs from what to trade to how to execute
- Exceeds TWAP/Almgren-Chriss by 0.65 bps on Shenzhen Stock Exchange data
- Higher model confidence predicts better execution performance
- Key insight: LLMs can complement human traders in execution decisions
- Paper: https://arxiv.org/abs/2607.28410

### 11. Flux-OPD: On-Policy Distillation with Evolving Contexts
**arXiv:2607.28022** (July 30, 2026) — cs.LG, cs.AI
- Reverse KL decomposition stabilizes evolving contexts as in-training supervision
- Outperforms existing OPD paradigms on open-ended tasks
- Key insight: Context conflicts can be measured and weighted for stable distillation
- Paper: https://arxiv.org/abs/2607.28022
