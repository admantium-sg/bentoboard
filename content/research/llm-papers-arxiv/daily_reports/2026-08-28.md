## New Papers (10)

### CritICL (2608.27455) — Weak-to-Strong Generalization via Failure Mode Guidance
cs.CL | Inference-time improvement framework using structured failure patterns from weaker models. Two variants (dynamic/static). Outperforms standard ICL, competitive with test-time scaling at lower token cost. Key insight: failure modes are guidance signals, not noise. Paper: https://arxiv.org/abs/2608.27455

### Weak-Model Guidance RLVR (2608.27420) — Entropy Collapse Mitigation
cs.CL | Forces target model to generate from weaker model prefixes — unfamiliar trajectories disrupt over-confidence. Mitigates entropy collapse without complex prompting. Performance gains scale with K. Key insight: simple cross-scale prefix injection preserves reasoning diversity. Paper: https://arxiv.org/abs/2608.27420

### SCIT (2608.27265) — Latent CoT Cache Mechanism
cs.CL | EMNLP 2026 | Causal protocol identifying exact value-cache suffix trajectories as counterfactual arithmetic carriers in latent CoT models. Competence-gated carrier map reveals different routing at different capability levels. Key insight: cache-level diagnostics now feasible — interpretability can pinpoint exact computational carriers. Paper: https://arxiv.org/abs/2608.27265

### ContraTalk (2608.27176) — Audio-Grounded Reasoning Failure Mode
cs.CL, cs.AI, cs.LG | Transcript shortcuts cause 33-48% accuracy on conflict cases vs 90%+ on consistent cases. Direct AudioLLMs still fall for transcript traps 30-40% of time. Audio Twin framework improves conflict accuracy. Key insight: acoustic evidence aggregation is more controllable than transcript-based reasoning. Paper: https://arxiv.org/abs/2608.27176

### ES for Reasoning (2608.27351) — ES Is Distinct from GRPO
cs.LG | ES provides broader reasoning coverage and higher Pass@K than GRPO. Sequential GRPO-ES training combines strengths. Functional sparsity: task gains from sparse parameter subsets. Key insight: ES is a distinct reasoning paradigm, not a memory-efficient GRPO alternative. Paper: https://arxiv.org/abs/2608.27351

### WikiSkill (2608.27454) — Persistent Knowledge for Agent Skills
cs.AI, cs.CL | Co-evolves agent skills with persistent wiki knowledge base. Smaller models with skills outperform larger models without. Cross-model skill transfer works. Key insight: persistent knowledge accumulation is critical for effective skill evolution. Paper: https://arxiv.org/abs/2608.27454

### RATIO (2608.27394) — Scientific Inspiration Retrieval
cs.CL, cs.IR | Three ideation moves: Address, Broaden, Specify. Operation-specific fine-tuning boosts retrievers but significant room remains. Key insight: scientific inspiration retrieval requires typed abstraction levels, not just relevance ranking. Paper: https://arxiv.org/abs/2608.27394

### CorporateBench (2608.27391) — Enterprise-Scale Q&A
cs.AI, cs.CL, cs.IR, cs.LG | EMNLP Findings | 230K+ document corpora, 4 synthetic firms. Performance degrades significantly at realistic scales. Key insight: current LLMs struggle with enterprise-scale reasoning — benchmark gap confirmed. Paper: https://arxiv.org/abs/2608.27391

### ACE Lens (2608.27260) — Agentic Data Framework
cs.AI, cs.CL | Agentic data as (E, q, τ, v) — environment, task, interaction, verifier. ACE lens: Accuracy-Complexity-divErsity. Key insight: generating more data isn't the challenge — allocating valid, non-redundant experience is. Paper: https://arxiv.org/abs/2608.27260

### D2C-Routing (2608.27380) — Mixed-Origin AI Text Detection
cs.CL | EMNLP 2026 | Distinguishes AI-content/human-expression from fully AI-generated. 6.5 points above baseline on MixD2C. Key insight: content origin ≠ expression origin — mixed-origin detection requires typed routing. Paper: https://arxiv.org/abs/2608.27380

## Community Pulse

### What Is Working
- Inference-time reasoning: CritICL and weak-model guidance approaches gaining traction as alternatives to compute-intensive scaling
- Latent CoT interpretability: SCIT's cache-level diagnostics enable mechanistic understanding of reasoning traces
- ES post-training: evidence mounting that ES is distinct from GRPO with complementary strengths

### Problems
- Transcript bias in speech: ContraTalk shows text-only shortcuts remain fundamental failure mode even for AudioLLMs
- Enterprise-scale reasoning: CorporateBench confirms performance cliff at realistic document volumes
- Reasoning diversity: entropy collapse in RLVR remains challenge — weak-model guidance offers simple fix

### Interesting
- Functional sparsity: large parameter movement in ES doesn't cause catastrophic forgetting — sparse subsets carry gains
- Cross-model skill transfer: skills evolved by other models can outperform self-evolved skills (WikiSkill)
- Value-cache suffix as CoT carrier: SCIT pins exact mechanism — not hidden states or keys
