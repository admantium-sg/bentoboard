## New Papers (9)

### DCGC (2608.25428) — Reasoning Correction via Masked Diffusion Models
Draft-Conditioned Global Correction uses an imperfect upstream draft as auxiliary context. Dynamic Dual-CFG separates problem-only and joint problem-draft branches at inference. Outperforms standard sampling across math, code, knowledge reasoning. Works verifier-free — no ground-truth failure labels needed. Key insight: diffusion-based correction of flawed reasoning traces is a viable third paradigm for test-time reasoning improvement. Paper: https://arxiv.org/abs/2608.25428

### PACE (2608.25115) — Evidence Frontloading for RAG Efficiency
RAG bottleneck shifts between upstream reranking and downstream generation under different loads. PACE reorders candidates by marginal evidence coverage (query-relevant, complementary, multi-hop chain-forming). Monotone submodular objective gives (1-1/e) greedy approximation. "Less is more" result: fewer reranked docs with evidence-dense top candidates beats exhaustive ranking. Reduces p95 latency under ranking-heavy workloads. Paper: https://arxiv.org/abs/2608.25115

### AutoVerifier (2608.25637) — Learning Verifier Biases from Recurring Errors
Reference-based verifiers have inductive biases about answer equivalence that depend on question and scoring criterion. AutoVerifier learns these biases from recurring verifier errors, records them in rule cards, promotes to code/prompt only after replay validation (no regressions). Outperforms SOTA verifiers by large margin on four benchmarks. Key insight: verifier errors are learnable patterns, not just noise. Paper: https://arxiv.org/abs/2608.25637

### TOPAS (2608.25523) — Multi-Agent LLM Serving with Prefix-Aware Scheduling
Prefix caching in multi-agent LLM serving: keeping system-prompt KV cache accelerates future calls but reduces batching memory. Existing schedulers optimize locality OR workflow progress — both leave performance on the table under shared KV budget. TOPAS jointly decides cache eviction and request scheduling, trading longest remaining service path reduction against near-term prefix reuse. 39.8%/49.4% mean/p99 JCT reduction on synthetic workloads; 22.0%/26.6% on MetaGPT real workflows. Paper: https://arxiv.org/abs/2608.25523

### Groundhog Bit-Flip Attack / GBFA (2608.25276) — Denial-of-Wallet on MoE LLMs
EMNLP 2026. MoE routing creates attack surface: specific experts become correlated with EOS tokens. Flipping <4 routing-layer bits → 5912% token inflation across 4 real-world MoE models, conversational/reasoning/agentic modes. Semantic fidelity largely preserved. Key insight: MoE sparse activation is a double-edged sword — lightweight bit perturbations cause massive DoS without semantic distortion. Paper: https://arxiv.org/abs/2608.25276

### Trace Integrity (2608.26036) — Beyond Answer Accuracy for LLM Agents
Answer accuracy insufficient for agent reliability: CAIT (Correct Answer/Invalid Trace) rates of 45-55% on BIRD Mini-Dev show benchmark-correct answers often come from invalid computation. Structure Gap: natural language reasoning doesn't reliably specify operator-level programs. Execution contracts operationalize Trace Integrity with auditable, editable, reusable verification artifacts. Key insight: answer accuracy and trace validity are distinct evaluation signals — current benchmarks miss the majority of silent computation failures. Paper: https://arxiv.org/abs/2608.26036

### PeakBench (2608.24509) — Resource-Aware Tool Invocation in LLM Agents
cs.AI/cs.SE | TLDR top 5. Existing agent benchmarks evaluate tool selection under serial execution — miss parallelization and resource scheduling. PeakBench benchmarks executable multi-tool workflows with dependency annotations and resource profiles. Two-part evaluation: logical planning vs physical scheduling separately. Key finding: strong logical planning does NOT predict safe parallel execution under resource constraints. Resource info exposure reduces avoidable overflows. Paper: https://arxiv.org/abs/2608.24509

### Expert-Informed Skill Prompting (2608.25579) — Cross-Dataset Stability
Chinese metaphor identification across CMRE Test, CCIME, CMC datasets. Four conditions: BERT-FT, LLM-FT (QLoRA), zero-shot prompting, zero-shot with frozen procedural Skill. Skill-ZS has highest external floor (82.64) and smallest cross-dataset range (4.08 points) vs fine-tuning's higher mean but larger range. Key insight: expert procedural prompting is more robust across datasets than task-specific fine-tuning. Paper: https://arxiv.org/abs/2608.25579

### Unsupervised Post-Training Survey (2608.24982) — 80 Methods Catalogued
Findings of EMNLP 2026. Catalog of 80 strict UPT methods (signal from model artifacts, not external oracle). Input Visibility × Update Persistence framework maps deployment regimes. Key insight: recursive error amplification risk is real — signal choice determines whether UPT improves model or amplifies error. Paper: https://arxiv.org/abs/2608.24982
