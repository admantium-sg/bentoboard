## New Insights:

### Attic-KV: Self-Quiz KV Cache Compression — Rehearse Everything, Remember Nothing
**arXiv:2610.12133** (Oct 8, 2026) — cs.CL, cs.LG
- Prevailing approach: score KV entries by rehearsal (model rereads context, keeps attended entries)
- Core finding: under tight budgets this assumption backfires — at 3% keep ratio, rereading whole context keeps only 31.5/96.5 on RULER; on LongBench it falls below methods that rehearse nothing at all
- Cause: rereading spreads budget across whole context, so the answer's own entries survive at little more than chance
- Fix: "rehearse what will be read" via self-quizzing — model quizzes itself with Q&A pairs that quote the context, alongside anchor tokens in content-adaptive amount
- Attic alone is best training-free method across 8 settings on RULER and LongBench; raises KVgrad by 17.1 points, RestoreKV+ by up to 28.1 points
- 41.9 points over full rereading at 3% keep ratio
- Key insight: a cache remembers more by testing itself than by rereading — self-quizzing is a structural advantage over passive rehearsal
- Paper: https://arxiv.org/abs/2610.12133

### Symmetry-Aware Cross-Layer Value Cache Compression
**arXiv:2610.12338** (Oct 8, 2026) — cs.CL, cs.LG
- KV caches dominate memory at long context lengths; inter-layer cache similarities represent underutilized capacity
- Symmetry-aware value cache merging: reduces cache memory without architectural changes or performance degradation
- Composes with existing techniques — achieves higher compression ratios when combined with high-ratio quantization or key cache pruning
- Key insight: value cache has major underutilized capacity; merging across layers is a simple, architecture-agnostic direction for scaling context windows under memory constraints
- Paper: https://arxiv.org/abs/2610.12338

### All Verdicts are Not Equal: Comprehensive LLM-as-Judge Reliability Audit
**arXiv:2610.12083** (Oct 8, 2026) — cs.CL, cs.AI (Accepted at AACL IJCNLP 2026)
- LLM-as-Judge is standard NLP evaluation paradigm but systemic reliability is poorly understood
- Six frontier models tested across four benchmarks, five prompt formats, two presentation orders, three temperatures, ten repetitions
- Severe vulnerabilities: verdicts change across identical replications at temperature zero; position-order swaps flip majority of verdicts on challenging tasks
- Most deterministic judge achieves perfect consistency by trivially repeating incorrect verdicts — agrees with ground truth only 51% of the time
- Introduces trustworthy verdict rate (T): unified metric capturing reproducibility, order-invariance, and accuracy simultaneously
- Position bias imposes theoretical upper bound on accuracy; reliability is item-specific, not model-level
- Shifting from pairwise win-rate to holistic rubric scoring improves trustworthiness more than any single-format prompting intervention
- Key insight: LLM-as-Judge is far from deterministic ground truth; single-verdict evaluations are unreliable and potentially misleading
- Paper: https://arxiv.org/abs/2610.12083

### Legal Chain-of-Thought Is Not Faithful: Counterfactual Audit
**arXiv:2610.12361** (Oct 8, 2026) — cs.AI, cs.CL, cs.CY
- When explicitly required to justify a verdict by naming governing authority, models name the correct one in 66.7%-100% of generations
- But verdict-swap sensitivity is far less consistent: 0.0%-21.7% on CaseHOLD, 30.0%-76.7% on ECHR/SCOTUS, 43.3%-50.0% on ContractNLI
- Neither scale nor purpose-built legal-reasoning models close this gap
- Red-teaming: compliance with adversarial instructions (73.3%-96.4%) exceeds verdict-swap sensitivity by wide margin — holding without exception across model rankings
- Naming a legal authority is a poor proxy for verdict dependence; same verdict is separately vulnerable to adversarial manipulation
- Key insight: chain-of-thought citations in legal reasoning are not faithful indicators of logical reliance — legal CoT is post-hoc justification, not causal reasoning
- Paper: https://arxiv.org/abs/2610.12361

### LLM-BlockFE: Offline Feature Engineering for Long Text Without Inference Cost
**arXiv:2610.12390** (Oct 8, 2026) — cs.LG, cs.CL
- Industrial risk control: unstructured text contains valuable info, but requiring LLM for every real-time input is impractical
- LLM-BlockFE: LLM-guided offline feature construction — converts long text into executable feature programs, avoiding LLM calls during online inference
- Block-level rollback mechanism + depth-calibrated credit allocation + interleaved multi-trajectory search
- Across two public + two private datasets: absolute AUC improvements of 0.0069-0.0358 over strongest baseline
- Five deployed financial risk-control applications: absolute KS improvements of 0.02 to 1.56 percentage points
- Key insight: offline feature program search with block-level rollback eliminates per-request LLM overhead while preserving structured extraction quality
- Paper: https://arxiv.org/abs/2610.12390

### LLM Turnover Undermines AI-Assisted Scientific Writing Screening
**arXiv:2610.11599** (Oct 8, 2026) — cs.CL, cs.AI, cs.CY, cs.DL, cs.SI
- Journals screen manuscripts for LLM-written text; reliability depends on fixed model versions while actual versions keep changing
- 4,000 pre-ChatGPT PNAS abstracts paired with rewrites by 23 LLM versions (June 2023 – August 2026)
- Detectors trained only on past versions collapse at generational boundaries: catch >99% just before boundary, only 3.8% immediately after
- Two realistic screening scenarios: cover all 23 versions → either flag 1 in 8 human-written abstracts OR miss 1 in 3 rewrites of newest version
- Commercial detector missed most rewrites just after generational boundary while flagging almost no human-written abstracts
- Vocabulary differences between versions largely track where detection transfers and where it fails
- Key insight: LLM-assisted writing detection is fundamentally unstable across model turnover — benchmark accuracy should be treated as provisional pending per-version re-verification
- Paper: https://arxiv.org/abs/2610.11599

## Trend Analysis

**KV Cache Efficiency:** Two complementary papers on same day — Attic-KV (self-quizzing rehearsal) and symmetry-aware value cache merging. Both address memory-constrained long-context scenarios from different angles. The "desirable difficulties" principle from cognitive science is now being applied to KV cache management.

**Evaluation Reliability:** LLM-as-Judge and legal CoT papers converge on same theme: generated text quality ≠ causal reasoning quality. Citation of authority and verdict consistency are decoupled phenomena. This has implications for how we use CoT as evidence.

**LLM Writing Detection:** Model turnover is a structural threat to detection reliability. Policy implication: benchmark accuracy is provisional, must re-verify per release.

**Model Ecosystem:** FMRT top 3 reshuffling (Grok 4.7 enters), DeepSeek V4 Flash enters top 10; BenchLM top 10 scores all jumped significantly — possible methodology update. Composite fine-tunes combining multiple frontier models signal active multi-model distillation.

**Quantization:** Ternary recovering (4.46M, up from 4.39M), Qwen GSQ variants stable. Underdog-Saluki viral growth 4x in 3 days — independent small model space heating.
