## Task 1: arXiv Papers (cs.CL/cs.LG/cs.AI)

### Notable Papers from July 14 Submissions

**ARMT — Associative Recurrent Memory Transformer (2607.11614)**
Context extension via associative memory. Key result: 30% fewer FLOPs while preserving baseline performance within original context. Processes inputs beyond original context limits without degradation, generalizes to out-of-distribution context lengths. Combines continued pretraining + synthetic long-context data + curriculum learning. Practical constant-memory alternative to standard transformer quadratic scaling.

**Structured Thoughts (2607.10386)**
CoT efficiency via alternating `<try>` and `<outcome>` blocks — enables granular context pruning by treating reasoning steps as separate nodes. Dynamically prunes completed or failed branches while preserving successful paths. Outperforms conventional structured prompting that treats reasoning as monolithic. Highly relevant to chain-of-thought efficiency.

**MET-D: Multilingual Ethics with Theory-Grounding (2607.11736)**
COLM 2026. Two-step prompting: select situation- and culture-specific moral grounds, then reason in native language. Self-distillation requires no external supervision. +3.71pts macro-F1 on MCLASH, +4.23 on MMoralExceptQA average across Qwen3-4B/8B and Gemma3-4B; +12.94pts peak for Malay on Qwen3-8B. Native-language reasoning +62.13pts average. Beneficial grounds differ systematically across cultures — culture-specific grounding outperforms universal approaches.

**AdvancedMathBench / ProverBench (2607.11849)**
Graduate- and doctoral-level math proof benchmark. 296 problems with automatic verification pipeline trained on expert annotations. ProverBench + VerifierBench (888 proof trajectories). Addresses gap between high-school/olympiad math benchmarks and true advanced reasoning.

**Hallucination Detection — Financial QA (2607.11414)**
Linear probes on residual stream detect confident hallucinations in financial QA. 15-23% of all-confident-agreed answers are wrong on FinQA. Probes achieve 0.68-0.77 AUROC vs best baselines at 0.55-0.63 across Qwen3-8B, Llama-3.1-8B, Gemma-2-9B. 8-resample agreement as behavioral confidence signal. Probing as triage mechanism for human review in high-stakes applications.

**Hallucination Detection — Legal Citations (2607.11127)**
Legal citation hallucination benchmark. Models generate plausible but non-existent case citations. Domain-specific failure mode distinct from financial QA.

**ResearchQA (2607.11074)**
Citation-grounded scientific QA. Scientific claims verified against cited sources.

**GEIS: Generation-Evaluation-Improvement Loop (2607.11503)**
Agent skills for long-form article generation. Request → Plan → Draft → Audit → Refine → Deliver pipeline. +8.0pts over baseline on 100-point PDF rubric. Patched writing skill raises average 82.90 → 86.95 across 20 Wikipedia Featured Article topics. Declarative skill composition enables inspectable, modular improvement.

**On-Policy Distillation Framework OPD (2607.11012)**
Easy-to-use framework for distilling LLM reasoning. Simple, general approach to transferring reasoning capabilities.

**Theory of Mind: EAST Task (2607.11363)**
Epistemic Asymmetry Schelling Task — two-player dialogue game requiring convergence on semantic Schelling points. Significant capability gap: only frontier models navigate varying epistemic demands. Coordination failures driven by epistemic tracking errors (conflating private knowledge with mutual knowledge). High performance on static benchmarks, critical bottleneck on social reasoning.

**Metacognition in LLMs (2607.11881)**
Comprehensive survey of LLM metacognition: measurement methods, benchmarks, elicitation techniques, applications, open questions. GitHub: github.com/yale-nlp/LLM-Metacognition
