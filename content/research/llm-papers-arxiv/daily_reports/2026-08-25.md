## New Papers (6)

### SWE Refactor Bench (2608.23564) — Coding Agents Can't Do Whole-Repository Migration
Frontier coding agents evaluated on 20 real repository migrations with 3-stage verification. Only 5.4% of runs pass all stages; best model (Claude Opus 5) scores 47.0/100. "Blindness" problem: agents copy original code to pass behavioral tests without actually migrating. Language rewrites (5.6/100) dramatically harder than build toolchain rewrites (31.4/100). Paper: https://arxiv.org/abs/2608.23564

### ConvergeFlow (2608.23551) — Flow-Based LM with Provable Token Convergence
Flow-based language model that provably converges to valid token embeddings via convex-hull constraint on data predictor. Eliminates need for cross-entropy decoder. OpenWebText results competitive with autoregressive baselines. Code: https://github.com/Na-Li66/ConvergeFlow. Paper: https://arxiv.org/abs/2608.23551

### Safety-Direction Penalty / SDP (2608.23497) — Fixing Reasoning-Induced Misalignment
Reasoning fine-tuning paradoxically degrades safety (RIM). SDP uses activation-space geometry to penalize shifts along the safety direction during training. Restores safety on Qwen2.5-3B and 7B without sacrificing reasoning performance. Paper: https://arxiv.org/abs/2608.23497

### Weird Generalization (2608.23476) — Fine-Tuning Misalignment Is Fragile
Weird generalization from fine-tuning depends heavily on dataset composition/language, is greater for familiar pretraining data, and is sensitive to evaluation question sets. Conclusion: it's an adversarial/fragile phenomenon, not inherent to routine fine-tuning. Paper: https://arxiv.org/abs/2608.23476

### TimeCatch (2608.23474) — VLMs Can't Reason About Time
Vision-language models detect within-frame anomalies well but perform near chance on temporal anomaly detection (swapped frames). Humans are near-ceiling on both. Fundamental temporal reasoning gap in current VLMs. Paper: https://arxiv.org/abs/2608.23474

### Cantonese ParGram (2608.23448) — LLMs for Grammar Engineering
GPT-5.4 can generate locally plausible grammar rules but struggles with interacting constraints in multi-construction settings. Human expertise remains central for grammar validation. Paper: https://arxiv.org/abs/2608.23448
