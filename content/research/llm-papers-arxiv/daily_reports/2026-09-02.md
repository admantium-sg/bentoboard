# Daily Report — 2026-09-02

## New Insights Summary

### 1. LLM-as-Judge Internal Mechanisms Revealed (EMNLP 2026)
**arXiv:2609.01604** — Mechanistic study of how LLM evaluators rate summaries. Two-stage evaluation pipeline: below layer 15, attention performs local error comparison and routes result; above it, MLP integrates and writes rating. Decision crystallizes in residual stream at late layer (L=26 Themis, L=25 Prometheus). Key insight: fine-tuning sculpts existing substrate rather than building pipeline from scratch — base model reproduces routing architecture but not stage separation.

### 2. Why Safety Alignment Collapses Under Benign Fine-Tuning (EMNLP 2026 Findings)
**arXiv:2609.01455** — Fisher-geometric explanation: safety Fisher is low-rank; alignment flattens safety geometry while preserving output-routing pathway. After 100 benign examples, output-side MLP modules selectively re-sharpen, causing asymmetric collapse: attack success rate skyrockets while general utility degrades mildly. Few safety examples restore refusal — internal safety representations are preserved. LoRA/ASAM delay early collapse but weaken at scale. Key insight: safety failure = output-routing disruption, not gradient conflict.

### 3. Verbal Reinforcement Learning: First Unified Taxonomy
**arXiv:2609.01597** — Natural language emerging as primary feedback channel for language agents. Three pillars: (1) Language as Grounding Signal — defines task/goal structure; (2) Language as Deliberative Feedback — guides test-time reasoning without parameter updates; (3) Language as Learning Signal — shapes model parameters via training. Key insight: VRL is reshaping agent development; this taxonomy provides the organizing framework the field lacked.

### 4. CordisBench: Lifecycle Reasoning for Dynamic Agent Harnesses
**arXiv:2609.01600** — 1,200-question benchmark testing component lifecycle reasoning in agent harnesses (plugin changes, dependencies, cleanup). Models handle small systems well, degrade with more interactions (especially final state prediction and teardown ordering). GPT-5.6 Luna uses ~3,000 reasoning tokens/question at medium effort. Key insight: independent finite reference semantics agree with Cordis execution on all 528 executable questions — formal methods can replace costly inference for controlled instances.

### 5. StudentSim: LLM-Based Student Simulators for AI Tutoring
**arXiv:2609.01591** — Pooled training + per-student specialization creates individualized simulators. Outperforms GPT-5.4 on both behavioral fidelity (F=0.51 vs 0.23) and guidance responsiveness (R=0.91 vs 0.72) in chess. As tutor RL reward model, produces tutors rated more accurate, better-guided, and more personalized. Key insight: sparse per-student data can be turned into effective simulators; proof-of-concept for simulator-based tutor development.

### 6. Difficulty-Aware Document VLM: 80% Cost Reduction
**arXiv:2609.01575** — MoE VLM (35B total / 3B active) fine-tuned on in-house + curated open data. Fits on single H100. Leads all deployable non-reasoning baselines up to 10x larger. Quality-adjusted cost: 80%+ reduction vs human baseline, 50%+ vs best open-source. Key insight: efficiency + curation + quality-adjusted economics beats raw scale for document understanding.

### 7. Latent Recurrent Thoughts (LRT): Continuous-Space Reasoning with Frozen LLMs
**arXiv:2609.01117** — Performs reasoning in continuous embedding space instead of discrete token space. Frozen LLM + small recurrent reasoner iteratively refines latents. Outperforms prior frozen-decoder continuous methods AND non-thinking CoT prompting at small fraction of compute. Works on Countdown-4, Sudoku, HumanEval, MBPP, StrategyQA. Key insight: decoupling depth of computation from model size via recurrent refinement.

### 8. DroneCATS: MLLM Drone Control Reveals Protocol Adherence Gap
**arXiv:2609.01404** — MLLM-as-VLA-agent for drone control without fine-tuning. Small open models navigate successfully but fail by premature arrival declarations or protocol violations. Key insight: the gap between deployable edge models and frontier models is NOT navigation — it's the discipline to sustain declared protocols and emit correct terminating actions.
