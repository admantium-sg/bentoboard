**Key benchmark status for 2026:**
- **Saturated** (no longer useful for frontier comparisons): MMLU, HumanEval, MBPP, HellaSwag, WinoGrande, DROP
- **Active**: MMLU-Pro (knowledge, high-80s), GPQA-Diamond (reasoning, high-70s), ARC-AGI-2 (reasoning, mid-60s), Humanity's Last Exam (frontier, below 20%), LiveCodeBench (coding, anti-contamination), SWE-bench Verified (coding agents, low-to-mid 70s), WebArena (agentic, high-40s)

**Critical insight:** MMLU is now useless for comparing frontier models. Frontier clusters in low-90s on a benchmark designed for 2020-era models. MMLU-Pro (10-choice, mandatory CoT) replaced it. Similarly, HumanEval/MBPP are saturated — use LiveCodeBench instead (structurally contamination-resistant via post-training-cutoff problem sourcing).

**Editor's recommended 2026 stack:** MMLU-Pro (knowledge), GPQA-Diamond (reasoning), SWE-bench Verified (coding agents), Chatbot Arena (human preference), MMMU (multimodal knowledge).

### 2. RL-Based Reasoning Training: DAPO and R1-Zero-Like Methods Ascendant

The most influential ML papers of 2026 so far show a clear focus on reinforcement learning for reasoning:

**DAPO (arxiv:2503.14476)** — "An Open-Source LLM Reinforcement Learning System at Scale" from Tiger AI Lab. Unlike closed implementations, DAPO publishes four key techniques that make large-scale LLM RL work. Currently #1 most influential ML paper of 2025 by citation.

**R1-Zero-Like Training analysis (arxiv:2503.20783)** — Critical examination of base model selection and RL algorithm choice in scaling reasoning-oriented RL without SFT. Shows that the base model matters enormously for downstream reasoning quality.

**Open-Reasoner-Zero (arxiv:2503.24290)** — First open-source implementation of large-scale reasoning-oriented RL training on base models, emphasizing scalability and accessibility.

**SimpleRL-Zoo (arxiv:2503.18892)** — Investigated zero RL training across 10 diverse base models (LLaMA3-8B through Qwen2.5 32B). Findings suggest base model family matters more than size for reasoning RL.

**Implication:** The field has moved from "can we do RL for reasoning?" to "how do we do it properly?" with base model selection emerging as a critical hyperparameter.

*Sources: [DAPO paperdigest](https://www.paperdigest.org/reader/?paper_id=arxiv-2503.14476), [R1-Zero paperdigest](https://www.paperdigest.org/reader/?paper_id=arxiv-2503.20783), [Open-Reasoner-Zero paperdigest](https://www.paperdigest.org/reader/?paper_id=arxiv-2503.24290)*
