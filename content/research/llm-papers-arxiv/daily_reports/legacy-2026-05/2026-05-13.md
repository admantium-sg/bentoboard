### LongMemEval-V2: Evaluating Long-Term Memory for Web Agents

**Paper:** *Evaluating Long-Term Agent Memory Toward Experienced Colleagues*
**arXiv:** [2605.12493](https://arxiv.org/abs/2605.12493) [cs.CL] — submitted May 13, 2026 (Work in Progress)

Introduces LongMemEval-V2 (LME-V2), a benchmark for evaluating memory systems in specialized web environments. Contains 451 manually curated questions across five core memory abilities: static state recall, dynamic state tracking, workflow knowledge, environment gotchas, and premise awareness. Uses context-gathering formulation with up to 500 trajectories and 115M tokens per question.

Key findings:
- AgentRunbook-R (RAG-based) achieves 48.5% average accuracy
- AgentRunbook-C (coding agent in augmented sandbox) achieves 72.5%, outperforming strongest RAG baseline by 24pp
- Off-the-shelf coding agent baseline achieves 69.3%
- Coding agent methods have high latency costs but advance the accuracy-latency Pareto frontier

*Source: [arXiv:2605.12493](https://arxiv.org/abs/2605.12493)*

### Task-Adaptive Embedding Refinement via Test-Time LLM Guidance

**Paper:** *Task-Adaptive Embedding Refinement via Test-time LLM Guidance*
**arXiv:** [2605.12487](https://arxiv.org/abs/2605.12487) [cs.CL, cs.IR, cs.LG] — submitted May 12, 2026

Proposes LLM-guided query refinement paradigm that extends embedding model usability to challenging zero-shot search and classification tasks. Refines query embeddings using feedback from a generative LLM on a small set of documents.

Key findings:
- Consistent gains across all models and datasets
- Up to +25% relative improvement in literature search, intent detection, key-point matching, and nuanced query-instruction following
- Expands practical settings where embedding models can be effectively deployed
- Code released at: https://github.com/IBM/task-aware-embedding-refinement

*Source: [arXiv:2605.12487](https://arxiv.org/abs/2605.12487)*

### The Algorithmic Caricature: LLM Political Discourse Analysis

**Paper:** *The Algorithmic Caricature: Auditing LLM-Generated Political Discourse Across Crisis Events*
**arXiv:** [2605.12452](https://arxiv.org/abs/2605.12452) [cs.CL, cs.AI, cs.CY] — submitted May 12, 2026

Paired corpus of 1,789,406 posts across nine crisis events (COVID-19, Jan. 6 Capitol attack, 2020/2024 elections, Dobbs/Roe, BLM protests, etc.). Compares observed discourse with synthetic discourse generated for same context.

Key findings:
- Synthetic discourse is fluent but population-level unrealistic
- Generally more negative and less dispersed in sentiment
- Structurally more regular, lexically more abstract than observed discourse
- The "Caricature Gap" varies by event: larger for fast-moving/decentralized crises, smaller for formal/institutionally mediated events
- Main limitation is reduced population realism, not grammar/fluency

*Source: [arXiv:2605.12452](https://arxiv.org/abs/2605.12452)*

### CLM Detour Improves Encoder Continued Pretraining

**Paper:** *A Causal Language Modeling Detour Improves Encoder Continued Pretraining*
**arXiv:** [2605.12438](https://arxiv.org/abs/2605.12438) [cs.CL, cs.AI] — submitted May 12, 2026

Shows that temporarily switching from Masked Language Modeling (MLM) to Causal Language Modeling (CLM) — followed by short MLM decay — improves downstream performance when adapting encoders to new domains.

Key findings:
- CLM detour outperforms MLM baselines by +1.2-2.8pp (French biomedical) and +0.3-0.8pp (English biomedical)
- CLM's dense supervision impacts low transformer layers (0-7) far more than MLM
- Freezing low layers during CLM eliminates downstream benefit; freezing mid layers preserves it
- Changes persist through MLM decay phase and scale with model capacity
- Released ModernCamemBERT-bio and ModernBERT-bio as state-of-the-art biomedical encoders

*Source: [arXiv:2605.12438](https://arxiv.org/abs/2605.12438)*

### Geometric Factual Recall in Transformers

**Paper:** *Geometric Factual Recall in Transformers*
**arXiv:** [2605.12426](https://arxiv.org/abs/2605.12426) [cs.CL] — submitted May 12, 2026

Theoretical and empirical account of geometric memorization in transformers — where learned embeddings encode relational structure directly rather than storing facts in weight matrices.

Key findings:
- Single-layer transformer can memorize random bijections with logarithmic embedding dimension (not linear)
- MLP acts as relation-conditioned selector via ReLU gating, not associative key-value mapping
- Multi-hop queries show provable capacity-depth tradeoff with and without chain-of-thought
- Empirically, gradient descent discovers precisely the predicted structure
- MLP transfers zero-shot to entirely new bijections when subject embeddings are re-initialized — reveals generic selection mechanism, not memorized facts

*Source: [arXiv:2605.12426](https://arxiv.org/abs/2605.12426)*
