## Task 1: arXiv Papers (Chain-of-Thought, Prompt Engineering, Efficiency)
19 papers analyzed from June 12 submissions on cs.CL, cs.LG, cs.AI.

### Key Findings:

1. **Operadic Consistency** (2606.13649) — cs.CL, cs.LG
   - Label-free signal for compositional reasoning failures using operad theory
   - Pearson r ∈ [0.86, 0.94] across 12 LLMs (4B–671B) on 4 multi-hop QA datasets
   - Only signal with r ≥ 0.85 uniformly; CoT-SC drops to r ≈ 0.45 on harder datasets
   - AUARC lifts of +0.086 to +0.096 at equal-cost K=3 budget
   - Key insight: Compositional reasoning failures detectable without labels via operadic consistency

2. **Operads for Compositional Reasoning** (2606.13634) — cs.CL, math.CT
   - Mathematical foundation for question decomposition using operads
   - QA models as algebras over the questions operad Q
   - Key insight: Operads are the natural mathematical home for question decomposition

3. **RA-RFT: Retrieval-Augmented Reinforcement Fine-Tuning** (2606.13680) — cs.CL, cs.AI
   - Teaches LLMs to reason by analogy via reasoning-aware retrieval
   - Retriever ranks by expected reasoning benefit, not semantic overlap
   - AIME 2025: +7.1 over GRPO for Qwen3-1.7B, +2.8 for Qwen3-4B
   - Key insight: Reasoning-aware retrieval is orthogonal to reward design improvements

4. **Recursive Agent Harnesses / RAH** (2606.13643) — cs.CL
   - Harness recursion: code-first extension of model recursion (RLMs)
   - Parent agent spawns subagent harnesses in parallel for fine-grained workloads
   - GPT-5: 71.75% → 81.36% on Oolong-Synthetic (up to 4M tokens); Claude Sonnet 4.5: 89.77%
   - Key insight: Harness recursion substantially improves long-context reasoning without model change

5. **HyperTool** (2606.13663) — cs.CL
   - Beyond step-wise tool calls; unified executable MCP-style interface
   - Folds deterministic tool subroutines into single outer call
   - Qwen3-32B: 15.69% → 35.29%; Qwen3-8B: 9.93% → 33.33% on MCP-Universe
   - Key insight: Execution-granularity mismatch is a major tool-use bottleneck

6. **EvoArena + EvoMem** (2606.13681) — cs.CL
   - Benchmark for dynamic environments; current agents score 39.6% average
   - EvoMem: patch-based memory; +1.5% on EvoArena, +6.1% on GAIA, +4.8% on LoCoMo
   - Key insight: Agent evaluation must model evolution; static benchmarks miss critical failures

7. **FORGE: Fake Online Recommendations** (2606.13610) — cs.CL, cs.AI
   - Single polluted page: fooled rates up to 27%; top-3 replacement: 73.8%
   - Reasoning generates spurious social proof to justify false recommendations
   - Key insight: Reasoning models are more vulnerable to content pollution, not less

8. **Influcoder** (2606.13668) — cs.CL
   - Distills decoder gradient influence rankings into encoder for data attribution at scale
   - Key insight: Influence-based data attribution requires efficiency beyond traditional methods

9. **Adaptive Compression for Time Series LLMs** (2606.13624) — cs.CL
   - Asymmetric token compression: frequency-domain TS token compression + progressive prompt reduction
   - Up to 7.68x inference acceleration; 78% of settings show performance gains
   - Key insight: TS and prompt tokens have fundamentally different information structures

10. **SkMTEB: Slovak Text Embedding Benchmark** (2606.13647) — cs.CL, cs.AI, cs.LG
    - 31 datasets across 7 task types; e5-sk-small (45M) and e5-sk-large (365M)
    - 62% size reduction with competitive performance
    - Key insight: Vocabulary trimming enables efficient local embeddings for under-resourced languages

11. **Ontology Memory-Augmented ASR** (2606.13464) — cs.CL, cs.AI
    - Structured ontological memory for context-grounded ASR correction
    - Improves in 9/10 paired backbone-setting combinations
    - Key insight: ASR correction requires structured memory, not raw history concatenation

12. **ProReviewer** (2606.13349) — cs.CL
    - 8B scientific peer review agent with structured review log + proactive investigation
    - Outperforms prompt-based frontier LLMs by 39%
    - Key insight: Proactive investigation via structured workspace enables small models to beat frontier

13. **S-GBT: Smooth Growth Bound Tensor** (2606.13439) — cs.CL, cs.LG
    - Second-order certified robustness; up to 23.4% improvement in certified robust accuracy
    - Key insight: Curvature-aware training (controlling gradient variation) essential for robustness

14. **ArogyaSutra** (2606.13572) — cs.CL, cs.AI
    - Multi-agent medical reasoning in 7 Indic languages; 31 body systems, 6 imaging modalities
    - Actor-critic framework with tool grounding + dual-memory mechanisms
    - Key insight: Multilingual medical reasoning requires agentic multi-turn reasoning with domain training

15. **Grounding VLA in Scientific Labs** (2606.13578) — cs.CL
    - Existing VLA policies lack scientific lab exposure (instruments, protocols)
    - Key insight: Scientific lab execution requires domain-specific VLA training

16. **Query Embedding Interpolation** (2606.13537) — cs.CL — ACL 2026 Oral
    - Optimal mixing outperforms pure monolingual in 88/105 cases
    - English dominance asymmetry; mixing beneficial for non-English indices
    - Key insight: Mixed-language retrieval sensitivity is structured and predictable

17. **Audio-LLM for S2ST Filtering** (2606.13507) — cs.CL — INTERSPEECH 2026
    - Rank-to-Distill: audio-LLM filters speech-to-speech training data without manual labels
    - Up to +1.4 ASR-BLEU for end-to-end S2ST
    - Key insight: Audio-LLMs can autolabel noisy S2ST data at scale

18. **Low-Latency Game Commentary** (2606.13322) — cs.CL — IJCAI-ECAI 2026 Demo
    - Parallel text generation reduces inter-utterance silence from 9.6s to 0.3s
    - Key insight: Accumulated waiting time is the real bottleneck in streaming audio generation

19. **Algerian Dialect Rumour Detection** (2606.13411) — cs.CL
    - F1 0.84 with hybrid approach; domain-specific pre-training > model size
    - Key insight: Social media-trained models outperform larger formal-corpus models for dialect NLP
