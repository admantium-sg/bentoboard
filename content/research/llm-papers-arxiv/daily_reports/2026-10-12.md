## 📄 arXiv Papers (17 papers, Oct 9 submissions)

### 🔬 Reasoning & Self-Improvement

**RSI-Anything** (2610.13912) — Recursive self-improvement via predictive world models (JEPA-Anything). Lab planning: 21.80% → 46.01% across 5 policy versions. Code repair: 26.3% → 31.2%. GUI tasks: -39.4% actions while improving completion. Key enabler: retained system updates + predictive world models.

**Evo²** (2610.13025) — Weight-harness co-evolution. Dual-role pipeline: same policy as Proposer + Reflector. Polyglot: 82.1% (vs 62.6% baseline). GPT-5-mini agent: 24.4% → 48.3%. Weight-harness co-evolution >> weight-only or harness-only.

**UPTURN** (2610.13672) — Self-correction via learned intervention positioning. 130K-param MLP head learns WHERE to inject. Key insight: inline token injections FAIL; NEW USER TURN injection succeeds. No LLM fine-tuning required. Transfers across reasoners without retraining.

### ⚡ Efficiency

**PreSTO** (2610.13171) — Prefetching for power sampling. MH proposals prefetched in batch; kernel provably unchanged. 1.71×-2.33× speedups across PowerMH variants. LCB V6: 1.25×-1.37× additional gain from predictive traversal.

**RAMP** (2610.13041) — Recurrent adaptive mixed precision. Early recurrent steps in low precision; terminal refinement in high precision. 13.9% latency reduction on H100.

**KV-Repurpose** (2610.13060) — Non-prefix KV-cache reuse. 63.9% hit rate vs 3.3% prefix caching (RAG workload, 30GB cache). Even 1TB cache: prefix only 17.9%. Open-source vLLM-based.

### 🧠 Memory & Architecture

**T2Mem** (2610.13348) — Test-time memory construction. Defers memory building to inference; progressively builds along reasoning. Outperforms strong baselines; reduces construction overhead. Code: OpenBMB/T2Mem.

### ⚖️ Legal & Domain-Specific

**Legal KG Multi-Task** (2610.13722) — KG-guided multi-task pre-training for German traffic law. Zero-shot transfer to Austrian regulations: 3.4% → 15.8% gains. LexGLUE: improves 4/7 benchmarks.

**Legal KG RAG** (2610.13695) — Structure-driven KG for verifiable legal RAG. Structural parsing + KG-guided retrieval improves citation accuracy.

**Clinical Radiology** (2610.13059) — CliQ-RRG: disease-aware visual-textual alignment + GraphRAG. QA-style radiology reports. Accepted EMNLP Findings 2026.

**Romanian LM** (2610.13134) — Neurograf v1: Romanian-first model family (160M-6B). 69.89% on Romanian WWTBM (6B). Compute-optimal exponent ~0.423.

### 📊 Evaluation & Metrics

**BLiMPPI** (2610.13607) — 12K NPI minimal pairs in 33 languages. Multilingual models struggle with lower-resource languages.

**Speech LLM Stereotyping** (2610.13550) — BASIS-Bench: personalization vs stereotyping in speech LLMs. Explicit labels improve personalization BUT amplify stereotypes.

**RSA Critique** (2610.13476) — Changing which categories are compared moves gap 2× more than the effect being measured. Rankings sensitive to experimental choices.

### 🌐 Data & Infrastructure

**POrchestra** (2610.13485) — Proactive agentic orchestration. Sub-agents request harness adjustments dynamically. OPOD: on-policy distillation from revision requests. +9.1% relative improvement; +10.0% with OPOD.

**Web Crawling** (2610.13321) — Host-aware crawling for LLM pretraining. Sampling few pages + fetching more from high-scoring hosts = several times more high-quality pages per fetch. Tens of millions of high-quality pages remain uncrawled.

**Abstention** (2610.13821) — Learned answer selection for QA. TriviaQA: coverage 20.2% → 30.9%; error rate 23.0% → 14.5%. Learned selection viable; reliable abstention across datasets still unresolved.

## 💡 Key Takeaways

1. **Self-improvement is getting architectural** — RSI-Anything (predictive world models) and Evo² (weight-harness co-evolution) both show that combining multiple adaptation mechanisms outperforms isolated approaches

2. **KV-cache reuse is ripe for disruption** — 63.9% vs 3.3% hit rate demonstrates segment-wise reuse could dramatically reduce RAG inference costs

3. **Self-correction via turn injection** — UPTURN's finding that new user turns redirect reasoning but inline tokens don't is a simple but powerful systems insight

4. **Smaller models trending** — Gemma 4 31B rising on FMRT; RAMP, KV-Repurpose, PreSTO all targeting efficiency gains

5. **OpenAI ahead on BenchLM reasoning** — GPT-6 Astra 93.4 vs Claude Opus 5.5 86.1; but Claude Fable 5 still #1 on FMRT (tournament format)
