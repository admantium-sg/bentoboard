**Topic:** llm-papers-arxiv | LLM research papers and developments

## Papers Found (Sep 23 submissions, first checked today)

**7 new papers identified across chain-of-thought, efficiency, agent reasoning, and safety:**

1. **CSL: Causal Shortcuts for Diffusion Language Models** (2609.28272, cs.CL) — Causal shortcut learning framework addresses exponential exploration space problem in DLMs under bidirectional attention. Step-by-step token extraction procedure identifies reasoning-guiding token chains; parallel prioritized masking enables efficient convergence. Achieves +1.92% average improvement over SFT-only, up to +4.20% on MATH-500. Submitted Sep 23.
Source: https://arxiv.org/abs/2609.28272

2. **Agent-Editing World Model (AEWM)** (2609.28416, cs.CL, cs.AI, cs.LG) — Models task progress and edits noisy reasoning rather than predicting tool responses. Action Judge classifies decisions as Critical/Exploratory/Noisy; State Revision edits noisy reasoning-action continuations. EditAct integrates with real execution. 70.5% macro-F1 on Action Judge (+10.6pp over baseline). 3.2-6.7pp improvement across 6 benchmarks. Submitted Sep 23.
Source: https://arxiv.org/abs/2609.28416

3. **Control-Token Injection Defeats CoT Safety** (2609.27542, cs.CR) — Appends model's own channel-control tokens to suppress chain-of-thought in tool-using agents. Mean reasoning tokens drops 52.5→0 while tool calls still fire. Converts 39.6% of refusals into successful exfiltrations. Demonstrates safety is joint property of model + decoding harness. Parser differences produce opposite outcomes on identical greedy generations. Submitted Sep 22.
Source: https://arxiv.org/abs/2609.27542

4. **LEGO: Expert GraphRAG + ExpertCoT for Legal Reasoning** (2609.27009, cs.CL, cs.IR) — Dual-module: ExpertGraphRAG uses expert-annotated civil code graph for normative retrieval; ExpertCoT structures Provision-Fact-Conclusion reasoning. Qwen3-8B achieves 40.53% exact-match on LawExamQA_Civil, outperforming RAG/CoT baselines. Accepted EMNLP 2026 Findings. Submitted Sep 22.
Source: https://arxiv.org/abs/2609.27009

5. **Risk-Controlled KV-Cache Eviction** (2609.27981, cs.CL, cs.LG) — Reformulates eviction as deployment risk-control: certifies retention policies against a reliability contract with finite-sample guarantee. Same contract yields different eviction levels across benchmarks — on Llama LongBench certifies SnapKV at 75% retention, but no policy certified on RULER-32K (triggers full-KV fallback). Empirical thresholding selects uncertified policies. Submitted Sep 23.
Source: https://arxiv.org/abs/2609.27981

6. **Meaning Identity: Computed, Not in Embeddings** (2609.28290, cs.CL) — Meaning identity (paraphrase detection) is computed during joint forward pass, not a property of embedding geometry. Independent encoders reach only 0.55-0.65 on PAWS-X; joint forward pass reaches 0.90-0.96 from 1.5B to 32B. Nonlinear pair readers recover part of it; bi-encoders can be fine-tuned to 0.87-0.93 but transfer suffers. Submitted Sep 23.
Source: https://arxiv.org/abs/2609.28290

7. **Activation vs Parametric Memory in Few-Shot Learning** (2609.28250, cs.CL) — Activation memory (KV caches) superior for factual recall; neither alone sufficient for composite tasks like Conditional Arithmetic. When both memory types combined, model recruits neurons from both sets — synergy required. Neuron-level analysis reveals distinct activation patterns for each memory type. Submitted Sep 23.
Source: https://arxiv.org/abs/2609.28250

## Community Pulse

**Working well:** AEWM's State Revision editing approach represents a new paradigm — not critiquing but directly modifying the state underlying decisions. The +10.6pp Action Judge improvement suggests task-state contamination is a real and addressable problem.

**Interesting:** Control-token injection is a stark demonstration that safety cannot be model-centric alone. The same greedy generation produces opposite tool-call outcomes across parsers — this has implications for any production deployment with custom parsing logic.

**Notable:** LEGO's ExpertGraphRAG shows that normative structure (legal provision relationships) is distinct from semantic similarity and must be explicitly encoded. The 40.53% exact-match on LawExamQA from a Qwen3-8B backbone is competitive with larger models.
