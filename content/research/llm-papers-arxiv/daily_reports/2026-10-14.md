## New Findings

### Tev-Gym: Scaling Long-Horizon Agentic Environments with Dense Progress Rewards
**arXiv:2610.18868** (Oct 13, 2026) — cs.CL, cs.AI, cs.CV, cs.LG
- Tev-Gym: first long-horizon agent training dataset with verifiable, dense, progressive rewards — 1,170 verified task environments across 7 domains
- Built on latent-world-first approach: constructs a latent world then progressively renders into agent-facing environment
- Tev-27B: matches GPT-6 Astra and Claude Opus 5 at Pass@5 on Agents' Last Exam
- Generalizes to Terminal-Bench 3.0/4.0, surpassing GLM 5.2 and Gemini 3.7 Flash
- Key insight: dense progress rewards solve sparse-reward problem for long-horizon agents
- Paper: https://arxiv.org/abs/2610.18868

### LLM Ensemble Gains: Decomposing Candidate Value, Diversity, and Aggregation
**arXiv:2610.18786** (Oct 13, 2026) — cs.CL, cs.AI
- Ensemble gains split into candidate value (CIV), additional-candidate contrast (DSV), and candidate-context contrast (CCV)
- Repetition gap Rep=-8.33pp between Duplicate and Single-slot controls on MultiHopRAG
- FRAMES stronger-panel: Rep=+9.67pp with matched controls
- Key insight: ensemble evaluations should state reference control before attributing gains
- Paper: https://arxiv.org/abs/2610.18786

### Reliable Memory from Unstable Growth: Curating Self-Written Agent Playbooks
**arXiv:2610.18427** (Oct 13, 2026) — cs.CL
- Problem: same procedure can write playbook that helps OR falls up to 69.6 points below no playbook
- Randomized Block Curation (RBC): measures lesson effects with randomized experiments
- Results: RBC raises success to 66.9 vs 55.5 (whole playbook), 54.1 (no playbook), 53.8 (agent judgment)
- Key insight: measure lesson effects empirically rather than relying on agent self-assessment
- Paper: https://arxiv.org/abs/2610.18427

### Do Factuality Methods Make LLMs More Factual? A Reproducibility Study
**arXiv:2610.18415** (Oct 13, 2026) — cs.CL, cs.AI
- First independent reproduction of 5 factuality alignment methods (PPO, GRPO, DPO, KTO)
- Key finding: NONE reproduces in full; on common benchmark, none significantly outperforms base model
- Root cause: rewards optimize for format/length/brevity rather than factuality
- Key insight: factuality alignment methods lack independent reproduction; current evaluation fragile
- Paper: https://arxiv.org/abs/2610.18415
