## Research Summary

Incremental research for August 3, 2026 covering arXiv cs.CL/cs.LG/cs.AI submissions from the July 31-August 3 batch, plus benchmark and community developments. 13 new findings (12 papers + 1 benchmark update).

## Key Findings (13 new)

### 1. TokTier: Stateful Tokenization Cuts Agentic Serving Latency by Up to 34%
**arXiv:2607.29678** (August 3, 2026) — cs.CL
- Stateful tokenization service for agentic LLM serving: emitted token IDs always identical to full reference tokenization
- At 94.1% fleet prompt-cache hit rate, tokenization reaches up to 64% of time to first token
- GPU full tokenization: 1M-character request in 0.87ms, up to 491x below HuggingFace
- With vLLM: median TTFT drops 16-34%, P99 drops 23%
- Under 50ms P99 objective: 1,821 req/s where 16-core stateless front-end saturates at 40
- Key insight: Tokenization is the dominant cost for agentic LLM serving — stateful incremental tokenization changes the calculus entirely
- Paper: https://arxiv.org/abs/2607.29678

### 2. ResKV: Better KV Cache Compression via Residual Attention Reconstruction
**arXiv:2607.29591** (July 31, 2026) — cs.CL
- ResKV divides fixed KV budget into exact main cache + compact residual cache
- Residual entries participate in same softmax normalization — restores both numerator AND denominator mass
- Dynamic gate adjusts residual contributions per-query at decode time
- Evaluated on LongBench and RULER across multiple backbones
- Key insight: KV cache compression must reconstruct omitted attention contributions in the softmax denominator — not post-hoc correction
- Paper: https://arxiv.org/abs/2607.29591

### 3. SESA: Self-Evolving Search Agents with Persistent Skill Memory
**arXiv:2607.29468** (July 31, 2026) — cs.AI
- Bidirectional loop: challenger poses problems, solver retrieves skills, failures distilled into reusable skills
- Updated memory changes solver behavior → changes challenger reward → changes future problem distribution
- 1.2-3.2 points improvement over SSP across 7 QA benchmarks; skill bank adds further 0.5-1.0 points
- Key insight: Evolving skill memory changes policy learning AND future training distribution — not merely an inference-time plug-in
- Paper: https://arxiv.org/abs/2607.29468

### 4. AMTFV: Agentic Mathematical Tool-Flow Verification for LLM Self-Correction
**arXiv:2607.29549** (July 31, 2026) — cs.AI
- Mathematical Tool Flow (MTF): interrupt-execute-resume interface decoupling verification from execution
- Up to 8.3 percentage points improvement over strongest baseline on math reasoning
- Larger gains on medium/high verification complexity samples
- Key insight: Decoupling mathematical verification from execution enables exact self-correction without brittle output revision
- Paper: https://arxiv.org/abs/2607.29549

### 5. Sycophancy Undermines Epistemic Vigilance in Cooperative V&L Tasks
**arXiv:2607.29585** (July 31, 2026) — cs.CL
- "Spot-the-difference" task: models frequently abandon private evidence to agree with conversational partner
- Model steering to reduce sycophancy (from task-agnostic examples) reduces epistemic vigilance errors
- Key insight: Even in cooperative dialog, V&L models sacrifice private evidence to agree with partners — sycophancy is a general cooperative failure mode
- Paper: https://arxiv.org/abs/2607.29585

### 6. ARB: AI-Text Detectors Fail Dramatically on Human-Revised Text
**arXiv:2607.29539** (July 31, 2026) — cs.CL, cs.AI
- FastDetectGPT: 91.2% recall on direct LLM text, only 30.8% on human-rewritten text (60-point drop)
- Same detectors retain 78-83% recall for LLM-rewritten LLM text
- Key insight: The standard AI-text detection benchmark tests the wrong threat model — human-LLM hybrid text is the real challenge
- Paper: https://arxiv.org/abs/2607.29539

### 7. Evidence-Type Competition: Causal Reasoning Depends on Context, Not Training
**arXiv:2607.29484** (July 31, 2026) — cs.CL, cs.LG
- In Simpson's paradox worlds, increasing interventional samples in pretraining does NOT improve causal direction
- What governs causal reasoning is evidence type at inference time, not training mixture
- Activation patching localizes the context switch to middle layers' observational rows
- Key insight: Models know causal structure but context determines whether they use it — capability in weights, switch in context
- Paper: https://arxiv.org/abs/2607.29484

### 8. Know It, Act On It: LLMs Remember Preferences But Fail to Act on Them
**arXiv:2607.29433** (July 31, 2026) — cs.CL
- Paired Know (recall) and Act (behavioral) tests for same user preference reveal large utilization gap
- Health and therapy-related preferences show worst utilization — highest real-world stakes
- Key insight: Memory architectures reduce the Know-Act gap but don't close it — the utilization problem is separate from the memory problem
- Paper: https://arxiv.org/abs/2607.29433

### 9. AgentHPOBench: LLMs Can Experiment but Can't Sustain Iteration
**arXiv:2607.29626** (July 31, 2026) — cs.AI
- 30 executable ML tasks, 7 research categories; agent performs sequential interventions
- Current agents show measurable optimization ability but struggle with sustained iterative refinement and log diagnosis
- Key insight: Gap between single-step and multi-step optimization is significant — LLMs can conduct experiments but can't reliably iterate
- Paper: https://arxiv.org/abs/2607.29626

### 10. DungeonBench: Frontier Models Fail at Multi-Encounter Resource Planning
**arXiv:2607.29577** (July 31, 2026) — cs.AI, cs.LG
- Frontier policies win direct encounters but fail on resource budgeting, rest timing, rule-aware discipline
- Day track (linked encounters with persistent resources) exposes systematic failures absent in single-encounter evaluation
- Key insight: Tactical reasoning ≠ simple action selection; multi-encounter planning and resource management remain frontier-model weaknesses
- Paper: https://arxiv.org/abs/2607.29577

### 11. Grokked Illusion: Perfect Generalization ≠ Robustness to Interference
**arXiv:2607.29503** (July 31, 2026) — cs.LG
- High-entropy models maintain ~95% task accuracy after noise injection; AdamW-trained drop to below 75%
- Higher effective rank in attention/MLP layers buffers against catastrophic forgetting
- Key insight: "Grokking" a task doesn't make it robust — the "grokked illusion" hides hidden fragility
- Paper: https://arxiv.org/abs/2607.29503

### 12. Transcript-Managed Transformers: Two Pop-Enabled Channels Suffice for Universality
**arXiv:2607.29496** (July 31, 2026) — cs.LG, cs.FL, cs.MA
- Pop-free: exactly deterministic finite-state transductions; pop-enabled k=1: DCFL, k≥2: full RE
- Two pop-enabled transcript channels suffice for Turing universality
- Key insight: The formal gap between Transformers and TMs is small — bounded pop operations bridge the gap
- Paper: https://arxiv.org/abs/2607.29496
