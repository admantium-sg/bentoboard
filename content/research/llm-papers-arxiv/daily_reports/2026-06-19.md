# Daily Report — June 19, 2026 (Friday)

## New Findings

### 1. ASAG: Attention-State Adaptive Generation — Stop Overthinking (ICML 2026 Spotlight)
**arXiv:2606.15070** (June 13, 2026) — cs.CL
- Large reasoning models (LRMs) suffer from overthinking — generating redundant tokens that hurt accuracy
- ASAG: training-free, plug-and-play framework that infers the model's reasoning state and adaptively adjusts generation strategy
- No weight changes required — wraps any existing LRM
- **Result: +3.2% average accuracy, ~40% fewer generated tokens** on Qwen3-8B across 9 benchmarks
- Works consistently across DeepSeek-R1-Distill and Qwen3 series
- Key insight: Attention distribution is a reliable signal for reasoning state — use it to decide when to stop

### 2. Variable-Width Transformers: Hourglass Architecture
**arXiv:2606.18246** (June 16, 2026) — cs.CL
- Standard transformers allocate uniform width across layers despite different computational roles
- ×-shaped (hourglass) transformer: wider early/late layers, narrower middle layers via parameter-free residual resizing
- 200M–2B dense + 3B MoE models tested
- **22% FLOPs reduction, 15% KV cache and I/O reduction** at matched loss
- Key insight: Bottleneck structure in middle layers creates qualitatively different residual stream representations — nonuniform width is more resource-optimal

### 3. ZPPO: Zone of Proximal Policy Optimization — Teacher in Prompts, Not Gradients
**arXiv:2606.18216** (June 16, 2026) — cs.CL
- Knowledge distillation to small models: logit imitation concentrates student on teacher's sharpest modes → hurts generalization
- GRPO avoids imitation but fails on zero-advantage questions (silent discard), breaking on-policy assumption
- ZPPO: keeps teacher inside the prompt (Vygotsky-inspired zone of proximal development)
  - BCQ: Binary Candidate-included Question — one correct teacher + one incorrect student response as anonymized candidates
  - NCQ: Negative Candidate-included Question — aggregates student's wrong rollouts to surface shared failure modes
  - Prompt replay buffer recirculates hard questions until graduation or FIFO eviction
- **Outperforms off/on-policy distillation and GRPO** on Qwen3.5 family (0.8B–9B), with largest gains at smallest scale

### 4. HydraHead: Head-Level Attention Hybridization
**arXiv:2606.20097** (June 18, 2026) — cs.CL
- Prior work noted difficulty integrating Linear Attention (LA) with Full Attention (FA) at layer level
- Key observation: heads within the same layer show distinct functional specialization despite sharing input features
- HydraHead: hybridizes FA and LA along the head axis
  - Interpretability-driven selection: identifies retrieval-critical heads, preserves FA only for them
  - Scale-normalized fusion: reconciles distributional gap between FA and LA head outputs
- Three-stage transfer: parameter reuse + distillation for minimal training overhead
- **7:1 LA-to-FA ratio matches 3:1 layer-wise hybrid's long-context performance**
- 69% improvement over baseline at 512K context, approaching Qwen3.5 with only 15B tokens trained

### 5. Reasoning-Aware Compression (RAC): Pruning Without Losing CoT
**OpenReview / ICML 2026** — (appears to be ICML 2026 submission)
- Standard pruning on reasoning LLMs causes worse performance than on standard language models — pruned models produce MORE thinking tokens but with lower accuracy
- Root cause: standard pruning focuses on input reconstruction, but reasoning is decode-dominated
- RAC: during pruning, jointly reconstruct activations from input AND model's on-policy chain-of-thought traces
- Drop-in fix for existing pruning workflows (SparseGPT, etc.)
- **~95% accuracy maintained even at 50% sparsity**
- Key insight: Reasoning models need CoT-aware compression, not generic weight pruning

### 6. Decoupled Search Grounding (DSG): 91% Lower Search Cost
**arXiv:2606.18947** — cs.AI, cs.CL, cs.IR
- LLM agents couple real-time search with reasoning — expensive, slow, provider-dependent
- DSG: decouples search from reasoning; vendor-agnostic grounding architecture
- Granular control: provider routing, caching, context rendering
- **Near-native SimpleQA accuracy with 91% lower search cost, 68% lower latency**
- Key insight: Offloading retrieval to a separate grounding layer frees the reasoning model to focus on what it does best

### 7. SIMMER: 56% of LLM Plans Have Latent Failures
**arXiv:2606.14574** — cs.CL, cs.AI
- SIMMER: benchmark for detecting latent failures in LLM planning for autonomous agents
- Uses human-curated symbolic world model in kitchen domain
- Finds **up to 56% of LLM plans contain latent failures** — most leading to irreversible consequences
- Key insight: Overt correctness masks hidden failure modes in LLM planning — world-model-based validation is essential

### 8. QMFOL: Quantifiable Monadic First-Order Logic Benchmark
**arXiv:2606.20227** — cs.AI, cs.SE
- Framework for evaluating LLM deductive reasoning with controllable logical complexity
- Generates monadic first-order logic tasks with precise control over reasoning depth, width, label types, distractors
- Round-trip formal-to-natural-language verification ensures consistency
- Key insight: Controllable formal benchmarks needed to systematically probe LLM logical reasoning boundaries

### 9. Actionable Activation Directions for Misalignment Detection
**arXiv:2606.20225** (June 18, 2026) — cs.CL
- Fine-tuning on insecure code induces emergent misalignment across model families
- Difference-in-means direction at final layer achieves 99.6% separation of aligned/misaligned activations
- Causal steering: subtracting this direction reduces code spillover by 21–51 points
- Cross-architecture transfer: Gemma and Qwen act as geometric donors, Llama as receiver
- Within-model directions are causally specific; cross-model directions are real but non-specific
- Key insight: Misalignment has a causally actionable geometric signature — linear steering is feasible within architecture families

## Community Pulse

### Reasoning & Efficiency
- **ASAG and RAC are complementary**: ASAG stops unnecessary reasoning at test time; RAC compresses reasoning models for deployment. Together they address the full cost pipeline.
- **HydraHead and Variable-Width Transformers both exploit non-uniform capacity**: one at head level (FA/LA mix), one at layer width level. Different granularities, same principle.
- **DSG's decoupling approach is gaining traction**: separating search from reasoning appears to be a consistent theme across multiple recent works.
- **Pruning reasoning models requires special handling**: standard techniques cause models to generate MORE tokens but with worse accuracy — the CoT structure itself must be preserved during compression.

### No Major Issues Reported
- No significant regressions or issues reported this week in community discussions around reasoning models.

## Trend Analysis

**1. Test-time compute efficiency is now a first-class research concern:**
ASAG (stop early), RAC (compress for deployment), ZPPO (efficient distillation) all address different points on the test-time compute ladder. The era of "just generate more tokens" is giving way to "generate the right tokens."

**2. Architectural efficiency through non-uniform allocation is gaining empirical support:**
Variable-width transformers (22% FLOPs reduction) and HydraHead (7:1 LA:FA ratio matching layer-wise 3:1) both show that uniform allocation is wasteful. Different layers/heads do different things.

**3. Reasoning faithfulness in multimodal RLVR is a new sub-topic:**
CORA (#9 in arxivtldr) and earlier findings on CoT faithfulness suggest the community is increasingly concerned with whether reasoning traces actually cause answers, not just correlate with them.

**4. Latent failure detection is maturing:**
SIMMER's 56% latent failure rate for kitchen-agent planning suggests that visible benchmark performance dramatically understates real-world risk. This aligns with earlier findings on agentic coding and persona drift.
