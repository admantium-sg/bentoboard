## Notable Papers: July 24 Batch

### 1. Muon Grokking: The Active Ingredient — Orthogonalization Is Key
**arXiv:2607.20512** (July 6, 2026) — cs.LG, cs.AI
- Muon optimizer reaches grokking faster than AdamW — but NOT due to spectral-norm constraints
- Speedup comes entirely from orthogonalization (Newton-Schulz iteration)
- Orthogonalize-only matches full Muon; spectral-only is no faster than AdamW and unreliable
- Reducing Newton-Schulz iterations from 5 to 1 accelerates but makes solution fragile
- Key insight: The field misattributed Muon's mechanism — orthogonalization is the active ingredient, spectral-norm is incidental
- Paper: https://arxiv.org/abs/2607.20512

### 2. SOAP, Muon, and Beyond: LLM Pretraining at Scale
**arXiv:2607.20548** (July 13, 2026) — cs.LG, cs.AI
- Higher-order optimizers outperform AdamW at multi-billion-parameter LLM scale
- Stable at batch sizes up to 100M tokens where AdamW degrades
- Layer-wise distributed optimizer compatible with Megatron-LM
- First large-scale empirical validation of Muon/SOAP at true LLM pretraining scale
- Paper: https://arxiv.org/abs/2607.20548

### 3. Thermodynamic Weight Decay: CvAdamW for Grokking Acceleration
**arXiv:2607.20552** (July 15, 2026) — cs.LG
- Treats attention logit variance as specific heat (Cv); Cv peak reliably precedes generalization transition
- CvAdamW dynamically scales weight decay when phase transition detected
- Enables grokking at epoch 2802 where baseline never groks; reduces mean latency by 257 epochs (6.0%, p=0.049)
- Scale-invariant z-score reformulation removes task-specific hyperparameters
- Key insight: Neural networks expose detectable precursors to impending generalization transitions
- Paper: https://arxiv.org/abs/2607.20552

### 4. Agentic Context Management: Lifecycle, Not Storage
**arXiv:2607.21503** (July 23, 2026) — cs.AI, cs.IR
- Reframes agent memory as lifecycle problem: architecting, ingesting, scoping, anticipating, compacting
- Naive context accumulation grows token cost quadratically; validated compaction achieves linear cost
- Maximem Synap achieves 92% on LongMemEval, 93.2% on LoCoMo
- Key insight: Agent failures stem from drowning in accumulating history, not inability to reason
- Paper: https://arxiv.org/abs/2607.21503

### 5. Differentiable Logic Programming: Reasoning Shortcut Mitigation
**arXiv:2607.21185** (July 23, 2026) — cs.AI, cs.LO
- Matrix-based differentiable logic programming to mitigate shortcuts in NeSy systems
- Two shortcut types: constraint satisfaction shortcuts and cognition shortcuts
- One-to-one grounding of neural outputs to logical atoms significantly reduces both
- Key insight: Architectural choices in coupling symbolic knowledge with neural learning are critical
- Paper: https://arxiv.org/abs/2607.21185

### 6. PTME Profiling: Precision-Time-Memory-Energy for Lightweight LLMs
**arXiv:2607.20806** (July 23, 2026) — cs.AI
- Introduces PTME framework for edge LLM deployment with hardware-level measurements
- Static proxies (parameter count, FLOPs) approximate cost but fail to predict precision
- Pareto analysis reveals non-dominated configurations hidden by accuracy-only or efficiency-only assessments
- Key insight: Selecting by size, FLOPs, latency, or accuracy alone can select wrong deployment candidate
- Paper: https://arxiv.org/abs/2607.20806

### 7. StrideDiffusion: Spectral-Aware Diffusion Acceleration
**arXiv:2607.20545** (July 13, 2026) — cs.AI, cs.CV
- Training-free spectral-aware sampler; uses only 14-66 function evaluations instead of 500-1000 steps
- Up to 18.9x wall-clock speedup while preserving generation quality
- Monitors band energy, log-power drift, phase velocity to adaptively select denoising stride
- Key insight: Different spectral bands evolve at different rates during reverse process
- Paper: https://arxiv.org/abs/2607.20545

## Quantization & Efficiency Developments

### 2026 LLM Inference: KV Cache Quantization Frontier
- Literature shifting from generic model compression to deployment-specific optimization
- **OSCAR** (2605.17757): 2-bit KV cache quantization via offline spectral covariance-aware rotation
- **SAW-INT4** (2604.19157): System-aware 4-bit KV cache for vLLM with paged layouts and fused attention
- **ModeSwitch-LLM** (2605.23057): Single-GPU controller routing across FP16/quantized/speculative modes
- Key trend: Long-context claims on consumer GPUs increasingly depend on KV-cache-specific quantization, not weight quantization alone
- Source: https://www.gpuhunter.io/research/2026-llm-inference-papers
