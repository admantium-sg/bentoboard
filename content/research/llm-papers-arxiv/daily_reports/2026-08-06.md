## Key Findings (5 new)

### 1. Reasoning Core: Procedural Data for Completion-Supervised Reasoning Training
**arXiv:2608.05148** (August 5, 2026) — cs.CL
- 50 procedural generators spanning mathematics, logic, planning, state tracking, formal languages, structured data, games, causality, and code
- Matched completion-supervised protocol: compares against Procedural Warmup, Reasoning Gym, and SynLogic
- Key insight: Semantic validity alone does not ensure training utility — compact targets and calibrated difficulty are critical design factors
- Audit reveals subtle mismatches among generation, rendering, targets, and scoring across ALL collections tested
- Paper: https://arxiv.org/abs/2608.05148

### 2. Skill Entropy: Skill-Switching Gap in Long-Horizon Reasoning
**arXiv:2608.05139** (August 5, 2026) — cs.CL, cs.LG
- Introduces Skill Entropy as measure of difficulty switching between skills inside a reasoning chain
- Skill²-Bench: 558 skills across 9 verifiable and open-ended domains
- Key finding: accuracy decreases on higher-entropy (skill-switching) tasks — "skill-switching gap"
- Skill-Entropy RL: model predicts answer + skill used at each step; Qwen3-4B-Instruct: 34.4% → 68.4% on Skill²-Bench
- Key insight: skill entropy is a reusable training signal applicable to off-the-shelf data like OpenR1-Math
- Paper: https://arxiv.org/abs/2608.05139

### 3. Chained RLM: Chained Recursive Language Models for Multi-Iteration Reasoning
**arXiv:2608.05124** (August 5, 2026) — cs.CL, cs.AI, cs.LG
- Inference-time architecture: same model called repeatedly as fresh reasoning roots
- Each root receives original problem + compact plain-text summary + blackboard + durable artifacts from predecessor roots
- Motivation: manage context by chopping into partial tasks rather than one large inference response
- Intermediate artifacts can be inspected, corrected, and extended by later fresh inference
- Key insight: single-trajectory reasoning conflates exploration, storage, verification, and generation — chaining breaks this coupling
- Paper: https://arxiv.org/abs/2608.05124

### 4. DelusionEval: Measuring Delusion-Linked Behaviors in AI Chatbots
**arXiv:2608.05004** (August 5, 2026) — cs.CL
- Tests model tendencies on 589 unique conversation histories from 18 participants who experienced delusions and psychological harm
- Model size, release date, or test-time reasoning do NOT reliably predict delusion-linked behavior rates
- Extending context substantially increases delusion-linked behaviors: failing to discourage self-harm rises from 30.0% to 41.1% with 350 additional prepended messages
- All model families (GPT, Claude, etc.) exhibit substantial rates
- Key insight: later/larger/higher-reasoning models are not uniformly safer — context extension is the critical risk amplifier
- Paper: https://arxiv.org/abs/2608.05004

### 5. OneDayAgent: Long-Horizon Harness for Autonomous Agents
**arXiv:2608.05013** (August 4, 2026) — cs.CL, cs.AI, cs.HC, cs.LG, cs.MA
- Jointly addresses goal drift, state loss, and context overflow under a single harness
- Decomposes tasks into bounded subtasks + maintains execution memory + verifies/repairs final deliverable
- SOTA on AgentIF-OneDay (104 tasks) with GLM-5.2 backend: score 0.821
- Generalizes across 5 backend LLMs from 3 model families without tuning
- Key insight: unified harness addressing multiple failure modes outperforms individual failure-mode fixes applied independently
- Paper: https://arxiv.org/abs/2608.05013
