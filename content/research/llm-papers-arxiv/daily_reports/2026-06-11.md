## Task 1: arXiv Papers (Chain-of-Thought, Prompt Engineering, Efficiency)
14 papers analyzed from June 10-11 submissions on cs.CL, cs.LG, cs.AI.

### Key Findings:

1. **CHAIR: Layer-wise Logit Analysis for Hallucination Detection** (2606.12160)
   - Extracts max/min/mean/std/slope from token logits across all layers
   - Zero-shot hallucination detection on TruthfulQA and MMLU
   - Internal representations guide advanced decoding strategies
   - Key insight: Layer-wise logits contain rich signal about generation reliability

2. **Soft-Prompt Tuning for Benchmark Evaluation** (2606.12117)
   - 10 soft-prompt vectors (~0.0006% params for 7B) adapt to benchmark formats
   - Saturates format-following in 80 steps (~640 samples)
   - Base model rankings predict post-trained rankings better than zero/few-shot
   - Key insight: Benchmark scores misrepresent knowledge; format ≠ capability

3. **MedMisBench: Epistemic Resilience Under Adversarial Context** (2606.12291)
   - Medical accuracy drops 71.1% → 38.0% under misleading context
   - 51.5% attack success; authority-framed falsehoods reach 69.5%
   - 38.2% of cases identified as serious potential harm by clinical panel
   - Key insight: Medical LLM evaluation has structural blind spot

4. **EBA: Embedding-Based Agreement for Open-Ended Self-Consistency** (2606.12003)
   - Clusters sampled generations in embedding space
   - Central generations = higher quality; peripheral = less accurate
   - Stable across model families and embedding spaces
   - Key insight: Self-consistency is geometric, not exact match

5. **FORT: Shortcut-Resistant Search Task Synthesis** (2606.12087)
   - Four shortcut risks: co-coverage, selectivity, exposed constants, prior binding
   - FORT-Searcher (SFT only) best among comparable open-source agents
   - Key insight: Structural complexity alone doesn't guarantee search difficulty

6. **Semantic Progress in Multi-turn Dialogue** (2606.12332)
   - Information-theoretic metric: question-conditioned uncertainty reduction
   - Gaussian formulation with monotonicity, additive decomposition
   - CPU-only execution viable with lightweight embeddings
   - Key insight: Dialogue quality emerges across turns

7. **RACES: Recursive Composition for Reasoning Generalization** (2606.12373)
   - Verifiable environments as LEGO bricks; composable when codomain matches domain
   - 50 base achieve comparable to 300 individual environments
   - DeepSeek-R1-Distill-Qwen-14B: 48.2→51.3, Qwen3-14B: 58.8→61.1
   - Key insight: Linear scaling through recursive composition

8. **ALIGNBEAM: Cross-Vocabulary Safety Alignment** (2606.12342)
   - Translates anchor logits to target vocabulary token-by-token
   - Small LLM judge selects safest among K continuations
   - No weights changed; safety-utility tunable at deployment
   - Key insight: Safety transferable between model families at inference time

9. **Doc-to-Atom: Compositional Memory via Micro-LoRA Atoms** (2606.12400)
   - Documents → knowledge atoms → independent micro-LoRA + retrieval key
   - Query router assembles relevant atoms; end-to-end distillation
   - Outperforms Doc-to-LoRA; reduces memory cost
   - Key insight: Monolithic adapters cause interference; atoms enable query-specific assembly

10. **C-DIC: Context-Driven Incremental Compression** (2606.12411)
    - Per-thread compression states with retrieve-revise-write-back loop
    - Stable latency over hundreds of dialogue turns
    - TBPTT adaptation for multi-turn learning
    - Key insight: Incremental compression with cross-turn sharing

11. **ModSleuth: Auditing Invisible LLM Dependencies** (2606.12385)
    - 1,060 source-verified dependencies across four LLM releases
    - Multi-hop license obligations, train-evaluation coupling revealed
    - Key insight: Dependency structures exceed human tracing ability

12. **AGDO: Attention-Guided Denoising for Diffusion LLMs** (2606.12273) - ACL 2026
    - Tokens with strong unmasked context attendance = greater stability
    - Attention-guided denoising order; emphasis on attention-critical tokens
    - Key insight: Random masking overlooks token dependencies

13. **CADFT: Compatibility-Aware Dynamic Fine-Tuning** (2606.11206) - ACL 2026
    - Compatibility signal modulates updates; suppresses high-variance gradients
    - Delayed rewriting of persistently incompatible demonstrations
    - Key insight: Sample-level compatibility control essential for SFT stability

14. **MLJailDe: Multilingual Jailbreak Detection** (2606.11202)
    - 11 languages; relative-distance reduces cross-lingual dispersion
    - F1 98.5% across languages; 97.1% on unseen
    - Key insight: Safety training concentrated in dominant languages creates gaps
