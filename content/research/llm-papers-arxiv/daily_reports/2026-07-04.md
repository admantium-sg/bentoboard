### 🔬 Interpretability & Explainability

**TokenScope (2607.01235)** — Interactive token-level explainability for code-oriented LLMs
- **What:** Decoder introspection tool exposing token-level metrics, attention patterns, and AST-structured code awareness during generation. Supports interactive token replacement and counterfactual branching.
- **Key insight:** Unifies decoding-time signals with structural program analysis via AST-aware aggregation
- **Why notable:** First tool combining interactive token replacement with code AST structure for systematic LLM code behavior investigation
- **Paper:** https://arxiv.org/abs/2607.01235

### 🧠 Reasoning & Chain-of-Thought

**RusFinChain (2607.01388)** — Russian financial CoT reasoning benchmark
- **What:** First Russian-language symbolic benchmark for verifiable chain-of-thought reasoning in finance. 5,280 examples, 17 domains, 172 topics. Gold-standard reasoning chains with intermediate numeric values for automatic verification.
- **Key metrics:** Fuzzy Numeric Alignment and Soft-Attention Alignment outperform original ChainEval (rho ~0.48 vs ~0.38–0.46)
- **Finding:** Models achieve ~65% Hard F1 for step alignment but only ~29% final answer correctness — substantial reasoning gap between step-level quality and outcome quality
- **Why notable:** Verifiable CoT in non-English financial domain; fuzzy metrics better predict reasoning success
- **Paper:** https://arxiv.org/abs/2607.01388

**FaithMed (2607.01440)** — Training LLMs for faithful evidence-based medical reasoning
- **What:** Formalizes evidence-based medicine principles as process-level criteria. Uses step-level process reward assignment + advantage grouping RL. Outperforms agentic-search baselines (+9%) and outcome-only RL (+5.8%).
- **Key finding:** Rubric scores improved +15.5% over agentic-search Qwen3 baselines; explicit step-level supervision improves both task success AND reasoning faithfulness
- **Why notable:** Process-level criteria + RL > outcome-only RL for medical reasoning fidelity
- **Paper:** https://arxiv.org/abs/2607.01440

**Turkish Reasoning Pipeline (2607.01927)** — SFT + GRPO for non-English math reasoning
- **What:** Base Qwen3.5-27B → SFT on 15,991 Turkish reasoning examples → GRPO-family RL on proxy-filtered Turkish math environment
- **Key finding:** SFT reduced response length and thinking exhaustion but reduced benchmark accuracy. RL recovered some math performance (AIME24), but did not exceed base model on Macro-6 average. Technically honest evaluation — not claiming SOTA
- **Why notable:** Honest RL+SFT pipeline for language-specific reasoning; shows base model may remain superior overall for low-resource languages
- **Paper:** https://arxiv.org/abs/2607.01927

### 🎯 Hallucination & Safety

**Grounded Optimization (2607.01457)** — Reducing hallucination in automated personal document rewriting
- **What:** Five-layer framework for resume rewriting: temporal context validation, contamination detection, structural invariant enforcement, prompt-level grounding, and evaluator agent
- **Novel taxonomy of resume hallucinations:** (1) anachronistic technology injection, (2) cross-domain terminology contamination, (3) structural mutation, (4) content fabrication
- **Finding:** Prompt-level grounding alone achieves zero detected hallucinations at low temperature with capable instruction-following model; higher temperatures require deterministic layers as complement
- **Why notable:** Domain-specific hallucination taxonomy with evidence that training-free prompt grounding can be sufficient under right conditions
- **Paper:** https://arxiv.org/abs/2607.01457

**OpenSafeIntent (2607.02047)** — Intent-calibrated safe completion evaluation
- **What:** Benchmark of controlled prompt-sets varying intent while holding task fixed (benign/dual-use/malicious variants of same task)
- **Finding:** Prompt-level safety hides important failures — models fail to remain safe across matched intent variants; dual-use behavior brittle under paraphrase; reframing into safer tasks less likely to cross safety boundary
- **Why notable:** Evaluates safety as intent-calibrated behavior over controlled task variants, not single safety-helpfulness tradeoff over independent prompts
- **Paper:** https://arxiv.org/abs/2607.02047

### 💻 Code Generation & Agentic AI

**PairCoder (2607.01883)** — Pair programming for verifiable code-driven multimodal artifact generation
- **What:** Driver-Writer agent writes program, Navigator-Reviewer reviews against toolchain diagnostics/execution results/renderings; role switching on errors. 17 benchmarks, 7 models tested.
- **Key results:** Blender scene executability 0.20→0.78; TikZ compile rate +10–30 pts on every model; 2.9–9.2× single model cost (~7× overall)
- **Finding:** Improvements concentrate where toolchain provides informative oracle; ties or beats single-pass on verifiable tasks
- **Why notable:** Generalizable multi-agent paradigm for any compiler/renderer/simulator-visible artifact generation; orthogonal to single-model improvements
- **Paper:** https://arxiv.org/abs/2607.01883

**DecompRL (covered Jul 3)** — Reminder: modular code generation via problem decomposition; ~50× GPU token reduction via make-task-easier approach

### ⚡ Efficiency & Infrastructure

**Parameter Golf (2607.01517)** — Community challenge: what really works in constrained LLM training
- **What:** Train best LLM in <16MB artifact, <10 min on 8×H100. 2,037 PRs, 1,430 submissions analyzed. Taxonomy of 84 optimization techniques.
- **Key finding:** BPB dropped from 1.2244 to 1.058 (13.6% reduction) across 3 phases; individual techniques rarely improve BPB by >1%; most gains shrink across competitive submissions; few methods transfer across stacks
- **Why notable:** Large-scale empirical ranking of optimization techniques under strict compute constraints; isolation of generalizable vs environment-dependent methods
- **Paper:** https://arxiv.org/abs/2607.01517

**KV Cache Compression Risk (2607.01520)** — Theoretical characterization of KV cache compressibility
- **What:** Minimax risk characterization of KV cache compression in terms of intrinsic compressibility; design principles for prefill and autoregressive decoding
- **Key insight:** Bridges theory-practice gap — shows when/how accurate compression is possible; LongBench results confirm
- **Why notable:** First principled theory for KV cache compression; practical algorithm with minimax-optimal guarantees
- **Paper:** https://arxiv.org/abs/2607.01520

**Rollout Infrastructure Tax (2607.01415)** — Coding-agent RL infrastructure
- **What:** Comparative study of 4 execution substrates for coding-agent RL: single containers, hosted sandboxes, Kubernetes, cloud VMs. Cold-start latency varies 110×; 1.8× spread in projected worker-hours for 1M 150-step trajectories.
- **Finding:** Future coding-agent RL should optimize execution substrates as part of training system
- **Paper:** https://arxiv.org/abs/2607.01415

### 🗣️ Speech & Multilingual

**JSTIP (2607.01733)** — Joint Speech-Text Interleaved Pretraining for ASR
- **What:** Word-level and segment-level interleaved speech-text sequences for speech-LLM architectures; 38k hours ASR data
- **Key finding:** On-par entity recognition using domain transcription text vs synthetic speech-text pairs; zero-shot speech QA behaviors suggest in-context learning capability
- **Why notable:** Simplified domain adaptation for speech LLMs; text pretraining benefits without synthetic data overhead
- **Paper:** https://arxiv.org/abs/2607.01733

**Mamba for South African ASR (2607.01502)** — Mamba SSM matches Conformer accuracy across 7 South African languages with fewer compute resources; multilingual training consistently improves over monolingual; language embeddings act as task-specific control vectors (not typological similarity)
- **Paper:** https://arxiv.org/abs/2607.01502

### 💬 Dialogue & Persuasion

**DiPS (2607.01557)** — Dialogue Policy Selection for high-stakes persuasion (SIGDIAL 2026)
- **What:** Q-learning framework for dynamic persuasion strategy selection in fire-evacuation scenario; critic maximizes evacuation success
- **Finding:** DiPS outperforms zero-shot LLM and generic RAG-augmented approach in both simulated and real human interactions
- **Why notable:** Dynamic policy selection > static approaches for high-stakes conversational AI; Q-learning for strategy adaptation in safety-critical dialogue
- **Paper:** https://arxiv.org/abs/2607.01557

## Key Themes from July 1–3 Submissions

1. **Reasoning evaluation getting more granular:** RusFinChain shows step-level metrics (F1 ~0.65) don't predict final-answer correctness (~29%) — need better intermediate supervision metrics

2. **Faithfulness via process supervision:** FaithMed demonstrates step-level reward assignment + RL outperforms outcome-only RL for medical reasoning; rubric-driven EBM principles transfer

3. **Hallucination defense is domain-specific:** Grounded Optimization taxonomy (temporal, contamination, structural, fabrication) suggests general hallucination mitigation needs domain-specific adaptation

4. **Pair programming as universal artifact paradigm:** PairCoder shows toolchain-grounded multi-agent review improves essentially all verifiable code generation tasks; 7× cost for major gains

5. **Safety evaluation needs controlled variants:** OpenSafeIntent reveals prompt-level safety is insufficient; intent-calibrated behavior evaluation over matched variants is the right frame

6. **Constrained training insights:** Parameter Golf shows individual optimization techniques rarely transfer; the field needs better isolation of general vs environment-dependent methods

7. **Claude family dominance:** Across HLE (64.5%), SWE (95.5%), OSWorld (85%), Terminal (88%), GPQA (96.2%) — Anthropic's Claude lineup holds multi-domain lead
