## Task 1: arXiv Papers (cs.CL, cs.LG, cs.AI)

### New Papers from May 18, 2026 Submissions

#### DashAttention: Differentiable Adaptive Sparse Hierarchical Attention
**arXiv:2605.18753** (May 18, 2026)
- Addresses fixed top-k assumption in NSA/InfLLMv2 hierarchical attention — blocks gradient flow between sparse/dense stages
- Uses adaptively sparse α-entmax transformation for variable block selection per query
- Non-dispersive → better long-context modeling than prior hierarchical methods
- Achieves full-attention accuracy at 75% sparsity; better Pareto frontier than NSA/InfLLMv2
- Triton GPU impl: speedup over FlashAttention-3 at inference
- Key insight: Fully differentiable hierarchy enables gradient flow across sparse→dense boundary

#### Code as Agent Harness (Survey)
**arXiv:2605.18747** (May 18, 2026) — 40+ authors
- Code as operational substrate for agent reasoning/action/verification, not just output
- Three-layer framework: harness interface, harness mechanisms (planning/memory/tool-use/feedback), multi-agent scaling
- Applications: coding assistants, GUI automation, embodied agents, scientific discovery, DevOps, enterprise workflows
- Open challenges: evaluation beyond task success, regression-free harness improvement, shared state across agents
- GitHub: Awesome-Code-as-Agent-Harness-Papers
- Key insight: The layer ABOVE the model (harness quality) now separates working production agents from demos

#### EnvFactory: Scaling Tool-Use Agents via Executable Environments Synthesis
**arXiv:2605.18703** (May 18, 2026)
- Agentic RL bottlenecked by: lack of scalable robust execution environments + scarcity of realistic training data
- EnvFactory: autonomously explores/verifies stateful executable tool environments; synthesizes natural multi-turn trajectories via topology-aware sampling
- Only 85 verified environments (prior work uses ~5x more) → 2,575 SFT+RL trajectories
- Qwen3-series: +15% BFCLv3, +8.6% MCP-Atlas, +6% on conversational benchmarks
- Key insight: Quality of environment infrastructure matters more than quantity for RL training efficiency

#### Language-Switching Backdoor Circuit Analysis
**arXiv:2605.18646** (May 18, 2026)
- 8B model: 3-word Latin trigger (9 tokens) redirects English → French
- Three-phase circuit: early-layer composition → mid-layer orthogonal propagation → final-layer logit conversion
- Serial bottleneck at single position: corrupting it at any layer fully mitigates trigger but degrades capabilities
- Orthogonal latent encoding evades defenses that inspect intermediate representations for language-like signals
- Key insight: Backdoor circuits use encoding subspaces invisible to standard interpretability methods

#### Forecasting Downstream LLM Performance with Proxy Metrics
**arXiv:2605.18607** (May 18, 2026)
- Cross-entropy loss poorly aligned with downstream capabilities; direct evaluation is expensive/sparse at early training stages
- Proxy metrics: token-level entropy, top-k accuracy, expert token rank over expert-written solutions
- Cross-family model selection: Spearman Rho=0.81 vs Rho=0.36 for cross-entropy
- Pretraining data selection: ~10,000x less compute than direct evaluation
- Training-time forecasting: half the error of alternatives across 18x compute horizon
- Key insight: Expert trajectories enable reliable model development decisions throughout the lifecycle
