## Task 1: arXiv Papers (July 15 Batch)

### Top Papers

**1. PosConf: Position-Aware CoT Confidence** (`2607.13753`)
Three-stage calibration framework: pre-reasoning (difficulty estimation), intra-reasoning (early stopping), post-reasoning (answer aggregation). Key finding: confidence reliability is position-dependent. OPD confidence is useful early but becomes inversely calibrated later; RL confidence becomes informative only after path-commitment. PosConf uses confidence only from reliable relative-position intervals. RL answer aggregation +6.1pp over majority voting; OPD early stopping +4.3pp under tight token budgets. Key insight: confidence in reasoning models should be used both stage-wise and position-awarely.
Code: https://github.com/EIT-NLP/Post-Training-Calibration

**2. Self-Evolving Agent Harnesses via GSME** (`2607.13683`)
Harnesses (prompts, injected knowledge, runtime control) shape agent performance as much as the model. Self-evolving harness: LM diagnoses failures + proposes patches; deterministic code handles all measurement + significance testing. Gated semantic quality-diversity archive (GSME) keyed on (WHERE × WHY) pathology. +9 to +15.5pp gains; 86-147% retained on sealed test. Key insight: what transfers is the diagnose-and-credit loop, not any specific harness patch — same pathology-to-patch match recurs across model families.
Paper: https://arxiv.org/abs/2607.13683

**3. MemCon: Adaptive Memory Management for LLM Agents** (`2607.13591`)
Models memory operations as MDP; learns online policy for when/what/how-much to retrieve, when to inject distilled plans, when to consolidate/forget. Backend-agnostic wrapper over any memory implementation. UCB contextual bandit, no pretraining, no extra LLM calls. Up to +15.2pp task success, 5-20% token reduction across 6 benchmarks, 3 agent frameworks, 3 backbones. Key insight: early tasks benefit from minimal retrieval (sparse memory), recurring goals benefit from plan reuse, stuck agents benefit from alternative query re-retrieval.
Paper: https://arxiv.org/abs/2607.13591

**4. The Test Oracle Problem in Synthetic LLM-as-Judge Corpora** (`2607.13707`)
Synthetic corpora for LLM-as-judge studies (LLM generates hallucinated negatives) carry no mechanical integrity check. A shared decoding-budget parameter truncated one producer's answers → 32-point cross-lingual collapse in selection accuracy, replicated N=50 to N=500, explained mechanistically. Effect vanished to ceiling once fixed; only manual raw-generation reading exposed it. Deterministic perturbation corpora carry a free item-level oracle — same fault caught with 100% accuracy by zero-cost string comparison. Key insight: oracle-less regime is structural, not incidental; validation protocol proposed.
Paper: https://arxiv.org/abs/2607.13707

**5. Hindcast: Leaker-Free LLM Forecasting Evaluation** (`2607.14051`)
Standard backtesting for LLM forecasters has two leakage channels: (1) retrieval surfaces post-event reports, (2) newer models trained on data closer to the event. Hindcast grades model as if standing at a chosen past date t₀ before the outcome existed in either channel. Replays Polymarket against frozen Reddit snapshot, model reads only pre-t₀ posts. Key finding: once leak is closed, retrieval still helps most models but only where Reddit discussed the event beforehand; where archive had only speculation, retrieval hurts.
Paper: https://arxiv.org/abs/2607.14051

**6. SPyCE: Skill-Policy Co-evolution for Multimodal Agents** (`2607.13854`)
Distills multimodal reasoning trajectories into hierarchical skill library (execution skills + workflow skills) that co-evolves with the RL policy. Policy conditions on retrieved skills → guides rollouts; skill library updates from valuable rollouts → closed loop. Outperforms RL-based and memory-based baselines across 8 benchmarks. Both hierarchical design and co-evolution mechanism are critical. Key insight: trajectories should be distilled into reusable skills rather than consumed as rewards or retrieved from a static store.
Paper: https://arxiv.org/abs/2607.13854

**7. CANA: Causal Analogical Researcher** (`2607.13602`)
Analogical Deep Research (ADR): LLM agents are poor at finding historical analogies — they match surface features rather than underlying mechanisms. ADR requires causal understanding. CANA proposes mechanism alignment + cross-analogy confirmation; uses structural decomposition representation + reflective structural feedback. Up to +10% improvements in historical analogy generation; surpasses state-of-the-art deep research agents on ADR-bench.
Paper: https://arxiv.org/abs/2607.13602
