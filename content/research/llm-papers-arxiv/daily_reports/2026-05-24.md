## New Findings (May 24)

### MOSS: Self-Evolution through Source-Level Rewriting in Autonomous Agents
**arXiv:2605.22794** (May 21, 2026)
- Current self-evolving agents confined to text-mutable artifacts — cannot touch harness code itself
- Argues source-level adaptation is fundamentally more general: Turing-complete, strict superset of text-mutable scope
- MOSS self-rewrites at source level on production agentic substrates
- Results on OpenClaw: 4-task mean grader score 0.25 → 0.61 in single cycle without human intervention
- Key insight: Text-mutable agents hit structural ceiling — source-level access unlocks higher capability

### Gated DeltaNet-2: Decoupled Erase/Write for Linear Attention
**arXiv:2605.22791** (May 21, 2026)
- Problem: scalar gate controlled both erasing AND writing in prior delta-rule models
- Solution: separates channel-wise erase gate (b_t) from channel-wise write gate (w_t)
- 1.3B params, 100B FineWeb-Edu tokens; outperforms Mamba-2, Gated DeltaNet, KDA, Mamba-3
- Best on long-context RULER needle-in-a-haystack benchmarks
- Key insight: Decoupling erase/write is the missing piece for linear attention

### AI-Driven Formal Proof Search for Open Mathematical Problems
**arXiv:2605.22763** (May 21, 2026)
- First large-scale evaluation: LLMs generating formal proofs (Lean) for genuinely open problems
- Resolved 9 of 353 open Erdős problems at few hundred dollars per problem
- Proved 44/492 OEIS conjectures; deployed in combinatorics, graph theory, algebraic geometry
- Key insight: LLMs + formal verification is now viable for actual open research problems

### HarnessAPI: Unified Framework for APIs and MCP Tools
**arXiv:2605.22733** (May 21, 2026)
- Problem: Python functions deployed as LLM tools require dual representation (HTTP + MCP)
- HarnessAPI: typed skill folder as single source of truth
- 74% boilerplate reduction vs dual-stack (FastAPI + FastMCP)
- Key insight: Tool deployment infrastructure catching up to model capabilities
