## New Findings (July 17 Batch — 4 Novel Papers)

### 1. Breaking Refusal in the First Half: Prefill Jailbreak Mechanistic Study
**arXiv:2607.14147** — cs.CL, cs.AI, cs.CR, cs.LG
- Single prefill ("Sure, here is") strips refusal from aligned LLMs across four models, 1.5B–14B
- Harm representation stays intact — linear probe reads harm as high as on refused prompts (0.91–0.98), but behavioral refusal drops to chance
- Causal localization: first half of response suffices to break refusal; second half is nearly inert
- Mechanism: generic autoregressive conditioning, not safety-specific suppression
- Three causal probes converge on early response window; injecting refuse-state reverses jailbreak (74%)
- Base model control: same knockout collapses prefill-specific continuation even without safety tuning
- Safety implication: prompt-side monitors are immune by construction, but refusal is structurally shallow and local
- Code: https://github.com/collapseindex/breaking-refusal
- **Significance:** First mechanistic account of why prefill jailbreaks work — refusal is response-site, early-token computation, not deep semantic property

### 2. Implicit Reasoning Steering via Concept Chaining
**arXiv:2607.14242** — cs.CL
- Concept Chaining generates short connection paragraphs linking question entities to target via 1–2 intermediate concepts
- Continuing pretraining on these paragraphs shifts model answer preferences without explicit triggers or direct answer cues
- Indirect natural-looking text systematically steers predictions while being substantially less inferable than direct paraphrases
- Key insight: reasoning brittleness creates a practical channel to covertly redirect model decisions — not merely an evaluation artifact
- **Significance:** Practical vulnerability with no obvious fix — subtle contextual text can bias decisions without detectable triggers

### 3. KV-Cache Grafting: Byte-Exact Verified-Knowledge Flywheel
**arXiv:2607.14431** — cs.CL, cs.AI, cs.LG, cs.PF
- Makes frozen small language model both more capable AND cheaper without weight changes
- Verified knowledge deposited as byte-exact KV-state artifact; restored via graft into fresh inference context
- Bit-exact: grafted logits byte-for-byte identical to fresh computation (SHA-256 equality), zero KL divergence, 100% argmax
- AIME 2025: frozen Gemma-4-12B moves from 80.0% → 93.3% with verified solution library graft (above 31B sibling's 89.2%)
- Recurring problems solved in 61 decode tokens vs 401,026 tokens (~8,700x less energy)
- Extends usable context from 32,768 to 2,854,766 tokens at zero extra accelerator memory
- Byte-identical between machines of same architecture; all numbers backed by committed input/output hashes
- **Significance:** Major efficiency breakthrough — verified knowledge flywheel enables small models to outperform larger siblings at fraction of compute cost

### 4. Reasoning Graphs for Robust LLM Authorship Attribution
**arXiv:2607.14905** — cs.CL, cs.AI
- Extracts reasoning structures (not surface features) from LLM-generated texts using argument mining + graph neural network
- Outperforms Longformer baseline by 27pp under obfuscation attacks (paraphrasing, backtranslation)
- 19pp improvement on texts from unseen model versions (simulates continuous LLM release cycles)
- Key insight: reasoning structure is the robust attribution signal — surface features are easily evaded
- **Significance:** Critical for AI detection in adversarial settings where simple paraphrasing/backtranslation is used to evade detection
