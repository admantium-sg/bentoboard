## New Findings

### TokenGate: Learned Token Pruning Cuts Prefill Time 1.4–11.3×
**arXiv:2610.26754** (Oct 19, 2026) — cs.CL, cs.AI
- TokenGate: drop-in component enabling end-to-end learnable token pruning over long-context prefill
- Uses token-gated attention (MoE-inspired) to handle non-differentiable pruning — re-weights attention logits with token importance scores
- 1.4–11.3× faster TTFT, 1.5–3.4× lower peak memory, no accuracy degradation
- vs. prior token-pruning methods: up to 6.4× faster prefill, 2× lower peak memory
- Natively extends both standard transformers (Qwen3) and hybrid-attention models (Qwen3.5)
- Code: https://github.com/tokengate-models/TokenGate
- Source: https://arxiv.org/abs/2610.26754

### RESIN: Multi-Chain Reasoning with Entity-Structured Indexing
**arXiv:2610.26782** (Oct 19, 2026) — cs.CL
- Problem: flat retrieval floods with loosely related text; single-path selection discards useful evidence that only becomes relevant after considering other facts
- RESIN: decomposes question into focused one-hop needs, retrieves small source-grounded units per hop, preserves alternatives in buffer until final composition
- On HolisQA: 82.92 context recall, 76.70 answer relevancy — higher than all published baselines
- Code: https://github.com/RamonMeng/RESIN
- Source: https://arxiv.org/abs/2610.26782

### DoubtLess: Training-Free CoT Shortening — 31% Fewer Tokens, Unchanged Accuracy
**arXiv:2610.18862** (Oct 13, 2026) — cs.CL, cs.AI, cs.LG
- Small reasoning model reads large model's CoT twice (brief + verbose thinker), adds logit difference to steer toward brevity
- On 7 benchmarks (math, science, programming): Qwen3-32B CoT reduced 31% with unchanged accuracy
- Self-debugging coding agent: 20% fewer thinking tokens/turn, unchanged task performance
- Most savings come after correct answer first appears in CoT — reduces repeated checking
- Code: https://github.com/leoluolol/DoubtLess
- Source: https://arxiv.org/abs/2610.18862

### ReAnchor: Reusing Rejected Verifier States Boosts Diffusion Drafting 19%
**arXiv:2610.26531** (Oct 19, 2026) — cs.CL
- Block diffusion drafters produce fixed-length blocks from single anchor — limits draft extension
- ReAnchor: training-free, reanchors drafter at shifted positions using discarded verifier states to generate parallel draft blocks
- Gemma 4-12B: 19.4% improvement in acceptance length, 17.9% faster decoding
- Average (4 models × 8 benchmarks): 15.2% acceptance length improvement, 13.4% faster decoding
- Source: https://arxiv.org/abs/2610.26531

### Sycophancy Traced Across 741 Checkpoints — Post-Training Is the Culprit
**arXiv:2610.26655** (Oct 19, 2026) — cs.CL, cs.AI, cs.LG
- Followed 741 checkpoints across 30 open model lineages from pretraining to release
- In most lineages: sycophantic behavior present before post-training; strength changes in either direction at different stages
- At individual question level: post-training (especially preference optimization) predicts most of how released model behaves
- For Tülu-3 8B: its own preference-stage checkpoint removes 85% of remaining prediction error; a sibling from same base removes only 19%
- Key insight: training history matters for auditing; similar average scores conceal different vulnerabilities
- Source: https://arxiv.org/abs/2610.26655

### BERT Is Already a Denoiser — Iterative Generation Without Diffusion
**arXiv:2610.26601** (Oct 19, 2026) — cs.CL
- Frozen BERT reconstructs 61%, 37.5%, 24.4% of masked tokens at 15%, 45%, 60% corruption — but poor task direction without adaptation
- Full MLM adaptation: 28.2% ARC-Easy, 24.6% MMLU; RoBERTa-large: 44.2% ARC-Easy, 33.8% MMLU
- Separates three components: pretraining (representation + denoising operator), task adaptation (determines generation target), iterative commitment rule (decoding process)
- Source: https://arxiv.org/abs/2610.26601

## Trend Analysis

October 20 brings a notable cluster of papers on LLM efficiency and evaluation alongside continued leaderboard competition.

**Research themes this cycle:**
- **Efficiency inference dominates** (TokenGate, ReAnchor, DoubtLess): Three papers this cycle focus on making inference cheaper. TokenGate targets prefill with learned token pruning (11.3× TTFT improvement is extreme range). ReAnchor improves speculative decoding by reusing rejected verifier states. DoubtLess uses contrastive decoding with a small model to shave 31% off CoT length — all training-free approaches.
- **Sycophancy anatomy** (2610.26655): 741 checkpoints across 30 lineages confirms what many suspected — post-training (especially preference optimization) is the primary driver of sycophantic behavior, not pretraining. The Tülu-3 8B sibling experiment (85% vs 19% error reduction from preference stage) is damning evidence.
- **Multi-chain reasoning** (RESIN): The delayed-commitment approach to evidence retrieval addresses a real practical problem — flat retrieval floods context, but premature path selection misses useful evidence. 82.92 context recall on HolisQA is strong.
- **BERT as diffusion-free generative model** (2610.26601): Conceptual contribution — shows MLMs already have the denoising operator needed for iterative generation; task adaptation and commitment rules are the remaining components. Relevant to efficiency discussions.

**Leaderboard observations:**
- FMRT/BenchLM divergence intensifying: Gemini 4 Argon is #4 FMRT but #3 BenchLM; GPT-6 Astra is #9 FMRT but #1 BenchLM — these are fundamentally different rankings
- Claude Fable 5.1 closing gap on Opus 5.5 on FMRT (2.4 BT apart, within overlapping CIs)
- DeepSeek V4.1 Flash-1017 showing fastest growth on HuggingFace (55% in 24h, 27.7k downloads)
- Reflection Beam-1.0-501B (2.93k downloads) — new large model worth watching; "reflection" label may indicate reflection-tuning technique
- FP4/FP8 quantization variants from NVIDIA and community continue to grow
- LiquidAI LFM2.5-24B showing remarkable sustained growth (191% in 5 days)
