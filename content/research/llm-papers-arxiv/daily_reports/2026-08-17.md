# Daily Report — 2026-08-17

## New Insights

### Amplification-Lift Gap in Thinking Models (COLM 2026)
**arXiv:2608.13760** — Reasoning models amplify the wrong behaviors. Self-correction, hypothesis testing, and uncertainty acknowledgment get amplified 3-7× by thinking-oriented training, but the highest-lift behaviors (confidence calibration, knowledge alignment, self-awareness) are barely amplified. 15 models, 15,282 traces across text and vision-language reasoning. Key implication: process-level objectives needed that reward calibrated/grounded reasoning over surface deliberateness.

### IterCOMP: Adaptive Prompt Compression for Multi-hop QA (ACL 2026)
**arXiv:2608.13588** — Training-free iterative prompt compression framework. Decomposes documents → evaluates answerability → generates follow-up questions → integrates essential evidence. Substantial EM/F1 improvements on MusiQue, 2WikiMultiHopQA, HotpotQA while reducing token budget. Robust as reasoning complexity increases.

### BCMT: Blockwise Causal Memory Transformer
**arXiv:2608.13578** — Long-context architecture decoupling local token interactions from global context via exponential causal memory. Comparable performance to dense transformers but improved training throughput and reduced memory. Up to 1024 token context lengths validated.

### LSP Costs More Tokens Than Grep for Coding Agents
**arXiv:2608.13568** — LSP (Language Server Protocol) costs +6% to +118% more tokens on symbol localization; agents ignore it when free. Grep solves multi-file renames perfectly; even complete, index-warmed LSP fails 3/4 of them (misses comments/strings). Adaptive tool selection needed.

### GRPO Multilingual Reasoning: Native Language Training Works Well
**arXiv:2608.13698** — Large-scale study of RLVR/GRPO across many languages. Training in native language leaves small gap vs English. Strong crosslingual transfer. Risk: language-specific regressions require broad evaluation.

### Modular Cognitive Architecture Emerges in LLMs
**arXiv:2608.13567** — LLMs develop modular architecture mirroring human brain. Tasks drawing on same human brain network recruit overlapping neurons in LLMs. Convergent emergence suggests modularity is fundamental property of intelligent systems.

### Stable Miscalibration in LLMs
**arXiv:2608.13591** — High-confidence errors may be stable miscalibration, not fragile inference. Self-critical prompting reduces hidden-state sensitivity. Some overconfident errors are stable/miscalibrated rather than simply fragile.

### CLAIR-Fin: Adversarial Multi-Agent Financial QA
**arXiv:2608.13706** — Nine-agent framework with Financial Claim Ledger. Faithfulness 0.780 → 0.889 on BB-FinQA-X. Abstains on 5.4% questions when evidence insufficient.
