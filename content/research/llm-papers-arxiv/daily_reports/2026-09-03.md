# Daily Report — 2026-09-03

## New Insights Summary

### 1. Declarative Attention: LLM-Native Sparse Attention
**arXiv:2609.02737** — Chain-of-thought efficiency via model-controlled attention. Models declare `<global>`, `<focus>`, or `<local>` mode within CoT, enabling KV cache skipping. Gemma-4-31B: 52% token reduction, 1.27pp accuracy drop. Qwen-3.6-27B: 31% reduction, 2.75pp drop. Key insight: models already know which context parts matter — DA elicits this intrinsically.

### 2. EarlyEval: Cheaper Agent Evaluation via Early Outcome Prediction
**arXiv:2609.02783** — EMNLP 2026 Main. Trains LightGBM classifiers on behavioral features to halt agent runs early. 13-26% step reduction, 44.1% input token reduction, 29.4% output token reduction at 89-97% accuracy across SWE-bench Verified, TerminalBench, Toolathlon. Key insight: final outcome often evident from intermediate behavior well before execution completes.

### 3. HyperStyler: Low-resource Authorship Style Transfer
**arXiv:2609.02772** — EMNLP 2026 Main. Uses Stylo-navigator + Stylo-hypernet for style transfer with 2.4% additional parameters over T5-large, 1.8x faster than LLMs. Outperforms LLM-based approaches on Reddit, Blog, News datasets.

### 4. REAL-Q: E2E-Loss Aligned LLM Quantization
**arXiv:2609.00049** — Addresses information misalignment in PTQ via dynamic block-wise gradient descent (128 columns) with sliding window. ~49% KL divergence reduction vs state-of-the-art on LLaMA-3.1 (8B, 70B) and Qwen3 at W4A16. Key insight: fine-grained correction with sliding window mitigates error propagation.

### 5. User Feedback Signal for LLMs
**arXiv:2609.02859** — User feedback is highly actionable for LLM improvement. Root cause of perceived ineffectiveness: LLM judges systematically prefer inferior baseline outputs over feedback-corrected responses. Key insight: evaluation bias limits feedback-driven learning, not feedback quality.

### 6. CORAL: LLM-Native Recommender Harness
**arXiv:2609.02730** — RecSys '26 OARS Workshop. Agentic loop for production recommenders: observes signals, reasons over memory, invokes optimizer tools. Two platforms: engagement improvement at same cost OR cost reduction without engagement drop. Key insight: single agentic loop automates continual optimization.

### 7. Misleading Context in Medical QA
**arXiv:2609.02754** — ML4H 2026. Models more susceptible to bare assertions (10-27 points) than fabricated evidence. LLM monitors catch 78% of corrupted decisions from open reasoning traces vs 32% from responses. Key insight: what models are most susceptible to is least disclosed; frontier models withhold reasoning traces.

### 8. Influence-Guided Response Rewriting
**arXiv:2609.02771** — Response rewriting produces stronger, more persistent behavioral shifts than reweighting same examples. Same qualitative contrast extends to safety refusal. Key insight: local reweighting effects ≠ broader intervention leverage.
