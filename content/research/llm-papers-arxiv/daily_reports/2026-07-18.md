## New Findings (July 18)

### 1. CausalDS: Causal Reasoning Benchmark for Data-Science Agents
- New benchmark evaluating causal reasoning, data science, and tool use in LLM agents
- Uses synthetic SCMs with observational data and natural-language stories
- Tasks span Pearl's three causal inference rungs: association, intervention, counterfactual
- First major benchmark specifically targeting causal reasoning within agentic data-science workflows
- **Significance:** Enables systematic evaluation of causal reasoning in operational agent contexts

### 2. Verifier-Based RL Fine-Tuning (RFT)
- Adapts reasoning models for physical control tasks using dense verifiable rewards
- Converts DP action values into dense rewards → bridges RL to real control tasks
- Results: CO2 emissions reduced from 70.5 to 61.2 kg (near-optimal: 60.8 kg)
- **Significance:** Demonstrates RL fine-tuning of reasoning models for non-language domains

### 3. Digital Pantheon: Coalition Formation with LLM Agents
**arXiv:2607.15095** (July 16, 2026)
- Multi-agent political coalition simulation using SFT + DPO + per-party RAG
- MILT traces agreement clauses back to manifesto origins
- CIS identifies which party shaped the agreement
- Validated on 2019 Flemish election; predicts real-world outcomes
- Manifesto-anchored lineage predicts materialization; hallucinated content does not

### 4. Ring-Zero: Zero-RL for Trillion-Parameter Models
- Scales RL with verifiable rewards and NO human-annotated data to trillion-parameter regime
- Addresses: poor readability, token redundancy, non-adaptive reasoning depth
- Techniques elicit high-quality CoT behavior at scale
- Community interest: If transferable to open weights → controllable reasoning without annotation pipelines
- Key differentiator: adaptive reasoning depth (treats reasoning setting as upper bound, skips on trivial queries)
