### ConvMem: Training-Free Long-Context Reasoning via Hierarchical Convolution
Sequential memory approaches (MemAgent) extend context but suffer high latency and require costly RL training that overfits to specific datasets. ConvMem reformulates long-context reasoning as a hierarchical convolution, treating an LLM prompted with a specific query as a convolutional kernel. This shortens the reasoning path from a linear chain into a logarithmic tree.

Key innovations: Configurable Strides and Skip Connections for robust evidence capture, Multi-Kernel Convolution to decompose complex queries into disentangled semantic channels. Enables massive parallelization across text segments and reasoning threads.

Outperforms training-free baselines on RULER-HotpotQA and RULER-2WikiMultiHopQA. Avoids the overfitting risk that RL-trained models face on out-of-distribution tasks.

**Significance:** Long-context reasoning may not require expensive training or sequential processing — a convolution paradigm could make 100K+ context commercially viable without specialization.

### Fortunate Recall: Curing LLM Memory Hallucination via Lifecycle Management
Current LLM memory systems treat all personal facts identically — stores grow without bound, retrieval precision degrades, and confabulation increases. Fortunate Recall (FR) introduces a 10+1 behavioral ontology for personal facts and applies category-specific lifecycle policies: differential temporal decay, slot-key supersession, event-time validity, and category-aware retrieval routing.

FR-Bank reaches 76.9% on LifecycleBench (516 questions) — ahead of Mem0 (61%), A-MEM, Memory-R1, and MemoryOS (up to 70.5%). 75.2% on LongMemEval-S under the canonical Wu et al. judge protocol with no measurable cost on standard retrieval.

The key decomposition: generic lifecycle metadata carries the correctness advantage (statistically unchanged at -1.7pp when replacing the typed layer), while the behavioral ontology carries calibration — cutting downstream confabulation from 45.1% to 22.4% (Mem0 baseline) and from 32.2% to 13.0% (all queries). Results replicate on open-weight Kimi K2.5.

**Significance:** Memory lifecycle management is a solved problem at the infrastructure level — the remaining challenge is behavioral typing of facts. Confabulation halving via taxonomy is a strong result.

### TRACE: Causal Diagnostic Reasoning with Synthesized Rewards
RLVR excels in math and code where answers are verifiable, but diagnostic reasoning (finding root causes in complex data) lacks this advantage. TRACE engineers verification by sampling an intervention, injecting it into a controlled simulator, and generating the observations it would produce — the hidden intervention provides an oracle label and objective reward.

Instantiated in a digital-advertising diagnostic environment (12 root causes, fine-grained segment attribution). On a 235-episode held-out test: strongest prompted baseline (Claude Opus 5) reaches 0.686 FullAttr@1. SFT raises Qwen3.5-35B-A3B from 0.159 to 0.637; subsequent RL with synthesized rewards reaches 0.757 — outperforming all prompted baselines including frontier closed-source models. The policy also uses substantially fewer tool calls than the prompted 35B base.

**Significance:** Simulation-based verification makes ambiguous diagnostic reasoning tasks amenable to scalable RL. This opens RLVR to enterprise diagnostics, fraud investigation, and scientific data analysis — domains previously thought to require human expert labeling.

### JarvisGUI: Cross-Device GUI Agents (EMNLP 2026)
Existing GUI benchmarks evaluate agents on single-device, statically defined tasks — resulting in an overly optimistic assessment of real-world readiness. JarvisGUI introduces a dynamic benchmark evaluating cross-device workflows across Android, Windows, and Ubuntu, formulating GUI tasks as input-output transformations under a lightweight type system.

Reveals that state-of-the-art open-source GUI agents struggle with: state-transfer awareness, cross-platform contextual reasoning, and long-horizon dependency management. These gaps are invisible to existing single-device benchmarks.

**Significance:** Agent capability assessment is due for recalibration. Real-world GUI workflows expose a critical capability gap that single-device benchmarks systematically conceal.

### FGPO: Full-Group Policy Optimization for Scientific Tool Selection
Standard GRPO degrades in specialist scientific settings where the tool-subset space is enumerable but combinatorial. As training succeeds, sampled rewards collide and the group-normalized advantage vanishes — the fraction of questions yielding no reward signal rises from 0.2% (uniform reference) to 20.8% (after GRPO training).

FGPO scores every tool subset and optimizes the exact action expectation (vs GRPO's sampling). Precomputes the reward of each question–subset pair into an exhaustive table, removing frozen-reasoner calls from the training loop entirely.

Outperforms GRPO in all 15 evaluated settings (5 frozen reasoners × 3 genomic benchmarks) by 6.75 points on average, up to 14.20. Cuts invoked tools per question from 2.36 to 1.40. On GenomeQA specifically, FGPO requires 2.4× fewer frozen-reasoner reward evaluations than standard GRPO.

**Significance:** GRPO's advantage estimation breaks down systematically in structured scientific domains. Exhaustive action-space optimization is viable when the domain bounds are known — a key insight for scientific agent design.

### RD-Forget: Separating What an Agent Stores from What It Uses
Persistent language agents face a fundamental tension: superseded facts can mislead current answers yet remain essential for historical queries. RD-Forget separates stored experience from query-dependent evidence use — a retained source archive preserves all observations, while a query-conditioned memory view controls their influence on each answer.

A frozen language-model curator extracts relevant evidence, groups facts into semantic slots, and preserves historical accessibility.

**Significance:** The store/use distinction provides a principled architecture for persistent agents that need both long-term coherence and temporal accuracy.
