## New Findings Today (Aug 21 Listing — Tail Papers)

### 1. OenoBench: Wine-Domain Knowledge Benchmark for LLMs
**arXiv:2608.20106** (Aug 20, 2026) — cs.CL
- 3,266 MC questions across 6 pillars and 4 difficulty tiers, built from 38,104 provenance-verified facts
- 16 frontier configs: accuracy 53%-84%, led by o3 at 83.6%. Reasoning-mode lift only in DeepSeek R1 (+6.8pp), absent in Claude Opus and Gemini Pro
- Frontier open-weight models share Pareto frontier with proprietary reasoning models on domain-specific knowledge
- Key insight: Open-weight models have closed the gap with frontier proprietary models on specialized domain knowledge
- **Paper:** https://arxiv.org/abs/2608.20106

### 2. FlashPrefill V2: 47x Speedup for Long-Context LLM Serving
**arXiv:2608.19758** (Aug 20, 2026) — cs.CL
- Block-sparse prefill attention, production-ready: FP8, paged KV cache, continuous batching (SGLang-compatible), FlashAttention-3/4 aligned
- Up to 47.26x speedup over FlashAttention-2 at 128K context (FP8), 27.19x (BF16)
- Key insight: Production-grade sparse prefill for 128K+ context is now viable on H20 GPUs
- **Paper:** https://arxiv.org/abs/2608.19758

### 3. UniLang: Unified Generative Framework for Machine-Native Symbols
**arXiv:2608.19529** (Aug 20, 2026) — cs.CL, cs.AI
- Treats discrete machine-native symbols as first-class generative units alongside text tokens under single autoregressive objective
- Outperforms strong baselines on sequential recommendation and legal precedent prediction
- Key insight: Structured prediction and language modeling unified — no verbalization or task-specific architectures needed
- **Paper:** https://arxiv.org/abs/2608.19529

### 4. Hear2Act: Prosody Matters Only When Lexical Evidence is Insufficient
**arXiv:2608.19515** (Aug 20, 2026) — cs.CL
- 480 scenarios testing prosodic cues vs explicit lexical feedback in task-oriented dialogue
- Audio-capable LLMs recover prosodic info but don't reliably carry it into action without explicit intermediate representation (39.6% vs 40.7% ground truth)
- Key insight: Prosody adds value only when lexical evidence is insufficient — explicit intermediate representation is the critical step
- **Paper:** https://arxiv.org/abs/2608.19515

### 5. TCS Research Benchmark: Autoformalization is Sharpest Bottleneck
**arXiv:2608.20153** (Aug 20, 2026) — cs.CL
- 175 instances from STOC/FOCS/SODA/COLT 2025-2026 with expert-verified Lean formalizations
- Autoformalization: best model 11.5 Pass@1 vs 28.6 Pass@8 for human-provided formal statements
- Automated framework: 64 generated claims → only 6 pass expert evaluation + proof verification
- Key insight: Limited research taste is another major barrier beyond formalization — autonomous TCS research still far from reliable
- **Paper:** https://arxiv.org/abs/2608.20153

### 6. Patient-Context Agent: +57.1pp Accuracy via Ambiguity Mitigation
**arXiv:2608.19875** (Aug 20, 2026) — cs.CL, cs.AI
- Knowledge-guided framework: interprets query → constructs hypotheses via knowledge graph → asks targeted follow-up questions → combines into clarified prompt
- Diagnosis retrieval: +57.1pp Top-1 accuracy, +77.7pp Recall@5 vs direct prompting across 5 models
- Key insight: Structured hypothesis-followup dramatically outperforms direct answering for underspecified health queries
- **Paper:** https://arxiv.org/abs/2608.19875

### 7. ReCache: 3.655x Speedup for Tool-Augmented LLM Agents
**arXiv:2608.19662** (Aug 20, 2026) — cs.CL
- Resource-wise attention removes cross-resource interactions, producing composition-invariant KV blocks; structural + semantic pruning
- Matches dense invocation (82.3% vs 82.4% Inv-F1), 3.655x time-to-first-token speedup, 92.43% KV memory reduction
- Key insight: Separating reusable schema encoding from selective resource access enables practical agentic inference at scale
- **Paper:** https://arxiv.org/abs/2608.19662
