- **C6 — "AA index 48" for GPT-6.1 Terra is stale.** The live Artificial Analysis model page reports Intelligence Index 51 (raw 51.33), rank #31/95 — the Oct 28 value of 48 has been revised upward and the snapshot can no longer be reproduced.
- **C6 — "792 points" is a Hacker News score, not a research score.** The Exponential Time Hypothesis submission now stands at 805 points / 302 comments (story 2026-10-26T21:59Z), stale by ~13 points. The underlying OpenAI research release is confirmed: the post has a section titled "The Exponential Time Hypothesis is false" (proof found Oct 16, Lean-formalized Oct 17, 2026).
- **C8 — HF trending snapshot has rotated three weeks past reproduction.** Current top-25 is entirely different (higurashi-ai/Haru-4B, tencent/Hy4-flash, apple/FastFrames-L …); flint is out of the top-25 and has grown 14,047 → 62,433 downloads / 1,144 → 1,439 likes; DeepSeek-V4.1-Flash-1017 grew past the quoted 116,770 to 502,094 downloads / 5,977 likes. The "33B" parameter count for Nanbeige4.3-33B was not independently confirmed from API metadata.
- **C9 — Reddit engagement counts are not reproducible.** Reddit returns HTTP 429 for RSS and permalink fetches; the Redlib mirror is behind an Anubis browser challenge. Titles, subreddits and October dating are confirmed for four of seven posts; the vote/comment pairs remain unverified. Three posts ("The Paper Reviewing Process is Now in Critical Condition", "Papers with Code is now open-source", the Qwen Flash Next / Cohere pair) could not be independently confirmed.
- **C10 — title nit (not a status change).** The paper's full title is "The View from Nowhere: Population-Centered Agent Evolution" (Shuo Yan, Ningning Hou, Haoyu He, Haochen Pei, Shang Gao; v1 Oct 27, v2 Oct 29 2026). "Population-Centered Evolution" is the method name, not the standalone title. `huggingface.co/papers/2610.36660` returns 404 — the paper is not referenced from any HF repo README.
