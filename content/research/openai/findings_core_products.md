## DALL-E and Image Generation

### DALL-E 3 (Current Version)
- **Key Capabilities**:
  - Text-to-image generation with precise adherence to prompts
  - Improved prompt understanding compared to previous versions
  - Automatic generation of tailored, detailed prompts
  - Image refinement capabilities (users can make tweaks with minimal input)
  
- **Safety Features**:
  - Declines requests for public figures by name
  - Improved safety performance for visual bias issues
  - Will not create images in the style of living artists (with opt-out options)
  - Research on provenance classification for AI-generated content

- **Usage Rights**: Images created with DALL-E 3 are fully owned by users for commercial use
