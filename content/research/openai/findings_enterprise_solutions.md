## 2. Security, Compliance & Data Privacy

### Data Protection & Encryption
- **Default Training Exclusion**: By default, customer data is NOT used for model training
- **Encryption at Rest**: AES-256 encryption for all stored data
- **Encryption in Transit**: TLS 1.2 or higher for all data transfers
- **Enterprise Key Management (EKM)**: Optional customer-controlled encryption keys
- **Data Residency**: Support for storing sensitive customer content in multiple regions (US, Europe, UK, Japan, Canada, South Korea, Singapore, Australia, India, UAE)

### Compliance & Security Certifications
- **CCPA Compliance**: California Consumer Privacy Act compliance
- **CSA STAR**: Cloud Security Alliance STAR certification
- **SOC 2 Type 2**: Service Organization Control 2 Type 2 compliance
- **HIPAA Support**: Available for healthcare industry customers
- **FINRA Support**: Available for financial industry customers
- **GDPR Compliance**: General Data Protection Regulation support

### Administrative Security Controls
- **Zero Trust Architecture**: Security implemented from design through deployment
- **Defense in Depth**: Layered security controls across endpoints, infrastructure, networks, and applications
- **24/7 Security Team**: On-call security rotation with automated alerts and manual investigation processes
- **Regular Audits**: Independent third-party audits including red team and adversarial assessments
- **Supply Chain Security**: Security implemented throughout the software development lifecycle

### Data Retention Controls
- **Custom Retention Windows**: Organizations can configure how long OpenAI retains business data
- **Zero Data Retention Option**: Available for qualifying organizations in the API platform
- **Selective Retention**: Controls for different types of data and use cases
