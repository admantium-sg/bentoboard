## Simon Willison

### Weblog (5 new)

- **2026-11-15** [datasette 1.0a43](https://simonwillison.net/2026/Nov/15/datasette/) — Release: datasette 1.0a43. "I've been leaning hard into Claude Fable 5.2 to help knock things off the 1.0 milestone, which is now 53% complete." Biggest 1.0 item so far: streaming support for output renderers — built-in TSV and CSV export now stream too, and plugins can register as capable of streaming every row in one go via the new `Response.stream()` method. Two security fixes, one deemed deserving of a GitHub advisory: private stored queries could be exposed, granting access to the title and SQL of the query (though not allowing it to be executed).
- **2026-11-15** [datasette 0.65.6](https://simonwillison.net/2026/Nov/15/datasette-2/) — Release: datasette 0.65.6. Backported the minor security fix from 1.0a43: a database registered via `add_database(db, name=..., route=...)` with a route differing from its name could be downloaded from `/<route>.db` by actors denied access to it.
- **2026-11-15** [datasette-maplibre 0.1a0](https://simonwillison.net/2026/Nov/15/datasette-maplibre/) — Release: datasette-maplibre 0.1a0. The first new Datasette geospatial plugin in quite a while, combining MapLibre GL with OpenFreeMap (the free vector map server operated by Zsolt Ero). "I built most of this with a single prompt to Claude Fable 5.2" — asking it to study datasette-cluster-map and datasette-leaflet-geojson and then "be creative and think outside the box". His favourite result: it displays SVG previews of GeoJSON shapes and only loads a WebGL preview when they scroll into view.
- **2026-11-15** [datasette-apps 0.4a0](https://simonwillison.net/2026/Nov/15/datasette-apps/) — Release: datasette-apps 0.4a0. Datasette Apps are sandboxed HTML/JS applications living inside Datasette — "think Claude Artifacts, but these ones can run SQL queries against your data". 0.4a0 adds linking: `#fragments` in the URL are visible to the app, and supported URL schemes are reported back to Datasette Agent so it can help write apps that link to each other.
- **2026-11-15** [datasette-agent 0.6a0](https://simonwillison.net/2026/Nov/15/datasette-agent/) — Release: datasette-agent 0.6a0. Accumulated fixes for his agent plugin, which lets you ask questions about your data. Most notably it now adds an agent prompt directly to the Datasette homepage, with support for hash-mentions of tables and queries (e.g. "Tell me about #re" autocompleting to the repos and releases tables).
