## Summary

A quiet day by volume but not by substance: four genuinely new artefacts, three of them Harrison's and one Simon's, with the rest of the radar reduced to re-fingerprints and counter ticks. The event of the day is LangChain's "Agents Are Going Async", which makes the case that the ReAct loop's blocking-tool-call structure is now the binding constraint on agent work, and answers it by splitting the agent into a user-facing orchestrator plus background subagents that run as un-awaited tasks — the same convergence Claude Code (background subagents by default), OpenAI's dots and DeepSeek's harness router have reached from the other side. The design details are worth stealing: five lifecycle tools, an `update_strategy` field that separates a correction ("interrupt", restart with the new instruction) from an addition ("enqueue", deliver after the current run), and approvals handled on the subagent's own thread so a pending consent never freezes the orchestrator, with the post explicitly hinting the pattern generalises from subagents to tools, echoing OpenAI's async tool calling. Harrison frames the payoff in one line — agent throughput now scales with the number of background workers rather than the length of one loop — and his accompanying X post claims most agents LangChain builds internally already rely on async subagents meaningfully, so this reads as dogfooding rather than roadmap. The companion YouTube piece, "LangChain vs. LangGraph vs. Deep Agents: when to use each one", is a vendor writing its own selection guide at exactly the moment its product surface has split three ways, which is either the clearest positioning anyone in this space has attempted or an admission that the naming confusion has become a sales problem. Simon Willison contributed the day's only non-agent item, a quotation of Paul Ford on the browser being very powerful application software whose cost of access keeps falling — Ford's evidence being Tiny Little Office, a URL-stored office suite that took a couple of hundred thousand visitors at roughly zero hosting cost, which is a tidy counterpoint to this week's browser-agent cost benchmarks. Everything else was inert: 99 of the 110 updates are LangChain blog re-fingerprints (title and summary swapped fields, no content change), and Lilian Weng and Chip Huyen shipped nothing new for a thirteenth consecutive day.
