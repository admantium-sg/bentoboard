### 2. Anthropic Launches Managed Agents (April 16, 2026) - After Blocking OpenClaw (April 4)
**The 12-Day Enclosure Play:**
- April 4: Anthropic quietly blocked Claude Code subscriptions from calling OpenClaw (no announcement)
- Community discovered via HN thread that climbed past 1000 points in 48 hours
- April 16 (12 days later): Anthropic launched Managed Agents public beta - official agent runtime with sandboxing and built-in tools

**Why It Matters:**
- Anthropic enclosed the "harness layer" - the runtime container that makes a model behave like a persistent agent
- OpenClaw had captured enterprise value (enterprises paid OpenClaw, not Anthropic)
- OpenClaw's plugin ecosystem was approaching critical mass (1,200+ skills)
- OpenClaw shipped multi-model routing, allowing users to swap Claude for GPT-5 - undermining Anthropic's pricing power
- This represents a new competitive dynamic at the harness/platform layer

**Managed Agents Capabilities:**
- Sandboxed file system (1 GB quota during beta)
- Shell command execution
- Web browsing
- Code execution
- Async API for agent definition submission
