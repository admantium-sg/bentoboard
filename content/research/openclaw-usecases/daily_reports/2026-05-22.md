## Findings Summary

### Platform Releases — v2026.5.20 Stable (May 21, 20:44 UTC)

**Critical Security Fix — SKILL.md Sandbox Bypass Blocked:**
The most important change in this release removes the old `cat SKILL.md && printf ... && allowlist` compatibility path. Skill files must now be loaded via the read tool, and only raw skill executables are auto-allowed. This shuts down malicious "Trojan skills" attempting to smuggle arbitrary shell commands under markdown pretenses. Community commentators noted: "The lobster's shell has finally been hardened; it's like putting bulletproof armor on our lobsters."

**Discord Voice User Following Officially Live:**
The Discord voice proxy's "VC User Following" function is now stable. The agent can automatically follow configured Discord users in and out of voice channels, with allowed-channel safety checks, multi-user manual handoff, and DAVE encryption recovery.

**Realtime Voice Session Instruction Upgrades:**
Voice sessions now load IDENTITY.md, USER.md, and SOUL.md profile context by default. The agent is "deeply aware of its soul and mission" when speaking. Users can disable via `voice.realtime.bootstrapContextFiles: []`.

**Policy Plugin Integration:**
New bundled Policy plugin supports policy-backed channel conformance checks, doctor diagnostic lint findings, and opt-in workspace repair.

**Additional Changes:**
- xAI device-code OAuth for headless/remote setups
- OpenRouter provider-level routing policy with model/agent param overrides
- Per-agent `experimental.localModelLean` for lean local-model mode
- Cron now delivers preferred final assistant output even when trailing plain tool warnings remain
- @openai/codex bumped to 0.132.0
