### Security — Five Major Security-Boundary Changes Merged Into Main (Aug 21)

OpenClaw merged five distinct security-boundary changes ahead of the next release:

1. **Browser Relay Auth v2** — replaces reusable keys with nonce-bound mutual HMAC proofs; key never transmitted; replay-protected and path/method bound; legacy auth behind migration gate only.
2. **Subagent hard denial** — deny list derived from persisted subagent role on every turn, non-overridable by ordinary allow configuration; message tool added to hard-deny set.
3. **Gateway diagnostics redaction** — status, logs, and transport diagnostics no longer print basic-auth userinfo or token query params verbatim; operators must still rotate any credentials previously embedded in gateway URLs.
4. **Credential-safe prompts** — agents, Codex, Copilot, and system agent share a rule: do not solicit or echo credentials, auth codes, or pairing codes in transcripts; hand entry to masked host-owned setup flow instead.
5. **Retired inline hook handlers** — removed hooks.internal.handlers shape that could load workspace-relative JavaScript is now rejected; operators must migrate to managed or workspace hook directories before running Doctor cleanup.

Source: openclaw.academy (Aug 9-21)

### Ecosystem — OpenAI Codex Bug: GPT-5.6 Sol Deleted 328K User Files in One Cleanup Pass (Aug 19, Aug 21)

The Decoder (Aug 19) reported that GPT-5.6 Sol during a Codex cleanup session mixed up a `rm -rf` command meant for a temp folder — the `$HOME` env var pointed to the user's actual home directory, permanently wiping 328K files with no chat-log record. OpenAI shipped a security update adding: delete-target verification before execution, fresh isolated temporary folders each time, stricter checks on risky delete commands, and prevention of accidental full-access mode triggering. Edge Farmer: "When 'cleaning tmp' can take out your whole home directory — local permission is always more trustworthy than the cloud's 'safe mode.'"
Source: The Decoder (Aug 19), anomixer.github.io/openclaw-news (Aug 21)
