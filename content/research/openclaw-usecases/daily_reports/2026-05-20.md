## Key Findings (May 20, 2026)

### Platform Releases — v2026.5.19-beta.1 (May 19, 2026)

**Headliner changes:**

**Dependency updates:**
- **Node.js minimum raised to 22.19** — raising the minimum supported Node.js line to 22.19 across all OpenClaw components
- **@openclaw/proxyline updated to 0.3.3** — likely carrying proxy-related fixes or improvements
- **Pi packages updated to 0.75.1** — core runtime package refresh

**Developer tooling:**
- **Python debugging skill:** pdb, breakpoint(), post-mortem inspection, and debugpy remote attach support
- **Meme-maker skill:** Curated template search, local SVG/PNG rendering, Imgflip hosted rendering, and Know Your Meme provenance links
- **Node inspector debugging:** Spike workflow skills for debugging
- **/codex plugins list, enable, disable** — native Codex plugin management commands from chat
- **openclaw browser evaluate --timeout-ms** — long-running page functions can extend both evaluate action and request timeout budgets

**Gateway performance:**
- **Startup overlap optimization:** Gateway startup logging and plugin-service startup now overlap with channel sidecars, reducing restart ready latency while preserving /readyz sidecar gating
- **Startup probe attribution:** Startup probe, config, runtime, and resource-count costs attributed in restart traces

**Mac App:**
- **Settings redesign** (carried from May 18 pre-release) — consistent card layouts, cached navigation, cleaner permissions/voice/skills/cron/exec/debug panes, steadier spacing around native sidebar
- **Voice & Talk recognition-language and wake-phrase settings** refined to use compact card rows matching rest of Settings

**Docker/Podman improvements:**
- **OPENCLAW_IMAGE_APT_PACKAGES** — new runtime-neutral image build arg for extra apt packages (legacy OPENCLAW_DOCKER_APT_PACKAGES preserved)
- **OPENCLAW_IMAGE_PIP_PACKAGES** — opt-in Python package installation in local image builds

**QA-Lab expansion:**
- **Runtime parity scenarios:** First-hour 20-turn and optional 100-turn scenarios with tier metadata for standard and soak QA gates
- **Token-efficiency artifact lane:** Live-frontier Codex-vs-Pi runtime token-efficiency artifact lane scheduled in all-lanes QA workflow
- **Tool fixture coverage:** `openclaw qa coverage --tools` exposes coverage for Codex-native, OpenClaw dynamic, and plugin-backed tools
- **Release gate hardening:** Required OpenClaw dynamic runtime-tool drift now hard-gated in standard Codex-vs-Pi tier with blocking release-check verifier
- **Personal-agent approval-denial scenario:** Benchmark verifies denied local reads stop cleanly without tool progress leaks
- **Live-only harness self-health scenarios:** Plugin hook crashes, manifest contract errors, WebChat direct-reply self-message routing

**Proxy & network:**
- **HTTPS forward-proxy support** (from May 18 pre-release) — support for HTTPS managed forward-proxy endpoints with scoped proxy.tls.caFile CA trust for proxy endpoint TLS

**Security hardening:**
- **Codex app-server fails closed** — when chat or sender policy denies tools, native MCP surfaces disabled for restricted turns
- **Plugin hook timeout** — default 15-second timeout on legacy before_agent_start hooks prevents hung plugin handlers from blocking agent startup

**Plugin ecosystem:**
- **Admin HTTP RPC clients** can now start and wait for web QR login flows — enabling trusted admin integrations to bridge login sequences
- **Plugin presentation capability limits** — channel renderers expose capability limits, adapt rich message controls before native rendering
- **Legacy interactive/Slack directive producer APIs** marked as deprecated

**Skills & CLI:**
- **Skills CLI --global flag** — `openclaw skills install` and `openclaw skills update` can now target shared managed skills with --global
- **Repo-local Codex closeout review skill** renamed to "autoreview" with preserved Codex-first fallback behavior
- **Obsidian skill updated** — now targets official obsidian CLI, dropping third-party obsidian-cli dependency
- **Plugin delivery route canonical metadata** — channel delivery routes stored as canonical session metadata (deprecating ad hoc subagent hook delivery-origin fields)
