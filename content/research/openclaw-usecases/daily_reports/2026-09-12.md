# DIAC Daily Report — OpenClaw Use Cases
**Date:** 2026-09-12
**Topic:** openclaw-usecases

## New Findings (3)

### Platform — v2026.9.4 Ships Sep 11: Skill Learning, Cloud Ready-Workers, GPT Image 2.5
OpenClaw v2026.9.4 landed Sep 11 — 1,558 PRs, 293 contributors. The headline feature: **visible skill learning** — turn past conversations into reusable skills through a steerable chat session. Also notable: **cloud ready-workers** (prepared sessions from Git projects or GitHub repos), **GPT Image 2.5** (Flare + Sunburst variants), **terminal questions** (keyboard-driven multi-question prompts in TUI), and **read-only deployments** (OPENCLAW_CONFIG_READONLY=1). Update recovery now rolls back safely when schema checks pass. Community: "When 'learn from past' becomes 'visible skill you can steer,' the lobster's memory graduates from recall to curriculum."

### Platform — v2026.9.3 Ships Sep 8: Revocable Chat Links, Live Browser Automation
OpenClaw v2026.9.3 shipped Sep 8 — 1,844 PRs, 190 contributors. Key: **revocable read-only chat links** (publish conversations, revoke access anytime), **live browser automation** (watch it work), **repository-backed cloud work** (start Linux sessions from public repos), **searchable meeting transcripts**, and **persistent Workshop skills** across workspaces. Community: "When 'share a chat' means 'revoke it whenever,' the lobster's gate finally ships the sharing equivalent of the permission file."

### Platform — v2026.6.35 Closes June 2026 Extended Stable (LTS)
OpenClaw v2026.6.35 (Sep 10) is the final June 2026 Extended Stable release. Safer provider/channel boundaries, bounded untrusted response bodies, and durable channel delivery. June LTS track is now closed. Community: "When 'extended stable' closes, the lobster's LTS promise keeps its word."

## Summary
Three releases since last check: v2026.9.4 (Sep 11), v2026.9.3 (Sep 8), and the June LTS closing release v2026.6.35 (Sep 10). The 9.x series continues its rapid cadence with focus on cloud worker management, skill authoring, and deployment controls.
