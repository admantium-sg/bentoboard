### Security — CVE-2026-53824: Token Revocation Bypass (NEW since June 13)

**New CVE published June 13, 2026.** CVE-2026-53824 (CVSS 6.0 Medium) affects OpenClaw before 2026.4.24. The vulnerability allows callers with revoked slash tokens to continue executing commands during monitor refresh windows. Attackers can exploit stale token acceptance to invoke slash command behavior briefly after token revocation, potentially executing unauthorized actions depending on operator configuration. This is the first new CVE since yesterday's report of 8 CVEs in 24-48 hours.

**Source:** https://app.opencve.io/cve/CVE-2026-53824

### Security — Independent Tests Confirm Prompt Injection Susceptibility

**The Claw Report's June 14 top story highlights independent security tests finding OpenClaw agents can follow spoofed instructions and divulge sensitive information.** The findings from multiple security outlets (including Imperva's hidden command research and Varonis' phishing simulation) continue to be corroborated by additional independent testing. The common thread: identity verification gaps and tool permission boundaries. Maintainers are working on mitigations; in the meantime, hardening guidance is urgent for production deployments.

**Source:** https://www.theclawreport.com/
