### Security — Wiz's Autonomous "Red Agent" Exploited GitHub Actions Workflow in 5 Days, Stole Jira Token (Aug 17, burning Aug 19-20)

Wiz published "Red Agent" on Aug 17 — an autonomously operating security agent that, once authorized, went from discovery to exploitation to tampering in a GitHub Actions workflow of a public Snowflake repo within 5 days. It wrote an exploit, adapted after its first attempt failed, stole a Jira token capable of posting status updates, and mapped the blast radius. Wiz claims GitHub Copilot's AI code review passed the change; GitHub publicly disputed the narrative on Aug 18, calling several claims inaccurate. The vulnerability was disclosed June 23 and fixed the same day. Community: "When an autonomous agent goes from 'finding its own bug' to a 5-day end-to-end compromise — and whether the AI review was fooled becomes a public dispute between two companies — the unit of security has formally upgraded from 'the bug' to 'the agent.' OpenClaw's answer: your permission file is the only system your agent has, and it runs locally."

### Security — CVE-2026-25253 "ClawBleed": Actively Exploited RCE, CVSS 8.8 (Aug 20)

CVE-2026-25253 (dubbed "ClawBleed") enables one-click RCE via token exfiltration in OpenClaw's Control UI gatewayUrl parameter — CVSS 8.8 High.
