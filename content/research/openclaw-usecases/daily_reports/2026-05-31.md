# Daily Report — 2026-05-31

## Platform Releases — v2026.5.29 Pre-release (May 31)

**New pre-release landed May 31 at 02:39 UTC — the rapid May release streak continues into its final day.** The pre-release delivers sweeping runtime recovery, channel delivery hardening, provider expansion, and a major new Workboard orchestration system.

**Runtime recovery overhaul — the most significant change:** Agents and CLI-backed runtimes now recover cleanly from interrupted tool calls, stale session bindings, compaction handoffs, and media delivery retries. Session locks release properly on timeout abort. Subagent workspace isolation strengthened. This addresses the "haunted feeling" users reported with long-running multi-agent deployments where one failure cascaded.

**Channel delivery steadier across 10+ platforms:** Telegram, WhatsApp, iMessage, Slack, Discord, Microsoft Teams, Google Chat, Google Meet, and iOS realtime Talk all receive delivery hardening. Specific fixes: Matrix room-id case preserved, iMessage polling continues after denied reactions, duplicate native exec approvals suppressed, Telegram polling keepalives improved, Teams URL trust checks stricter.

**Provider and plugin expansion:**
- GitHub Copilot agent runtime externalized as @openclaw/copilot plugin
- Tokenjuice payment plugin externalized as @openclaw/tokenjuice
- SecretRef provider integration manifest contract added
- Claude Opus 4.8, NVIDIA featured models, MiniMax streaming music, voice model catalogs all covered
- Encrypted PDF extraction (ClawPDF) confirmed working

**Workboard — Major new orchestration system:** Adds orchestration primitives and agent coordination tools for multi-agent planning and run tracking. This is a significant architectural addition for enterprise multi-agent workflows.

**Skill Workshop matures:** Proposals can now carry approved support files under standard skill folders with scanner, hash, and rollback safeguards. Pending proposals can be revised in place with versioned, dated proposal frontmatter before approval. The skill_research agent tool can apply, reject, and quarantine explicit Skill Workshop proposals through the guarded proposal lifecycle. Community contributor @shakkernerd driving this.

**Timer bounding throughout:** Provider and plugin requests now bound more timers, retries, OAuth/device-code lifetimes, media downloads, local service probes, and generated-content polling paths — addressing the "mushy hangs vs clear failures" problem users reported.

**Quality assurance hardening:** Release, CI, Docker, E2E, and diagnostics lanes now cap more logs, response bodies, readiness probes, artifact checks, and status polling — "failing lanes produce proof instead of stalling or false-greening."

**Code mode namespaces:** Internal namespaces added for scoped agent/global sessions and exact namespace tool dispatch.

**Control UI Dreaming tab:** Agent selector now propagates through Dreaming status, diary, and diary actions. Thanks @stevenepalmer.
