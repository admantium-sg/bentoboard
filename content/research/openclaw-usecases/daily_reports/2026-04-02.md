### 2. Security Crisis & Response (February 2026)

**The Incident:**
- 1,467 malicious skills discovered on ClawHub (3% of registry)
- 91% combined prompt injection with traditional malware
- Primary attack vector: Typosquatting on popular skills (e.g., "githob-integration" vs "github-integration")
- 200,000+ self-hosted instances estimated affected
- Average malicious skill had 847 installs before discovery

**ClawHub's Response:**
- Automated scanning for known malicious patterns
- Removed all 1,467 identified skills
- Introduced author verification badges
- Required code signing for new submissions
- Dedicated security team reviewing flagged skills

**Blink Claw's Alternative Approach:**
- Curated library of 50+ skills only
- All skills security-reviewed by Blink team
- No arbitrary ClawHub skill installs allowed
- Eliminates typosquatting and prompt injection attack surface
- Covers 95%+ of common use cases

**6-Step Security Checklist for Self-Hosted Users:**
1. Read SKILL.md entirely (look for prompt injection patterns)
2. Inspect scripts/ folder (watch for curl|bash, base64 payloads, data exfiltration)
3. Check author profile and history (account age, other skills, verification badge)
4. Verify install count vs account age math
5. Run in isolated environment first (Docker, secondary instance, sandboxed testing)
6. Search security advisories and community reports

**Safe Skill Categories:**
- Official integrations from verified authors
- Read-only data skills
- Skills with no scripts (pure SKILL.md)
- Authors with 2+ years ClawHub history + verification badges
- Blink Claw's curated library

**High-Risk Skill Categories:**
- Broad permission requests ("all file operations", "all API calls")
- New skills mimicking popular names (typosquatting)
- Complex bash scripts calling non-official endpoints
- Accounts with short history and high install counts
- "System optimization" or "performance" category skills

### 4. Multi-Agent Team Workspaces

**Key Findings:**
- Shared agents experience 3× more context collisions
- Isolated agents prevent memory contamination and credential exposure
- Each agent needs dedicated runtime environment, unique identity, and curated skills
- Shared workspace layer enables cross-agent coordination without shared context
- File-based handoff pattern creates auditable inter-agent communication

**Optimal 5-Agent Team Roles:**
1. **Research Agent** - Industry news, competitors, market signals
2. **Coding Agent** - Code review, PR descriptions, test generation, deploy coordination
3. **Communications Agent** - Email, Slack, client updates, CRM data
4. **Operations Agent** - Task tracking, calendar, meeting prep, document organization
5. **Fifth Agent (Custom)** - Sales, content, or finance based on team bottleneck

**Teams with 10+ people:** Typically run 8-10 agents with specialized roles (customer support, data analysis, compliance monitoring).
