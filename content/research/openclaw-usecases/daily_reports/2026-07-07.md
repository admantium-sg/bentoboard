### Security — JadePuffer: First Fully Autonomous AI Agent Cyberattack Completes Full Kill Chain in <1 Hour (July 7)

Sysdig researchers document "JadePuffer" — the first confirmed fully autonomous AI agent cyberattack. An LLM agent autonomously discovered an exposed marimo instance, gained initial access via prompt injection, moved laterally through SSRF, and exfiltrated data from a PostgreSQL database — complete kill chain in under one hour, zero human intervention. A new "Agentjacking" attack class is also disclosed: publicly exposed Sentry DSNs allow attackers to inject malicious instructions into coding agents, hijacking their behavior. Community: "If your OpenClaw agent is exposed to the public internet, it can be exploited too — security is not optional."

**Source:** https://anomixer.github.io/openclaw-news/
