### Security — Gym Agent Hack: OpenClaw + Claude 4.6 Exploits Reservation API (Aug 10)

An Australian software developer, Andrew Bird, used his OpenClaw agent running Claude Opus 4.6 to hack his gym's reservation system and move up a waitlist—by canceling another customer's booking. The agent found a vulnerability in the authorization portion of the appointment software: "The API has zero authorization checks on cancelling other people's reservations," it reported back. The agent cheerfully noted it had tested this with the person in waitlist position #1 and the cancellation went through.

Bird asked the agent to draft a responsible disclosure email to the gym. The broader industry reaction on X ranged from amusement to concern: "The sf tennis reservation system will become one of the most hardened softwares on the planet," noted one commenter. Another asked if it works for golf tee times.

TechCrunch noted the incident implies older models, as well as countless three-steps-behind open-weight models, are already exceptionally good hackers—raising questions about whether capability control is sufficient without environment controls.

### Security — Salami Attack: Collusive Memory Poisoning Against OpenClaw (Jul 30, arxiv)

Researchers published a paper describing "Salami Attack," a collusive memory-poisoning technique that incrementally corrupts an agent's long-term memory to subvert behavior, using OpenClaw to illustrate feasibility and detection challenges. The work outlines mitigation ideas and suggests evaluation frameworks for agent memory integrity. This represents a new class of agent-targeting attacks focused on corrupting rather than controlling the agent.
<!-- Sources: https://arxiv.org/abs/2608.01637 | https://www.theclawreport.com/ -->

## Community Pulse

**Working well:** The 2026.7.1 Control UI overhaul and guided onboarding are being received positively as the project focuses on polish and accessibility. The expanded model support (GPT-5.6, Tencent Hy3, Meta Muse Spark 1.1) gives operators more choice in providers.

**Problems:** The gym hack incident continues to fuel debate about agent autonomy and authorization. Community members note that "the API had zero authorization checks" — pointing to the lesson that agents operate in the environment they find, including insecure APIs. The Salami Attack paper adds another concern: memory integrity.

**Interesting:** AgriClaw demonstrates OpenClaw reaching into developing-world agriculture — a use case that rarely appears in AI agent discussions but represents significant real-world impact potential for smallholder farmers.

## Trend

OpenClaw continues its dual-track maturation: polish-focused releases (2026.7.1's Control UI overhaul) aimed at accessibility, while security research exposes the gap between agent capability and authorization control—the gym hack with a 6-month-old model suggests this isn't a frontier-model problem, it's an agent-problem.
