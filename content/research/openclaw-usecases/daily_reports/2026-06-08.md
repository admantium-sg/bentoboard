## New Findings

### Platform Releases — v2026.6.5: Parallel Web Search, MCP Fixes, SQLite Auth

**June 7 pre-release delivers a focused quality-of-life release.** v2026.6.5-beta.1 landed June 6, promoted to stable by June 7. Key changes since v2026.6.2:

**Parallel web search now bundled:** OpenClaw ships Parallel as a first-class bundled web_search provider with PARALLEL_API_KEY discovery, guarded endpoint handling, cache-safe session IDs, onboarding picker support, and documentation. This diversifies OpenClaw's web search capabilities beyond the default provider.

**MCP and Anthropic recovery overhaul:** MCP tool results now coerce resource_link, resource, audio, malformed image, and future non-text/image blocks at the materialize boundary — preventing Anthropic 400 errors and poisoned session history. Anthropic extended-thinking sessions also recover properly after prompt-cache expiry or Gateway restart.

**SQLite-backed auth durability:** Auth profiles now live in SQLite instead of JSON, official npm plugin install records keep their trusted pins, and prerelease fallback integrity checks avoid carrying stale integrity forward. This is a significant data durability improvement for production deployments.

**QQBot reasoning strip:** QQBot now strips model reasoning/thinking scaffolding before native delivery, preventing raw `<thinking>` content from leaking into channel replies. Final answers are preserved while internal model narration stays hidden.

**macOS node mode stability:** macOS node mode no longer silently self-reconnects away from a healthy direct Gateway session, reducing unexpected companion app session churn.

**Release train shift to monthly patch numbering:** The release process now uses YYYY.M.PATCH monthly numbering, with the June 2026 floor pinned at 2026.6.5 after the published beta. This formalizes the faster-than-weekly cadence into a clearer versioning scheme.

## Community Pulse

**Working well:** Parallel web search bundling is being well received — "finally a search provider that doesn't require juggling API keys" is the common thread. SQLite-backed auth is seen as the right move for production stability, replacing the fragile JSON store that could corrupt on unexpected shutdown.

**Focus areas:** Community is monitoring the release train transition (YYYY.M.PATCH numbering) — some enterprise operators track versions manually and the new scheme requires adjustment to internal dashboards. The macOS node mode fix for silent reconnection is appreciated by desktop companion app users.

**Interesting:** The star count plateau at ~377K after Build 2026 suggests the Microsoft partnership announcement didn't trigger a new star surge — the audience that would star the project likely already did during the January 2026 viral growth. The action is now in enterprise deployment, not community growth.
