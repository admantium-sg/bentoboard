### Security — CVE-2026-26323: Critical OpenClaw Vulnerability Exposes Skills/Chain Integrations (Aug 13)

A critical OpenClaw vulnerability, tracked as CVE-2026-26323, drew alerts from the National Vulnerability Database and multiple security researchers for exposing the platform's skills/chain integrations to abuse. Project advisories urged immediate updates, key rotation, and tighter skill permissions while organizations audit logs for suspicious chained invocations. This was The Claw Report's top story for Aug 13. Operators on extended-stable channel should check upgrade path. Community: "Skills and chain integrations represent the most common extension point — this one hits the ecosystem broadly."

### Security — Six Main-Branch Security/Release Advisories in 48 Hours (Aug 11-12)

OpenClaw Academy published a flurry of main-branch analyses in the 48 hours leading up to Aug 13:
- Per-Requester OAuth for MCP Tools (Aug 12): Shared bots can now isolate MCP credentials by trusted sender.
- Verified Identity and Delegated Run Authority (Aug 11): Gateway scopes, internal turns, channel approvals and delegated retries now carry canonical owner context.
- MCP Refresh Token Issuer Binding (Aug 11): Stops stored MCP refresh tokens being replayed to a different authorization server.
- SQLite Secret Store with Stricter Validation (Aug 11): Team-scoped store now has Control UI management and stricter value validation.
- Telegram Silent Replies Remain Open (Aug 12): A recurring no-payload Telegram failure is still unresolved.

Community: "Six advisories in 48 hours — the security surface keeps hardening but the cadence is demanding operator attention."
