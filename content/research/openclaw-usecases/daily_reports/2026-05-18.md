### Security — OpenClaw Pulse Comprehensive Security Guide

**OpenClaw Pulse published a definitive security reference covering the complete threat landscape:**

**The "Lethal Trifecta" Architecture Problem:**
Adversa.ai identified why OpenClaw has structural security challenges that can't be solved by patching alone:
1. Access to private data — reads email, files, credentials, browser history, chat messages
2. Exposure to untrusted content — browses web, processes incoming messages from anyone, runs community skills
3. Ability to communicate externally — sends emails, posts to messaging platforms, makes API calls

Palo Alto Networks added a fourth element: **persistent memory**. OpenClaw stores context across sessions in SOUL.md and MEMORY.md. Malicious payloads can be fragmented and time-shifted — injected on one day, triggered when agent state aligns later. This enables logic-bomb style attacks.

**The core architectural insight:** In LLM-driven agents, instructions and data occupy the same token stream. There is no firewall between "data the agent reads" and "instructions the agent follows." A malicious email is structurally indistinguishable from a legitimate instruction.

**CVE-2026-25253 (CVSS 8.8) — One-Click RCE via Token Exfiltration:** Patched in v2026.2.6. Control UI accepts gatewayUrl parameter without validating URL legitimacy. Victim visits one URL → token exfiltrated → WebSocket back to local instance → exec.approvals.set='off' → host command execution.

**CVE-2026-24763/CVE-2026-25157 (CVSS 7.5) — Command Injection:** Both patched. Improperly sanitized input fields accepted shell metacharacters.

**Current status:** Patched versions available. Full security posture requires understanding the architecture-level limitations, not just patching individual CVEs.
