## Key Findings (May 9, 2026)

### Platform Releases — Rapid May Cycle

**v2026.5.3 (May 4):** File transfer plugin (file_fetch, dir_list, dir_fetch, file_write) with 16MB per-round-trip ceiling and default-deny path policy; unified streaming progress mode across Discord/Telegram/Slack/Matrix/Teams; plugin hardening for externalized plugins; macOS LaunchAgent upgrade fix; config fails-closed behavior (no auto-restore).

**v2026.5.4 (May 5):** Google Meet + Twilio realtime voice bridge with paced audio streaming (120-150 WPM), backpressure-aware buffering (prevents "robot voice" when buffer exceeds 500ms), and barge-in queue clearing (VAD at 0.7 confidence threshold). Gateway startup performance improved via lazy-loading. OpenRouter response caching opt-in.

**v2026.5.5 (May 6):** Cross-platform bug fixes — xAI/Grok-4.3 reasoning effort fix (clamped to 'off' by default), LINE channel validation fix, iOS pairing improvements (ws:// for LAN/.local, Tailscale stays wss://), Docker capability hardening (drops NET_RAW/NET_ADMIN, enables no-new-privileges), Telegram/Codex progress draft fix, Discord heartbeat timeout fix (was measuring from startup, not actual send).

**v2026.5.6 (May 6):** Same-day hotfix reverting v2026.5.5 doctor --fix that broke GPT-5.5 Codex OAuth routes. Users affected should run: openclaw models set openai-codex/gpt-5.5 && openclaw config validate

**v2026.5.7 (May 7):** Latest stable — 50+ fixes including: ClawHub CLI dependency install retry logic, openai/chat-latest support, cron status in --json output, admin scope required for global memory toggles, before-tool-call authorization hooks for inline skill tool dispatch, Tavily credential resolution fix, subagent archiveAfterMinutes honoring, and Doctor/Codex OAuth route preservation.
