### Platform — OpenClaw v2026.8.1 Ships Today: Secret Egress Binding, GPT-5.6 Ultra, SQLite Snapshots, macOS Profiles, Fish Audio, Buzz Overhaul (Aug 18)

The highly anticipated Tuesday release landed as v2026.8.1 with major reliability, security, and feature improvements. Key highlights:

- **Secret egress host binding**: bind each shared-store secret to exact HTTPS destination hosts — unbound sentinel substitution fails closed before plaintext egress. Directly hardens the CVE-2026-26323 class of issues.

- **GPT-5.6 Ultra atomic switching**: support Sol, Terra, and Luna across OpenClaw and Codex engines; keep model, runtime, and thinking selection atomic.

- **SQLite snapshots**: `openclaw backup sqlite create|list|verify|restore` for compact, verified database artifacts.

- **macOS app profiles**: isolate named app instances across state, Keychain, Gateway services.

- **Fish Audio**: hosted S2.1 speech synthesis plus local Fish S2 Pro in native macOS Talk.

- **Buzz overhaul**: typing indicators, native NIP-27 mentions, sender directory.

- **ClickClack channel**: new channel plugin with guided setup and bot-authored inbound dispatch.

- **Skill Workshop approvals**: agent-initiated apply/reject/quarantine runs without additional prompt by default.

- **External gateway supervision**: `OPENCLAW_SUPERVISOR_MODE=external` for OCM-style lifecycle owners.

The Claw Report's top story: OpenClaw outlines next release timeline with stability, performance, and tighter security by default — extending ExtendedStable for production use.
