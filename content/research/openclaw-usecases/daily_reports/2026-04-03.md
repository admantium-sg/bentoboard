## Multi-Agent Workflow Patterns Solidifying

**Production-Ready Design Guidelines (NEW)**
From theaiagentsbro.com, comprehensive multi-agent workflow design guidance:

**Core Pillars:**
1. **Roles vs Tools vs Skills**: Keep roles stable (planner, researcher, QA); swap skills as needed
2. **Manager/Worker Split**: Manager coordinates queue and acceptance criteria; workers execute narrow jobs
3. **Safety Defaults**: Sandbox on, dmPolicy allowlist, minimal tool profiles per agent
4. **Deterministic Inputs**: Each agent consumes specific files, writes specific outputs

**Design Patterns:**
- Planner → Workers flow with clear handoff artifacts
- Router for cost/quality optimization (fast models for linting, high-quality for drafting)
- Task queue with locks and STATUS markers
- Explicit termination with PASS/FAIL codes and intelligent rerouting

**Isolation Best Practices:**
- Separate workspaces per agent
- Allowlist tools per role (researchers get web_search, drafters get read/write/edit)
- Per-role env files for credential scoping
- Gateway health checks before task dispatch

**Observability:**
- Lossless logging enabled
- STATUS and STATUS_HISTORY.md files as audit trails
- File-based contracts (01-serp-raw.json, 06-brief.md, 07-draft-vN.md, etc.)

This represents a maturation of multi-agent practices from experimental to production-ready.

## Team Multi-Agent Deployment Guidance (NEW)

**Key Stats:**
- 5-agent team cost: ~$110/month on Blink Claw
- Context collision reduction: 3× fewer issues with isolated agents vs shared agents
- Team productivity gain: Reclaims 2-3 hours/week/person in rework reduction

**Isolated vs Shared Agent Comparison:**

| Aspect | Shared Agent | Isolated Agents |
|--------|--------------|-----------------|
| Context Collisions | 3× more frequent | Minimal |
| Memory Contamination | High (conflicting instructions) | None |
| Credential Exposure | All users see all tools | Per-agent credentials |
| Specialization | Generalist (50% effectiveness) | Specialists (90% effectiveness) |
| Audit Trails | Impossible (12 users) | Clear per-agent traces |

**Team Setup Phases:**
1. **Infrastructure**: One Claw instance per agent (on Blink Claw: 5 instances = $110/month)
2. **Agent Provisioning**: Each agent gets isolated memory, unique skills, separate identity
3. **Workspace Connection**: Shared coordination layer through integrations

**Cost Comparison (5-Agent Team):**
- Self-hosted: $20-80/month API + 20-40 hours DevOps/month (~$1,500-3,000/month total)
- Blink Claw managed: $110/month all-inclusive (LLM included, 99.9% SLA)

**Verdict**: Managed hosting decisively cheaper for teams without dedicated DevOps.

## Security Landscape Update

**No New Security Incidents Reported**
- Post-February 2026 crisis period has been stable
- Community awareness of skill vetting practices improving

**Historical Context Reminder:**
From openclawpulse.com, the "lethal trifecta" of AI agent vulnerabilities:
1. Access to private data (email, files, credentials, browser history)
2. Exposure to untrusted content (web browsing, community skills)
3. Ability to communicate externally (email, API calls, messaging)

**CVE-2026-25253 Status (One-Click RCE):**
- CVSS: 8.8 (High)
- Fixed in OpenClaw v2026.2.6
- Attack: Malicious URL → token exfiltration → disable sandbox → RCE
- Current status: Patched; update if running earlier versions

**Ongoing Risk Model:**
- Cannot "patch away" all risks due to LLM architecture (data and instructions in same token stream)
- Defense in depth required: vetting, isolation, monitoring
- Time-shifted prompt injection possible via persistent memory (SOUL.md, MEMORY.md)
