## New Findings (5)

### 1. 9 New CVEs Disclosed June 16 — Coordinated Security Drop

OpenCVE catalogued 9 new OpenClaw CVEs on June 16, none covered in prior reports. The batch spans multiple attack surfaces:

- CVE-2026-53856 (CVSS 5.5): Insecure file permissions in config recovery — restores OpenClaw.json with overly broad permissions on shared hosts, allowing local attackers to read sensitive config data.
- CVE-2026-53851 (CVSS 5.3): Slack reaction events bypass disabled notification settings, entering the agent pipeline and enabling unauthorized lower-trust input processing.
- CVE-2026-53857 (CVSS 8.1): Zalo contacts with mutable display metadata can match allowFrom policy entries through display name changes, causing response leakage to wrong identities.
- CVE-2026-53859 (CVSS 6.5): Hostname validation bypass via trailing-dot notation in model or workspace-derived URLs — attackers circumvent hostname blocklists inconsistently.
- CVE-2026-53865 (CVSS 7.1): Path traversal in maintenance task execution — workspace-derived service paths influence trash command selection, enabling unintended local executable execution. Most severe standalone privilege-escalation vector in this batch.
- CVE-2026-53844 (CVSS 6.5): Session visibility bypass in shared memory search — authenticated callers retrieve memory entries without proper authorization via the search path.
- CVE-2026-53845 (CVSS 4.3): Hook bypass in skill command dispatch — affected path skips before-tool-call hook coverage, bypassing audit and policy enforcement.
- CVE-2026-53864 (CVSS 8.1): Insufficient sanitization of Node.js control variables in the host environment sanitizer — attackers with .env or skill environment block access can influence child process behavior.
- CVE-2026-53863 (CVSS 7.1): Input validation vulnerability in tool group policy callers accepting unvalidated input, enabling policy enforcement bypass.

The disclosure rate remains elevated — 9 CVEs in a single day represents the largest coordinated batch since the January viral period. Affected versions vary by CVE; operators on 2026.6.8 stable (June 16) are protected against most of these. OpenCVE count now at 496 tracked vulnerabilities.

**Source:** https://app.opencve.io/cve/?vendor=openclaw | https://stack.watch/product/openclaw/openclaw/

### 2. "Clawjacked" — Malicious Webpages Can Steer OpenClaw Agent (June 18)

The Claw Report's June 18 edition names "Clawjacked" as the day's top story: multiple security researchers and outlets report a technique abusing malicious webpages to steer OpenClaw's agent, potentially leaking secrets and triggering unintended account actions. This is a distinct attack class from the previously disclosed vCard/injection vectors — it operates through the browsing/automation scope rather than message metadata. OpenClaw maintainers are urging users to update to the latest build, tighten permissions, and restrict risky browsing/automation scopes while longer-term hardening lands. No CVE assigned yet; investigation is ongoing. This follows the pattern of Varonis's "agent phishing" research — social manipulation through normal communication channels — but delivered via web content rather than email.

**Source:** https://www.theclawreport.com/

### 3. NVIDIA SkillSpector — Open-Source Skill Vulnerability Scanner (June 18)

NVIDIA released SkillSpector, an open-source security scanner that flags dangerous AI agent skills before installation. It scans for 64 vulnerability patterns across 16 categories, specifically targeting prompt injection, data exfiltration, and supply chain risks in skill packages used by Claude Code, Codex CLI, Gemini CLI, and other agent frameworks. Output is standardized SARIF format for CI/CD integration. Directly relevant to OpenClaw's ClawHub ecosystem — the 341+ malicious skills found on ClawHub earlier in 2026 underscore the need for pre-installation scanning. SkillSpector positions NVIDIA as a security infrastructure provider for the broader agentic tooling ecosystem rather than competing with OpenClaw directly.

**Source:** https://newclawtimes.com/

### 4. Verona Raises $18.5M for EarnOS — Verified Data Layer for Autonomous Agents (June 18)

Verona (formerly XION, the web3 infrastructure platform) announced an $18.5M raise and strategic pivot to become the cryptographic verification layer for AI agents. EarnOS lets users delegate agentic tasks — booking, payments, purchasing — while maintaining cryptographic proof of data ownership. Total funding: $36M. This addresses a core architectural vulnerability flagged by OpenClaw security research: agents with access to private data, untrusted content, and external communication are inherently risky. Cryptographic data provenance could provide the "trust layer" that makes agent delegation verifiable rather than blind. An orthogonal but relevant ecosystem development for OpenClaw's enterprise positioning.

**Source:** https://newclawtimes.com/

### 5. TechTarget CISO Guide to OpenClaw Security Risks (June 18)

TechTarget published a detailed enterprise security guide cataloguing the specific attack vectors CISOs face when employees deploy OpenClaw agents. The guide covers CVE-2026-25253 (CVSS 8.8, now patched), the ClawHavoc supply chain campaign, indirect prompt injection via Simon Willison's "lethal trifecta" framework, and Meta's Summer Yue losing control of an agent that deleted hundreds of emails. This is enterprise-level documentation that validates OpenClaw as a production consideration worthy of formal risk assessment — the guide signals the platform has crossed from hobbyist/experimental into enterprise visibility. The inclusion alongside CVE-2026-25253 and the lethal trifecta framing also reinforces that security remains the primary inhibitor of broader enterprise adoption.

**Source:** https://newclawtimes.com/ | https://www.mintmcp.com/blog/secure-openclaw-enterprise

## Trend Analysis

Security dominates the news cycle for the third consecutive week — a coordinated 9-CVE disclosure, the new "Clawjacked" web-based steering attack, and a TechTarget CISO guide collectively push security to the forefront. The ecosystem is beginning to respond structurally: NVIDIA's SkillSpector addresses skill supply chain risks at the tooling level, and Verona's cryptographic data layer attempts to solve the "lethal trifecta" problem architecturally. Both are ecosystem plays rather than OpenClaw-specific, but they position the broader agentic category as maturing toward enterprise governance. The persistent challenge: every new CVE and attack technique documented in enterprise guides reinforces the perception that OpenClaw requires specialized security expertise to operate safely — a barrier to mainstream enterprise adoption even as validation signals (Microsoft Scout, ASUS OEM) accumulate.
