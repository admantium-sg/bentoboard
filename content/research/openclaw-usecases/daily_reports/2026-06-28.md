## New Findings (5)

### 1. Security — "Clawjacked" Web Hijack Attack Emerges (June 27)

Multiple security reports highlight a one-click "Clawjacked" attack that lets booby-trapped websites commandeer OpenClaw sessions. The attack works through malicious web pages that exploit browser integration weaknesses to seize control of active OpenClaw sessions. Combined with a surge of malicious ClawHub skills—including credential-stealing infostealers masquerading as legitimate add-ons—the incidents expose supply-chain and browser integration weak points. OpenClaw has removed the malicious listings and banned accounts, prompting urgent calls for audits of installed skills, permissions, and network access. This is being tracked as the top story by The Claw Report for June 27.

**Source:** https://www.theclawreport.com/ | https://www.techradar.com/pro/security/multiple-malicious-openclaw-skills-found-online-including-two-macos-infostealers

### 2. Platform — OpenClaw v2026.6.11-beta.1 Detailed: Slack Relay, Mattermost Queue, Safer Plugins (June 24)

The v2026.6.11-beta.1 pre-release brings significant channel control improvements: native Slack relay mode, native Mattermost /oc_queue support, and per-DM model overrides for more granular automation and tuning. New operator workflows include openclaw agent --message-file and the RAFT CLI wake bridge for practical file-driven and remote wake-up paths. Plugin distribution is made safer with cleaner externalization and bundled plugin icon metadata. Android settings panels receive UX improvements. More reliable agent turns come from Codex partial deltas, harness activation, and long-context prompt-cache stability. The complete v2026.6.10..HEAD cycle merged 305 PRs. This beta continues the June release train's stability and quality focus.

**Source:** https://openclawai.online/releases/openclaw-v2026611-beta1 | https://github.com/openclaw/openclaw/releases

First, the security surface continues expanding in novel directions — "Clawjacked" represents a new browser-based hijack vector distinct from previous CVE patterns, targeting how OpenClaw integrates with web content rather than the agent itself.
