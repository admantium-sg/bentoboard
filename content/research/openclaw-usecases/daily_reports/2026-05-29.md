# Daily Report — 2026-05-29

## Platform Releases

**v2026.5.28-beta.1 (May 29, tag by @steipete):**
Major runtime reliability and performance release. Agent and Codex runtime recovery substantially improved: subagents maintain cwd/workspace separation, hook context stays prompt-local, session locks release on timeout abort, stale restart continuations avoided, and Codex app-server/helper failures no longer tear down shared runtime state.

Channel delivery and session identity safer across outbound plugin hooks, Matrix room ids, iMessage reactions/approvals, Slack final replies, Discord recovered tool warnings, and Microsoft Teams service URL trust checks.

Mobile and chat surfaces refreshed: iOS Pro UI now has Pro Command, Chat, Agents, and Settings tabs wired to gateway sessions, diagnostics, chat, and realtime Talk. Gateway chat transport, onboarding, Talk permissions, WebChat reconnect delivery, and session picker preserve more state across reconnects.

CLI, auth, doctor, and provider paths fail faster with actionable recovery: malformed numeric/version options rejected, OAuth and local service startup requests bounded, legacy api_key auth profiles migrate to canonical form.

Plugin and Gateway hot paths do less repeated work: install records, config JSON parsing, tool search catalogs, session stores, manifest model rows, auto-enabled plugin config, browser tokens, and viewer assets all cached.

Notable new capabilities: ClawHub adds plugin display names plus skill verification and trust surfaces. PDF extraction now uses ClawPDF and surfaces MCP structured content in agent tool results. Diffs language pack expanded with coverage contributions from @RomneyDa.

**v2026.5.27 (May 28, stable):** Tightened security boundaries, steadier Codex runs, faster replies on busy setups. Group prompt text isolated from system prompts, unsafe Node runtime env overrides blocked, no-auth Tailscale exposure rejected, node/device-role approvals require admin authority. Community: "OpenClaw tightened several security and content-boundary paths, made Codex app-server runs much harder to knock off course."
