### Platform — v2026.9.9 Lands: GPT-6.1 Sol in Codex, Claude Haiku 5.5, Hardened Update Recovery (Oct 8)
OpenClaw shipped v2026.9.9 on October 8 — 112 pull requests, 69 direct commits, 91 contributors. Key additions: GPT-6.1 Sol added to the Codex model list, Claude Haiku 5.5 supported through Anthropic and Claude CLI, improved recovery after failed updates, fixes for missing iMessage replies, and a fix preventing old scheduled jobs from interrupting newer conversations. ### Platform — ClawStat Rates v2026.9.9 ⚠️ "Too New to Call": Windows Crashes, Update Recovery Failures (Oct 9)
Independent tracker ClawStat assessed v2026.9.9 on Oct 9 at 02:43 UTC, issuing ⚠️ "Update with care" with verdict "Too new to call." Two credible Windows Gateway startup blockers confirmed: #167406 (Codex plugin on MSIX build 2026.9.900.0 starves the main thread, readiness never settles) and #167466 (Gateway listens but stays unresponsive for 15+ minutes, pinning a full CPU core). A cluster of update/recovery failures names this exact version: #167343 (macOS update fails at gateway-recovery-verification), #167428 (macOS blocked by stale ACP-session-metadata record), #167506 (Linux deleted handoff database leaves update-recovery-pending), #167557 (Linux deferred plugin migration never converges, ~800 MB rollback artifacts stranded), and #167385 (hand-deleted session archive permanently blocks doctor --fix). One message-loss bug confirmed: #167543 shows a completed answer replaced by a generation-failure warning on Telegram for reasoning-only follow-ups. Against: only 4 👍 across 52 tracked issues vs ~4.3M weekly npm downloads — no issue reaches 10 👍, and most update failures leave the Gateway itself serving normally. Three breaking default changes (session jsonl→sqlite, secrets store enforcement, exec approval default-on) caused 11+ hours of debugging for one reporter. Validator critique flagged several category mis-assignments and noted two MSIX-build items may belong to a future release's evidence. Community: "Nine-point-nine gets its gate, the update-path cluster is live — back up first, update second."
Source: https://clawstat.us/latest.json (assessed Oct 9, 2026) | https://thedailyclaw.com/ (Oct 8, 2026)

### Security — CVE-2026-100545: Incorrect Authorization in OpenClaw Before 2026.8.1 (Oct 2, newly surfaced)
Snyk published CVE-2026-100545: session-memory filename generation in OpenClaw before v2026.8.1 could retain tools removed by sender policy, enabling actions outside the intended scope. The vulnerability was fixed in v2026.8.1 and users on earlier versions should upgrade. ClawScan's Tencent AIG integration (98.6% malicious-case accuracy) and NVIDIA SkillSpector provide ongoing ClawHub-level protection. Community: "Authorization bypass via filename generation — the lobster's memory was writing passes no one should have signed."
Source: https://security.snyk.io/vuln/SNYK-MINIMOSLATEST-OPENCLAW-20372485 (Oct 2, 2026) | https://www.theclawreport.com/ (Oct 2, 2026)
