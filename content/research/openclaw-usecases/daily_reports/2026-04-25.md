## Key Findings Today

### OpenClaw v2026.4.23 Released (April 24, 2026)
**Significance:** Incremental feature release focused on image generation parity and bug fixes. **4th release in 4 days** continuing the rapid release velocity.

**New Features:**
1. **OpenAI Image Generation via Codex OAuth** - gpt-image-2 now works without OPENAI_API_KEY when using Codex OAuth authentication. Fixes #70703.
2. **OpenRouter Image Generation** - Added image generation and reference-image editing through image_generate tool for OpenRouter models. Fixes #55066.
3. **Image Generation Quality Hints** - Agents can now request provider-supported quality and output format hints. OpenAI-specific background, moderation, compression, and user hints passed through image_generate tool.
4. **Optional Forked Context for Sessions Spawn** - Native sessions_spawn runs can optionally inherit requester transcript, while keeping clean isolated sessions as default.
5. **Per-Call Timeout Support** - Optional timeoutMs for image, video, music, and TTS generation tools to extend provider request timeouts when needed.
6. **Local Embedding Context Size** - New configurable memorySearch.local.contextSize (default 4096) for tuning on constrained hosts.

**Bug Fixes:**
- Codex harness routing fixes for Windows PATHEXT, request_user_input prompts, context-engine failures
- WhatsApp onboarding reliability improvements (Baileys dependency decoupling)
- Slack MPIM classification and verbose progress suppression
- Telegram markdown image syntax parsing for outbound media
- Gateway/WebChat error surfacing for billing/auth/rate-limit failures
- Many additional fixes across providers, plugins, and Control UI
