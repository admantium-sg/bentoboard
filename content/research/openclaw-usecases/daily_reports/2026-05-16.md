## Key Findings (May 16, 2026)

### Security — Claw Chain Vulnerability Disclosure

**Four critical vulnerabilities discovered by Cyera Research:**

| CVE | CVSS | Description |
|-----|------|-------------|
| CVE-2026-44112 | **9.6 CRITICAL** | TOCTOU filesystem write escape in OpenShell sandbox — allows attackers to redirect writes outside sandbox boundary, plant backdoors, achieve persistent control |
| CVE-2026-44113 | 7.7 | TOCTOU filesystem read escape — exposes system files, credentials, internal artifacts via symbolic link swap |
| CVE-2026-44115 | 8.8 | Execution allowlist bypass via heredoc shell expansion — environment variables (API keys, tokens) leaked through commands that appear safe at validation |
| CVE-2026-44118 | 7.8 | MCP loopback privilege escalation — senderIsOwner flag spoofing gives non-owner attackers owner-level gateway control |

**Attack chain:** Malicious plugin/prompt injection → TOCTOU escapes expose credentials → senderIsOwner spoofing escalates to owner → TOCTOU write plants backdoors.

**All patched in v2026.4.22 (April 23, 2026).** Security researcher Vladimir Tokarev credited.

**Exposure:** ~65,000 (Shodan) to ~180,000 (Zoomeye) publicly accessible OpenClaw instances as of May 2026.

**Immediate actions recommended:** Patch to 2026.4.22+, rotate secrets, audit agent access, place instances behind authentication.

**Source:** https://thehackernews.com/2026/05/four-openclaw-flaws-enable-data-theft.html | https://www.cyera.com/pt-br/blog/claw-chain-cyera-research-unveil-four-chainable-vulnerabilities-in-openclaw

### Additional CVE Published May 11

**CVE-2026-45006 (CVSS 8.8):** OpenClaw Gateway improper access control — allows compromised models to write unsafe configuration changes.

**Source:** https://www.thehackerwire.com/openclaw-gateway-improper-access-control-cve-2026-45006/

## Community Pulse

**Working Well:**
- OpenClaw responded quickly to responsible disclosure — all four Claw Chain CVEs patched April 23
- Telnyx realtime voice integration adding provider diversity for voice workflows
- "Steering by default" making mid-conversation corrections feel immediate
- Diagnostic improvements helping operators identify what actually failed

**Problems Reported:**
- Claw Chain vulnerabilities expose the fundamental tension in AI agents — broad access + sandbox gaps = high impact attack surface
- 180K+ exposed instances remain a significant attack surface even with patches available
- The "agent as attack vector" pattern (using the agent's own privileges to move through systems) is new territory for security tooling
- CVE-2026-45006 (May 11) adds to the active CVE list alongside the Claw Chain batch

**Interesting:**
- Cyera explicitly notes traditional controls miss this attack chain because "each step looks like normal agent behavior" — security monitoring needs agent-aware tooling
- The senderIsOwner spoofing flaw (CVE-2026-44118) was a simple trust issue — client-controlled flags without server-side validation
- 180K exposed instances vs ~135K reported earlier — exposure counting methodology differs by scanner (Shodan vs Zoomeye)
- The heredoc env-var disclosure (CVE-2026-44115) bypasses allowlist validation by embedding shell expansion tokens in heredoc body
