# DIAC - OpenClaw Use Cases — 2026-05-27

## New Findings

**Platform: v2026.5.26-beta.1 Delivers ~4,100x Latency Improvement (May 26)**
Major performance release tagged at 23:30 UTC by Peter Steinberger (@steipete). Hot-path model listing cost drops from ~20s to ~5ms (~4,100x improvement). Reply delivery optimization preserves Telegram typing/progress context, lazy-loads slash-command metadata, avoids hot-path model hydration. Agent replay repaired (legacy tool results, sessions_spawn preservation, sandboxed workspace media staging). Codex runtime hardened — turn timeouts stay inside Codex boundary, preventing poisoning of shared app-server clients. Channel improvements across Telegram, iMessage, WhatsApp, Slack, Discord/voice. Security locking adds owner identity proof requirements for stale plugin lock removal.
