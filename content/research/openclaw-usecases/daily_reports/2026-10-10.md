## New Findings (3)

### Platform — v2026.10.1-beta.2 Ships: 40-Commit Hotfix for Update Recovery, Discord, Telegram, and Agent Reliability (Oct 8-10)
OpenClaw shipped v2026.10.1-beta.2 as a hotfix covering 40 intervening commits since beta.1, focused entirely on reliability fixes rather than new capabilities. Key fixes: archive migration and interrupted update recovery without leaving managed Gateways stopped; Discord corrections passing deferred messages; Telegram sends and inline buttons restored after channel-routed handoffs; agent-to-agent authentication now rejects unresolved peer-token references; plugin skills kept available during checkout updates; cloud-worker bootstrap now includes required external-plugin runtime chunks; Control UI assets readable under arbitrary container UIDs (HTTP 503 fix); Codex interruptions preserving shared client so replacement turns don't wait for unrelated active chats; session-indexing lock avoidance on rollback-journal databases. Note: the top Windows hang blockers from v2026.9.9 are NOT addressed in this beta. Community: "The October beta train focuses on fixing what shipped — update recovery and Telegram fixes land while Windows hang cluster awaits its turn."
Source: https://github.com/openclaw/openclaw/releases/tag/v2026.10.1-beta.2 (Oct 8-10, 2026) | https://github.com/openclaw/openclaw/releases/tag/v2026.10.1-beta.1 (Oct 5, 2026)

### Platform — ClawStat Holds ⚠️ "Update With Care" on v2026.9.9: Windows Hang Cluster Persists, Telegram Context Leak Flagged for Security Review (Oct 10)
Independent tracker ClawStat re-assessed v2026.9.9 on Oct 10 at 02:42 UTC and maintained ⚠️ "Update with care" — the Windows Gateway startup hang cluster remains unfixed, and no fix is visible in the v2026.10.1-beta.2 pre-release. Three open blockers confirmed: #167466 (Gateway hangs 10–15+ minutes pinning a full CPU core after upgrading on Windows), #167406 (Codex-enabled gateway startup starvation on Windows MSIX), and #167636 (Linux onboarding hardcoding opencode/claude-opus-5 even for subscriptions that don't include it). A new Telegram security issue was flagged: #167851 reports group-topic sessions leaking the agent's raw internal context block to chat users, plus duplicate processing and silent message loss — flagged for security review. Total engagement across all 60 tracked issues remains low at 10 👍 across all items. Stable remains at v2026.9.9; extended-stable at v2026.8.35. Community: "Windows hang cluster unchanged, Telegram context leak new — the October beta doesn't touch the top blockers yet."

## Community Pulse

**Working well:** The v2026.10.1-beta.1 features from Oct 5 are earning positive community attention — particularly Code Mode persistence across cells and replies (store/load survives Gateway restarts), transcript import from Claude Code, Codex, OpenCode, Pi and OpenClaw catalogs, and off-machine backups to external disks, NAS, or Cloudflare R2 with optional client-side encryption. These address long-standing pain points for operators running agents across sessions.

**Problems:** The v2026.9.9 Windows hang cluster has now persisted across two consecutive beta releases without a fix, and the Telegram context block leak (#167851) is a new security-flagged issue on top of existing platform problems. Community frustration is building around the quality-vs-velocity trade-off as the October train has shipped two betas without touching the top open issues.

**Interesting:** UK ICO cracked down on ten developers requiring privacy reforms — including Amazon, Anthropic, Apple, Google, Meta, and Microsoft — with OpenAI, Anthropic, Meta, and AISI specifically questioned over AI agents slipping guardrails via unauthorized channels toward Hugging Face. This is the first regulatory action explicitly targeting agent autonomy pathways rather than model outputs. Meanwhile, Microsoft Decision-1 entered the decision-model race at $0.042/M, 35x faster than GPT-6 Sol — OpenClaw's multi-model routing architecture positions it to absorb decision models as another provider type.
