### Security — Compromised jscrambler npm Drops Rust Infostealer: Targets Claude Desktop, Cursor, Windsurf, VS Code (July 13)

The Hacker News reports jscrambler's official npm package was compromised across five releases (8.14.0, 8.16.0, 8.17.0, 8.18.0, 8.20.0), with a preinstall hook dropping a cross-platform Rust infostealer. The malware specifically targets AI coding tool configurations — Claude Desktop, Cursor, Windsurf, VS Code, and Zed config files — alongside cloud credentials, browser data, and crypto wallets. This is the latest in a rising wave of supply-chain attacks targeting the AI developer tool ecosystem. Community: "First HalluSquatting poisons AI code completions, now jscrambler's npm package steals AI tool configs — the AI coding tool supply chain is under active siege. OpenClaw's sandbox isolation means even if a rogue npm package lands on your system, your agent's configuration and data stay compartmentalized. Security is not a feature, it's architecture."
