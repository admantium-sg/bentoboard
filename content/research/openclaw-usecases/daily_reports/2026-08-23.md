### Platform — OpenClaw Ships beta.3 RC1 Ahead of Schedule + claw-perms Permission File Scanner (Aug 23)

OpenClaw shipped v2026.8.1-beta.3 RC1 on Aug 23 — ahead of the tentative Aug 25 date — with a major addition: claw-perms, a local permission-file scanner that audits what each agent is authorized to do before it runs. The beta.3 scope includes SQLite migration rebuilds on both fresh-install and v2026.7.1-upgrade paths, permission-file fail-closed becoming the default, and automatic pre-upgrade snapshots. The claw-perms scanner is the most direct instantiation of the "permission file as first-class security boundary" concept that the Agentic AI Foundation codified in MCP spec 2026.8 on Aug 22. Community: "When the lobster ships a permission-file scanner before the week is out — the standard-setting and the implementation arrived in the same 48-hour window."
Source: anomixer.github.io/openclaw-news (Aug 23), openclawradar.com (Aug 23)

### Security — Phantom Context Formally Registered as CVE-2026-54210; Three Cloud Coding Agents Patch (Aug 23)

Unit 42's "Phantom Context" memory-injection attack — where malicious instructions planted in an agent's persistent memory auto-replay on the next session — was formally assigned CVE-2026-54210 on Aug 23. Three mainstream cloud coding agents patched. OpenClaw's architecture was again spared by design — the permission file boundary that separates execution also separates memory replay. The CVE assignment formalizes what was a research disclosure into an official vulnerability track. Community: "When 'memory injection' gets a CVE number, the threat model of every AI coding platform has to account for it — and the lobster's answer (memory lives inside the permission boundary, not outside it) is now the exception rather than the rule."
Source: anomixer.github.io/openclaw-news (Aug 23), openclawradar.com (Aug 23)

### Open Models — Nous Research Releases Hermes-5 Open Weights; ExploitBench Beats GLM-5.3 (Aug 23)

Nous Research released Hermes-5 weights on Aug 23. The divergence between CyberGym and ExploitBench performance suggests the two benchmarks are measuring meaningfully different threat models. Community: "CyberGym tests 'can the model answer security questions correctly'; ExploitBench tests 'can the model autonomously run an attack chain.' Hermes-5 leading on ExploitBench while trailing on CyberGym is a signal that benchmark scores and actual autonomous capability are not the same thing."
