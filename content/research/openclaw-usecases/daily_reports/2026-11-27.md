## The five things worth knowing

**1. A production user is running OpenClaw as a deterministic workflow engine, not a chatbot.**
Discourse `t/547` (`tidma-development`): self-hosted **Plane Community 1.5.0** in Docker on Ubuntu 26.04.1 /
Node 24.22.2, **OpenClaw 2026.11.8**, a **systemd timer polling Plane every ~20 s**, and the pattern —
*poll, exit with zero model calls when idle → atomically claim the assignment → dispatch via `/hooks/agent`
with `agentId` + `waitForCompletion: true` + `Idempotency-Key` → verify the result in Plane independently →
then notify the manager*. The in-thread advice is explicitly **not** to add an LLM-powered dispatcher. This is
the strongest real-world-deployment evidence in weeks.

**2. A community thread and an upstream P1 turned out to be the same bug.**
`SaaL_Burgos` on Discourse `t/555`: with the Codex harness, a turn that starts a **fresh native thread** loses
everything the agent had read with tools earlier, so his lead agent skipped its closeout after "merged". Upstream
**P1 #206320** (filed 02:58Z today) names the mechanism: since 2026.11.10, **Codex-engine threads get OpenClaw's
base prompt instead of Codex's model prompt**, so an unattended job ignored its workspace workflow's "finish every
item" rule in **4 of 4** replayed runs, while the Codex prompt followed it 3/3 (p = 0.029). Silent instruction loss
is the most dangerous failure class for unattended fleets — and it is now confirmed from both ends.

**3. Platform stability is deteriorating on four axes while use-case sophistication rises.**
P1 **#206422**: after a Gateway crash restart, child runs stay `execution.status: running` forever (the
settlement sweeper is not reactivated). Reddit reports **sub-agent spawning stopping entirely after an update**.
P0 **#206215**: a Claude Code auth expiry is recorded as an *unknown* failure, so it cannot be classified.
P0 **#205908**: an update failure on the **2026.10.10 extended-stable** line. Meanwhile the ClawHub supply side
ships: per-agent tool allow/deny scoping (t/483), an agent-to-agent marketplace with **escrowed payments**,
Elo-rated agent arenas, **machine identity** for agent workloads on Alibaba Cloud ACK, and a skill that
**totals token consumption across all your agents** (`iorireal/agent-worklog-review`) — the closest thing to
self-instrumented ROI anyone has published.

**4. ClawHub supply and deployment are diverging by two orders of magnitude.**
In-window: **166 new skills / 51 publishers / 8,686 downloads / 1 install**. The single installed skill in the
entire visible catalogue is `crystaria/letitlearn` (48 downloads, 1 install, 2 versions). Conversion ≈ **0.01 %**.
Use-case clusters are coherent and commercially shaped: an end-to-end **creator pipeline** (research → script →
thumbnail → long-form render → repurpose → scheduled publish to YouTube/IG/TikTok), **read-only Chinese social
intelligence** (Douyin/Xiaohongshu/Weibo monitoring + WeChat account-safety operations), **US real-estate data
resold per API call** (Trulia, Zillow, RentCafe, Carvana…), and an **agent-to-agent economy**.

**5. Reddit came back — and one user churned after five months.**
Via `redlib.hbubli.cc` (1 of 6 mirrors worked; the rest returned 403/418/dead pages/Anubis challenges). The
substance of *"Is OpenClaw still relevant?"* (43 upvotes, 71 comments) is **model-provider independence** — the
agent layer is the durable asset, not the model — plus a hybrid OpenCode + Hermes + OpenClaw
**watcher/fixer/auditor** stack. On the other side: a five-month deployment broke after a 2026.11.x upgrade
(~23 failed exec calls, broken CLI, Telegram unlinkable) and the user moved to Hermes. Memory-provenance
quarantine is reportedly reversible only by **stopping the gateway and editing the database directly**.
