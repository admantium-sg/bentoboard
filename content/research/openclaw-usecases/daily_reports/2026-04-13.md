## New Platform Releases

### v2026.4.11-beta.1 (April 11, 2026, 15:15 UTC)

**Notable Features:**
- **ChatGPT Import Ingestion (Dreaming):** Enhanced with new Imported Insights and Memory Palace diary subtabs; Dreaming can now inspect imported source chats, compiled wiki pages, and full source pages directly from the UI
- **Control UI Enhancements:** Render assistant media/reply/voice directives as structured chat bubbles; added `[embed ...]` rich output tag with configurable external URL gating
- **Video Generation Improvements:** URL-only generated asset delivery, typed providerOptions, reference audio inputs, per-asset role hints, adaptive aspect-ratio support, higher image-input cap for richer generation modes
- **Feishu Integration:** Improved document comment sessions with richer context parsing, comment reactions, and typing feedback
- **Microsoft Teams Integration:** Added reaction support, reaction listing, Graph pagination, and delegated OAuth setup for sending reactions
- **Plugin Manifest System:** Plugins can now declare activation and setup descriptors for auth/pairing/configuration without hardcoded core special cases
- **Ollama Caching:** Cached `/api/show` context-window and capability metadata during model discovery; repeated picker refreshes stop refetching unchanged models
- **Model Provider Debug:** Surface how configured OpenAI-compatible endpoints are classified in embedded-agent debug logs
- **QA Improvements:** Added GPT-5.4 vs Opus 4.6 agentic parity report gate with shared scenario coverage checks

**Bug Fixes:**
- OpenAI/Codex OAuth scopes fix
- Audio transcription restoration for OpenAI, Groq, and Mistral
- macOS Talk Mode microphone permission handling
- WhatsApp default account handling
- Agents timeouts alignment with configured limits
- Various cross-platform fixes

### v2026.4.12-beta.1 (April 12, 2026, 23:27 UTC)

**Memory & Active Memory Improvements:**
- Default QMD recall to search mode with better search-path telemetry for more predictable memory-backed recall
- Memory/wiki: Added recommended QMD + bridge-mode hybrid recipe plus zero-artifact troubleshooting guidance
- Active memory lexical improvements: Better fallback ranking and hybrid search exclusion

**Plugin Architecture:**
- Narrowed CLI, provider, and channel activation to manifest-declared needs
- Preserve explicit scope and trust boundaries
- Centralize manifest-owner policy to avoid loading unrelated plugin runtime during startup, command discovery, and runtime activation

**Dreaming Enhancements:**
- Consume managed heartbeat events exactly once
- Stage light-sleep confidence from all recorded short-term signals
- Wake scheduled jobs immediately
- Raise dreaming-only promotion enough to cross durable-memory gate
- Stop dreaming from re-ingesting its own narrative transcripts
- Hardened transient narrative cleanup with retry logic and stale artifact scrubbing

**Memory System Fixes:**
- Preserve Unicode letters, digits, and combining marks in wiki slugs and contradiction clustering
- Cap Unicode filename segments to safe byte lengths to prevent collapsing or path limit overflows
- Allow nested daily notes under `memory/**/YYYY-MM-DD.md` to feed short-term recall
- Exclude generated dream reports under `memory/dreaming/**` to prevent dreaming from promoting its own output
- Watch memory directory directly and ignore non-markdown churn (fix for macOS + Node 25 environments)

**Cross-Platform Fixes (60+ total fixes):**
- **WhatsApp:** Fallback to first mediaUrls entry, centralized per-account connection ownership
- **Telegram:** Route approval button callback queries onto separate sequentializer lane to prevent deadlocks
- **Discord:** Stop `openclaw doctor --fix` from rewriting legacy preview-streaming config
- **Matrix:** Keep room mention gating strict while accepting visible @displayName labels
- **Gateway/Auth:** Blank shipped example gateway credential in `.env.example`; fail startup when copied placeholder token or password is still configured
- **Gateway/Keepalive:** Stop marking WebSocket tick broadcasts as droppable to prevent self-disconnection during long-running work
- **Doctor:** Warn when on-disk agent directories exist under `~/.openclaw/agents/<id>/agent` but matching `agents.list[]` entries are missing from config
- **Media/Audio Transcription:** Surface real provider failure when every audio transcription attempt fails
- **Infra/Net:** Fix multipart FormData fields being silently dropped when crossing FormData implementation boundaries

**CLI Improvements:**
- `openclaw update` respawn tracked plugin refresh from updated entrypoint after package self-updates
- Honor memory-wiki when `plugins.allow` is set for `openclaw wiki`
- QA/packaging improvements for npm distributions

## Analysis

### Platform Velocity

- **6 releases in 5 days** (April 8-12): Unprecedented iteration speed
- **Production Stability:** Despite rapid release cycle, no major breakage reported in v2026.4.12-beta.1 changelog
- **Quality Focus:** v2026.4.12-beta.1 is primarily bug fixes (60+ fix items) following major feature releases in v2026.4.7-v2026.4.10

### Development Patterns

**Refinement Phase:** Platform has shifted from major feature announcements (v2026.4.7-4.10) to refinement and stability (v2026.4.11-beta.1 and v2026.4.12-beta.1). This pattern indicates:

1. Feature freeze for major features released April 8-11
2. Focus on bug fixes and edge cases
3. Performance optimization (Ollama caching, memory recall improvements)
4. Documentation improvements (QMD + bridge-mode recipe)

### Memory System Evolution

Active Memory plugin (introduced in v2026.4.10) is receiving rapid refinement:

- v2026.4.10: Initial release with automatic context retrieval
- v2026.4.11-beta.1: ChatGPT import ingestion integration
- v2026.4.12-beta.1: QMD recall defaults, better telemetry, lexical improvements

**Significance:** Memory system is becoming core platform infrastructure, not an afterthought. This aligns with the "Automatic Memory" trend identified on April 12, 2026.

### Plugin Architecture Hardening

Plugin system is receiving security and trust boundary improvements:

- **Manifest-Declarative Needs:** Plugins now explicitly declare activation requirements instead of loading everything by default
- **Scope Preservation:** Explicit scope and trust boundaries preserved during startup and runtime
- **Centralized Policy:** Manifest-owner policy centralized to avoid loading unrelated plugin runtime

**Significance:** Follows security hardening trend (third major security incident in 2026). Plugin isolation and trust boundaries are now core architecture.

### Cross-Platform Integration Maturity

Feishu, Microsoft Teams, WhatsApp, Telegram, Discord, and Matrix are all receiving polish:

- **Reaction Support:** Teams and Feishu now support reactions
- **Delegated OAuth:** Teams delegated OAuth for writing reactions while preserving read paths
- **Message Handling:** Better routing, connection ownership, and fallback behavior across platforms
- **Typing Indicators:** Better typing feedback and live markers (Matrix MSC4357)

**Significance:** Platform is maturing from "integrations work" to "integrations work beautifully." Polish and edge case handling indicate production-grade maturity.
