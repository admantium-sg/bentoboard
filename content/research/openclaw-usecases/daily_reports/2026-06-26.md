### 3. Security — The Claw Report: Chained Multi-Path Attacks Enable Full Agent Compromise (June 26)

The Claw Report June 26 leads with security researchers detailing chained attack paths—spanning untrusted skills, browser automation, and file handlers—that let attackers seize OpenClaw agents and exfiltrate data. There is no single patch; maintainers advise updating to the latest build, pruning risky skills, tightening API scopes, and enforcing strict egress and filesystem controls. A related Dark Reading piece documents five malicious ClawHub skills that bypassed VirusTotal checks and could steal credentials or perform other abuse, underscoring supply-chain risk. Help Net Security separately highlighted 23 ClawHub plugins squatting "official" @openclaw/@clawhub scopes despite being from unrelated accounts—registry changes were made after disclosure. Community response: "Piping constant screenshots to cloud servers is a massive security and privacy risk. Edge-based OpenClaw instances using local models remain the only way to achieve secure, zero-latency computer use."

**Source:** https://www.theclawreport.com/ | https://www.darkreading.com/cyber-risk/malicious-openclaw-skills-clawhub-threaten-ai-supply-chain | https://www.helpnetsecurity.com/2026/06/22/clawhub-code-executing-plugins/

## Trend Analysis

Two patterns crystallize today. First, the security threat model has evolved from individual CVEs to chained multi-path attacks— attackers now chain untrusted skills, browser automation, and file handlers in sequence, meaning no single patch suffices and operators must adopt layered defenses. This is a qualitatively different threat category than anything documented before. Second, the regulatory pressure on cloud AI (GPT-5.6 government oversight, IPO delays) contrasts sharply with the momentum of edge deployments like Taipei's CiviClaw—government adoption of local-first agents validates the privacy-respecting architecture in a way that abstract community enthusiasm cannot.
