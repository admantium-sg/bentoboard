## Key Findings (May 15, 2026)

### Platform Releases — New Beta Track (May 13-14)

**v2026.5.12-beta.4 (May 13):** Major release including:
- **Telnyx realtime voice:** New voice call provider for conversational voice calls via realtime media-streaming ([#81024](https://github.com/openclaw/openclaw/pull/81024))
- **Native sessions_spawn delivery:** Subagent tasks now appear in first visible [Subagent Task] message instead of hidden system prompt — more auditable ([#78592](https://github.com/openclaw/openclaw/issues/78592))
- **/context map command:** New treemap image showing current session context contributors ([#79867](https://github.com/openclaw/openclaw/pull/79867))
- **pnpm 11 upgrade:** Workspace package management upgraded to pnpm 11
- **WhatsApp Baileys migration:** Moved from @whiskeysockets/baileys to baileys package (7.0.0-rc10 runtime preserved)
- **Slack unfurl controls:** New `unfurlLinks` and `unfurlMedia` config options to suppress link/media previews in Slack without workspace-wide settings ([#80145](https://github.com/openclaw/openclaw/pull/80145))
- **Slack replyBroadcast support:** Agents can opt into parent-channel reply_broadcast behavior for thread replies ([#64365](https://github.com/openclaw/openclaw/pull/64365))
- **Local service model startup:** Provider-level on-demand local model server startup for OpenAI-compatible requests with one-shot probes
- **Agent run retries config:** New `agents.defaults.runRetries` and `agents.list[].runRetries` for embedded Pi runner retry loop limits
- **Status reaction emoji overhaul:** New self-explanatory emoji set: 🧠 thinking, 🛠️ tool, 💻 coding, 🌐 web, ⏳ stallSoft, ⚠️ stallHard, ✅ done, ❌ error, 🗜️ compacting — lifecycle indicators not emotional commentary
- **OpenAI /chat-latest support:** Explicit direct API-key model override for ChatGPT Instant API
- **Clawdtributor skill:** New Discrawl-backed contributor PR triage tool with live status checks

**v2026.5.12-beta.6 (May 14):** iMessage fix — stop sending visible `<media:image>` placeholder text for media-only native image sends while preserving internal echo key preventing self-echo duplicate replies ([#81209](https://github.com/openclaw/openclaw/pull/81209))

**v2026.5.12-beta.6 also includes from beta.4:**
- **Codex app-server session binding:** Continue existing Codex CLI sessions from OpenClaw conversation
- **Gateway heartbeat metadata:** Optional `isHeartbeat` metadata on agent event payloads to distinguish scheduled heartbeat runs from ordinary chat runs
- **Telegram Mini App support:** Web App inline buttons in generic message presentation for private chats ([#81356](https://github.com/openclaw/openclaw/pull/81356))
- **Agent system prompt trimming:** Reduced prompt tokens while preserving GPT-5 personality guidance
- **Release validation Docker lanes:** Package-installed Docker user-journey tests for onboarding, mocked model setup, plugin install/uninstall, ClickClack messaging, gateway restart survival
- **Plugin SDK deprecations:** Removing legacy barrel/test/zod subpath exports and owner-specific provider-auth-login subpath
