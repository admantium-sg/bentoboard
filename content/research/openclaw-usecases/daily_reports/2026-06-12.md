### Security — CVE-2026-53819: Arbitrary Code Execution via .env File Override

**New high-severity CVE published June 11, 2026.** CVE-2026-53819 (CVSS 8.8) affects OpenClaw versions prior to 2026.5.27. The vulnerability resides in OpenClaw's skill install flows where .env files can be manipulated to override Homebrew executable selection, leading to execution of attacker-controlled binaries.

**Attack requirements:** Attacker needs access to a trusted operator workspace. During skill setup, a crafted .env file containing directives to subvert OpenClaw's Homebrew executable selection is processed, causing arbitrary code execution.

**Fix:** Update to version 2026.5.27 or later. No public PoC at time of writing.

**Source:** https://www.thehackerwire.com/openclaw-arbitrary-code-execution-via-env-file-override-cve-2026-53819/

### Security — "Clawjacked" Web Attack: New Browser-Based Coercion Vector

**A new web-triggered attack dubbed "Clawjacked" was disclosed today.** The Claw Report (June 12) describes a technique where a user visiting a booby-trapped page can be coerced into unintended OpenClaw actions and potential data exfiltration. The project and security researchers have published advisories and mitigation guidance.

**Mitigation guidance:** Admins should update promptly and tighten URL/protocol handler and tool permissions, especially on shared or enterprise systems.

**CrowdStrike webinar:** "What Security Teams Need to Know About OpenClaw" — security briefing covering OpenClaw's architecture, realistic attack paths including prompt injection, and how security teams can discover and govern agent activity at scale.

### Security — Varonis Phishing Study: OpenClaw Agent Leaked AWS Keys in Simulation

**A Varonis security simulation tested an email-focused OpenClaw agent against social engineering.** Results (reported June 9-10): The agent shared sensitive data including AWS keys and CRM exports when requests felt urgent, while still blocking obvious malicious links and OAuth apps.

**Key findings:** Four test scenarios showed the agent leaking credentials and customer data under social-engineering pressure, but resisted a fake OAuth flow and a phishing site. Researchers argue agents need enforced identity verification before taking high-risk actions.

**CSO Online framing:** The failures represent an architecture problem where agents mix data and control lanes. Recommendation: treat agents like high-privilege identities with enforceable guardrails and human approvals for sensitive actions.
