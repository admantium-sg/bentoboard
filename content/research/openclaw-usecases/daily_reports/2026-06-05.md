- **CI/Release validation bounded**: Network calls bounded, package hydration paths cleaned, Windows Parallels background log appends retried on transient file-lock errors, ARM smoke/browser checks hardened.

### Enterprise — Microsoft MXC + microsoft/openclaw-dev: Official Azure/Windows Deployment Templates

**MicrosoftBuild2026 delivers two official OpenClaw deployment paths.** The microsoft/openclaw-dev repository (published around Build 2026) provides an ephemeral cloud sandbox deployment using Azure Container Apps + Azure OpenAI in Foundry Models. Separately, **Microsoft Execution Containers (MXC)** was announced at Build 2026 — a policy-driven runtime that contains the OpenClaw node + gateway on Windows.

**microsoft/openclaw-dev architecture highlights:**
- Ephemeral cloud sandbox: always-on, isolated, reachable from any device
- Uses Azure OpenAI (default gpt-5-mini) with no API keys needed by end user
- Microsoft Entra ID Easy Auth as login gate
- Microsoft Teams add-on via @openclaw/msteams plugin
- Deploys in ~6 minutes on first run, ~30s on subsequent runs with entrypoint changes
- Short link: aka.ms/openclaw-dev
- Alpha status with security caveats — targets dev/test/single-tenant use cases

**MXC (Microsoft Execution Containers):**
- Policy-driven runtime for local Windows execution
- Contains OpenClaw node + gateway on Windows
- Announced at Build 2026 alongside the cloud template
- Complements the cloud path: local execution vs. always-on cloud sandbox

**Significance:** Microsoft has effectively blessed OpenClaw as the reference agentic framework for Windows/Azure environments. The dual cloud/Windows local paths cover the two dominant enterprise deployment scenarios. This is the most concrete enterprise validation signal since the Microsoft Build keynote demo.

### Security — Four New CVEs Since June 1 (OpenCVE)

**Active CVE disclosure cycle continues.** OpenCVE shows four new vulnerabilities disclosed between June 1-2:

**CVE-2026-35674 (High8.8) — Gateway scope bypass:** OpenClaw before 2026.5.18 contains a scope bypass in the Gateway chat.send route allowing scoped clients to execute privileged commands. Attackers with operator.write scope can deliver commands through inherited external routes to bypass operator.approvals and operator.admin scope requirements, enabling unauthorized plugin, config, MCP, allowlist, and ACP mutations.

**CVE-2026-35630 (High 8) — QQBot authorization bypass:** OpenClaw before 2026.5.18 fails to enforce configured approver identity in QQBot native approval buttons. Non-approver users can click approval buttons to resolve pending exec or plugin approval requests without proper authorization.

**CVE-2026-32906 (Medium 4.3) — Slack plugin privilege escalation:** OpenClaw before 2026.5.12 allows exec-authorized users to resolve plugin approvals through the exec approver gate, bypassing intended approval splits.

**CVE-2026-35673 (Medium 6.5) — SSRF policy bypass:** OpenClaw before 2026.4.29 allows reuse of already-open blocked tabs to bypass private-network SSRF policies in browser debug and export routes.

**Note:** CVE-2026-41385 (mentioned in earlier reports) was not found in the current OpenCVE listing — its status may have been updated or it may be pending NVD publication.

## Community Pulse

**Working well:** The microsoft/openclaw-dev template is being well-received as a "finally, a cloud path that doesn't require managing API keys" solution. Enterprise operators appreciate MXC's policy-driven containment model for Windows. The operator install policy replacing the dangerous-code scanner is seen as the right architectural move — "finally treating plugin security like an operator concern, not a scanner concern."

**Focus areas:** Community is watching the rapid June release cadence (4 releases in 3 days) for stability signals. The CVE batch (CVE-2026-35674 in particular, rated 8.8) is prompting enterprise operators to prioritize upgrades to 2026.5.18 or later. The GitHub After Hours event (June 3) should generate community content in the coming days.

**Interesting:** Microsoft now has two official OpenClaw deployment paths (cloud sandbox + MXC for Windows) less than a week after Build 2026 — the speed of enterprise adoption is outpacing community documentation. OpenCVE shows 4 new CVEs in 48 hours, suggesting the security team is in active disclosure mode rather than batching.
