## New Findings

### Security — Six New CVEs Since June 12: Critical Node Pairing Bypass, PowerShell Allowlist Break, Hook Privilege Escalation

**A significant batch of new OpenClaw CVEs was published June 12-13, including several high-severity items.** OpenCVE shows the following since yesterday's report:

**CVE-2026-53838 (June 12, CVSS 6.0 Medium):** State mutation in node pairing reconnection allows paired nodes to confuse approval scope decisions. Attackers can exploit reconnection logic to restore or present broader node authority than intended, potentially bypassing approval restrictions. Affects OpenClaw before 2026.5.27. Note: initial search snippets showed this as Critical 9.8 — the OpenCVE listing shows 6.0 Medium at time of writing; NVD may have a different score.

**CVE-2026-53836 (June 12, CVSS 8.8 High):** Allowlist bypass in PowerShell encoded-command handling. Attackers can execute encoded commands using abbreviated flag aliases not recognized by the allowlist parser. Remote authenticated operators can bypass execution allowlist checks using unrecognized alias forms to execute arbitrary PowerShell content. Affects OpenClaw before 2026.5.12.

**CVE-2026-53814 (June 13, CVSS 8.7 High):** Privilege escalation via hook-triggered agent runs that incorrectly receive owner-scoped MCP loopback authority instead of hook-appropriate scope. Attackers with a valid hook token can exploit the /hooks/agent endpoint to access or invoke owner-only MCP tools, potentially executing privileged actions like persistent cron state modifications. Affects OpenClaw before 2026.5.20.

**CVE-2026-53809 (June 13, CVSS 3.8 Low):** Policy bypass in embedded runner policy where requests using provider aliases compare against aliases instead of canonical provider identities. Attackers can exploit this to select bundled tool access outside intended provider policy restrictions. Affects OpenClaw before 2026.4.25.

**Additional June 12 CVEs:** CVE-2026-53839 (Medium 6.5, hostname validation), CVE-2026-53837 (Low 3.7, Mattermost improper access control), CVE-2026-53835 (Medium 4.3, Feishu config-write bypass), CVE-2026-53834 (High 7.5, QQBot authorization bypass).

**Combined count:** At least 8 new CVEs in a 24-48 hour window. The disclosure rate continues at an aggressive pace. Enterprise operators should monitor OpenCVE daily.

### Community — Reddit Discussion: $0 OpenClaw Setup Using Local Models

**A Reddit post on r/AskClaw highlighted the cost benefits of local model deployments.** Key points from the discussion: OpenClaw runs a health check every 30-60 minutes; on cloud models like Claude Opus, every heartbeat costs tokens — estimated at roughly $30-50/month just in idle heartbeats. On local models, heartbeats are free. Sub-agents inherit the primary model, compounding costs for multi-agent setups. The $0 setup uses a local model (likely Ollama or similar) as the primary, eliminating per-token heartbeat costs entirely.

**Community reaction:** The post resonated widely, with many users sharing their own local model configurations. The discussion reflects growing community interest in self-hosted, cost-efficient OpenClaw deployments as token costs accumulate at scale.

**Source:** https://www.reddit.com/r/AskClaw/comments/1s55ubm/the_0_openclaw_setup_that_nobody_talks_about/
