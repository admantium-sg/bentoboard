## Key Findings (May 6, 2026)

### Platform Releases

**v2026.5.4 Stable (May 5-6, 2026):**
- **Google Meet/Twilio Realtime Voice Integration:** Twilio dial-in joins now speak through Gemini realtime voice bridge with paced audio streaming, backpressure-aware buffering, barge-in queue clearing, and no TwiML fallback during realtime speech
- **Paced Audio Streaming:** 120-150 words per minute matching human conversational cadence; token-aware buffer releases audio at punctuation/semantic boundaries
- **Backpressure-Aware Buffering:** Prevents "robot voice" distortion by throttling LLM generation when WebSocket buffer exceeds 500ms; resumes when buffer drains below 200ms
- **Barge-In Queue Clearing:** VAD (voice activity detection) at 0.7 confidence threshold flushes pending audio on interruption
- **Secure File Transfer:** Binary policies and workspace-scoped plugin metadata make file operations auditable and fast
- **Performance:** Plugin scan times reduced by 90%; diagnostics moving to separate plugins

**v2026.5.5-beta.1 (May 5, 2026):**
- Richer streaming progress across chat channels; UI refinements; continued plugin externalization

**v2026.5.4-beta Series Highlights:**
- Windows IPv6 loopback binding fix (prevents localhost HTTP requests from wedging)
- Plugin install hints pointing operators to correct install commands
- Pi 0.73.0, ACPX adapters, OpenAI, Anthropic, Slack, TypeScript preview updates
- Agent/workspace performance optimizations
- Control UI improvements (agent-first session picker, collapsible cron job form)
