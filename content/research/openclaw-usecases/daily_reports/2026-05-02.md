## Key Findings (May 2, 2026)

### Platform Stability Issues

**v2026.4.26 Gateway Crashes and Discord Issues (April 29, 2026):**
- After updating to v2026.4.26, users reported gateway crashes and Discord integration issues
- PiunikaWeb documented user reports of problems with Discord and other communication platforms
- Issue appears to have been addressed in subsequent releases (v2026.4.27, v2026.4.28, v2026.4.29)
- Operators on v2026.4.26 should consider upgrading to latest stable

**v2026.4.29 Operational Hardening (May 1, 2026 - Clawly Analysis):**
- **Global visible-reply enforcement:** New `messages.visibleReplies` control requires explicit sends in group chats, prevents accidental auto-posting
- **Least-privilege tool profiles:** Configured tool sections (tools.exec, tools.fs) no longer implicitly widen restrictive profiles
- **20-minute hardening playbook:** Clawly published step-by-step guide for operators to audit configurations
- **Practical impact:** Better security defaults for teams running agents in shared channels (Telegram, Discord, Slack)

### Security Landscape

**Third-Party Security Guides Proliferating:**
- Multiple sites publishing comprehensive security guides: openclawpulse.com, blog.shiptasks.com, tswira.com
- Coverage includes CVE-2026-41394 (new CVE assignment from NVD)
- "Complete 2026 security guide: all CVEs, RCE exploits, token exfiltration risks, and production hardening steps"
- Community response to security spiral: detailed hardening documentation emerging from third parties

**Enterprise Identity Governance (lyzr.ai):**
- "This isn't a flaw unique to OpenClaw; it's a signal that enterprise identity and governance models weren't designed for autonomous actors"
- Recommendation: Clearer boundaries around access, behavior, and accountability before agents move into production
- Positioned as industry-wide challenge, not OpenClaw-specific
