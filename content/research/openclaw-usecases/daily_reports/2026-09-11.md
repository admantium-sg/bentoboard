# DIAC - OpenClaw Use Cases - 2026-09-11

## New Findings

### Platform — OpenClaw v2026.9.4 Ships Sep 11: Plugin Discovery, Skill Learning, Cloud Snapshots, GPT Image 2.5 (Sep 11)

OpenClaw v2026.9.4 landed September 11 as the fourth release in the v2026.9.x stabilization cycle. Release scale: 1,558 pull requests, 20 direct commits, 293 contributors. Key additions: unified Plugins workspace with bundled and ClawHub plugin discovery and one-click install from Control UI; visible skill learning from past work in a normal steerable chat session; prepared cloud sessions with reusable snapshots from Control UI before starting a conversation; GPT Image 2.5 Flare and Sunburst variants via OpenAI or fal without changing existing defaults; terminal question prompts with keyboard navigation and free-text answers; OpenAI SDK credential prompt migration path entering deprecation (removes string argument to buildCredentialSafetyPrompt, must pass { controlToolsAvailable } by November 30, 2026); externally managed configuration via OPENCLAW_CONFIG_READONLY=1 for deployment-managed environments; and more dependable conversation history with recovery of final replies after interrupted streams. Community: "Plugin discovery, skill learning, and cloud snapshots — 9.4 turns the lobster into a proper platform you can build on, not just a box you talk to."

### Platform — ClawStat Issues First Verdict on v2026.9.4: "Safe to Update" (Medium Confidence) — Best Version Remains 9.1 (Sep 11)

Independent release tracker ClawStat.us issued its first verdict on v2026.9.4 today: "Safe to update (medium confidence)." Evidence cited: no credible confirmed blocking issue for this version. However, the tracker immediately notes the release is "too new to call settled" — bug reports keep arriving in the days after release and more problems may surface. Watch-outs flagged: MCP cron runtime leaks (#144527, high) where every isolated cron run leaks a session MCP runtime until the live runtime limit of 256 is reached, and isolated update-failure reports. ClawStat's best version to run today remains v2026.9.1: 8 days in the field, 11 credible known issues, none widespread. Community: "ClawStat reads the tea leaves so you don't have to — 9.4 gets a provisional green light with a fine-print note that 'too new to call' means watch for the next 48 hours before committing."

## Community Pulse

**Working well:** v2026.9.4's unified plugin discovery and skill learning features are being received as the most significant platform-building additions in the 9.x cycle — turning OpenClaw from a chat interface into something you can extend and build on. The OPENCLAW_CONFIG_READONLY flag for enterprise deployments is addressing a long-standing DevOps friction point.

**Problems:** MCP cron runtime leaks (#144527) in 9.4 are the most immediate concern — every isolated cron run leaks a session MCP runtime until the 256 limit is hit, and mcp.sessionIdleTtlMs doesn't evict them. The "too new to call" verdict on 9.4 means operators who are risk-averse still have a的理由 to hold on 9.1.

**Interesting:** With 9.4 landing just 3 days after 9.3 (itself only 2 days after 9.2), the September release train has delivered four versions in eight days — and ClawStat is now issuing verdicts fast enough to track the cadence. The SDK credential prompt deprecation path (November 30, 2026 deadline) will require plugin authors to audit their code before the holiday season.

## Trend

v2026.9.4 pivots the September release train from reliability fixes toward extensibility — unified plugin discovery, skill learning, and cloud snapshot controls position OpenClaw as a platform rather than a tool, while ClawStat's provisional "safe to update" verdict acknowledges the feature richness without pretending the regression risks have vanished.
