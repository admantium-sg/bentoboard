## New Findings

### Platform — OpenClaw v2026.7.1-beta.2 Ships ClawRouter, Control UI Overhaul, Ollama Auto-Discovery (July 5)

OpenClaw released v2026.7.1-beta.2 on July 5, building on the beta.1 framework with new infrastructure capabilities. The headline additions: ClawRouter becomes a bundled provider plugin offering credential-scoped dynamic model discovery across multiple upstream providers through one policy-scoped key, with managed budget reporting across all OpenClaw usage surfaces. Mac local Gateway setup — the macOS app can now install and start the Gateway automatically, eliminating manual setup steps. Control UI gets a full navigation overhaul: session-first sidebar, compact context meter, warm light theme, reasoning-effort slider, streamlined composer, and slash-command picker. Ollama auto-discovery — OpenClaw now auto-discovers local inference nodes running Ollama on the network. Telegram gains multi-lane progress summaries; Signal adds target aliases. The release carries an extensive fixes matrix spanning Telegram durability, agent context reliability, provider safety bounds, Windows execution, and mobile UI stability — reflecting heavy post-launch stabilization.
