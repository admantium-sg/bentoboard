# Daily Report — 2026-05-30

## Platform Releases — v2026.5.28-beta.1 (May 29 late)

**Rapid May release cadence continues into day 5 of consecutive releases.** The v2026.5.28-beta.1 tagged May 29 at 22:48 UTC delivers substantial additions across providers, enterprise features, and quality assurance hardening.

**New provider and model coverage:**
- Claude Opus 4.8 officially supported
- NVIDIA featured models added to catalog
- MiniMax streaming music responses wired
- Voice model catalogs expanded
- GitHub Copilot agent runtime support added
- Codex Supervisor plugin path for delegated Codex workflows

**Quality assurance overhaul:** Release, QA, and E2E validation now bound more log, artifact, harness, and cross-OS waits — "failing lanes produce proof instead of hanging or false-greening." Community developers note this should reduce the rare cases where CI silently passes despite test failures.

**Encrypted PDF extraction:** ClawPDF now handles encrypted PDF extraction, extending the PDF processing capabilities added in the previous release.

**Status improvements:** Active subagent details now shown in status output — helpful for monitoring multi-agent deployments.

## Security — No New CVEs, Claw Chain Mitigation Ongoing

**No new CVEs published today.** The Claw Chain cluster (CVE-2026-44112 through CVE-2026-44118) remains the primary security concern, all patched in v2026.4.22+ (April 23) and v2026.5.27 stable (May 28). CVE-2026-45006 patched May 11.

**Enterprise context:** Cyera research confirming ~245,000 publicly accessible OpenClaw instances (65K on Shodan, 180K on ZoomEye) underscores the importance of patching for organizations with internet-facing deployments. Financial services, healthcare, and legal sectors face highest risk given PII/PHI/credential processing patterns.

OpenClaw appears to be in a stability-focused phase — continued security hardening without major new capabilities, matching the pattern observed in yesterday's report.
