## New Findings

### Platform Releases — v2026.6.5-beta.6: SQLite Migration Deferred, Stricter Loops

**June 9 beta release adds new quality improvements while deferring one risky change.** Key additions since the June 7 stable:

**Session-metadata SQLite migration deferred:** The session-metadata → SQLite migration was pulled from this beta train to allow more time to address migration risk on main. Existing JSON-backed session metadata path is preserved for this release. This is a cautious call — operators on the beta track won't get the migration this cycle.

**Stricter agent/tool/provider loops:** Agent, tool, and provider loops now enforce tighter validation around MCP lease timestamps, prompt-cache tool names, local tool catalogs, unreadable dynamic tools, owner-only HTTP tools, and provider catalog metadata. This reduces hidden retries and unsafe exposure — a meaningful hardening for production.

**ClawHub skill install API improved:** ClawHub skills backed by GitHub repositories are now installed through the resolved install API, downloading the pinned GitHub commit, keeping install-policy checks, and reporting install telemetry after success. Large skill trees also benefit from a fix that avoids spawning one filesystem watcher per skill file during refresh.

**Google Chat native approval cards:** Google Chat approvals now use platform-native approval card actions and click handling instead of generic message flow — cleaner UX for enterprise Google Chat deployments.

**Memory QMD rerank toggle:** Memory search now has a rerank toggle for QMD, and the memory adapter status uses the resolved default model identity when checking plain status.

## Community Pulse

**Working well:** The session-metadata SQLite migration deferral is being received positively — the community notes that a cautious release is better than a migration that corrupts production state. The ClawHub GitHub-based skill install flow is also well-received as it gives more transparency about what commit is being installed. Parallel web search bundling continues to generate positive sentiment.

**Focus areas:** Operators are watching the MCP lease timestamp loop hardening — it closes a subtle vector where long-running MCP sessions could have their leases silently extended. The Google Chat native approval cards are being adopted by enterprise Google Chat users.

**Interesting:** The star count uptick to ~1.1K/2 days after the post-Build plateau is notable. If sustained, it suggests the Microsoft Build2026 exposure is still converting to GitHub stars with a lag rather than all at once during the event.
