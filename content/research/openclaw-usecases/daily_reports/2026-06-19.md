## New Findings (3)

### 1. ClawJacked — Full Technical Disclosure: Any Website Can Hijack OpenClaw Agent

Oasis Security published the complete technical breakdown of the "ClawJacked" vulnerability (June 19), filling in details first flagged in yesterday's report. The attack chain is stark: any malicious webpage can silently open a WebSocket to the OpenClaw gateway on localhost, brute-force the gateway password at hundreds of attempts per second (the rate limiter exempts loopback connections entirely), then auto-approve a device pairing (localhost pairings bypass the normal user-confirmation step) — giving the attacker full admin-level access to the agent. From that foothold, attackers can send messages to the agent, dump gateway configuration (exposing providers, models, and channels), enumerate all paired devices, and read application logs. The practical impact: an attacker could instruct the agent to search Slack for API keys, read private messages, exfiltrate files from connected devices, or execute arbitrary shell commands on any paired node. Oasis classified it as High severity and reports the fix was shipped in version 2026.2.25 — a notably older version than current stable (2026.6.8), indicating the patch predates the current release train and may have been applied as a hotfix. The Claw Report's June 19 edition leads with "multiple independent reports flag severe OpenClaw security flaws — including command injection and policy-bypass vectors" and urges teams to update immediately, audit installed skills, and rotate any potentially exposed secrets.

**Source:** https://www.oasis.security/blog/openclaw-vulnerability | https://www.theclawreport.com/

### 2. Coordinated CVE Window Much Larger Than Reported — ~25 CVEs June 17-18

OpenCVE data reviewed today reveals the June 17-18 disclosure window was substantially larger than the 9 CVEs highlighted in yesterday's report. Approximately 25 CVEs were updated on OpenCVE during this window, spanning CVE-2026-53841 through CVE-2026-53866. Newly surfaced entries include:

- CVE-2026-53846 (CVSS 7.1): Path traversal in install helper — workspace .env files can override npm_execpath, enabling unintended local package-manager execution during dependency setup.
- CVE-2026-53858 (CVSS 7.1): Environment variable injection — workspace STATE_DIRECTORY can influence runtime dependency root loading, enabling arbitrary code execution during dependency resolution.
- CVE-2026-53843 (CVSS 8.8): Authorization bypass — surviving pairing-scoped device session can re-establish node token authority after revocation, weakening revocation controls.
- CVE-2026-53866 (CVSS 8.1): Shell inline-command parsing allowlist bypass — authenticated operators can execute unapproved commands through a parser path missing expected allowlist decisions.
- CVE-2026-53861 (CVSS 6.6): macOS Swift exec allowlist bypass — combined POSIX inline-command flag forms bypass intended allowlist checks.
- CVE-2026-53855 (CVSS 8.1): Inline-eval bypass via shell positional parameters — authenticated operators can place inline-eval content in shell carriers outside allowlist rules.
- CVE-2026-53849 (CVSS 8.1): Discord allowFrom privilege escalation — mutable display names exploited instead of immutable user IDs to gain unauthorized agent access.
- CVE-2026-53842 (CVSS 7.1): Environment variable injection via CLOUDSDK_PYTHON — workspace .env can manipulate Python runtime selection during Gmail/gcloud setup.
- CVE-2026-53841 (CVSS 6.1): XSS in exported session HTML — exported files preserve unsafe javascript: and data: links.

This revised scope underscores that the June 16-18 security period was the most prolific CVE window in OpenClaw's history, far exceeding the January viral period in volume.

## Trend Analysis

Security is not easing — it is intensifying. The ClawJacked full disclosure makes concrete what was previously a vague warning: the gateway password can be brute-forced from any webpage at high speed because localhost is rate-limit exempt. This is a fundamental architectural flaw, not a configuration mistake, and the fix (2026.2.25 hotfix) predates the current stable by several major versions — raising the question of how many operators are actually running the patched version. The expanded CVE scope (~25 vs 9 reported) suggests yesterday's report undercounted by a significant margin. The pattern is clear: as OpenClaw's attack surface is studied more broadly, more severe vulnerabilities keep appearing. For enterprise operators, the advice is now stark: assume compromise, rotate secrets, audit skills, and watch for a stable release that bundles all recent patches.
