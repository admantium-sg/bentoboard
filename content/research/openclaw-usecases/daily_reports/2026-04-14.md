### 1. OpenClaw v2026.4.12 Stable Release (April 13, 2026)

**Major Release:** OpenClaw v2026.4.12 published on April 13, 2026 at 12:35:53 UTC as a broad quality release focusing on plugin loading, memory/dreaming reliability, local-model options, and Feishu setup improvements.

**Key Features (Stable Version of v2026.4.12-beta.1):**
- **Active Memory Plugin:** Dedicated memory sub-agent that automatically pulls relevant context before main reply (no manual "remember this" commands needed)
- **Bundled LM Studio Provider:** Runtime model discovery, stream preload support, memory-search embeddings for local/self-hosted OpenAI-compatible models
- **Local MLX Speech Provider:** Experimental local speech processing for Talk Mode on macOS with explicit provider selection
- **CLI exec-policy command:** New command with `show`, `preset`, and `set` subcommands for synchronizing exec approvals
- **Gateway commands.list RPC:** Command discovery for remote gateway clients with surface-aware naming
- **Plugin loading hardening:** Narrow activation to manifest-declared needs, preserving explicit scope and trust boundaries
- **QA/Testing improvements:** Convex-backed pooled Telegram credential leasing, multipass lane for Linux VM testing

**Security Fixes:**
- Remove busybox/toybox from interpreter-like safe bins
- Prevent empty approver list from granting explicit approval authorization
- Broaden shell-wrapper detection and block env-argv assignment injection
- Gateway auth: Blank example credential and fail startup with placeholder tokens

**Memory/Dreaming Reliability:**
- Default QMD recall to search mode for better out-of-box behavior
- Consume managed heartbeat events exactly once (prevent double-counting)
- Stage light-sleep confidence from all recorded short-term signals
- Stop dreaming from re-ingesting its own narrative transcripts
- Preserve Unicode letters/digits in wiki slugs and contradiction clustering
- Allow nested daily notes under `memory/**/YYYY-MM-DD.md`

**Cross-Platform Improvements:**
- Matrix: MSC4357 live markers for typewriter animation during preview sends
- WhatsApp: Fall back to first `mediaUrls` entry when `mediaUrl` is empty
- Telegram: Route approval button callback queries on separate sequentializer lane
- iMessage: Retry transient `watch.subscribe` startup failures before tearing down monitor

**Significance:** This is the stable release of v2026.4.12-beta.1, bringing all beta improvements to production readiness. Most features were already documented in the April 13 check, but this represents the production-ready milestone.
