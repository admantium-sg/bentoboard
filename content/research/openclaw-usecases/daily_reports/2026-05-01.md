## Key Findings (May 1, 2026)

### Platform Releases

**OpenClaw v2026.4.29 (April 30, 2026):**
- **Active-run steering** with visible-reply enforcement and spawned subagent routing metadata
- **Opt-in follow-up commitments** for heartbeat-delivered reminders (commitments.enabled config)
- **Memory/wiki people features:** Provenance views, person cards, relationship graphs, privacy/provenance reports
- **Per-conversation Active Memory filters:** Optional allowedChatIds/deniedChatIds filters for conversation-scoped recall
- **Partial recall on timeout:** Bounded partial recall summaries when memory sub-agent times out
- **NVIDIA provider addition:** API-key onboarding, setup docs, static catalog metadata
- **Security/tools fix:** Configured tool sections no longer implicitly widen restrictive profiles
- **SQLite-backed plugin state store:** Restart-safe keyed registries with TTL and eviction
- **20+ contributors** across messaging, memory, provider, and channel fixes

### Security Developments

**ClawJacked Browser Hijack Technique (April 27, 2026):**
- Security researchers disclosed browser-driven takeover technique
- Coerces agents into attacker-controlled actions via embedded web content
- Can leak local data through malicious web content
- OpenClaw published security advisories and shipped updates
- Users advised to patch immediately, rotate keys, lock down browsing/extension permissions

**Additional CVEs Disclosed (CVE-2026-35650 series):**
- Policy bypass vulnerabilities allowing prompt-injected outputs to bypass sandbox policies
- Bundled tools could be smuggled past policy filters
- API traffic could be redirected to attacker-controlled hosts
- Impact: npm package versions before 2026.4.20 affected

**TechRadar Coverage (April 24, 2026):**
- "Shadow AI and agents like OpenClaw are hijacking corporate data too easily"
- Cisco research cited: malware-like community skills and weak default hardening in viral agent stacks
- New exfiltration and supply-chain risks highlighted
