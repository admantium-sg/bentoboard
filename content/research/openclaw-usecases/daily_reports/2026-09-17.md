## New Findings

### Platform — ClawStat Escalates v2026.9.4 to 30 Blockers: "Skip" Verdict Holds (Sep 16-17)
Independent tracker ClawStat.us updated its v2026.9.4 verdict on September 16, maintaining "Skip" but escalating from 27 to 30 credible blocking issues. The core defect remains unchanged: v2026.9.4 shipped without PR #144208 (merged after branch cut), so any host carrying a legacy version-1 managed-update handoff lease row fails every config write on 9.4. Newly surfaced in the expanded tracker: issue #149538 — a Gateway that reaches ready but never serves because every /health probe times out while the event loop is starved, documented on a 632-agent fleet. The verdict holds because there is NO pre-release ahead of stable — the fix lives only on the development branch. ClawStat's best version to run: v2026.9.1, 13 days in the field, 11 credible known issues, none widespread. Zero community engagement (0 👍) across 60+ tracked issues against ~3.16M weekly npm downloads — the blockers are upgrade-path-specific and fresh installs remain unaffected.

### Platform — OpenClaw Gate Rests for Fourth Consecutive Day (Sep 17)
September 17 marks the fourth straight day without a new OpenClaw release. The platform remains on v2026.9.4 (September 11). Community frustration on upgrade-path failures is contrasted with appreciation for the release cadence discipline — no new release has been shipped while 30 blocking issues are tracked, suggesting the team is focused on stabilization rather than adding features to an already-troubled release. The absence of a v2026.9.5 or hotfix is notable given the severity of the upgrade-path cluster.

### Security — Anthropic Confirms In-Flight Credential Theft via Infostealers; Logs Out Users, Wipes Cards, Issues Refunds (Sep 17)
Anthropic confirmed that infostealer malware (Vidar, LummaC2, StealC, RedLine, Acreed on Windows; AMOS on Mac) is siphoning live Claude login sessions and burning usage quotas. The attack vector is local infection (pirated downloads, malicious apps) rather than a Claude-side flaw. The symptom: usage limits appear refilled, then are drained, while the user never opened Claude. Anthropic is responding by logging users out, wiping stored payment cards, and issuing refunds. The incident is relevant to OpenClaw operators: the same infostealer landscape that targets Claude sessions targets OpenClaw credentials and agent sessions — particularly for operators with cached API keys or long-lived token states on compromised machines.

### Security — LiteLLM CVE-2026-59822 (CVSS 8.8) Federal Remediation Deadline Hit September 16 (Sep 16)
LiteLLM CVE-2026-59822 — a critical flaw in pre-1.84.0 MCP Streamable HTTP endpoints allowing a fake Bearer token bypass — hit its federal remediation deadline on September 16 (CISA KEV listed September 2). OpenClaw's MCP integration is directly affected if operators run an older LiteLLM version behind the gateway. Operators using LiteLLM as an MCP bridge should verify their deployment is on 1.84.0 or later.

## Community Pulse

**Working well:** The decision to hold off on shipping a new release while 30 blockers are tracked is read by the community as restraint and discipline — contrasted with earlier cycles where feature trains shipped while regressions were still being filed. The ecosystem's star-count momentum continues quietly in the background, and Hermes-Agent's near-React milestone is generating positive signal in community channels.

**Problems:** The upgrade-path cluster remains unresolved with no staged fix in any released artifact. The #149538 event-loop starvation issue on a 632-agent fleet is a new escalation — it suggests the upgrade-path problems can produce silent runtime failures that look like a healthy gateway while serving nothing. ClawStat's zero community engagement on 60+ tracked issues continues to be read two ways: either the issues are niche, or the community has given up engaging.

**Interesting:** The broader AI safety conversation (pacing frontier development, Amodei's essay, OpenAI's direct three-way talks with Anthropic and Google) is being watched by OpenClaw operators as a potential leading indicator — if major labs slow down frontier training, the pressure on agent platforms to ship faster on existing models could increase, shifting OpenClaw's release cadence calculus.
