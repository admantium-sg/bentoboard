# DIAC Daily Report — 2026-09-30

## Platform — v2026.9.7 Ships Sep 30: macOS Hotfix + Update Safety + OpenAI Agents API Plugin (Sep 30)
OpenClaw v2026.9.7 shipped September 30 as the critical macOS hotfix and update-safety release. Key highlights: (1) **Update safety** — backups now capture every state and agent database before migrations and restore on rollback, with consistent snapshots while Gateway keeps writing; (2) **9.5 upgrade path fixed** — managed updates no longer roll back with stack overflow, Windows updates complete after state migration, macOS app handoffs activate, npm updates recover; (3) **OpenAI Agents API plugin** — run agents on OpenAI-hosted or self-hosted environments with streamed replies, steering, live web search, OpenClaw tools, preserved tool history, persona and workspace context, and accurate token usage (#151176, #156092, et al.); (4) **Sign in with ChatGPT** — new authentication choice alongside Codex login and API keys (#160011, #160078, #160023); (5) **Gateway responsiveness** — busy chats no longer stall everyone else as transcript writes, cold history preparation, artifact reads, Control UI file reads, and database maintenance now run off the Gateway main thread (#147914); (6) **Chat performance** — long conversations scroll smoothly, streaming replies no longer stall, switching sessions shows fresh history sooner (#159294); (7) **Restart continuity** — in-flight worker turns survive Gateway restarts (#159565). Independent tracker ClawStat.us assessed v2026.9.7 as "Safe to update" (medium confidence): only 18 tracked issues vs 78-95 for prior releases, 0 of 18 closed as too new, with "no credible blocking issue confirmed for this version." Community: "When the update system finally backs up before breaking and the macOS gate opens again, the lobster's recovery manual writes itself."

## Ecosystem — DevDay Delivers: OpenAI Dots Always-On Agents Ship, Astra Withheld on Safety (Sep 29)
OpenAI's DevDay (September 29) delivered the "Dots" always-on agent platform — not the rumored "Aeon" codename. Key announcements: (1) **Dots agents** powered by Astra on OpenAI's own cloud computers, accessible from ChatGPT/Slack/Teams with texting coming soon, covering 4,000+ apps; (2) **GPT-6.1 Sol** launched alongside the new tier; (3) **GPT-6.1 Astra withheld** — the new flagship missed OpenAI's own internal safety bars and remains unreleased; safety chief Saachi Jain confirmed both development and shipping stay safe; (4) **1.2B weekly users** reached by ChatGPT; (5) new **$500/month Pro tier** launched. Notably absent: no Aeon branding. Community: "Rumored Aeon becomes shippable Dots — agents move from tomorrow to today; names go plural, bills go paid; the lobster's agents hold no meetings, they sign."

Working well: v2026.9.7's update safety hardening (backup before migrations, rollback restore) directly addresses the most consistent community pain point across September's turbulent release cycle. The ClawStat "Safe to update" verdict with only 18 tracked issues (vs 78-95 for prior releases) and no credible blockers is the clearest signal since v2026.9.1. Hermes-Agent's imminent React overtake represents the most competitive position any variant has ever held against GitHub's all-time leader.
