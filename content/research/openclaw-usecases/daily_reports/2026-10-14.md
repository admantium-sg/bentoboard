### Platform — v2026.10.3 Ships Oct 13: Update/Doctor Recovery Main Stage, ClawStat ⚠️ "Update With Care" on Single Upgrade-Boundary Regression (Oct 13)
OpenClaw v2026.10.3 landed October 13 as a maintenance consolidation — 79 pull requests, 8 direct commits, 97 contributors. The changelog groups work around update and maintenance recovery: blocked updates cleared of eligible leftover recovery work, interrupted 2026.9.8 updates now settleable by the updated CLI, FreeBSD package recovery via fixed updater helpers, Doctor can remove abandoned npm updater copies that block the next upgrade, and candidate checks no longer falsely reject updates when Doctor would update version or migration bookkeeping. Provider side: Meta Muse Wonder support, MiniMax M3.1 Flash Preview, and interrupted ChatGPT replies now continue from saved conversation state within existing retry limits. Messaging fixes keep channel tools working after the task that started or restarted a messaging account finishes, and recovery scanning avoids stealing messages with active senders. ### Security — Trail of Bits Audit Recap Published: 27 Advisories, 2 High/16 Medium/6 Low, All Actionable Issues Repaired in Stable (Sep 21, newly surfaced Oct 5)
OpenClaw published its Trail of Bits security engagement recap via Hacker News on October 5, covering an engagement through OpenAI's Patch the Planet initiative. Trail of Bits submitted 27 private repository advisories plus 3 standalone hardening PRs. Of 24 severity-rated reports: 0 Critical, 2 High, 16 Medium, 6 Low. Three additional defense-in-depth findings did not cross a documented trust boundary. Key theme: permission drift — requests could enter with limited access then trigger follow-on work that no longer carried the same limits. Other categories: checking one name but using another (legacy configuration aliases), checking something that changed before use (archive contents, file paths), and permissions checked at start but not when long-running work acted later. OpenClaw states every actionable issue is repaired and shipped in v2026.8.1 and v2026.7.33 LTS. Trail of Bits used Codex-assisted workflows to search and develop fixes before manual review — notable for the broader security industry. Community: "Permission drift was the lobster's deepest structural risk — the audit found it and the lobster fixed it."

**Problems:** ClawStat's ⚠️ on v2026.10.3 lands on one specific upgrade-boundary regression (#171373) where session SQLite migration hits 9 conflicting transcript events on older-version upgrades, with no fix PR staged.
