## New Findings (July 18)

### Security — Hugging Face Breached by Autonomous AI Agent: First Documented AI-vs-AI Cyberattack

Hugging Face disclosed an intrusion where a malicious dataset exploited two code-execution paths — a remote-code dataset loader and template injection in dataset config — on a processing worker. The attacker escalated to node access and moved laterally to harvest cloud and cluster credentials. The campaign was executed by an autonomous agent framework performing thousands of individual actions across a swarm of short-lived sandboxes, with self-migrating command-and-control staged on public services. This matches the "agentic attacker" scenario the industry has been forecasting. Hugging Face's own LLM-based anomaly detection flagged the compromise. Forensic analysis was run on GLM 5.2 (open-weight) after commercial frontier APIs (GPT, Claude) blocked attack-payload analysis due to safety guardrails. Community: "The irony: the same guardrails that protect users from harm also protect attackers from analysis. OpenClaw agents running locally with local models are immune to both problems — your security analysis never leaves your machine."

**Sources:** https://anomixer.github.io/openclaw-news/

### Security — CVE-2026-62219: Authorization Bypass in allowedAgentIds (July 17)

OpenClaw before 2026.5.26 contains an authorization bypass vulnerability in the allowedAgentIds feature (CVSS 7.1, High). Lower-trust callers or configured input paths could execute actions beyond their intended authorization. Listed on stack.watch and tracked in the CVE database as of July 17. Community: "Another auth bypass in the exec approval path — 2026.5.26 fixes it, update now if you're on an earlier version."

### Enterprise — Microsoft Project Perception Launches as Mythos 5 Rival

Microsoft released Project Perception, an AI security product using a combination of Anthropic, OpenAI, and Microsoft models to scan, identify, and provide fixes for enterprise vulnerabilities. Positioned as a lower-cost alternative to Anthropic's Mythos 5, its key advantage is distribution: no export restrictions, deployable in Europe where Mythos is unavailable to most buyers, and embedded in the Azure security stack already used by 90%+ of Fortune 500. The multi-model architecture keeps both AI labs as dependent partners. Community: "Microsoft's multi-model strategy is smarter than any single-model play — if one lab's model is restricted in your country, the next one works. OpenClaw's model-agnostic Harness has been doing this since day one."
