### 2. Karakeep Semantic Search - Vector Search for Bookmarks

**What's New:**
- **Technology:** Semantic/vector search sidecar for Karakeep bookmarks
- **Vector DB:** Qdrant for vector storage
- **Embeddings:** OpenAI API or Ollama (local)
- **Auto-Sync:** Watches Karakeep for new bookmarks and indexes automatically
- **REST API:** Simple query interface (GET /search)
- **OpenClaw Skill:** Ready-to-use skill included
- **Docker-Ready:** Single container with bundled Qdrant

**Capabilities:**
- Find bookmarks by meaning, not exact words ("that article about getting things done")
- Auto-sync every 5 minutes (configurable)
- Hybrid retrieval (semantic + keyword) planned
- "Find similar" bookmarks planned

**Significance:**
- Extends OpenClaw's semantic search capabilities to bookmark management
- Demonstrates pattern: add vector layer to existing tools
- Local-first option via Ollama

**Source:**
- GitHub: github.com/jamesbrooksco/karakeep-semantic-search
- Docker: ghcr.io/jamesbrooksco/karakeep-semantic-search:latest
