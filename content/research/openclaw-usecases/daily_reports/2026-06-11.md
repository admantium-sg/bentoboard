## New Findings

### Platform Releases — v2026.6.6-beta.1 + v2026.6.7-alpha.3: Major Security Hardening

**June 11 releases deliver the most significant security hardening in weeks.** Two releases dropped today:

**v2026.6.6-beta.1 (June 11):** Substantial security boundaries tightening across transcripts, sandbox binds, host environment inheritance, MCP stdio, Codex HTTP access, native search policy, elevated sender checks, deleted-agent ACP bypasses, loopback tools, Discord moderation, and Teams group actions. Exec approvals now fail closed on timeout. This is the most security-focused beta in recent memory — 15+ dedicated security PRs from @joshavant, @pgondhi987, @mmaps, @eleqtrizit, @shakkernerd, and @drobison00.

**Telegram delivery overhaul:** Account-scoped topics route correctly, streamed text survives tool calls, /compact works on generic ingress, callback handling uses concrete APIs, draft chunking shared, durable dispatch dedupe moved into SDK, unauthorized DM text stays out of cache and prompt context.

**iMessage recovery improvements:** Always-on inbound restart, durable echo markers, block streaming, idle approval discovery, hardened outbound transport, actionable inbound startup diagnostics.

**Control UI startup latency improved:** Cached model metadata, startup catalog wait removed, lazy slash-command loading, first-event tracing with slow-reply diagnostics.

**v2026.6.7-alpha.3 (June 11, 04:07 UTC):** Fresh alpha — 11 days since v2026.6.5 stable. Full changelog not yet summarized but follows the rapid June release cadence.

### Enterprise — Jensen Huang at GTC Taipei: "OpenClaw is the new Linux"

**Jensen Huang called OpenClaw "the new Linux" at GTC Taipei on June 1, 2026**, saying every company needs an OpenClaw strategy. This follows his Morgan Stanley TMT Conference statement in March where he noted OpenClaw had surpassed Linux in size and usage at record speed. NVIDIA is positioning NemoClaw as the enterprise deployment path for this "new Linux."

The irony: OpenClaw simultaneously has 454 documented CVEs, a ClawHub marketplace that was poisoned with 1,184 malicious skills, and a Gartner enterprise block advisory. NVIDIA is navigating this tension by positioning hardened enterprise tooling (NemoClaw) as the safe deployment path.

## Community Pulse

**Working well:** The massive security hardening in v2026.6.6-beta.1 is being well-received — operators note that 15+ security PRs in one release shows real urgency. The Control UI startup latency improvements are also appreciated as they've been a friction point.

**Focus areas:** The exec approvals now fail closed on timeout — operators need to verify their approval timeouts are correctly configured. The Telegram delivery overhaul should fix the topic routing issues some operators experienced.

**Interesting:** Jensen Huang's "new Linux" framing is resonating in enterprise conversations. The tension between his endorsement and the CVE count (454 documented) creates an interesting market dynamic — hardened enterprise forks like NemoClaw become more attractive precisely because of the security complexity.
