## Platform — ClawStat.us Escalates v2026.9.6 to SKIP: No-Rollback Database Migration (Sep 25)
Independent tracker ClawStat.us assessed v2026.9.6 as **"Skip"** (medium confidence, assessed Sep 25 04:41 UTC) with a severe new headline: the upgrade process itself migrates the state database (schema 15→18) and per-agent databases (→schema 23) **before verifying the new build can serve**. When the update fails, recovery rolls the npm package back but leaves the databases migrated — producing 'SqliteSchemaVersionError ... this build supports 15' — and the documented quick backup demonstrably does not include agent database files. This is a confirmed no-rollback migration with data-loss risk. The cluster spans Windows (workspace-state fsync EPERM, dirty gateway restarts), Android/Termux (legacy device-identity migration failure), Linux/Pi (candidate gateway canary timeout after ~5 minutes), and container gateways (plugin-doctor-post-session-state crash-loop). Fix velocity is slower: only 9/69 tracked issues closed (13%) versus ~18–33% for v2026.9.2–9.5. Best version to run: v2026.9.1. Community: "When the in-product backup demonstrably does not cover agent databases, the upgrade path has a data-loss trap the gate hasn't closed yet."
Source: https://clawstat.us/latest.json
