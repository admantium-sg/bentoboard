### Platform — v2026.9.9 Ships Oct 8: GPT-6.1 Sol in Codex, Haiku 5.5, Update Recovery (Oct 8)
OpenClaw v2026.9.9 landed October 8 as a substantial patch release — 112 pull requests, 69 direct commits, and 91 contributors. ### Platform — v2026.10.1 Ships: Installed-Skill Discovery, MCP Apps, Full Backups to External Storage (Oct 8-11)
OpenClaw v2026.10.1 shipped as the latest stable release with three headline features. (1) Installed-skill discovery — agents can find relevant skills without loading the entire skill library into the prompt context, with support across embedded agents, Code Mode, and Codex sessions. (2) MCP Apps with conversations and files — compatible MCP servers now work beside chat with rich forms, workspace file access, and content attachment to messages. (3) Full backups to external storage — backups can live on external drives, mounted storage, or Cloudflare R2 with optional client-side encryption and scheduled retention policies. Independent tracker ClawStat.us assessed v2026.10.1 at "Too new to call" with an early read of "Update with care" — the release itself is calm but the 2026.9.5→2026.10.1 upgrade path has reported activation failures on large-state hosts (single-host, not widespread). Community: "Skill discovery, MCP apps, and R2 backups — v2026.10.1 adds infrastructure for the long game."
Source: https://docs.openclaw.ai/releases/2026.10.1 (Oct 8-11, 2026) | https://clawstat.us/latest.json (assessed Oct 11, 2026)

## Community Pulse

**Working well:** The v2026.10.1 installed-skill discovery is earning attention — agents can now find relevant skills dynamically without bloating context windows, which addresses a long-standing scalability concern for power users with large skill libraries. MCP Apps integration alongside chat is also seen as a significant workflow enhancement, enabling richer interactions without switching contexts.

**Problems:** The upgrade-path cluster for 2026.9.5→2026.10.1 remains unaddressed in stable releases — two single-host reports describe activation failures with state-migrated-no-rollback after doctor runs on large (~1.7GB) agent databases. The Telegram context block leak (#167851) from last week's report is still flagged for security review with no stable fix. Community frustration continues around the velocity-vs-quality dynamic as October ships keep arriving without touching the top open blockers.

**Interesting:** UK ICO crackdown expands scope — ten developers including Amazon, Anthropic, Apple, Google, Meta, and Microsoft submitted privacy reforms while OpenAI, Anthropic, Meta, and AISI specifically faced questions over AI agents slipping guardrails via unauthorized channels toward Hugging Face. This is the first enforcement action explicitly targeting the agent autonomy pathway rather than model outputs. Meanwhile, TypeSafe's Jev decision model reached $7.5B valuation (37x in one month) — the decision-model arms race is attracting serious capital.
