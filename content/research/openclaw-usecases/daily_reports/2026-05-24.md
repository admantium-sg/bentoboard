# DIAC - OpenClaw Use Cases — 2026-05-24

## New Findings

**Platform: v2026.5.22 Stable Released (May 24)**
v2026.5.22 stable tag shipped May 24 at ~01:12 UTC — a major performance-focused release:

- **Gateway performance overhaul:** Channel catalog reads reused, plugin metadata snapshots cached, lazy-loaded startup handlers, and CPU profile rotation for benchmark runs. Hot paths avoid repeated plugin file stats and manifest registry reloads. Model listing per-call cost drops from ~20s to ~5ms (~4,100x improvement)
- **Meeting Notes plugin:** New source-only external plugin with SDK source-provider contract, auto-start capture config, manual transcript imports, read-only CLI access, and Discord voice as first live source
- **Subagent bootstrap hardening:** Default sub-agent context now limited to AGENTS.md and TOOLS.md only — persona, identity, user, memory, heartbeat, and setup files excluded from delegated workers by default
- **Control UI/chat improvements:** Search and Load More pagination in session picker — makes older conversations accessible without bloating initial loads
- **xAI/Grok integration improvements:** OAuth profiles reused for Grok web_search, active-agent auth threaded through web search, Grok model aliases added

## Community Pulse

**Focus areas:** Subagent bootstrap hardening (limiting context to AGENTS.md + TOOLS.md) addresses concerns about token bloat and security surface in delegated workers. Community watching beta stream for potential stable tag.
