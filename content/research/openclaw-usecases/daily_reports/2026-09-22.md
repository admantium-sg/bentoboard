## New Findings

### Platform — v2026.7.35 Ships Sep 21: July LTS Finally Closed with Doctor Registry Fix (Sep 21)
OpenClaw v2026.7.35 shipped September 21 as the first proper GitHub release for the July 2026 extended-stable line — closing out a turbulent July LTS cycle. The headline fix: Doctor now preserves the complete bundled plugin inventory when creating or repairing registry state, keeping default Browser, Canvas, pairing, file-transfer, phone-control, Talk voice, and Bonjour plugins available after restart. State-migration discovery also recovers from the partial registry written by the unpublished v2026.7.34. This release also backports the full changelogs from 2026.7.33 and 2026.7.34 — both of which were audited but unstable and intentionally unpublished as GitHub releases. The release was selected from a complete 1,418-commit audit; no other defect during clean install or 2026.6.35 upgrade required a July-line backport. Credit to @wangmiao0668000666 for the fix. Community: "When the July LTS finally closes its books, the lobster's audit trail gets a line that reads 'no other defects observed' — and that's the stamp worth more than any version number."

### Platform — ClawStat.us Revises v2026.9.5 Down to "Update with Care" (Sep 21 Assessed)
Independent tracker ClawStat.us revised its v2026.9.5 verdict on Sep 21 from "Skip" to "Update with care" (medium confidence) — its two-model review concluding the verdict matches the deterministic evidence gate: six credible blockers, none widespread. The updated thesis confirms: Windows gateway-startup hangs on workspace plugins with multiple agents (#152981, ~17 min CPU-pegged stall then fail), Windows Slack integration causing ~187-second event-loop stall making Slack unusable (#155152), model-catalog regressions breaking MiniMax-portal resolution and in-session model switching (#152804, #153639 — the latter a P1 beta blocker), and mid-upgrade failures across platforms. Notably absent from the alarm: fix velocity is normal (24 of 86 tracked issues closed, consistent with prior releases), and 1 👍 across all 60 tracked issues against ~2.7M weekly downloads suggests these are not widespread breakers. Best version to run: v2026.9.1. Community: "The lobster's field surgeons keep closing issues faster than the new ones open — but the OR table is still occupied."
