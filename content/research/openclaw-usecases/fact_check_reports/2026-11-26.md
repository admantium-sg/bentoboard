**Issue:** Window error — the statement was true only for the ~2026-11-10T08:34Z snapshot.
**Correction:** Two versions were published **later on 2026-11-10**: `2026.11.3` at 2026-11-10T17:59:44.785Z and `2026.9.37` at 2026-11-10T20:16:24.913Z. ## Trend Analysis
- **Error pattern is consistent with the previous three runs:** every hard correction is a *derived* or *scope* value — a window boundary (C02), an undercount (C07), a novelty superlative (C08), a classification (C15) — while raw quoted values (timestamps, commit messages, issue titles, PR numbers, labels) were essentially error-free.
- **New failure mode found this run:** *entity-type drift*. Two of fifteen claims (C15 "issue" = a PR; C05 implicitly P0 = actually P1) mis-state the GitHub entity kind or label tier. Findings that count issues should always separate `is:issue` from PRs and re-read the label set instead of trusting the run's summary.
- **Snapshot-vs-live gap:** ClawStat has no history endpoint, so every ClawStat claim older than the current assessment can only be corroborated second-hand. The accumulator should keep a same-day raw capture of `clawstat.us/latest.json` (it does — `tmp/2026-11-*/clawstat.json`) and cite it explicitly, as C10–C12 required.
- **Security-drift risk is real and still open:** the bundled-undici gap is *not* fixed in any shipped OpenClaw release (2026.11.10 / `main` still carry npm 12.2.1 → undici 6.29.0), while the npm fix (12.2.3 / 11.21.2) exists. The findings text "No fixed stable OpenClaw release picks this up yet" remains accurate and is worth re-stating in future windows until the pin moves.
- **Source reliability:** official endpoints (npm registry incl. tarball inspection, GitHub API, GitHub Advisories, OSV, clawstat.us) were fully reliable — every one of the 15 claims was decidable from them alone. No web search was needed at all.
- **Pipeline recommendation:** the legacy backlog is now annotatable in the archive, so the queue can be drained oldest-first without restoring `.bak` files — but the ~69 claims from 2026-11-20 onward are worth promoting ahead of the remaining 45 legacy items, since they describe the current state of the project.
