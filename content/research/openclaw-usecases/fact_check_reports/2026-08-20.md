## Verified Claims

### ✅ Claim 1: CVE-2026-25253 "ClawBleed" Exists

**Claim:** CVE-2026-25253 "ClawBleed" enables one-click RCE via token exfiltration in OpenClaw's Control UI gatewayUrl parameter
**Status:** VERIFIED
**Details:**
- NVD confirms OpenClaw (aka clawdbot or Moltbot) before 2026.1.29 obtains a gatewayUrl value from a query string and automatically makes a WebSocket connection without prompting, sending a token value
- CWE-669: Incorrect Resource Transfer Between Spheres
- Securelic confirms token leak leading to one-click RCE

**Sources:**
- https://nvd.nist.gov/vuln/detail/CVE-2026-25253
- https://securelic.com/blog/openclaw-clawbleed-cve-2026-25253-the-token-leak-behind-the-one-click-rce-nightmare/f62ff2a5ee913b48d4d2b0a5333a86e6
- https://cvereports.com/reports/CVE-2026-25253

### ✅ Claim 2: Wiz Red Agent Autonomous Exploitation

**Claim:** Wiz published "Red Agent" on Aug 17 — an autonomously operating security agent that exploited a GitHub Actions flaw within 5 days
**Status:** VERIFIED
**Details:**
- Confirmed via multiple sources: Wiz blog, CybersecurityNews, ExplainX
- Red Agent found the flaw June 23, 2026 — 5 days after it went live
- First exploit attempt hit a bash syntax error, agent diagnosed and rewrote payload autonomously
- Reached Snowflake internal Jira (qa@snowflake.net)
- **Correction:** Copilot did NOT write the vulnerable code — a human authored it in PR #1218 on June 18, 2026. Wiz corrected this attribution themselves on August 17.

**Sources:**
- https://www.wiz.io/blog/red-agent-snowflake-copilot-cicd-bug
- https://cybersecuritynews.com/ai-agent-hacks-snowflake-github-workflow/
- https://www.explainx.ai/blog/wiz-red-agent-snowflake-github-actions-jira-exploit-august-2026
