## Recommendations for the Next Research Cycle

1. **ClawStat is not a stable archive.** It keeps one record per version, overwriting interim assessments. Any Oct 20/21 snapshot quoted in findings should be captured as a local artifact at read time (`tmp/clawstat.json`), not cited as a live URL.
2. **Gate release-date claims on the GitHub API.** Three of the ten corrections this session were date errors (beta.3, v2026.10.5, FTC probe). The API is authoritative and cheap.
3. **Timestamp every GitHub number.** Comparing an Oct 21 star count to an Oct 22 star count is how the "+300" became "+3,200".
4. **Use a lower bar for aggregator-sourced minutiae.** Claims like the Lit→Solid migration ledger and the Hermes OpenShell deadline are structurally unverifiable and should be published as "community-reported" rather than as facts.
5. **Re-attribution check on any "who found it first" claim.** Both attribution errors this session (PHP2Shell, the AEGIS threshold) were single-source amplifications.
