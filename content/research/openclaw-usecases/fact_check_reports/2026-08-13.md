## Corrections Made

### Correction 1: OpenClaw CVE-2026-26323 Description Refinement
**Original:** "Critical OpenClaw vulnerability Exposes Skills/Chain Integrations"
**Refinement:** The CVE affects the **maintainer development script** (`scripts/update-clawtributors.ts`), NOT the shipped CLI. End users running `npm i -g openclaw` are NOT affected. Only contributors/CI running the maintainer script against untrusted commits are at risk.
**Impact:** Severity claim somewhat overstated for end users; actual risk is to maintainers/CI
**Sources:**
- https://nvd.nist.gov/vuln/detail/CVE-2026-26323
- https://www.sentinelone.com/vulnerability-database/cve-2026-26323/
